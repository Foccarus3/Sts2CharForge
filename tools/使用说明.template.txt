Sts2CharForge —— 杀戮尖塔 2 自定义角色生成器（使用说明）
=====================================================

一、怎么打开
  双击「启动 Sts2CharForge.bat」即可（启动器跟着文件夹位置走，解压到哪都能用）。
  想放桌面快捷方式：右键「启动 Sts2CharForge.bat」→ 发送到 → 桌面快捷方式
  （图标可在属性里改成 程序文件\waku.ico）；包内也带一份同版本的 .lnk。
  注意：不要只把 exe 单独拷出来，程序要跟同目录的一堆 dll 在一起才能跑。

二、压缩包怎么放
  · 程序文件\              ← 程序本体（含 waku.ico、launcher_help.ps1）
  · 启动 Sts2CharForge.bat ← 启动器
  · Sts2CharForge_环境包\  ← Godot + 便携版 .NET SDK（程序会自动认出，不用装任何东西）
  · 自定义角色存档\        ← 你的存档与生成的角色工程（第一次保存时自动建）
  · ！首次使用先点这个！\  ← GDRE 解包工具与图文教程（解包自己的游戏本体要用）

  包有三种，按需选：
    整合包 = 程序 + 环境包 + GDRE 工具 + 教程（第一次用选它，约 371 MB）
    更新包 = 只有 程序文件\ + 启动器（已经有旧版时选它，约 60 MB，解压覆盖即可）
    程序包 = 程序 + 使用说明（不带环境包）

  存档与生成的角色工程放在根目录「自定义角色存档」里，**跟程序文件分开**：
  以后覆盖更新程序（只换「程序文件」）不会碰到你的存档。

三、第一次打开要做的事
  1. 启动会先弹「配置存档」窗口，点「新建配置」即可（没有存档时是正常的）。
  2. 到「构建 / 日志」页，把「解包后的原版工程目录」选一下 —— 这是唯一需要你指定的东西
     （做法见下一节）。选好之后程序会记住，其余路径全部自动探测。
  3. 「构建 / 日志」页顶上那行绿字会显示环境状态（Godot ✅ .NET ✅ 游戏目录 ✅）；
     想看细节去「环境自检」页，绿色 ✅ 就是齐了。
  关窗口时会问一句「要不要保存」：有改动才会问，选「取消」就回到编辑界面继续改。

四、还需要你自己准备的（包给不了）
  1. 《杀戮尖塔 2》本体（Steam 正版）—— 提供编译用的 sts2.dll / 0Harmony.dll。
  2. 游戏「解包后的原版工程」—— 生成模组时的占位美术、场景模板、spine 插件都从这里取。
     做法见「！首次使用先点这个！\」里的教程，用 GDRE Tools 解包自己的游戏本体
     （涉及你自己的游戏文件，不能随包分发）。
     把解包目录填到「构建 / 日志」页的解包工程那一行即可；没填就点生成的话，
     程序会先自动找一遍，找不到会弹框让你选。

五、常见问题

  ── 存档与保存 ──
  · 存档会不会被工具弄丢？
      → 每次保存之前都会把【旧内容】自动备份一份：
        ① 存档目录里同名的 <你的存档>.json.bak；
        ② 存档目录下「_备份」文件夹里带时间戳的那份（最多留 30 份，旧的自动清）。
      → 万一连备份也没有了（存档目录被整个删掉）：到「配置存档」页点「从工程恢复存档…」，
        选一个以前生成出来的模组工程目录（里面有 cs 文件夹的那个），工具会从源码反推出一份存档 ——
        卡牌（含费用 / 稀有度 / 关键字 / 每条效果的数值与升级增量 / 条件 / 自定义描述）、诅咒、先古卡、
        遗物、药水、自定义状态、角色属性、本地化名字、上传过的图全部找回，另存为「工程名_恢复.json」。
        命令行也行：forge --recover "工程目录" --out "恢复.json"
      → 习惯建议：改完配置顺手点一下保存，别急着删旧的工程目录。
  · 「保存配置」会存到哪？会不会存成两份？
      → 直接保存进**当前打开的那份存档**，不弹路径选择。
        只有「模组 ID」和当前存档文件名不一样时问一次：
        「要把存档名称改成 <模组 ID>.json 吗？」
          答「是」= 文件真的改名过去（旧文件不留重复；旧内容照旧进「_备份」）；
          答「否」= 仍然保存进原文件，本次运行不再问（改了名字才会再问）。
      → 想存成另一个文件，用「配置存档」页的「另存为新存档…」（那个才让你选路径）。
      → 「用当前配置覆盖该存档」覆盖完，「当前存档」会切到你覆盖的那一份。
  · 两个存档会互相影响吗
      → 不会：生成的工程目录跟着**存档文件名**走（存档「七」→ 工程目录「七」），
        每次生成前先清掉该目录里上次生成的文件，不会残留旧代码。
      → 但两个存档如果**模组 ID 一样**，装进游戏会互相覆盖（dll / pck 名字一样）——
        左下角问题列表会提醒，把其中一个的模组 ID 改掉即可（「角色」页最上面）。

  ── 环境与构建 ──
  · 提示「效果库为空，增益/减益列表读不到」
      → 本机没找到游戏文件。看「环境自检」页哪一项标红。
  · 提示找不到 Godot / .NET SDK
      → 到「环境自检」页：没通过的那一项右边有「选择路径…」按钮，点一下当场选好（立即重新检测）。
        如果连按钮都没有，多半是环境包没解压到程序旁边：把环境包解压成程序文件夹的同级目录后重启，
        或在「环境自检」页点「重新检测」。
  · 编译时提示找不到包（NU1101 / 连不上 nuget.org）
      → 生成工程时会自动写一份 nuget.config，把 NuGet 源指向 Godot 自带的
        GodotSharp\Tools\nupkgs，正常情况离线也能编译。
  · 双击启动器没反应 / 一闪而过
      → 屏幕会说明原因并生成「启动失败日志.txt」，常见三种：① 在压缩包里直接双击的（要先全部解压）；
        ② 只解压了启动器没解压「程序文件」；③ 被安全中心 / 杀毒拦了。
  · 「安装目录」到底该选哪个文件夹？（装完游戏里看不到模组，多半是这里选错了）
      → 要选游戏目录下面的 **mods 文件夹**，例如
        D:\Steam\steamapps\common\Slay the Spire 2\mods
        （本体第一次装模组时会自己建这个目录；目录还不存在也可以先填，构建时会自动创建）。
      → 选错的典型症状：模组没出现、或 dll 被丢到游戏根目录里。
      → 点「浏览…」选中游戏根目录（或 data_sts2_xxx 目录）时，工具会自动改成它下面的 mods；
        启动时也会自动找一遍游戏目录并填好。
  · 点「生成」报错说「卡池里奖励能抽到的卡只有 N 张，至少要 3 张」
      → 本体发奖励时会「互不重复地抽 3 张」，所以「加入卡池」的卡至少要 3 张（且不能都是 Basic，
        Basic 不参与奖励）。按报错里的张数多勾几张即可；「卡牌」页的校验提示里也能提前看到。
  · 「一键构建」报「项目文件不存在（MSB1009）」
      → 构建用的是刚生成出来的那个工程目录，「打开输出目录」也是同一套规则；
        确认「输出目录」没被改成别的地方即可。存档名和模组 ID 不一样是正常的。

  ── 美术资源 ──
  · 上传图片后存在哪、什么时候生效？
      → 选完图片**立刻写进当前存档**（角色美术槽位、逐张卡面、遗物 / 药水 / 状态图标、
        额外资源量图标都一样），状态栏会显示「已写进存档：xxx.json」；清除图片与撤回也立刻落盘。
      → 上传文件按**原尺寸直接使用**（程序不缩放），尺寸按「美术资源」页每个槽位的提示准备。
        文字里内联的小图标会自动缩到本体规定的尺寸（能量 24×24 / 图集精灵 74×74 / 能量球 128×128），
        所以上传大图不会撑坏卡牌描述。
      → **预览会按「游戏里的显示区域」画一块黑底**（卡面是 1000×760，各槽位按本体原图尺寸）：
        上传图比例和它不一致时，游戏里会按比例缩放居中、多出来的那圈就是黑边 ——
        预览里那块黑底就是它，下面还会写清「图偏宽 → 上下留黑边 / 图偏窄 → 左右留黑边」和大概留多少。
        不想有黑边就把图裁成那个比例（或直接用推荐尺寸）。
      → 改完要重新「① 生成工程」+「② 一键构建 + 安装」，游戏里才会看到新图。
  · 勾了「未上传的槽位用本体（铁甲战士）素材占位」，游戏里是什么效果？
      → 四个角色场景直接借本体铁甲战士的场景（真骨骼动画）：
        · 战斗立绘 = 本体 scenes\creature_visuals\ironclad.tscn
        · 商店立绘 = 本体 scenes\merchant\characters\ironclad_merchant.tscn
        · 篝火立绘 = 本体 scenes\rest_site\characters\ironclad_rest_site.tscn
        · 选人背景 = 本体 scenes\screens\char_select\char_select_bg_ironclad.tscn
        · 其余未上传的槽位（头像、选人立绘、地图标记…）用本体的图。
        **发布模组前请取消勾选并提供自己的美术**；不勾则用工具自带的中性占位图。
      → 注意：`animations\characters\ironclad\*.png` 那几张是 Spine **图集页**，不是单张立绘，别当立绘传。
  · 「选人界面背景大图」要传多大？
      → **横图，建议 1920×1080 或更大**（和游戏画面同比例）。这张图整屏铺满、保持比例居中，
        传竖图会左右留黑边。留空则用「静态立绘」那张图当背景。
  · 状态 / 遗物图标显示成紫色「缺图」占位（日志里 Missing sprite 'xxx' in power_atlas / relic_atlas）
      → 本体取图标是按 Id.Entry 拼路径：先查图集精灵，查不到再回退到另一条路径 ——
        状态回退到 images\powers\<状态>.png，遗物回退到 images\relics\<遗物>.png。
        生成时两条路径的文件都会写；传了图标后重新生成 + 构建安装即可。

  ── 额外资源量（计数器 / 图标 / 名字）──
  · 「额外资源量」怎么用
      → 到「额外资源量/状态」页：设初始数量、是否跨战斗继承、是否始终显示计数器；
        还能上传一张自己的图标、填一个中文显示名，把血条下方那个资源计数器换掉
        （卡面费用图标会一起换，左侧能量球也会换成你上传的能量图标）。
      → 这个名字会用在**所有**文本里：计数器下方、鼠标悬停提示（标题 + 描述）、卡面描述
        （「获得 2 点冰附魔」）、条件说明（「拥有冰附魔至少 4 点」）、状态触发时机的说明
        （「花掉冰附魔后」）、那个隐藏起始遗物的名字与 flavor。没填就退回通用说法「额外资源量」。
      → 悬停提示的描述按你配的开场数量 / 是否继承 / 有没有消耗它的牌自动写：
        「冰附魔：每场战斗开始时获得 3 点（战斗结束清零）；打出需要消耗它的牌时会扣除，数量不足时无法打出。」
      → 卡牌上「获得 N 点额外资源量」支持**升级增量**：升级后卡面显示升级后的数字
        （用本体的 StarsVar + 卡面 {Stars:diff()} 占位符，升级后由本体自己算）。
      → 注意：计数器用的是本体「星星」这套资源机制，位置由本体决定。
  · 上传的图标 / 能量图标在游戏里怎么生效？
      → 资源计数器与卡面资源图标：按「贴图是不是本体那颗星星」识别并替换，只改你自己角色的战斗界面，
        别的角色不受影响；每帧兜底一次，别的模组把贴图改回去也会再贴回来。
      → 能量图标：上传后卡面费用图标（含文字内联小图标）用你的图，**左侧那个能量球也直接换成你的图**
        （缩到 128×128，本体另外 4 层球贴图隐藏，粒子光效按你的图着色）。
      → 日志里会写两行诊断：「额外资源量：计数器检查 → 图标已加载/没加载，角色=…，命中节点=N」、
        「额外资源量：左侧能量球用的是场景 = …」。看不到效果时把这两行发出来即可定位。
      → 改完要**重新生成并重新安装**（补丁在模组的 dll 里，只重新打包没用）。

  ── 卡牌与效果 ──
  · 「添加效果」新增的那条效果，**数值和升级增量都是 0**（免得加一条别的效果时被默认的 6/+3 带着走）；
    选好「效果种类」后自己把数字填上，填漏了生成前的检查会提示。
  · 「复制」一张卡 = **整张照抄**：自定义关键词、卡牌关键字（消耗 / 虚无 / 固有…）、标签、升级后关键字、
    每条效果的全部设置（数值、升级增量、召唤物 / 伙伴、概率生效、条件）都会跟着复制，只有名字加「·改」、
    英文类名留空（自动编号）—— 复制出来的牌和原卡完全一样，可以直接改数值做变体。
  · 效果可以加条件（每条效果各自一份：效果栏 → 选中一条效果 → 面板最下面）
      → 例如「本回合还没打出过这张牌」「手牌里只有攻击牌」「生命值低于 50%」「拥有某状态至少 N 层」
        「拥有额外资源量至少 N 点」「每场战斗只触发一次」等。
      → 「指向对象」：状态层数 / 生命值百分比这类条件要选看谁 —— 自己 / 指定敌人 / 任意一个敌人 /
        全部敌人（「全部敌人」= 每个活着敌人都得满足；「任意一个敌人」= 有一个满足即可；
        「指定敌人」= 这张牌打出去时玩家选中的那个目标）。
      → 「指定敌人」只能用在【这条效果的条件】里（那时玩家已经选好目标）。勾了
        「条件不满足时这张牌打不出去」就用不了它 —— 判断能不能打出时玩家还没选目标，校验会提示。
      → 卡牌：勾「条件不满足时这张牌打不出去」→ 条件进本体的 IsPlayable（卡面描金边）；
        不勾 = 能打出，但只有这一条效果不生效，其它效果照常执行。条件说明会写在这条效果的描述后面。
      → 遗物：「条件选项（整只遗物）」是整只遗物的触发条件（不满足时整个遗物不触发）；
        效果栏里每条效果还能有各自的条件。
      → 药水不支持条件；「每 N 回合触发一次」「每场战斗只触发一次」只有遗物能用。
  · 「消耗卡牌 / 变化卡牌」想从抽牌堆 / 弃牌堆选
      → 每条「消耗卡牌」「变化卡牌」下面有「从哪里选牌」下拉：手牌（本体默认）/ 抽牌堆 / 弃牌堆。
        手牌走本体 CardSelectCmd.FromHand；抽牌堆 / 弃牌堆走 CardSelectCmd.FromCombatPile
        （本体「充能 / 净化 / 降灵」选抽牌堆，「全息影像 / 头槌 / 挖掘 / 宇宙冷漠」选弃牌堆）；
        「随机」模式下就是从那一摞里随机抓，描述也会跟着写成「自己选从弃牌堆消耗 1 张牌。」
  · 想把一张牌从抽牌堆 / 弃牌堆「拿回手牌」
      → 效果种类里有「从抽牌堆拿牌到手牌（自己选）」「从弃牌堆拿牌到手牌（自己选）」：
        填要拿几张，打出后弹本体的选牌界面（本体「搜寻 / 全息影像 / 挖掘」的做法），
        界面提示语也会一起生成（<卡牌>.selectionScreenPrompt）。那一摞里没牌时什么都不做。
        这两种只能用在卡牌 / 遗物 / 药水上（状态触发器里弹不出这个界面，校验会拦住）。
  · 想让「获得格挡 / 回复生命 / 失去生命 / 获得最大生命」也作用在敌人身上
      → 能。这四种效果的作用对象可以选 自己 / 指定敌人 / 所有敌人 / 随机 N 个敌人，
        遗物和药水里也能选敌人（没有「这张牌打的目标」时自动取可打的第一个敌人）。
        卡面描述会自动写清给谁：「让所有敌人获得 6 点格挡。」「让指定敌人回复 5 点生命。」
      → 用途举例：造一张「给敌人加格挡」的牌当减伤 debuff、遗物每回合给全体敌人回血再配合
        「生命值低于 N%」条件，或者一张「先给敌人回血、再造成巨额伤害」的赌博牌。
      → 这类牌会自动变成需要选目标的牌（本体 AnyEnemy 目标模式），选不到目标时不报错、直接不生效。
  · X 费用卡牌怎么配（本体「旋风斩 / 天际钻头 / 挽歌 / 星尘」那种）
      → 卡牌属性里勾「X 费用（消耗全部能量）」；想按额外资源量算就勾「额外资源量费用为 X」；
        然后到每条效果的编辑器里勾「数值 = X」「生效次数 = X」「命中次数 = 对群数 = X」——
        例如「造成 8 点伤害 + 命中次数 = X」= 天际钻头，「格挡 + 生效次数 = X」= 挽歌。
        想升级 +1 就勾「升级后 X +1」（本体「倾泻 / Cascade」）。X 卡牌上费用栏填的数字会被忽略。
  · 升级之后想让费用变（2 费升 1 费、1 费升 0 费）
      → 「卡牌」页右边「升级增量」下面是「升级后费用」：填升级后花几点能量，留空 = 升级不改费用
        （这是**整张牌**的设置）。生成时用本体自己的办法：OnUpgrade() 里 EnergyCost.UpgradeBy(差值)。
      → X 费用牌改不了（本体遇到 X 费直接返回，工具会提示）；负费用的特殊牌不建议改（本体会夹到 0）。
  · 升级之后关键字也想变（本体「残影」升级获得固有、「幻影 / 寒冰」升级失去虚无 / 消耗）
      → 「升级后费用」下面就是「升级后的关键字」：6 个关键字各一行，三态可选
        「不变 / 升级后获得 / 升级后失去」，生成到 OnUpgrade() 里的 AddKeyword / RemoveKeyword。
        升级预览和实际升级后的关键字都由本体自己显示，不用写文本。
  · 想把本体的关键词换个说法（比如把「消耗」改叫「献祭」）
      → 「自定义关键词」页最上面那 7 行就是本体那 7 个关键词（消耗 / 虚无 / 固有 / 不能被抽出 / 保留 / 奇巧 / 永恒）：
        填「新显示名」（留空 = 不改），想连鼠标悬停里的说明一起改就再填「新说明」。
        生成后本体卡面上的金色词、以及本体卡牌 / 遗物 / 药水描述里出现的旧名字都会一起换掉。
        注意这是全局改动 —— 本体其他角色的牌上出现同一个关键词也会跟着改名。
  · 想要一个本体没有的关键字（比如「命定」），卡面上也能像「消耗 / 虚无」那样用金色标出来、鼠标移上去有说明
      → 到「自定义关键词」页「添加关键词」，填名字、英文标识（留空会自动编号）、说明；
        再到「卡牌」页勾选哪张牌用这个词（一张牌可以勾多个）。
        生成时会自动：把名字拼在这张牌描述的最前面、让鼠标悬停卡面时弹出「名字 + 说明」、
        把文案写进模组的 card_keywords.json（本体那张表逐键合并，不影响本体自己的关键字）。
        注意：本体的关键字是封闭枚举、模组加不了新值，所以走的是这套等价机制；
        另外「升级后获得 / 失去自定义关键词」暂不支持（那套只有本体那 8 个关键字）。
  · 想要「只这一回合」的保留 / 奇巧，或者给别的牌加个关键词
      → 效果种类选「**给予卡牌关键词**」：
        · **数值** = 给几张牌（**填 0 = 就是这张牌自己**）；
        · 数值 ≥ 1 时按「选牌方式」（自己选 / 随机）和「从哪里选牌」（手牌 / 抽牌堆 / 弃牌堆）挑；
        · 它下面新增的「**给予关键词**」里选给哪个关键词 —— 上面是本体的 7 个
          （消耗 / 虚无 / 固有 / 保留 / 不能被打出 / 奇巧 / 永恒），下面是你自己造的关键词；
        · 再下面勾「**是否为临时关键词**」= 只这一回合生效（回合结束自动去掉，卡面上那行字也一起消失）。
        例：数值 0 + 给「保留」+ 勾临时 = 以前那个「临时保留」；换成「奇巧」就是「临时奇巧」。
        给本体关键词时卡面上显示本体那两个字，给自定义关键词时显示你自己起的名字（本体卡也能给）。
  · 想让敌人「这一回合不行动」（击晕）
      → 效果种类选「**击晕（敌人本回合不行动）**」，作用对象选「指定敌人 / 所有敌人 / 随机 N 个敌人」。
        注意：它**不在**「增益 / 减益」那个下拉里 —— 本体里「击晕」不是一个状态（Power），
        而是「怪物意图」（本体卡「口哨」就是这么做的：CreatureCmd.Stun），所以单独列成一种效果。
        本回合被击晕的敌人该回合什么都不做（和本体一致）。卡牌 / 遗物 / 药水 / 自定义状态都能用。
  · 想要「本回合 +N 层某状态，回合结束就掉光」（比如本回合 +3 点力量）
      → 效果种类选「临时增益（本回合 +X，回合结束消失）」，数值填层数，
        「增益 / 减益」里选那个状态（自己 / 指定敌人 / 全体敌人都能选）。
        生成的是本体「临时力量 / 临时敏捷」那套：状态栏里出现「临时某某 +N」，回合结束自动消失；
        别的来源加的层数不受影响（只撤掉这次临时加的那 N 层）。
  · 想让某一张牌的伤害 / 格挡变高（本体「精准」强化小刀、「敏捷」加格挡那种）
      → 效果种类选「**强化指定卡牌（像「精准」，+N 伤害/格挡）**」：
        · 「**目标卡**」下拉里选要强化的那张牌（自己的牌和本体卡都能选，**必填**）；
        · 它下面新增的「**强化什么**」里选 伤害（像「精准」）/ 格挡（像「敏捷」）；
        · 「**数值**」= 加多少，**填负数就是削弱**那张牌（例：-2 = 你打出的这张牌少 2 点伤害）。
        生成的是挂在你身上的一张状态：只对**你打出的那张牌**生效，本场战斗内一直有效
        （战斗结束自动消失，不会改到存档里的卡牌）；状态栏里会显示「强化：某某」和它的层数。
        例：一张能力牌「你的戏法飞刀额外造成 3 点伤害」= 目标卡选戏法飞刀 + 伤害 + 数值 3。
        注意：它加的是「攻击伤害」和「卡牌格挡」（和本体「精准 / 敏捷」一致），
        对不是攻击牌的伤害（比如状态掉血）不生效。
  · 自动生成的卡面描述不合意，想自己写
      → 「卡牌」页「卡面预览」下面有「**自定义描述**」输入框（可以多行）：
        默认**追加**在自动描述后面（自动那句话还在，你在下面补一句）；
        勾上「**替换掉自动生成的描述**」就整段换成你写的（自动那句不生成）。
        自定义关键词那一行（如果你给这张牌勾了自定义关键词）仍然排在最前面。
        「从工程恢复存档」也会把你写的这段读回来（多行、追不追加都会还原）。
  · 想造一张「诅咒」（打不出去、留在手里坑自己）
      → 到「**诅咒 / 先古卡**」页，上面那栏点「添加诅咒」：
        · 费用固定 -1、类型 / 稀有度固定 Curse，生成时自动加上本体的「不能被打出」；
        · 右边加的效果会在**你的回合结束时，如果这张牌还在你的手牌中**触发
          （本体「受伤 / 疑虑 / 苦恼 / 厄运」就是这一类）；
        · 想让它开局就在手里就勾「固有」；想让它删不掉就勾「永恒」；
        · 想让它打几场战斗后自己消失，就勾「战斗结束时，如果它还在牌组里就消失」（本体「罪恶」那套）。
        怎么让玩家拿到它：诅咒**不会**出现在战斗奖励 / 商店里 —— 用卡牌效果「生成卡牌」（放进手牌 / 抽牌堆 /
        弃牌堆）、「获得卡牌（全局）」加进牌组，或者「获得卡牌奖励」；这三处的「目标卡」下拉里能搜到你的诅咒。
        生成时按**稀有度**认它（不是按它在哪一栏），所以老存档里手改过稀有度的卡也对得上。
  · 想造一张「先古卡」（像本体丰饶 / 神化 / 幽灵形态那样的强力牌）
      → 同一个页面下面那栏点「添加先古卡」：和普通卡一样填费用 / 类型 / 效果 / 关键字 / 自定义关键词，
        只是稀有度**写死**是「先古」、而且不进战斗奖励 / 随机生成（本体里 Ancient 就是被排除的）。
        怎么让玩家拿到它：① 先古之民给的遗物 —— 本体「尘封的书」会从**你的卡池**里随机挑一张先古卡
        （你做的先古卡也在候选里）；② 或者你自己的效果（生成卡牌 / 获得卡牌（全局）/ 获得卡牌奖励）里选它。
        提示：先古卡是**能打出、能升级**的普通牌，升级增量 / 升级后费用 / 升级后关键字都能用。
  · 想给诅咒 / 先古卡换卡框颜色（RRGGBB）
      → 「诅咒 / 先古卡」页每一栏上面都有一行「**诅咒卡框 / 先古卡框**」：
        · 默认「跟角色配色（默认）」= 和以前一样（诅咒用本体的灰色诅咒框，先古卡用角色的卡框）；
        · 也可以直接选本体的框色（铁甲红 / 无色灰 / 诅咒紫灰 / 任务深蓝…）；
        · 选「自定义」后在下面的 **RRGGBB** 框里填 6 位十六进制（例如 8A5CF6），右边色块能预览。
        生成时会按这个颜色算 HSV 写一份卡框材质，只有这一类牌用（角色自己的卡框颜色不受影响）。
        说明：能改的只有**卡牌边框**；牌堆底色和能量图标描边取的是「卡属于哪个卡池」，按类改不了
        （工具里就不给这两个框，免得填了没反应）。先古卡自带的先古观感（先古边框 / 横幅）不受影响，
        这个颜色是给它染色的。
  · 想让角色带一个「伙伴」（像亡灵缚者的奥斯提那样，有血、能帮你打）
      → 「召唤物」页点「添加召唤物」并勾上「启用这只召唤物」，填名字 / 英文类名 / 生命（可选上传一张 PNG 当它的样子）。
        然后在「卡牌」页给一张牌加效果「召唤伙伴」（数值填 0 = 用配置里的血量；已经有一只活着时会改成加血而不是召第二只），
        再加「伙伴攻击」让它打人（宠物不在场时这张牌会自动跳过，不会报错）。
        宠物类的效果一共 12 个（召唤 / 攻击 / 三种按生命值算的攻击 / 治疗 / 失去生命 / 最大生命 /
        牺牲换收益 / 施加状态 / 替主人承伤 开·关），全都在「卡牌」页的**效果种类**下拉里直接选；
        选到宠物效果时会多出「召唤物（哪一只）」下拉（留空 = 用第一只启用的）；
        下拉第一条「★ 全部召唤物」= 这条效果对**每一只启用的**各算一次
        （例：一张牌把三只全召出来，或让每一只都替你承伤；不在场的那只自动跳过）。
        放在遗物的「战斗开始时」触发就是开局自动召唤。
        注意：伙伴**每场战斗都要重新召唤**（战斗结束本体就会清空），敌人默认也打不到它 —— 想让它可以替你承伤，
        就在「召唤物」页勾上它的「替主人承伤」（可以勾多只：承伤的是列表里第一只活着的，它死后自动换下一只；
        本体的伤害重定向是链式的，所以由我们生成的守卫自己仲裁，行为确定）；
        没有上传图片时会用本体的占位图，能正常上场 / 攻击 / 死亡，只是长得不好看。
  · 效果栏里的下拉太长、找不到目标
      → 「增益 / 减益」和「目标卡」下拉可以直接打字搜索：输入「下」就只剩含「下」的选项；
        点选项或按回车会把选中名字补全到输入框。「目标卡」每项显示「中文名 (英文类名)」，
        例如「磨蚀 (Abrasive)」；还没指定解包工程时就只有英文类名（选好目录会立刻刷新，不用重启）。
  · 「目标卡」下拉里只有英文类名（没有中文）
      → 中文卡名只存在于「解包后的原版工程」里。程序启动时会自动在常见位置找一遍；
        找不到就在「构建 / 日志」页选一次（选完立刻生效）。
  · 窗口拉小了，卡牌属性下面的关键字 / 卡面看不到
      → 「卡牌属性」「遗物属性」「药水属性」三栏都能上下滚动，鼠标放上去滚一下即可。
  · 左下角的数字是什么
      → 状态栏右下角实时显示「卡牌：攻击 N ｜ 技能 N ｜ 能力 N ｜ 共 N 张」，按类型统计。
  · 一次想删好几个 / 误删了东西
      → **多选**：在任何列表里按住 **Ctrl 点**（一个个加）或 **Shift 点**（选一段）就能多选，
        也可以按 **Ctrl+A** 全选当前鼠标所在的列表 —— 这些都不用先开任何开关。
        想「点一下就加选、不用按 Ctrl」的，点列表旁边的「多选」按钮（按钮变蓝）即可，
        这时还会冒出「全选」按钮；选中多个再点「删除 / 删除选中」一次全删掉。
        支持多选删除的列表：卡牌、遗物、药水、召唤物、自定义关键词、自定义状态（含触发时机、效果）、
        本体状态改写、配置存档。
      → 删完可以点「撤回删除」恢复（可连撤多次，各类各记各的；位置和顺序都会复原；
        存档删除也能撤回，原文件逐字节写回）。

  ── 初始卡组：打击 / 防御 ──
  · 初始卡组里的「打击 ×5 + 防御 ×5」是什么？「角色」页那个勾选框呢？
      → 没有勾选框了。这两张是「卡牌」页列表里默认就有的**两张你自己的卡**，固定排在最上面
        （打击在前、防御在后）：
          · 英文类名固定成 Strike / Defend（别改，原因见下）；
          · 数值默认照抄本体：打击 1 费 6 伤害、防御 1 费 5 格挡，升级都 +3；稀有度 Basic；
          · 初始 5 张、不进奖励和商店；
          · 标了**本体卡标签** Strike / Defend（卡牌页「本体卡标签」那一行）。
      → 除了英文类名，**其它全都能改**：费用、类型、稀有度、数值、升级增量、效果、关键字、
        卡面立绘、名称与描述；想开局 4 张打击就把「初始份数」改成 4。整条删掉也行，
        点「＋打击/防御」按钮可以补回来（补在列表最上面）。
      → 为什么类名是 Strike / Defend：本体的模型 ID 只按**类名**算（忽略命名空间），
        自己再造一张叫 StrikeIronclad 的卡会和本体撞 ID，模组加载时抛
        DuplicateModelException（"conflict in mod content names"）；
        而 Strike / Defend 这两个裸名字本体没有（本体只有 StrikeIronclad / StrikeSilent…）。
        校验器会在卡牌类名和本体卡重名时直接报错。
      → 为什么要标 Strike / Defend 标签（重要）：本体那些「升级你的初始打击 / 防御」
        「只对打击牌生效」的遗物、事件、卡牌全按 CardTag 查牌
        （妮欧的护符 NeowsTalisman、叶敷剂 LeafyPoultice、大胶囊 LargeCapsule、幽灵种子 GhostSeed、
        完美打击 PerfectedStrike…），有些还会再加「稀有度 = Basic」。不标标签它们就找不到你的牌。
        给别的牌标上 Strike 也能吃到「完美打击」这类加成。

  ── 初始遗物 / 死亡文本 ──
  · 初始遗物从哪来？
      → 只按「遗物」页里勾了「起始遗物」的那些来；一只都没勾就是开局不带遗物。
  · 「死亡描述文本」「阵亡后台词」什么时候出现？
      → 死亡描述文本：显示在**死亡结算画面**上（角色立绘下面那句带引号的话）。本体那句是按遭遇
        随机取的通用文案，没有「每个角色一句」的键，所以生成时会打补丁：取文案那一步，
        如果是你的角色就换成你写的（日志里会写「死亡结算文案已替换为自定义文本」）。
      → 阵亡后台词：**自己阵亡的那一刻**冒一个 3 秒的对话气泡（日志里会写「角色阵亡，冒出阵亡后台词」）。
        本体里对应的键只在**联机**「回合结束 ping」时显示，那个键照旧写。
      → 两句都留空就不生成任何补丁。

  ── 自定义状态（能力）──
  · 想自己造一个状态给能力牌用（本体没有的那种）
      → 到「自定义状态」页：点「添加状态」，填名字（游戏里显示的状态名）和类型（增益/减益），
        再加「触发时机」，每个时机下面加「效果」（伤害 / 格挡 / 抽牌 / 能量 / 回复生命 / 施加状态 / 生成卡牌…）。
        三个例子：
          ① 每回合开始获得「等于层数」的格挡 → 触发时机「玩家回合开始时」+ 效果「获得格挡」
             并勾「数值 = 本状态的层数」（本体恶魔形态就是这个写法）；
          ② 每打出一张攻击牌就造成 2 点伤害 → 触发时机「打出一张牌后」+ 只对「攻击牌」生效 + 效果「造成伤害」；
          ③ 临时减益（每回合掉血、回合末消失）→ 触发时机「玩家回合结束时」+ 效果「失去生命」+ 勾「回合结束时移除」。
        还能配：图标（方形 PNG）、层数数字颜色、只叠一层、每回合衰减 N 层。
        做好后到「卡牌」页加一张能力牌（类型选 Power），效果选「施加增益/减益」——
        下拉列表最下面就是你造的状态；打出这张牌就永久获得它。
  · 「触发时机」下面那几句说明是干嘛的
      → 页面上有三处会跟着变（改触发时机、改效果种类 / 数值、加减效果都会立刻更新）：
        ① 「触发时机」下面那块灰底汇总：这个状态配了哪几条、每条做什么；
        ② 触发时机下拉框底下那句：「触发时机：玩家回合开始时 → 触发时做：获得 3 点格挡」；
        ③ 触发器列表里那一行（例：玩家回合结束时 → 伤害 5 → 单体敌人）。
      → 「描述」留空时游戏里显示自动写的那句；下面那行灰字「游戏里会自动显示：…」是实时预览。
        想自己写就填「描述」；「按触发时机重新生成描述」按钮会用当前配置重写一遍。
      → 触发时机里两个「附加条件」：
        · 「只对哪类牌生效」（选「打出一张牌后」时出现）：任意 / 攻击牌 / 技能牌 / 能力牌；
        · 「盯哪个状态」（选「某个状态层数变化后」时出现）：留空 = 除自己以外任意状态层数一变就触发；
          选了某个状态就只在它的层数变化时触发（生成 `if (power is StrengthPower) { … }`）。
      → 层数和效果的关系：层数只是一个数字，默认**不会**让效果多跑几遍、也不会放大数值。想让层数起作用：
        · 「数值 = 本状态的层数」→ 1 次触发、数值等于层数（3 层 = 3 点格挡）；
        · 「生效次数 = 本状态的层数」→ 按层数重复执行整条效果（5 层 +「造成 2 点伤害」= 打 5 次共 10 点）；
        · 「命中次数 / 对群数 = 本状态的层数」→ 只对「随机敌人」这类按次数挑目标的效果有意义。
        三个都不勾 = 每次触发只跑一遍、用你填的固定数字。
      → 生成的东西：cs/Powers/<类名>.cs（按触发时机重写本体钩子）+ 本地化里的名字 / 描述 + 图标 / 颜色补丁。
        用的都是本体自己的钩子（AfterPlayerTurnStart / AfterCardPlayed / AfterCardExhausted …）；
        「消耗卡牌 / 变化卡牌 / 结束回合」这类效果需要卡牌上下文，工具会拦住不让放进状态触发器里。
  · 状态描述里怎么看到「什么条件下才生效」
      → 自动描述会带上条件，例：「自己造成伤害后：施加 [blue]10[/blue] 层冻伤
        （条件：拥有冰附魔至少 2 点，不满足时这条效果不生效）。」卡面上的条件本来就会写
        （「条件：生命值低于 50%（不满足时无法打出）」）。
  · 卡面 / 遗物 / 药水描述里的状态，鼠标移上去没有说明
      → 生成的卡牌 / 遗物 / 药水会自动声明 ExtraHoverTips：凡是这条效果「施加的状态」
        或「条件里盯的状态」，悬停时都会弹出说明 ——
          · 被改写的**本体状态**：弹出来的是你改的新名字 + 新描述；
          · **自定义状态**：弹它自己的名字和描述；
          · 「下回合生效」的走那个延迟状态类，一样有说明。
        药水那份是 public override，卡牌 / 遗物是 protected override（和本体写法一致）；
        没提到状态就不会生成这一段。
  · 想「战斗胜利后获得卡牌奖励」（像本体「王国资产」那样，挂在能力牌的状态上）
      → 「自定义状态」页：加一个状态 → 触发时机选「战斗胜利后」→ 效果选「获得卡牌奖励（N 选一）」；
        再回「卡牌」页加一张能力牌，效果选「施加增益/减益」选这个状态。打出这张牌之后，
        每场战斗打赢都会给一条奖励。
      → 打赢之后**结算界面多出一条「选一张卡」**，N 选一，选中直接进牌组；打输了不会给。
        走的是本体自己的战斗奖励（AfterCombatEnd + room.AddExtraReward + CardReward，
        本体「王国资产」「猎杀」就是这么写的）。
      → 想让「层数越高奖励越多」：在那条效果上勾「生效次数 = 本状态的层数」；只想固定一条就别勾。
      → 挂在别的触发时机（例如「玩家回合开始时」）也能用，但那是**当场**弹出选牌界面、选中立刻进牌组。
      → 想给遗物配同款奖励：在「遗物」页把触发时机选「战斗胜利时」，效果同样选「获得卡牌奖励」。

  ── 本体状态改写 / 先古之民 ──
  · 能改本体的状态吗（把「中毒」改名、换图标、把血条那截绿色换掉）
      → 能，到「本体状态改写」页：点「添加改写」，选状态（可以直接打字搜「中毒」），
        然后填新名字 / 新描述 / 上传图标 / 填血条颜色和层数数字颜色，再点「生成」。
        · 名字和描述：写在模组的 localization/zhs/powers.json 里，键和本体同名（如 POISON_POWER.title），
          本体加载模组本地化表时会覆盖自己那份，所以不用补丁；改名时顺手点一下
          「把描述里的旧名字一起换成新名字」。
        · 「本体卡牌 / 遗物 / 药水描述里的旧名字也一起换掉」（默认勾上）：本体那些写着
          「给予 N 层中毒」的卡面描述会一起变成你的新名字（只改描述键、不动卡名）。
          要读「解包后的原版工程」里的中文表才换得了卡面描述。
        · 换状态时右边会自动填好新状态的本体名字 / 描述，图标和颜色会清空。
        · 图标：换的是本体状态的图标（状态栏里那个小图，以及施加 / 闪烁特效里的大图）。
        · 血条颜色：本体血条上只有「中毒」和「灾厄」两截按状态显示颜色，两种画法都支持 ——
          中毒那截是纯颜色（本体原色 79C03C），直接换 self_modulate；灾厄那截本体是着色器
          （doom_bar.gdshader）用紫色渐变按噪声画的，工具会照同样结构（3 个色标、同样偏移、
          同样的明暗比）用你的颜色造一条渐变换上去（本体主色 834181）。
        · 层数数字颜色：可以按状态改（本体默认：减益红、其它米白）；本体「中毒」「灾厄」自己重写过
          这个颜色，所以补丁打在显示那一端（NPower.RefreshAmount）上。
        · 注意：这是全局改动 —— 本体其他角色身上的这个状态也会跟着变；
          一条都没添加时不会写出任何相关补丁与本地化键。
  · 「先古之民」页是干什么的
      → 给本体那些先古之民写你自己角色专属的对话。左边选先古之民，右边按「第几次到访 / 第几次」
        加对话段（从 1 开始），每段可以写好几行，还能单独给某一段填「继续」按钮上的字
        （不填就用本体的默认文字）。
      → 两个注意点：① 本体的「第一次见到」对话是全体角色共用的，会顶掉你写的第一段，
        稳妥起见从第 2 次开始写；②「建筑师」那一项里的次数指的是**通关次数**而不是到访次数。
        生成时日志里会有一行「已给先古之民 XXX 注入 N 段」。
  · 「先古之民」页的「把原本会给的遗物换成你要的」是干什么的
      → 本体每位先古之民会从他自己的候选表里筛选、洗牌，然后给你 3 个遗物选项（有时第 3 个是
        「尘封古书」）。界面把他原本会给的遗物全部列出来（左边那一列）。
      → 用法：左边点一个「原本的遗物」→ 按「② 替换掉选中的这个 →」→ 右边出现一条「替换记录」，
        在里面选「换成哪个遗物」（默认已经帮你挑了你自己做的那个；没有的话挑一个别的本体的）。
        每条记录下面那行会告诉你这条会不会生效：
          ✅ 会替换：这次选项里正好有它就直接换掉它；没抽到它就不动（不会顶掉别的选项）
          ⚠ 还没选「原本的遗物」—— 不知道要换掉哪一个，这条不会生效
          ⚠ 还没选要换成什么遗物 —— 这样生成出来不会有任何变化
          ⚠ 和原本的遗物是同一个 —— 等于没改
      → 生成时的做法：这次选项里正好有那个「原本的遗物」就换掉它；没抽到就什么都不做
        （不会顶掉别的选项）；要换成的遗物本来就在选项里就跳过。选项数还是 3 个。
        造选项用的是本体自己的 RelicOption 方法，行为与本体一致。
      → 拿不准为什么没生效时看游戏日志：每次替换都会写一行「选项：换之前 → 换之后（换了哪个、为什么）」，
        没抽到的那次会写「本次不替换」。
      → 注意：补丁挂在先古之民的事件上（本体的那几位事件是共用的），本体角色也会受影响；
        改了要重新生成 + 构建。

  ── 语义提醒 ──
  · 勾了「数值 = 本状态的层数」，游戏里给的却是层数、不是我填的数字
      → 那是这个勾选的语义：勾上之后生成的是 base.Amount（本状态的层数），「数值」里填的数字不生效；
        生成前的校验会把这句话直接写出来。想要固定数值就把勾去掉。
  · 「施加 30 层缓慢」，游戏里只看到「缓慢」、没有 30
      → 本体「缓慢」显示的数字**不是层数**：它显示的是「本回合已打出的牌数 × 10」
        （每打出一张牌，该敌人本回合受到的攻击伤害 +10%），跟层数无关；本体自己施加时也只施加 1 层。
        层数照旧记着，只是状态栏那个数字由它自己算。
      → 想直接给敌人上「受到伤害 +30%」，用效果里那一行：效果选「施加增益/减益」→ 状态选「缓慢」，
        下面会多出「直接把「缓慢」设成 ___ %」，填 30 就行（0 = 不设置）。生成时按本体做法只施加 1 层，
        再把内部数值写成 30%（并刷新状态栏）；描述会自动写成「施加冻伤（受到伤害 +30%）」。
        按 10% 一档折算（填 25 会按 30 处理），并且和原版一样**每次敌人回合开始会清零**。
      → 同一类「显示的数字不是层数、填层数没用」的状态（生成前的校验会一一提示）：
        SlothPower、TenderPower、PaleBlueDotPower、AutomationPower、CacophonyPower、PanachePower、
        WitheringPresencePower、MonologuePower、FeralPower、HardenedShellPower、OrbitPower、TagTeamPower。
        这些没有「直接设成 N%」的开关（数字按各自规则算）；想要加伤建议用显示数字就是层数的状态
        （例：易伤 / 中毒），或者自己在「自定义状态」页造一个。
