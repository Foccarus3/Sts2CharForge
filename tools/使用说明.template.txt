Sts2CharForge —— 杀戮尖塔 2 自定义角色生成器（使用说明）
=====================================================

一、怎么打开
  双击「启动 Sts2CharForge.bat」即可（启动器跟着文件夹位置走，解压到哪都能用）。
  想放桌面快捷方式：右键「启动 Sts2CharForge.bat」→ 发送到 → 桌面快捷方式
  （图标可在属性里改成 程序文件\waku.ico）；包内也带一份同版本的 .lnk。
  注意：不要只把 exe 单独拷出来，程序要跟同目录的一堆 dll 在一起才能跑。

二、压缩包怎么放
  · 程序文件\              ← 程序本体（含 waku.ico、launcher_help.ps1）
  · 启动 Sts2CharForge.bat ← 启动器
  · Sts2CharForge_环境包\  ← Godot + 便携版 .NET SDK（程序会自动认出，不用装任何东西）
  · 自定义角色存档\        ← 你的存档与生成的角色工程（第一次保存时自动建）
  · ！首次使用先点这个！\  ← GDRE 解包工具与图文教程（解包自己的游戏本体要用）

  包有三种，按需选：
    整合包 = 程序 + 环境包 + GDRE 工具 + 教程（第一次用选它，约 371 MB）
    更新包 = 只有 程序文件\ + 启动器（已经有旧版时选它，约 60 MB，解压覆盖即可）
    程序包 = 程序 + 使用说明（不带环境包）

  存档与生成的角色工程放在根目录「自定义角色存档」里，**跟程序文件分开**：
  以后覆盖更新程序（只换「程序文件」）不会碰到你的存档。

三、第一次打开要做的事
  1. 启动会先弹「配置存档」窗口，点「新建配置」即可（没有存档时是正常的）。
  2. 到「构建 / 日志」页，把「解包后的原版工程目录」选一下 —— 这是唯一需要你指定的东西
     （做法见下一节）。选好之后程序会记住，其余路径全部自动探测。
  3. 「构建 / 日志」页顶上那行绿字会显示环境状态（Godot ✅ .NET ✅ 游戏目录 ✅）；
     想看细节去「环境自检」页，绿色 ✅ 就是齐了。
  关窗口时会问一句「要不要保存」：有改动才会问，选「取消」就回到编辑界面继续改。

四、还需要你自己准备的（包给不了）
  1. 《杀戮尖塔 2》本体（Steam 正版）—— 提供编译用的 sts2.dll / 0Harmony.dll。
  2. 游戏「解包后的原版工程」—— 生成模组时的占位美术、场景模板、spine 插件都从这里取。
     做法见「！首次使用先点这个！\」里的教程，用 GDRE Tools 解包自己的游戏本体
     （涉及你自己的游戏文件，不能随包分发）。
     把解包目录填到「构建 / 日志」页的解包工程那一行即可；没填就点生成的话，
     程序会先自动找一遍，找不到会弹框让你选。

五、常见问题

  ── 存档与保存 ──
  · 存档会不会被工具弄丢？
      → 每次保存之前都会把【旧内容】自动备份一份：
        ① 存档目录里同名的 <你的存档>.json.bak；
        ② 存档目录下「_备份」文件夹里带时间戳的那份（最多留 30 份，旧的自动清）。
      → 万一连备份也没有了（存档目录被整个删掉）：到「配置存档」页点「从工程恢复存档…」，
        选一个以前生成出来的模组工程目录（里面有 cs 文件夹的那个），工具会从源码反推出一份存档 ——
        卡牌（含费用 / 稀有度 / 关键字 / 每条效果的数值与升级增量 / 条件 / 自定义描述 / **是不是无色卡**）、诅咒、先古卡、
        遗物、药水、自定义状态、角色属性、本地化名字、上传过的图全部找回，另存为「工程名_恢复.json」。
        命令行也行：forge --recover "工程目录" --out "恢复.json"
        命令行还有：forge --profile x.json --build（生成 + 编译 + 导出 PCK，**不会安装**）；
        **要装到游戏里必须显式给 `--install`**：forge --profile x.json --build --install "D:\...\Slay the Spire 2\mods"
        （V0.2.137 起：存档里那栏「安装目录」只给**图形界面**用，命令行不再拿它兜底 ——
          以前会给，于是「只想编译一下」的探针会把模组真的装进存档里写着的游戏 mods 目录。）
        想自检这一点：forge --buildcheck（构建前后各数一遍存档里写着的那个安装目录，一个文件都不许多）。
        （V0.2.120 修好一个坑：以前「数值公式」那种变量回读不认，于是**卡牌的数值会被读成 0**、
        还会刷一片「升级增量找不到对应效果」—— 现在生成出来的数值 / 升级增量都原样回来。）
        **V0.2.134 起，「锻造」页那张节点图也能恢复了**（含升级后那块布、每个模块的每一格、
        【效果】模块的编辑器内容）—— 恢复完那张锻造卡的「*」标记和节点图都在。
        老工程（V0.2.133 及以前生成的）照旧恢复不出图，但**不会报错**，只是图空着要重做一次。
      → 习惯建议：改完配置顺手点一下保存，别急着删旧的工程目录。
  · 「保存配置」会存到哪？会不会存成两份？
      → 直接保存进**当前打开的那份存档**，不弹路径选择。
        只有「模组 ID」和当前存档文件名不一样时问一次：
        「要把存档名称改成 <模组 ID>.json 吗？」
          答「是」= 文件真的改名过去（旧文件不留重复；旧内容照旧进「_备份」）；
          答「否」= 仍然保存进原文件，本次运行不再问（改了名字才会再问）。
      → 想存成另一个文件，用「配置存档」页的「另存为新存档…」（那个才让你选路径）。
      → 「用当前配置覆盖该存档」覆盖完，「当前存档」会切到你覆盖的那一份。
  · 两个存档会互相影响吗
      → 不会：生成的工程目录跟着**存档文件名**走（存档「七」→ 工程目录「七」），
        每次生成前先清掉该目录里上次生成的文件，不会残留旧代码。
      → 但两个存档如果**模组 ID 一样**，装进游戏会互相覆盖（dll / pck 名字一样）——
        左下角问题列表会提醒，把其中一个的模组 ID 改掉即可（「角色」页最上面）。

  ── 自定义参数 / 组、锻造 ──
  · 「自定义参数 / 组」页是干什么的？
      → 上半部分定义参数：一个字母 = 一个中间变量，点「新建参数」会自动挑一个没被占用的字母
        （X / Y 是保留的：X = 当前所有能量，Y = 当前所有额外资源量）。来源可以选
        「当前血量 / 最大生命 / 金币数 / 能量数 / 最大能量数 / 增益减益」；选增益减益时再选是哪个状态，
        「从谁身上取」可以选自自己 / 指定敌人 / 全体敌人 / 全体友方 / 召唤物。
        这些值打出牌的那一刻才知道，所以在生成出来的模组里现算。
        ⚠ 选「**指定敌人**」的参数只能用在**会选中一个敌人**的牌上（单体牌）。
          如果你把它用在「对所有敌人」的牌上，打出这张牌时根本没有「选中的那个敌人」，
          它会永远是 0、公式等于白写 —— 生成前的检查会**报错拦住**并告诉你怎么改
          （把那条效果的「作用对象」改成「指定敌人」，或者把这个参数的「从谁身上取」
          改成「全部敌人」（取第一个活着的敌人）/「随机敌人」）。
        另外：公式是**整张牌只算一次**的，所以「每个敌人各自的状态层数」做不到；
          自动的话伤害数字对所有敌人是同一个。
        右边那两个下拉可以把某个参数指定成「给予多少能量 / 多少额外资源量」。
      → 下半部分是「组」：点「新建组」建一个并命名；「卡牌属性」标题右边会多出一排勾选框，
        勾上就表示这张牌属于这个组。组只影响生成器里的查看与筛选，不写进模组代码。
  · 「锻造」页是干什么的？      → 用另一套逻辑做卡牌 / 药水 / 遗物：最左侧上方选「卡牌列表 / 药水列表 / 遗物列表」，
        一类都不选时右侧是空白的，只提示「请选择卡牌、药水、遗物」。
        点「添加」会生成一项名字前面带 * 的条目。
      → **这一页只管右边的节点图**：属性（名称 / 类型 / 稀有度 / 卡池 / 关键字 / 卡面）都在
        「卡牌 / 药水 / 遗物」页照常改 —— 带 * 的条目在那里照样能改属性；
        **费用 / 额外资源量费用 / 升级后费用 / 升级后额外资源量费用那四个框整块藏掉**（由这一页的【触发时机】/【能量】定），
        **右边效果栏连按钮一起藏掉**（效果归这一页的节点图），只留一句说明告诉你去哪改。
      → 「卡牌」页的**类型**里有「状态」、**稀有度**里也有「状态」：照本体「粘液」做状态牌用的。
        稀有度选「状态」的牌会**不能升级**、也**不会跑进战斗奖励**（和诅咒 / 先古卡一样）。
        想要粘液那种手感就：类型=状态、稀有度=状态、1 费、勾「消耗」、效果加一条「抽 1 张牌」。
        这些牌在「**诅咒 / 先古 / 状态**」页最下面那一栏也能看到、也能改（同一份数据，见下面那条）。
      → 最右侧那块「布」就是**节点编辑器**：中间一个【触发时机】模块（默认「卡牌被打出时」），
        左上角固定一个【能量】模块（它**不能选中 / 不能拖动 / 删不掉**，见下面「编辑器里」那一段）。
        拖标题栏移动模块；**按住右边一个出口圆点往左边一个入口圆点拖**，
        拖的时候有根黄线跟着鼠标，松手就接上（也可以先点一下出口、再点一下入口）；松在空白处 = 不接；
        想删掉一条线：**在线上右键**（光标会变成手型，点上去就删）。点空白处取消；
        连错了会画成红色虚线并在下面说明原因。
        **Ctrl + 滚轮 = 放大 / 缩小这块布**（也可以按 Ctrl 加 + / −，Ctrl + 0 回 100%）；
        工具条右边有 −／百分比／＋／适应窗口／100% 几个按钮。不带 Ctrl 的滚轮还是上下滚画布。
        上面的下拉选种类 → 「添加」就多一个模块（if / 对象 / 状态 / 数值 / 效果 / 且 / 或 / 条件）。
        **效果种类底下只显示跟它有关的那几栏**：选「获得药水」才出现「指定 / 随机药水 + 哪一瓶」，
        选「生成卡牌」才出现「目标卡 / 生成到」，选「消耗 / 丢弃 / 升级 / 变化 / 复制卡牌」才出现「取牌方式」。
      → 布上【状态】/【效果】/【条件】模块里的「增益 / 减益」下拉，和「卡牌」页那个是**同一份清单**：
        里面既有本体状态，也有你在「自定义状态」页造的那些（下拉里可以打字搜，比如输入「染色」）。
        新建 / 删除自定义状态后那三个下拉会跟着更新（不用重新打开存档）。
        【对象】选「指定召唤物」时下面才会多出「召唤物名称」（只列你在「召唤物」页配的那些）。
        【数值】里可以填数字或公式（M*3、X、Y、min(2, X)…），X = 当前所有能量，Y = 当前所有额外资源量；
        其它字母是你在「自定义参数 / 组」页定义的参数，打出牌那一刻现算。
        **V0.2.128 起：模块里那些单行数字框也能填公式 / 参数**（【触发时机】的血量低于 / 到达 N 层 /
        仅生效 N 次，【能量】的两栏，【效果】的数值 / 生效次数 / 命中次数 / 概率，【条件】的 N / M，
        【关系符】的右值 —— 一共 12 处）：可用量和【数值】模块**完全同一套**。点数字框右边的「…」就能
        把 X / Y / 参数 / 内置只读量插进去；**布最上面那一行灰字就是可用量清单**（鼠标悬停有中文说明）。
        填法是「纯数字 / 能算出常数的公式（2*3、A+3）/ 运行时公式」三种，前两种生成出来和以前**一模一样**；
        填了运行时公式的框会**标蓝**（鼠标悬停能看到它变成什么表达式），**填错当场描红**、
        配置检查里也会报「哪个模块 · 哪一栏」——不会再像以前那样悄悄退回默认值。
        ⚠ 只有【能量】那两栏是例外：它们写进卡牌自己的费用（本体要**编译期常量**），所以只收
        「生成期就算得出来的数」——写 X 会被配置检查报错拦住，写 1+1 / A+3 可以。
        【数值】留空 = 用它接入点接进来的那一块（这样才用得上【能量】右边那两个出口）。
        ⚠ V0.2.129 起【效果】模块换成了**「卡牌」页那套效果编辑器**（同一个数据、同一份模板）：
        选一个效果种类，底下出现的可填写项**和「卡牌」页完全一致**（取卡方式 / 范围限定 / 目标药水 /
        范围界定 / 多选1 / 复制的份数 / 刮削 / 下回合生效 / 缓慢 / 牺牲伙伴…都跟着种类走）。
        那一块里的「数值 / 生效次数 / 命中次数 / 概率」**直接在框里写公式就行**（和上面同一套语法与可用量）；
        「作用对象」也摆出来了，但**显式接在【效果】左边「指向对象」口上的【对象】模块优先**，
        没接线而你又改过它 → 按你改的那一档，都没动过 → 照老规矩（这张牌选中的目标）。
        老存档（只有老字段的那种）打开时会**幂等**迁出一份编辑器用的数据、但**不回写老字段**，
        所以老存档生成出来的东西一个字节都没变；你改过之后才回写。
        节点图这一版实现的是 30 / 65 种效果：**没接上的种类、以及编辑器上有但节点图不生成的栏位，
        一律由「配置检查」报错拦住**（报错里会写清改用哪一档、或者去哪儿配）—— 不会静默生成一半。
      → 【能量】右边两个出口分别是「能量」和「额外资源量」：把它们接到【数值】（或【效果】的数值口）上，
        取到的就是当前能量 / 当前额外资源量，而且**两个出口各算一份、互不撞名**。
        这两个数就是**这张牌自己的费用扣完之后**的值（和本体的普通卡一个口径）。
      → 【能量】模块上那两栏（能量 / 额外资源量）填的就是**这张牌的费用**：
        填了之后卡面、游戏里都会显示这个费用，能量 / 资源量不够时本体不允许打出。
        ⚠ 老版本（V0.2.107 及以前）这两栏只在打出时偷偷扣一次、卡面一直显示 0 费 —— 见 V0.2.108 更新说明。
      → 「锻造」页左上角有「升级前 / 升级后」两页：升级后那一页左上角有个悬浮按钮
        「一键复制『升级前』的内容」，点一下就把「升级前」**那一刻的样子**整份拍下来当成「升级后」的
        内容 —— 之后在「升级前」上再怎么改都不会影响到它（两块独立的数据）。
      → 「升级后」那块布空着时，升级后的卡走的就是「升级前」那张布（所以不填也完全能用）；
        一旦点过复制或自己画过，升级后的卡就走「升级后」那张。
      → **节点图会跟着工程一起存下来**（V0.2.134 起）：生成时会在生成的 .cs 里写一行
        `// CET:ForgeGraph=…` 的标记（**只有图非空时才写**，没有图的存档生成结果一个字节都不变）。
        有了它，「从工程恢复存档」才能把整张图（含升级后那块布）原样找回来 ——
        代价是**含锻造图的存档**生成出来的那几个 .cs 会多出这行标记（一行 10~40 KB 左右），
        别的文件一个字都没改。老工程（V0.2.133 及以前生成的）没有这行标记，恢复时图照旧空着、也不会报错。
      → 布上右上角有 **「视图：节点图 / 积木（可拖）」** 两个单选（默认「节点图」）。
        切到「积木」= 同一块布换一种看法：按**执行顺序**从上往下一摞积木，缩进 = 在谁里面
        （【触发时机】在最上面；【if】下面是它的「条件：」那条链，再是「是：」「否：」两个分支标题
        + 「（if 到这里结束）」收口）。
        这一版它**能改**：
          · **拖块换位置** —— 拖到别的块**中间** = 放进它里面（【if】的两支，或【效果】/【状态】那种**取值口**）；
            拖到上 / 下边缘 = 插在它前面 / 后面；
            拖的时候有半透明预览块，目标会变色（橙色=插在旁边，绿色=放进里面）；
          · **✚** = 在那一块后面加一块（会弹菜单挑种类）；
          · **✕** = 删掉那一块和它的内容（同一支里后面的块会接回来，不留洞）；
          · 空布上直接点上面的调色板也能从零搭，会自动补一个【触发时机】当起点。
        改完**立刻写回节点图**（节点还是同一批、位置和字段都不动），所以切回「节点图」看到的就是改完的样子，
        生成器读到的也是改完的图；存档格式没变，老存档照旧能开。
        写回还保证「**取值槽那条线的方向**」是对的（【数值】→【效果】的「数值」口、【对象】→【状态】的「归属」…）
        —— 这一版修掉了一个老 bug：以前这条线会被写成反的，生成端读不到就**静默退回模块上填的常数**
        （表现就是「数值块明明连了但不算」）。
        ⚠ 两个限制：（1）【且】/【或】门那两条 A / B 线积木视图**不接管**（写回时原样留着），要改请在节点图里改；
        （2）把一整个容器（【if】/【效果】）拖进另一个容器里，复杂图上偶尔会有一支要在节点图里补一下线；
        放不进去的情况（比如拖进没有「取值口」的【对象】里）会**当场说一句**，不会悄悄写出一条无效的线。
      → 「自定义参数 / 组」页右边那两个「给予能量 / 给予额外资源量」是**给你标注用的**：
        它说明「这个参数的值打算当多少能量 / 多少额外资源量来用」，写在参数列表的说明里，
        方便你回头看「M 到底是干嘛的」。它**不会**自己给能量 —— 真要给能量，
        在节点图上用【效果】=「获得能量 / 获得额外资源量」，数值那边填 X / Y / 你的参数。
      → 遗物的触发时机里有「当遗物被点击时」和「血量低于 N」；这两个都能填
        「本场战斗 / 本回合 / 本次游玩仅生效 N 次」，填 0 = 无限次，用完会像本体一样变灰。
        「血量低于 N」填小于 1 的值按百分比算（0.5 = 血量低于 50%）。
      → **卡牌档的触发时机多了一条「这张牌被保留时」**（V0.2.128）：本体没有「被保留」这个钩子，
        它走的是「丢手牌那一刻」本体的 AfterFlush 回调 + `retainedCards.Contains(this)`
        （判据 = 有「保留」关键词 / 这回合被单回合保留 / 整手牌都不丢），
        和「卡牌」页条件里的「被保留」是**同一套语义**（不会把这张牌真的丢掉，只是那一刻收到通知）。
        这个钩子签名里没有「打出的记录」，所以那一支里「打出的目标」是空的（生成端会补一句 cardPlay = null）。
      → **遗物档的触发时机和「遗物」页那份是同一套**（V0.2.120 起补齐）：打出一张牌后 / 消耗一张牌后 /
        抽一张牌后 / 弃掉一张牌后 / 造成伤害（每一下）/ 花掉能量 / 花掉额外资源量 / 生成卡牌时 /
        自己失去生命时 / 自己获得格挡后 / 一个敌人死亡后 / 敌人回合开始 / 敌人回合结束 /
        敌人受到伤害后 / 敌人造成伤害后 / 敌人获得格挡后 / 战斗结束（房间结算之前）/
        某个状态层数到达 N 层 / 层数变化 / 被移除 …都补上了。
        选了「到达 N 层 / 层数变化 / 被移除」时，【触发时机】模块下面会多出「盯哪个状态」和「到达 N 层」。
        生成出来的钩子里带的「只认属于自己的那件事」守卫（例：敌人的伤害不会触发你的遗物）
        和遗物页**同一份**；本体没给 choiceContext 的时机（花掉能量 / 生成卡牌时…）工具会自己造一个。
      → 现在能真正跑起来的是「触发时机 → 执行链（含 if / 且 / 或 / 条件 分支）→【效果】→【数值】→【对象】」
        这一整套。效果种类接了伤害 / 格挡 / 抽牌 / 能量 / 回复 / 失去生命 / 最大生命 / 金币 / 额外资源量 /
        施加或扣除状态 / 翻倍状态层数 / 清除状态（单个或全部减益）/ 禁止获得格挡 / 击晕 / 结束回合 /
        生成卡牌 / 消耗卡牌 / 丢弃卡牌 / 升级卡牌 / 变化卡牌 / 复制卡牌 / 从三摞各拿牌到手牌 /
        预见 / 获得药水 / 获得卡牌奖励 / 将此牌放回手牌（后五种里带选牌的都有「自己选」和「随机」两档）。
        其它种类会在生成的代码里写一句说明并跳过，不会生成编译不过的工程。
      → 【对象】那十种是真不一样的：自己 / 全部友方（自己+召唤物）/ 全部召唤物 / 全部敌人 / 全体单位 /
        指定单体敌人（打出时选的那个）…写伤害或上状态时会逐个动手，不是只打第一个。
        「指定召唤物」是先按你选的**召唤物名称**找那一只（找不到才退回第一只）；
        「随机召唤物」才是随便给一只。
        ⚠ 「命中次数」（【效果】模块上那一栏）配**全体敌人**时是「**一次打全体、每个敌人挨 N 下**」
        （走本体的 `TargetingAllOpponents`）；配「随机敌人 / 指定敌人」时是「挑中的那个挨 N 下」。
        想「打完一轮再来一轮」请改用【效果】上的「**生效次数**」。
      → 【if】左边**两个**入口：上面那个「**接入**」接**前置**（【触发时机】/【指向对象】/【效果】/别的分支），
        下面那个「**条件**」接**判断条件**（把【条件】/【且】/【或】/【关系符】的「结果」出口拖过来）；
        右边「**是**」「**否**」两个出口分别走两支（结构决定顺序，不用再连一条链）。
        ⚠ **两个口要分清**（用户实测踩过）：「接入」是执行链、「条件」是「往里插一个能出『成立 / 不成立』的模块」。
        落错口画布会**当场拦下来**说清（把执行链的模块丢到「条件」上 = 条件恒不成立，那就白连了）。
        这一版**把「条件」从右边挪到了左边**（你反馈的「关系符的结果连不到 if 的条件」：
        老版条件口是个**出口**，只能从 if 那头往外拖，存下来的线方向是反的）—— 现在和别的模块一样，
        **从来源的出口拖到目标的入口**。
        **老存档打开就自动迁移**，不用重连：那条「从条件口往外拖」的线会被**扶正**
        （顺着它找到条件链末尾能出布尔的模块 —— 例：【对象】→【状态】→【关系符】—— 把「结果」接进新的「条件」口），
        「是 / 否」两个出口的下标也从 1 / 2 归到 0 / 1（**不会对调**）。
        条件口**没接**（或接的不是能出布尔的模块）时，「配置检查」会**报错**，并把三步接线写给你：
        ①【状态】(那个状态) 的「数值」出口 → 【关系符】的「左值」；②【数值】(N) 的出口 → 【关系符】的「右值」；
        ③【关系符】的「结果」出口 → 【if】左边下面那个「条件」口（【状态】左边的「归属」接【对象】= 那个敌人）。
      → **【指向对象】（就在【触发时机】后面，固定连着）**：它说的是「**这张牌在游戏里选中谁**」——
        决定卡牌的目标类型（要不要让玩家选一个敌人），也是这条链上
        「**效果没自己接【对象】时**默认打谁」。新布的默认值是「指定单体敌人」。
        · 和【效果】左边那个「指向对象」口**不是一回事**：那个是「这条效果打谁」，可以不一样
          （例：牌选中一个敌人、但效果对**全体**敌人造成伤害 —— 你举的例子就是这个）；
        · 做**自增益牌**（打给自己）就把这一块改成「自己」，下面那些效果也就默认打自己了；
        · 老图（没有这一块）行为一个字不变，但**图里用到「指定单体敌人」时配置检查会报错**，
          提示你补一个【指向对象】—— 不补的话那张牌根本不会让玩家选敌人，拿到的是**空目标**
          （读它的状态得 0、打它等于没打）。
      → **【关系符】（判断条件是否成立，可叠加）**：运算符有
        大于 / 小于 / 等于 / 大于等于 / 小于等于 / 非 / 且 / 或。
        · 左边「**左值**」接要比的东西（【状态】/【数值】，或另一个【关系符】的结果）；
        · 左边「**右值**」接拿来比的东西（【数值】）；不接就用模块上填的那个数字；
        · 右边「结果」接【if】的「条件」口（左边下面那个；或另一个【关系符】的左右值）—— 于是可以**叠起来**用：
          例「虚弱 > 3」且「易伤 > 0」= 两个【关系符】各比一条，再用一个【关系符】选「且」把两个结果合起来。
        · 左值 / 右值两个口**既能接数值、也能接条件**：选「非 / 且 / 或」时接的是条件
          （【条件】/【且】/【或】/【关系符】），选比较类时接的是数值。
          接错了配置检查会报错说清该接什么（不会生成编译不过的代码）。
        · 想要「拿到某个敌人身上的状态层数」：左边接【状态】（归属接【对象】= 那个敌人），
          再把它接到【关系符】的左值上。
      → 「获得卡牌奖励」只能挂在【触发时机】=「战斗胜利时」那一支上（本体没有战斗中直接弹奖励的入口），
        挂对了会像本体「王国资产」那样往战斗结算里加一条奖励；挂错了生成器会跳过并写明原因。
      → ⚠ **【效果】那一栏列的是「卡牌页效果栏」的全量候选 —— 不是每一档节点图都接上了。**
        选了节点图没接上的种类时，**配置检查会报错拦住**，并在错误里列出「节点图现在支持哪些」，
        同时告诉你把它放到「卡牌 / 遗物 / 药水」页的「效果」列表里（那边支持**全部**种类）。
        以前这一档只在生成的代码里留一行注释 —— 生成、编译、进游戏全都不报错，就是没反应，
        「给召唤物上 buff 不生效」就是这么来的。
        节点图现在支持：造成伤害 / 获得格挡 / 抽牌 / 获得能量 / 回复生命 / 失去生命 / 获得最大生命 /
        获得金币 / 获得额外资源量 / 施加·扣除状态 / 临时增益 / 翻倍状态层数 / 清除指定状态 / 清除全部减益 /
        禁止获得格挡 / 击晕 / 结束回合 / 生成卡牌 / 消耗卡牌 / 丢弃卡牌 / 升级卡牌 / 变化卡牌 / 复制卡牌 /
        从三摞各拿牌到手牌 / 预见 / 获得药水 / 获得卡牌奖励 / **给伙伴施加状态**。
      → 「**给伙伴施加状态**」在节点图里的目标由【对象】模块决定：
        指定召唤物 = 按名称找那一只（找不到退回第一只）；全部召唤物 = 逐只都加；没接【对象】= 第一只。
      → 【效果】需要选状态（施加 / 临时增益 / 翻倍 / 清除 / 给伙伴上状态）却没选时，
        报的是「还没选「状态」」—— 和「节点图没接上这个种类」是两回事，别被带偏。
      → 自定义状态上那块节点图生成端**还没接**（只有卡牌 / 药水 / 遗物的布会真的生成）：
        在布上画了东西会有一条警告，请在「触发时机」列表里配那个状态的效果。
      → **照着连一遍（「虚弱 > 3 就对全体造成 A+3 伤害，否则自己失去 5 点生命」）**：
        0. 「自定义参数 / 组」页加一个 A = 增益减益 → 选「易伤」，「从谁身上取」= 自己；
        1. 新建一张锻造卡：布上已经自动放好【触发时机】→【指向对象】，后者默认「指定单体敌人」，不用动；
        2. 在【指向对象】右边接一个【if】；
        3. 【if】左边下面那个「**条件**」口接【关系符】的「**结果**」出口，运算符选「大于」；
        4. 【关系符】的「**左值**」接【状态】（状态栏选「虚弱」），【状态】左边「归属」接【对象】（选「指定单体敌人」）
           —— 这一串读出来就是「那个单体敌人身上的虚弱层数」；
        5. 【关系符】的「**右值**」接【数值】（填 3）；
        6. 【if】的「**是**」出口接【效果】= 造成伤害：「数值」接【数值】（填 `A+3`）、
           「指向对象」接【对象】（选「**全部敌人**」）；
        7. 【if】的「**否**」出口接【效果】= 失去生命：「数值」填 5、「指向对象」接【对象】（选「自己」）。
        生成出来就是这一句：
          `if ((虚弱层数) > (3)) { 对全体敌人造成 (A + 3) 的伤害 } else { 自己失去 5 点生命 }`
        （「牌选中谁」由第 1 步那个【指向对象】决定，和「效果打谁」是两回事 —— 所以牌选一个敌人、
          效果打全体，是能同时成立的。）
      → 编辑器里：拖标题栏移动模块；空白处按住拖可以**框选**、Shift 点选、Ctrl+A 全选，
        多选之后拖任意一个会**一起移动**；选中后按 Delete 或点「删除选中」一起删。
        （标题栏右边那个 × 只删这一个模块，不会顺手把它拖起来。）
        ⚠ **【能量】是固定模块**（左上角那一块）：**不能选中、不能拖动、也删不掉**（点它只会提示一句，
        「全选」和框选都会跳过它，它的标题栏上也没有那个 ×）—— 它只负责把「当前能量 / 当前额外资源量」
        送出去给别的模块用，要改就在它自己那两栏里改（打出时消耗多少能量 / 额外资源量）。
        ⚠ **【触发时机】也是固定模块**（V0.2.128 起）：**删不掉、也不会被「全选」带走**（一块布只能有一个
        触发时机，整张图没有它就不生成）——它的标题栏上没有那个 ×，按 Delete 只会提示一句。
        它**照常能选中、能拖动**（位置还是你自己摆的），要换时机就在它自己那个下拉里换；
        积木视图的调色板里也**不给加**第二个【触发时机】。

  ── 动画 / 效果库 ──
  · 上传了待机 GIF，但提示「待机动图解不开」
      → 现在会带上**具体原因**（文件头不是 GIF / 没有全局色表 / 某一帧的数据解不出来…），照着原因排查。
        满 256 色的 GIF（绝大多数真实素材）以前会被一个色表尺寸的算法错误全体解不开，已经修好了。
      → 确认是 GIF（不是把 PNG 改了扩展名）；文件别是下载到一半的。
  · 提示「效果库为空：增益/减益列表读不到」，生成被拦住
      → 现在会在读「解包工程」读了个空时自动改用你游戏目录里的 sts2.dll（只读元数据，不加载），
        所以整合包里那种「空壳解包工程」（只有文件名、内容是空的）不会再挡住生成了。
      → 如果还是空的：到「环境自检」页看看游戏目录那一项有没有标红，或手动指定游戏安装目录。

  ── 环境与构建 ──
  · 提示「效果库为空，增益/减益列表读不到」
      → 本机没找到游戏文件。看「环境自检」页哪一项标红。
  · 提示找不到 Godot / .NET SDK
      → 到「环境自检」页：没通过的那一项右边有「选择路径…」按钮，点一下当场选好（立即重新检测）。
        如果连按钮都没有，多半是环境包没解压到程序旁边：把环境包解压成程序文件夹的同级目录后重启，
        或在「环境自检」页点「重新检测」。
  · 编译时提示找不到包（NU1101 / 连不上 nuget.org）
      → 生成工程时会自动写一份 nuget.config，把 NuGet 源指向 Godot 自带的
        GodotSharp\Tools\nupkgs，正常情况离线也能编译。
  · 双击启动器没反应 / 一闪而过
      → 屏幕会说明原因并生成「启动失败日志.txt」，常见三种：① 在压缩包里直接双击的（要先全部解压）；
        ② 只解压了启动器没解压「程序文件」；③ 被安全中心 / 杀毒拦了。
  · 双击时弹「打开文件 - 安全警告：无法验证发布者。你确定要运行此软件吗？」
      → **不是程序坏了，也不是杀毒在拦**：这个 exe **没有买代码签名证书**（发行商显示「未知发布者」），
        而 Windows 又认为这个文件「来自网络」（从浏览器下载的 zip 解开后，里面的文件会各带一份
        「来自网络」标记，运行未签名程序时就会问一次）。
      → 处理：右键那个 exe → 属性 → 最下面勾上「**解除锁定**」→ 确定；**更彻底**的做法是
        **在解压之前**右键下载来的 zip → 属性 → 解除锁定，再解压（这样里面每个文件都干净）。
        已经解压出来的一整份也可以批量解除：
          PowerShell：`Get-ChildItem -Path "解压出来的文件夹" -Recurse -File | Unblock-File`
      → 直接点「运行(R)」也是安全的（那就是你刚解压出来的程序本身）。
  · 「安装目录」到底该选哪个文件夹？（装完游戏里看不到模组，多半是这里选错了）
      → 要选游戏目录下面的 **mods 文件夹**，例如
        D:\Steam\steamapps\common\Slay the Spire 2\mods
        （本体第一次装模组时会自己建这个目录；目录还不存在也可以先填，构建时会自动创建）。
      → 选错的典型症状：模组没出现、或 dll 被丢到游戏根目录里。
      → 点「浏览…」选中游戏根目录（或 data_sts2_xxx 目录）时，工具会自动改成它下面的 mods；
        启动时也会自动找一遍游戏目录并填好。
  · 点「生成」报错说「卡池里奖励能抽到的卡只有 N 张，至少要 3 张」
      → 本体发奖励时会「互不重复地抽 3 张」，所以「加入卡池」的卡至少要 3 张（且不能都是 Basic，
        Basic 不参与奖励）。按报错里的张数多勾几张即可；「卡牌」页的校验提示里也能提前看到。
  · 「一键构建」报「项目文件不存在（MSB1009）」
      → 构建用的是刚生成出来的那个工程目录，「打开输出目录」也是同一套规则；
        确认「输出目录」没被改成别的地方即可。存档名和模组 ID 不一样是正常的。

  ── 美术资源 ──
  · 上传图片后存在哪、什么时候生效？
      → 选完图片**立刻写进当前存档**（角色美术槽位、逐张卡面、遗物 / 药水 / 状态图标、
        额外资源量图标都一样），状态栏会显示「已写进存档：xxx.json」；清除图片与撤回也立刻落盘。
      → 上传文件按**原尺寸直接使用**（程序不缩放），尺寸按「美术资源」页每个槽位的提示准备。
        文字里内联的小图标会自动缩到本体规定的尺寸（能量 24×24 / 图集精灵 74×74 / 能量球 128×128），
        所以上传大图不会撑坏卡牌描述。
      → **预览会按「游戏里的显示区域」画一块黑底**（普通卡 / 诅咒的卡面是 1000×760，各槽位按本体原图尺寸）：
        上传图比例和它不一致时，游戏里会按比例缩放居中、多出来的那圈就是黑边 ——
        预览里那块黑底就是它，下面还会写清「图偏宽 → 上下留黑边 / 图偏窄 → 左右留黑边」和大概留多少。
        不想有黑边就把图裁成那个比例（或直接用推荐尺寸）。
      → **先古卡的卡面是竖的**：本体先古卡用的是 `%AncientPortrait` 那块竖框（598×842，而且直接拉满、不保持比例），
        本体所有先古卡素材都是 **606×852**。所以选到先古卡时预览框会变成 606×852 的竖框、按「拉满」显示
        （比例不对能直接看到变形），上传按钮写「建议 606×852 竖图」，说明也改说「会被拉变形」而不是「留黑边」；
        生成占位图时先古卡同样走竖图（勾「用本体素材占位」= 用本体的 ancient_beta.png）。普通卡 / 诅咒不受影响。
      → 改完要重新「① 生成工程」+「② 一键构建 + 安装」，游戏里才会看到新图。
  · 勾了「未上传的槽位用本体（铁甲战士）素材占位」，游戏里是什么效果？
      → 四个角色场景直接借本体铁甲战士的场景（真骨骼动画）：
        · 战斗立绘 = 本体 scenes\creature_visuals\ironclad.tscn
        · 商店立绘 = 本体 scenes\merchant\characters\ironclad_merchant.tscn
        · 篝火立绘 = 本体 scenes\rest_site\characters\ironclad_rest_site.tscn
        · 选人背景 = 本体 scenes\screens\char_select\char_select_bg_ironclad.tscn
        · 其余未上传的槽位（头像、选人立绘、地图标记…）用本体的图。
        **发布模组前请取消勾选并提供自己的美术**；不勾则用工具自带的中性占位图。
      → 注意：`animations\characters\ironclad\*.png` 那几张是 Spine **图集页**，不是单张立绘，别当立绘传。
  · 多人联机宝箱房那只手 / 那句「开抢！！！」能换成自己的吗？
      → 能。「美术资源」页最下面有五个槽位：**手势（选择）/（剪刀）/（石头）/（布）/（拿取）**，
        再下面是一个「宝箱房那句催促文本」输入框。
        · 前四个是**本体按固定路径读**的一整套（`images/ui/hands/multiplayer_hand_<角色>_<手势>.png`）：
          本体就是 422×1200 的竖图（手从画面下沿伸进来），建议同尺寸等比、透明背景。
          只传一部分的话，没传的那几张会用占位图，联机进宝箱房时那只手会一半是你的一半是占位 ——
          **要么四张都传，要么都不传**（配置检查会提醒）。
        · 「拿取」是**本体没有的第五张**：本体拿遗物是「布（伸手）→ 石头（拳头攥住）」两步糊出来的
          （`NHandImage.GrabRelic`）。传了它，生成时会多写一张 `<角色>_grab.png` 和一个补丁
          （`cs/TreasureGesture.cs`）：只在我方角色的这一局里，把「攥住遗物」那一下换成你的图；
          不传就保持本体表现（攥住时用你传的「石头」那只拳头）。
        · 催促文本留空 = 沿用本体那句「开抢！！！」；填了就只在你玩这个角色的这一局里换掉那一行字
          （**不覆盖本体的本地化键**，所以别的角色、联机另一边的玩家看到的还是他们自己的那句话）。
        · 宝箱房只在**联机**出现，单机看不到这处美术 —— 四张手势不传也不会在单机里发现，
          等联机时才发现那只手是色块就晚了（勾「用本体素材占位」可以先用铁甲战士的手顶着）。
  · 「选人界面背景大图」要传多大？
      → **横图，建议 1920×1080 或更大**（和游戏画面同比例）。这张图整屏铺满、保持比例居中，
        传竖图会左右留黑边。留空则用「静态立绘」那张图当背景。
  · 状态 / 遗物图标显示成紫色「缺图」占位（日志里 Missing sprite 'xxx' in power_atlas / relic_atlas）
      → 本体取图标是按 Id.Entry 拼路径：先查图集精灵，查不到再回退到另一条路径 ——
        状态回退到 images\powers\<状态>.png，遗物回退到 images\relics\<遗物>.png。
        生成时两条路径的文件都会写；传了图标后重新生成 + 构建安装即可。
  · 同时装了两个自己做的角色，其中一个的**能量图标没了**（日志：Missing sprite 'card/energy_xxx' in ui_atlas）
      → 已修：以前每个模组各带一份「图集精灵表」`ui_atlas.tpsheet`（本体 102 条 + 自己那条），
        而同一个路径只有一个能生效（后加载的模组盖掉前面的），于是另一个角色的能量图标就查不到、
        游戏里直接消失（本体这套加载器对 ui_atlas **没有**回退路径）。
        从这一版起生成器**不再写任何 .tpsheet**，改成生成 cs/AtlasSpritePatch.cs：
        运行时把能量 / 药水图标直接供给本体的图集管理器，文件名每个模组都不同，装几个都不会互相覆盖。
      → 所以：把两个角色都**重新生成 + 构建 + 安装**一次即可（只重装旧的没用，补丁在模组 dll 里）。
  · 遗物栏里那个「额外资源量」的隐藏遗物显示紫色缺图（日志：Missing sprite 'xxx_extra_resource_relic'）
      → 已修：没上传额外资源量图标时，也会用本体的星星图标给它写一份回退图（以前这种情况直接跳过）。

  ── 逐帧动画（把 GIF 拆成帧动画）──
  · 「动画」页能干什么
      → 把 GIF 动图拆成一帧一帧，替换**战斗 / 篝火 / 商店**这三处的角色立绘；
        其它美术槽位（头像、选人立绘、地图标记、能量图标、模组预览图…）完全不受影响。
      → 拆帧是在**生成时**做的（游戏引擎读不了 GIF）：模组里只有裁好的帧图 + Godot 的帧动画资源，
        不用装任何解码器；帧图在游戏里会被缩放，所以顺便把底抠干净、边裁好。
  · 7 个动作怎么传
      → 「待机（循环）」**必须有** —— 其它动作没传时都会退回它，没待机等于整条动画都不生效；
        攻击 / 施法 / 受伤 / 死亡 / 篝火 / 商店都是可选，没传只会在日志里写一行「[提示] … 退回待机」。
      → 死亡素材是「播完定格在最后一帧」，其它非循环动作播完回待机。
      → 每个槽位的缩略图只是**第一帧**（工具界面播不了动图，真正逐帧播放的是游戏里）。
  · 素材怎么调
      → 7 个动作共用同一个裁剪框（默认取所有动作所有帧的并集，这样换动作时角色不会跳位置）；
        想自己控制就填「手动裁剪框 x0,y0,x1,y1」（x1/y1 是**开区间**，留空 = 自动）。
      → 白底 / 纯色底素材记得勾「抠背景（把纯色底变透明）」；轮廓外留了一圈浅色边的勾「剥掉浅色描边」
        （它会吃掉不透明像素，剥得太多时工具会整块还原保护素材）。
      → 像素画保持「最近邻过滤」勾上；「缩放 / Y 偏移」留 0 就是自动（按静态立绘的高和脚的位置算）。
      → 篝火和商店默认会先播你传的专属动画、过一会儿被本体切回待机；想一直保持就勾
        「篝火 / 商店里保持专属动画（不切回待机）」。
      → 播放快慢用「播放速度系数」调（1 = 原速，2 = 双倍速）；「每帧时长秒」留 0 = 用动图自己的延时。
  · 怎么确认素材没问题
      → 点「预览动画计划」：工具会**真解一遍动图**（不写任何文件），把裁剪框 / 每个动作的帧数 /
        每帧时长 / 缩放 / 位置 / 提示行都列出来 —— 待机解不开之类的问题在这里就能看到。
      → 「清除」清错了可以点「撤回清除」（拿回最后一次清掉的那个 GIF）。
  · 不勾总开关会怎样
      → 生成结果和以前完全一样（不写帧图、也不写逐帧动画的代码）；槽位里留着的 GIF 不会生效，
        界面会给一条橙色提示，并提供「一键启用逐帧动画」。
      → 老存档（以前的 JSON 里没有这一档）打开就是「没启用」，直接用即可。
  · 改了动画设置 / 换了 GIF 之后
      → 要重新「① 生成工程」+「② 一键构建 + 安装」，游戏里才会变。
      → 注意：**回读不还原这一档**（GIF 的源路径不在产物里），动画设置只存在存档 JSON 里；
        想改动画请回「动画」页改，别指望从工程反推。

  ── 额外资源量（计数器 / 图标 / 名字）──
  · 「额外资源量」怎么用
      → 到「额外资源量」页：设初始数量、是否跨战斗继承、是否始终显示计数器；
        还能上传一张自己的图标、填一个中文显示名，把血条下方那个资源计数器换掉
        （卡面费用图标会一起换，左侧能量球也会换成你上传的能量图标）。
      → 这个名字会用在**所有**文本里：计数器下方、鼠标悬停提示（标题 + 描述）、卡面描述
        （「获得 2 点冰附魔」）、条件说明（「拥有冰附魔至少 4 点」）、状态触发时机的说明
        （「花掉冰附魔后」）、那个隐藏起始遗物的名字与 flavor。没填就退回通用说法「额外资源量」。
      → 悬停提示的描述按你配的开场数量 / 是否继承 / 有没有消耗它的牌自动写：
        「冰附魔：每场战斗开始时获得 3 点（战斗结束清零）；打出需要消耗它的牌时会扣除，数量不足时无法打出。」
      → 卡牌上「获得 N 点额外资源量」支持**升级增量**：升级后卡面显示升级后的数字
        （用本体的 StarsVar + 卡面 {Stars:diff()} 占位符，升级后由本体自己算）。
      → 注意：计数器用的是本体「星星」这套资源机制，位置由本体决定。
      → 那只**载体遗物**（自动生成的隐藏起始遗物，负责开场发资源量 / 记跨战斗继承）在
        **同一页（「额外资源量」页）左栏底部那块「额外资源量遗物」**里看得见（写着它的类名 + 稀有度，
        并注明它不在遗物列表里）。那块里有一个勾选框「**在游戏中隐藏（不显示在遗物栏里）**」：
        · 不勾（默认）= 和以前一样，它占遗物栏里的一格；
        · 勾上 = 生成一个补丁（`cs/HideCarrierRelic.cs`），让它在遗物栏里**看不见** —— 这只是**视觉隐藏**（遗物栏照常把它建出来，只是那个格子不可见；「新获得遗物」的飞入动画不用管它（只改 icon 的透明度/位置/缩放、不碰可见性，父节点不可见就什么都看不到）），所以**发放资源量 / 跨战斗继承照常生效**，存档也兼容（改完要重新「生成」才生效）。为什么不干脆「不给它那一格」：本体没这个接口（遗物栏是遍历 `Player.Relics` 逐个建的），`RelicModel` 上也没有「别显示我」的虚属性可覆写；硬跳过原方法的写法（V0.2.113~V0.2.137）会让遗物栏节点列表比 `Player.Relics` 少一项 → 之后再获得任何遗物时索引越界、游戏**卡死**（V0.2.138 修的就是这条）。
      → 它挂的效果在**这一页右栏的「效果栏」**里（可加 / 删 / 撤回，每条效果直接在列表行里编辑，
        右下角能选那一条效果自己的条件）—— 触发时机固定是「战斗开始时」，只有**这一份**效果数据。
      → 这一页的页头叫「**额外资源量**」（以前叫「额外资源量/状态」）。
  · 「数量上限」怎么算？
      → 同一页的「数量上限」填 0 = 不限（和本体一样）；填 N = 涨到 N 就不再增加，
        超出的部分**直接不加**（不是先加满再扣掉，卡面/播报的数字就是实际拿到的）。
      → 本体自己没有上限这个概念（`PlayerCmd.GainStars` 直接往上加），所以这是我们加的：
        生成时多写一条 Harmony 前缀，把每次要加的增量夹到「还能装多少」。
      → **上限可抬**：效果种类里的「增加额外资源量上限值」给当前战斗加一层隐藏加成，
        实际上限 = 页面填的基础值 + 这个隐藏状态的层数；战斗结束清空（基础值不受影响）。
        所以「战斗中上限 9」这种设计：页面填 7，再放一张「上限 +2」的牌。
      → 只填了页面上的上限、存档里没有「增加额外资源量上限值」这个效果时，不会生成那个隐藏状态
        （省掉一个没人看的状态）；反过来只用了效果、页面上限填 0 时，上限就从 0 起加
        （等于「基础不限 + 战斗中额外能多拿多少」，所以想真封顶一定要填页面上的上限）。
  · 「增加额外资源量上限值」这个效果放哪都行
      → 卡牌 / 遗物 / 药水 / 节点图【效果】里都能选；数值填正数（抬多少层），填 0 也能配但没意义。
      → 它长的是隐藏状态的层数，不出现在状态栏里（不想让玩家看见一个莫名其妙的状态）。
  · 上传的图标 / 能量图标在游戏里怎么生效？
      → 资源计数器与卡面资源图标：按「贴图是不是本体那颗星星」识别并替换，只改你自己角色的战斗界面，
        别的角色不受影响；每帧兜底一次，别的模组把贴图改回去也会再贴回来。
      → 能量图标：上传后卡面费用图标（含文字内联小图标）用你的图，**左侧那个能量球也直接换成你的图**
        （缩到 128×128，本体另外 4 层球贴图隐藏，粒子光效按你的图着色）。
      → 日志里会写两行诊断：「额外资源量：计数器检查 → 图标已加载/没加载，角色=…，命中节点=N」、
        「额外资源量：左侧能量球用的是场景 = …」。看不到效果时把这两行发出来即可定位。
      → 改完要**重新生成并重新安装**（补丁在模组的 dll 里，只重新打包没用）。

  ── 卡牌与效果 ──
  · 卡牌的「**类型 / 稀有度**」下拉里显示的是**中文**（V0.2.136，用户要求「将类型和稀有度的英文替换成中文」）：
      类型 = 攻击 / 技能 / 能力 / 状态 / 诅咒 / 任务；稀有度 = 基础 / 普通 / 罕见 / 稀有 / 先古 / 状态 / 诅咒。
      中文**照抄游戏本体**（本体的 CARD_TYPE.* / CARD_RARITY.*），**档位一个都没加**。
      **存档里存的、生成代码里写的还是英文**（`CardType.Power` / `CardRarity.Uncommon`）——
      所以老存档读得回来、生成结果一个字节都没变，只有界面上那几处显示换了中文。
      ⚠ 和遗物 / 药水页的措辞**故意不同**（那两页是「常见 / 罕见 / 稀有」，遗物还有「初始」）：
        这里按本体的卡牌稀有度走的是「**普通** / 罕见 / 稀有」（Basic = 「基础」）。
  · 「添加效果」新增的那条效果，**数值和升级增量都是 0**（免得加一条别的效果时被默认的 6/+3 带着走）；
    选好「效果种类」后自己把数字填上，填漏了生成前的检查会提示。
  · **「升级增量」哪些效果有用**（有人问过「升级卡牌的升级增量没用吗」）：
      · 有用的：带数字的那些 —— 造成伤害 / 格挡 / 抽牌 / 回复生命 / 消耗卡牌 / 丢弃卡牌 /
        **升级卡牌（战斗内从手牌 / 牌堆挑）** / 变化卡牌 / 预见 / 获得额外资源量…（卡面写 `{…:diff()}`，
        升级后数字跟着变）；
      · **没用的**：数字只是「循环几次」或者根本没数字的那些 —— **升级卡牌（全局）/ 获得卡牌（全局）/
        变化卡牌（全局）/ 删除卡牌（全局）**、获得卡牌奖励、给予卡牌关键词、获得药水、结束回合、
        额外获得一回合、回合结束时自动打出。填了也不生效，**配置检查会警告**让你清成 0。
      · 锻造卡（有节点图）的【效果】模块**没有「升级增量」这一栏**：「升级后变强」的做法是
        给「升级后」那块布单独画一遍（右上角有「一键复制『升级前』的内容」，复制完改改就行）。
  · **「填入参数…」里的名字就是生成代码里声明过的变量名**（`{Damage:diff()}` / `{Cards:diff()}` /
    `{IntangiblePower:diff()}`…）。**不要自己手写 `{Value:diff()}`** —— 生成端从来不用 `Value` 这个名字，
    写上去游戏里取不到变量，会**原样把 `{Value:diff()}` 印在卡面上**（踩过）。
    同一张牌上同种效果用了多次时，第 2 / 3 / 4 个会自动起别名（`Cards2` / `Damage2`…），
    按「填入参数…」菜单给的那个名字写就对了。
  · **卡面 / 自定义描述里能不能写「牌堆现在有几张」？**
      → **不能（V0.2.130 起这个功能整块删掉了）**。以前「卡牌属性」那一栏有个
        「卡面显示牌堆张数（{DrawPile} / {DiscardPile} / {ExhaustPile}）」的勾选框，
        生成端会为它声明三个实时变量（`ForgePileCountVar`）—— 现在**勾选框、那三个占位符、
        「填入参数…」菜单里的三条、生成的辅助类文件全都删掉了**。
      → 老存档里勾过它的：打开**不会报错**（存档里那个字段被直接忽略），重新保存后字段就没了。
        自定义描述里已经写下的 `{DrawPile}` / `{DiscardPile}` / `{ExhaustPile}` 会**原样留着**，
        本体运行时替换不了它们，卡面上就按字面显示 —— 请到「自定义描述」里手动把那几个占位符删掉。
  · **「转化为先古卡」**（做本体那种「拾起时把牌变成先古卡」的遗物，例：古老牙齿 / 潘多拉魔盒）
      → 在**遗物**上：触发时机选「获得时」，效果种类选「转化为先古卡」，效果下面会出现**配对表**：
        · 左边选一个**「组」**（组在「自定义参数 / 组」页里新建，再到「卡牌」页把它勾给要替换的那些牌；
          自定义关键词那一组也能选）—— 来源**只用组**，没有「攻击 / 技能 / 能力」那类内置选项；
        · 右边勾**先古卡池**（本体 19 张先古卡 + 你自己做的先古卡）：这一组里每张牌按勾选顺序
          各拿一张**不同的**先古卡；
        · 先古卡勾少了（比如 5 张打击只勾了 2 张）→ 只换前 2 张，**多出来的保持原样**（不重复），
          日志里会写一行说明；想让 5 张全换就勾 5 张先古卡；
        · 升级和附魔会**跟着带过去**（和本体「古老牙齿」一致）；
        · 换完会弹本体那个「这些牌变成了这些」的预览界面（潘多拉魔盒用的是同一个）；
        · 「＋ 加一行」可以配多组（打击那行、防御那行各配各的，互不干扰）；每行右边有「删除」。
      → 只能挂在**「获得时」**：它改的是**牌组**，本体也只在拾取那一刻做（挂别处生成前的检查会报错）。
      → 先古卡不会出现在战斗奖励 / 商店里（本体 `CardFactory` 明确排除 Ancient），
        所以只能靠这只遗物（或你自己的效果）拿到 —— 这是本体设计。
  · **「转化为先古遗物」**（本体「欧洛巴斯之触」那种：拾起时把身上的一个遗物换成另一个）
      → 在**遗物**上：触发时机选「获得时」，效果种类选「转化为先古遗物」，效果下面两栏：
        · **要换掉哪个遗物**：`不限（身上第一个遗物）` / `只换初始遗物`（本体欧洛巴斯之触的判据）/
          `只换「某只本体遗物」`（把本体全部遗物列出来让你挑）；
        · **换成哪只遗物**：可以打字搜索 —— **你自己做的遗物** + **本体全部遗物**都在里面。
      → 行为：只换**第一个**匹配到的（本体也是 `First`），换出来的那只**占原来那只的位置**；
        身上没有符合条件的遗物时什么都不做（游戏日志里会写一行）。
      → 同样只能挂在**「获得时」**。想把「自己那只」换成先古版，就在右边选你自己造的那只。
  · 「复制」一张卡 = **整张照抄**：自定义关键词、卡牌关键字（消耗 / 虚无 / 固有…）、标签、升级后关键字、
    每条效果的全部设置（数值、升级增量、召唤物 / 伙伴、概率生效、条件）都会跟着复制，只有名字加「·改」、
    英文类名留空（自动编号）—— 复制出来的牌和原卡完全一样，可以直接改数值做变体。
  · 效果可以加条件（每条效果各自一份：效果栏 → 选中一条效果 → 面板最下面）
      → 例如「本回合还没打出过这张牌」「手牌里只有攻击牌」「生命值低于 50%」「拥有某状态至少 N 层」
        「拥有额外资源量至少 N 点」「每场战斗只触发一次」等。
      → 「指向对象」：状态层数 / 生命值百分比这类条件要选看谁 —— 自己 / 指定敌人 / 任意一个敌人 /
        全部敌人（「全部敌人」= 每个活着敌人都得满足；「任意一个敌人」= 有一个满足即可；
        「指定敌人」= 这张牌打出去时玩家选中的那个目标）。
      → 「指定敌人」只能用在【这条效果的条件】里（那时玩家已经选好目标）。勾了
        「条件不满足时这张牌打不出去」就用不了它 —— 判断能不能打出时玩家还没选目标，校验会提示。
  · **「消耗任意张手牌」怎么做**（本体观者的「净化」那种）
      → 效果选「消耗卡牌」/「丢弃卡牌」/「升级卡牌」/「从某一摞拿牌到手牌」时，下面会多一栏 **「取几张」**：
        · **恰好 N 张**（默认）= 必须选满 N 张；
        · **最多 N 张** = 可以少选（本体「净化」那种，选牌界面会出现确认键）；卡面写「最多 {Cards:diff()} 张」，
          升级增量照旧生效（想「升级后能多选」就用这档）；
        · **任意张** = 想选几张都行（上限 999999999，和本体一样），卡面写「任意张」，不显示数字；
      → 「取牌方式」选**随机**时没有选牌界面，所以「最多 / 任意」会被当成「恰好 N 张」——
        生成前的检查会提醒你（想要能少选就把取牌方式改成「自己选」）。
      → 卡牌：勾「条件不满足时这张牌打不出去」→ 条件进本体的 IsPlayable（卡面描金边）；
        不勾 = 能打出，但只有这一条效果不生效，其它效果照常执行。条件说明会写在这条效果的描述后面。
      → 遗物：「条件选项（整只遗物）」是整只遗物的触发条件（不满足时整个遗物不触发）；
        效果栏里每条效果还能有各自的条件（右栏**右下角**那块）。
      → 药水：效果栏右下角那块同样是「单条效果的条件」，能用遗物那一档的全部条件
        （生命值 / 手牌数 / 拥有某状态 / 每 N 回合触发一次 / 每场战斗只触发一次…）。
        ⚠ 药水**不支持**「概率生效」和「命中次数」这两栏：勾了 / 填了不会生成，生成前的检查会明确提示你；
        「卡牌时机」那一档也不能用在药水上。
  · 条件「卡牌时机」（被消耗 / 被生成 / 被保留 / 被丢弃 / 被变化 / 被给予自定义关键词）
      → 条件里选「卡牌时机（这张牌被消耗 / 被丢弃 / 被保留…时）」后，底下会多一个「卡牌时机」下拉，
        六项就是上面那六个。它和别的条件不一样：带它的效果**不在打出时执行**，而是挂到本体对应时机的
        钩子上（本体「战鼓」就是覆写 AfterCardExhausted 再判 card == this）—— 「这张牌被消耗了」这件事
        打出的时候可能还没发生（别的牌把你丢掉、回合结束时虚无…）。
      → 同一张牌同一个时机有好几条效果时会合并进同一个钩子，按顺序依次执行。
      → 只能用在【普通卡牌】上（遗物 / 药水 / 自定义状态没有「这张牌被消耗」这一说，诅咒也不行）；
        这些钩子里没有打出记录，所以不能用「打出的目标」、不能用 X 值、不能用「伙伴已经在场」类效果
        （这些校验器都会报错说明），但「召唤伙伴」照常可用。
      → 勾「条件不满足时这张牌打不出去」对它没用：效果只在该时机触发，牌本身照常能打出。
        卡面描述会写成「当这张牌被消耗时，…」这种条件句。
  · 条件填负数 = 判断反过来（只有「至少 / 至多 N」这几条支持）
      → 生命值低于 -20 → 生命值高于 20%；拥有某状态至少 -2 层 → 少于 2 层；
        拥有额外资源量至少 -2 点 → 少于 2 点；本回合已打出至少 -4 张牌 → 少于 4 张；
        手牌数不少于 -3 张 → 少于 3 张；手牌数不多于 -3 张 → 多于 3 张。
      → 卡面描述 / 生成代码里的注释 / 输入框的悬停提示都按**反向后的说法**写，校验器还会提示一句
        「填了负数 → 判断反过来：实际生效的是「生命值高于 20%」」。
      → 其它带数值的条件填负数**不反向**：按绝对值用，校验器会警告一句。
  · 生命区间：「生命值在 N%~M% 之间」
      → 选它之后「数值 N」和「~ 数值 M（%）」两栏一起出现（别的条件只显示数值 N）。
      → 两个数都填百分比，顺序写反也没关系（60 和 30 会自动排成 30~60）。
      → **任意一个填负数 = 判断成「区间外」**：25 / 75 = 生命在 25%~75% 之间；
        -30 / 60 = 生命低于 30% 或高于 60%。
      → 「指向对象」照常可用；描述会写「生命值在 30%~60% 之外（区间外）」，校验器也会提示一句。
  · 抽牌堆被打乱洗过牌（像本体先古遗物「大～抱抱」）
      → 条件里有两条：「抽牌堆本回合被打乱洗过牌」「抽牌堆本场战斗被打乱洗过牌」。
        这两条问的是「洗过没有」，而本体根本没有这个状态 —— 所以工具会**自动多生成一个文件**
        （<角色>ForgeShuffleTracker：记录器 + 打在 Hook.AfterShuffle 上的补丁），
        记下「谁、哪一回合、洗了几次」供条件查询。用到这两条时才会生成；
        生成完要**重新构建并重新安装**（补丁在模组 dll 里）。
      → 遗物的「触发时机」里也有「抽牌堆打乱洗牌时」：直接覆写 AfterShuffle，**在洗牌那一刻**触发，
        生成的效果里只认「自己洗的牌」（和大～抱抱一样）。
      → 注意（都是本体机制）：**开局的洗牌不算**（开战那次走 ModifyShuffleOrder，不触发 AfterShuffle），
        战斗结束 / 收尾阶段也不算。「本场战斗洗过」换一场战斗自动重新算。
  · 遗物想要「拿到的那一刻就生效」（像本体「好吃饼干 / 磨刀石 / 爪子」）
      → 遗物页的「触发时机」里选「**获得时**」：拿到这只遗物的那一刻触发一次
        （本体钩子 AfterObtained）。需要选牌 / 抽牌的那些效果（生成卡牌 / 抽牌 / 卡牌奖励…）
        在这个钩子里也能用 —— 工具会照本体的做法自己造一个选牌上下文。
        「获得卡牌奖励」放在这里是**当场弹 N 选一**、选中即进牌组；
        想要「打赢后结算界面多一条奖励」请把触发时机换成「战斗胜利时」。
  · 遗物想「某个状态涨到第 N 层的那一刻」干点什么
      → 遗物页「触发时机」选「**某个状态层数到达 N 层时**」，下面会多出两栏：
        · 「**盯哪个状态**」：只盯某一个状态（直接打字搜索）；**留空 = 自己身上任何状态**跨过 N 层都触发。
        · 「**到达 N 层**」：填 N。判的是「**之前不到 N、变化之后到了 N 或更多**」那一下 ——
          已经是 N 层再加一层**不会**重复触发；一次上 3 层（3→6）也只算跨过一次。
        本体这条钩子任何单位的状态层数一变都会调（敌人的 / 队友的），工具生成时会先判「是不是自己身上的」。
        留空「盯哪个状态」也可以再配效果自己的条件（例：条件「拥有某状态至少 N 层」）去进一步筛选。
  · 「触发时机上的数值」（每 N 次 / 每 N 点 / 数值 ≥ N）**填在哪？**
      → 就在**「触发时机」那个下拉的正下面**（遗物页在「遗物属性」里；状态页在「触发时机」那一块里、
        每条时机自己的下方）。这栏**只在有数值可填的时机上才出现** —— 选了战斗开始/结束、
        回合开始/结束、获得遗物时这种没有数值的时机，它整栏都不显示（下面那句灰色小字会写
        「这条触发时机暂时没有数值可填」）。
        标题跟着时机换说法：
          · 打出一张牌后 / 消耗一张牌后 / 丢弃一张牌后 / 抽到一张牌后 / 生成卡牌时 →
            「**每累计几次触发**」+ 一行「**统计范围**」（本回合 / 本场战斗）；
          · 一个敌人死亡后 → 「**每累计几次触发**」（本场战斗内计数，工具自己数）；
          · 花掉能量后 / 花掉额外资源量后 → 「**花掉多少点触发**」+ 「统计范围」；
          · 受到伤害后 / 造成伤害后 → 「**伤害至少多少才触发**」；
          · 自己失去生命时 / 获得格挡后 → 「**…至少多少才触发**」。
        留空 / 填 0 = 老行为（每次都触发）；填 N 就是上面的意思。输入框下面那行灰色小字随时告诉你
        现在是什么状态（例：「现在每累计 3 次触发一次，范围 = 本回合。」）。这一栏只能填**数字**
        （公式只做在卡牌上）；遗物和状态两边是同一套；状态可以配好几条时机，**每条各有自己的一份数值**。
        ⚠ 老版本（V0.2.106 及以前）**在编辑器里换完触发时机，这一栏不会当场出现** ——
        得重新在左边列表点一次遗物 / 状态才看得到（V0.2.107 修好了，现在换完立刻出现）。
      → 「某个状态层数到达 N 层时」的 N 不在这一栏，在它自己的「**到达 N 层**」那一行（见上面那条）。
  · 状态**被移除**的那一刻想干点什么
      → 遗物页 / 状态页的触发时机里选「**某个状态被移除时**」，下面同样有「**盯哪个状态**」：
        留空 = 自己身上任意状态被移除都触发，填了就只认那一个。层数掉到 0 自然消失、
        被「清除状态」直接清掉，都算「被移除」。
      → ⚠ 这条**不是**本体现成的钩子（本体只通知那个状态自己，遗物 / 别的状态都收不到），
        所以工具会自己给 `PowerModel.RemoveInternal`（本体所有移除的唯一出口）打一个补丁转发 ——
        **用到这条时机时才会多生成一个 `cs/PowerRemoval.cs`**，没用到的存档一个字节都不多。
  · 遗物 / 状态的触发时机现在是**同一套**（名字也统一了）
      → 遗物页的触发时机里现在也有：打出一张牌后 / 消耗一张牌后 / 抽一张牌后 / 弃掉一张牌后 /
        自己失去生命时（每一下）/ 自己获得格挡后 / 一个敌人死亡后 / 敌人回合开始时 / 敌人回合结束时 /
        敌人受到伤害后 / 敌人造成伤害后 / 敌人获得格挡后 / 某个状态层数变化后；
        状态页那边也补了「获得金币时」「抽牌堆打乱洗牌时」——两边基本一模一样（同一个时机同一个名字）。
      → 还只在遗物侧的三条：**获得时**（遗物才有「拿到的那一刻」）、
        **战斗结束时（房间结算之前）**（状态那边「战斗胜利后」就是同一个钩子）、
        **某个状态层数到达 N 层时**（状态那边用「层数变化后」+ 条件「刚好达到 N 层」做到）。
      → 老存档 / 老工程照旧能读（改名前写进工程的那句注释也认得回来）。
      → 卡牌没有跟着改：卡牌的时机是「打出的那一刻」+「卡牌时机」（被消耗 / 被生成 / 被保留 / 被丢弃 /
        被变化 / 被给关键词）。想要卡牌也能选「战斗开始时」这类时机，说一声我另做。
  · 「命中次数 / 对群数」填了没反应？
      → 这个数字生成端**只有三种场合**会读：① 造成伤害（多段）；② 作用对象 =「随机敌人」（挑几个敌人）；
        ③ 几种「伙伴攻击」。其它种类（失去生命 / 单体上状态 / 单体击晕 / 抽牌…）不看它 ——
        所以现在那一栏在这些种类上**自动收起**，填了的话生成前会**报错**（公式）或**警告**（固定数字）说清不生效。
        想「整条效果重复几遍」请填「**生效次数**」（那个所有种类都生效）。
      → 这里**没有**单独的「对群数」字段：从头到尾就只有这一个数字 ——
        在「造成伤害」上它是**命中次数**（多段攻击打几下），在「随机敌人」上它是**挑几个目标**。
        V0.2.131 起那三个「= X」勾选框（数值 / 生效次数 / 命中次数·对群数）也从界面上撤掉了，
        改成在公式框里写 `X`（见下面「X 费用卡牌怎么配」那一条）；
        V0.2.132 起卡牌链上那一行的标题就叫「**命中次数（公式）**」（和固定数字框并排），
        公式框留空 = 用左边那个固定数字。
      → 遗物 / 药水 / 状态 / 锻造链上那一行的老标题「对群数/命中次数」**保持原样**（这一版只重排了卡牌链）。
  · 遗物 / 自定义状态还有这四条触发时机（打人每一下 / 花能量 / 花资源量 / 生成卡牌）
      → 遗物页新增三条、自定义状态页新增一条，都对着本体钩子做的：
        · 「**造成伤害时（每一下）**」（遗物）= AfterDamageGiven：**每一下命中都触发**（连击就是多次），
          判据是「这次伤害是你造成的」。想「一次攻击只算一次」参考「受到攻击后」那种思路。
        · 「**每消耗一个能量**」（遗物）= AfterEnergySpent：按**点数**各触发一次
          （本体给的 amount 是「这一张牌一共花的」能量，X 费牌 = 当前全部能量）；
          0 费不触发，也只认「你自己花的能量」（联机时别人打牌不会触发）。
        · 「**每消耗一个额外资源量**」（遗物）= AfterStarsSpent：同上，按点数各触发一次。
        · 「**生成卡牌时**」（遗物 + 自定义状态）= AfterCardGeneratedForCombat：
          **每生成一张触发一次**，而且只算「你自己生成」的（敌人塞给你的状态牌不算）。
        这四个钩子本体都**没给**「选牌上下文」，所以需要它的效果（造成伤害 / 抽牌 / 施加状态…）
        工具会照本体的做法自己造一个（战斗里专用，不会卡住）；不需要的效果不会多造。
  · 想要「某个状态涨到第 5 层的那一刻」干点什么
      → 自定义状态的触发时机选「**某个状态层数变化后**」，再给那条效果加条件
        「**某状态层数刚好达到 N 层**」（想盯哪个状态就在条件里选）：
        判的是「这次变化**跨过**了 N 层」（之前不到、现在到了）；已经是 N 层再加一层不会重复触发。
        · 想「只要现在有 N 层就生效」是另一条条件：「拥有某状态至少 N 层」（卡牌 / 遗物 / 状态都能用）。
        · 这条条件**只能**挂在「某个状态层数变化后」上（别的钩子没有「这次变了多少」这个信息），
          挂错地方生成前的检查会报错并告诉你换哪一条。
  · 「受到伤害时」为什么一次攻击触发了好几次？
      → 遗物页和自定义状态页的触发时机里有**两条**长得很像、但语义不同：
        · 「**受到伤害时（每一下）**」= 本体钩子 AfterDamageReceived，**每一下伤害都触发一次**。
          本体的敌人攻击很多是多次连击（意图上写着「1 点 × 5 下」），
          所以一次「造成 5 点伤害」的攻击会触发 5 次 —— 这是本体语义，本体的「原体黏土」等遗物也是这个行为。
          这一条会判「全被格挡 / 0 伤害的那一下不算受到伤害」，还会排掉**「失去生命」那种掉血**：
          血祭 / 献祭代价 / 放血 / 中毒（本体 `DamageProps.cardHpLoss` = 穿盾 + 无来源加成）**不算「受到伤害」**，
          要接它们请用「**自己失去生命时**」那条时机。
        · 「**受到攻击后（连击只算一次）**」= 本体钩子 AfterAttack，**一次攻击的所有命中都结束之后只触发一次**，
          所以「1 点 × 5 下」也只算一次。判据是这一次攻击真的打到了你身上。
          注意它只认「攻击」：中毒、事件掉血这类不是攻击的伤害不会触发它（那种用上面那条）。
      → 另外：自定义状态里「每一下」×「生效次数 = 本状态的层数」会**相乘**
        （敌人的一次 5 连击 × 5 层 = 一次攻击执行 25 次），生成前的检查会把算式写出来提醒。
  · 「消耗卡牌 / 变化卡牌 / 丢弃卡牌」想从抽牌堆 / 弃牌堆选
      → 每条「消耗卡牌」「变化卡牌」「丢弃卡牌」下面有「从哪里选牌」下拉：
        手牌（本体默认）/ 抽牌堆 / 弃牌堆 / 消耗牌堆 / **牌顶**。
        手牌走本体 CardSelectCmd.FromHand；抽牌堆 / 弃牌堆走 CardSelectCmd.FromCombatPile
        （本体「充能 / 净化 / 降灵」选抽牌堆，「全息影像 / 头槌 / 挖掘 / 宇宙冷漠」选弃牌堆）；
        **「牌顶」= 抽牌堆最上面那张，直接拿走 —— 不弹选牌界面、也不随机**
        （要 N 张就从上往下依次拿；本体抽牌就是取抽牌堆的第一张，「预见」看的也是前 N 张）。
        「随机」模式下就是从那一摞里随机抓，描述也会跟着写成「自己选从弃牌堆消耗 1 张牌。」
        「丢弃卡牌」只有 手牌 / 抽牌堆 / 牌顶 三项（弃牌堆里的牌本来就在那儿，再丢一次没意义）。
  · 想把牌「放到某一摞」（含**牌顶**）
      → 效果种类选「**放置卡牌（数值 0 = 这张牌自己）**」，配两个下拉：
        · **放到哪一摞** = 手牌 / 抽牌堆（牌堆底）/ 弃牌堆 / 消耗牌堆 / **牌顶**（抽牌堆最上面）；
        · **从哪里选牌** = 手牌 / 抽牌堆 / 弃牌堆 / 消耗牌堆 / 牌顶（数值 ≥ 1 时才有意义）。
        · **数值 0 = 把这张牌自己放过去**（只有卡牌上有「这张牌」；遗物 / 药水填 0 会被报错拦住）；
        · **数值 ≥ 1** = 从「从哪里选牌」挑 N 张（自己选 / 随机 / 牌顶）再放过去；
        · 生成的还是本体同一套：`CardPileCmd.Add(牌, PileType.X, CardPilePosition.Top/Bottom)`
          ——「抽牌堆」那一档是本体默认的**牌堆底**，「牌顶」才是最上面。
  · 想「丢牌」（丢进弃牌堆，洗牌后会回来）
      → 效果种类选「丢弃卡牌」：数值 = 丢几张（1~9），「选牌方式」= 自己选 / 随机，
        下面「从哪里丢弃」= 手牌 / 抽牌堆。生成的是本体 CardCmd.Discard
        （本体「杂技 / 早有准备 / 幸存者」丢手牌就是这么写的）：
        · 自己选 + 手牌 → 弹本体的选牌界面挑 N 张手牌丢掉（奇巧牌在界面里会描金）；
        · 自己选 + 抽牌堆 → 从抽牌堆里挑 N 张丢掉；
        · 随机 → 从那一摞里随机丢 N 张，那一摞不够就有多少丢多少。
        和「消耗卡牌」的区别：**丢掉的牌洗牌后会回到抽牌堆**，消耗则是这一场不再回来。
        从抽牌堆丢的那条不经手牌，所以「奇巧」这种「从手牌被丢弃时」的效果不会触发（校验器会给提示）；
        状态触发器里用不了这一条（它要选牌界面 / 卡牌上下文，校验会拦住）。
  · 想「升级」战斗里的牌 / 牌组里的牌
      → 效果种类里有两条，**不是一回事**：
        · 「升级卡牌」= 升级战斗里的手牌 / 抽牌堆 / 弃牌堆（「从哪里升级」三摞都能选），
          只影响本场战斗（战斗牌是牌组牌的克隆），要弹选牌界面，所以只能用在卡牌 / 遗物 / 药水上；
        · 「升级卡牌（全局）」= 升级**牌组**里的牌（永久、写进存档、跨战斗），
          走本体「香盒 Pomander」那套界面，卡牌 / 遗物 / 药水 / 自定义状态里都能用。
        两条都只列「能升级的牌」，升不了的牌不会出现在选择里。
  · 想「只对某一类牌动手」（比如「只消耗攻击牌」「只随机丢技能牌」）
      → 效果种类选「消耗卡牌 / 丢弃卡牌 / 升级卡牌 / 给予卡牌关键词 / 复制卡牌 / 重放卡牌 /
        回合结束时自动打出 / 从抽牌堆拿牌到手牌 / 从弃牌堆拿牌到手牌 / 从消耗牌堆拿牌到手牌 / 预见」
        里的任意一条时，编辑器里会多出一行「**范围界定（哪些牌能选）**」：
        · 候选和「生成 / 变化卡牌」的「范围限定」**完全同一份**：
          不限 / 攻击 / 技能 / 能力 / 诅咒 / 状态 / **自定义关键词：××（那一组牌）**；
        · 它**一直在**（不像「范围限定」藏在「按范围随机」那一档后面），因为
          「自己选」和「随机」两条路都按它筛：自己选时选牌界面里只列符合范围的牌，随机时只从符合范围的牌里抓；
        · 「预见」是对**抽牌堆顶那 N 张**再筛：只把其中符合范围的列进「可以丢掉」的那一批；
        · 范围里一张牌都没有时这一条效果**什么都不做**（不会弹一个空选牌界面让你干等）；
        · 卡面描述会写清范围，例：「自己选消耗 1 张手牌（只限攻击牌）。」；
        · 选「不限」= 和以前完全一样（生成的代码、卡面描述一个字都不多）；
        · 「给予卡牌关键词」「回合结束时自动打出」数值填 0（= 这张牌自己）时不会出现这一行 ——
          那一档根本不挑牌；
        · 「自定义关键词」那一组一张牌都没有时，生成前的检查会**报错**拦住。
        注意：「**变化卡牌**」没有这一行 —— 它的「范围限定」早就有含义了（那是「变出来的新卡从哪个范围抽」），
        所以不重复给。另外这几样挑牌类效果在**自定义状态的触发器**里本来就用不了（状态钩子没有
        「打出这张牌时选牌」的上下文），生成前的检查会按**效果种类**报错拦住 —— 拦的是效果种类，不是范围。
  · 想「按范围随机生成 / 变化」（比如随机一张攻击牌、随机一张诅咒）
      → 生成 / 变化那几条效果（生成卡牌 / 变化卡牌 / 变化卡牌（全局）/ 获得卡牌（全局））的编辑器里，
        往下看有「**取卡方式（生成 / 变化）**」这一行：
        · 选「按范围随机」，下面**立刻**会出现「**范围限定（随机出什么）**」，
          挑 不限 / 攻击 / 技能 / 能力 / 诅咒 / 状态 / **自定义关键词：××（那一组牌）**
          （诅咒 / 状态会把本体那两个卡池 + 你自己的卡池一起算进来，所以你做的诅咒也在候选里）；
        · 还能勾「生成 / 变化出来的卡：直接升级 / 免费打出 / 仅本回合免费 / 仅本回合升级」这四行。
          「仅本回合升级」本体没有现成 API，工具会生成一个临时状态记着这几张牌、回合结束再把它们降回来。
        · 同一栏下面还有「**生成 / 变化出来的卡：加上关键词**」下拉：选了就自动给生成 / 变化出来的卡带上它
          （第一项「（不加关键词）」= 默认，和以前的版本一模一样；候选是本体的 7 个关键词 + 你自己造的关键词）。
        注意：这两组设置**卡牌 / 遗物 / 药水 / 自定义状态的触发器**都能用（自定义状态的触发器里
        生成出来的卡同样会按范围随机、会做上面的附加处理、也会带上关键词）。默认档（指定卡、
        不加任何附加处理）生成出来的文本与以前一字不差。
  · 想「获得一瓶指定的药水 / 随机一瓶药水」
      → 效果种类里有「**获得药水（指定 / 随机一瓶）**」：
        · 「**数值**」= 要获得几瓶（填 0 = 这条效果不显示也不执行）；
        · 「**取药方式（获得药水）**」选「指定药水」时，下面会多出一栏「**目标药水**」——
          那是个**可搜索**的下拉，和「目标卡」一样：直接打中文名（例：打「格挡」就只剩
          「格挡药水 (BlockPotion)」），点选项或按回车自动补全；
        · 选「随机药水」= 本体卡「炼制药水 Alchemize」那套（按稀有度从药水池里抽；
          战斗外的触发时机会自动换成非战斗药水表，所以治疗类药水也有机会抽到）；
        · **卡牌 / 遗物触发 / 药水 / 自定义状态的触发器**四个地方都能用；
        · **药水栏满时什么都不发生**：本体 TryToProcure 会失败，我们**不会**丢掉 / 替换你已有的药水，
          卡面（药水 / 状态的描述也一样）里都写明了「（药水栏满时不会发生任何事）」；
        · 「指定药水」没选目标药水、或者选的药水名认不出来 → 生成前的检查会**报错**拦住。
  · 想把「自定义关键词」当成一套**卡的组**来用（只从这一组里随机出牌）
      → 「自定义关键词」页加的关键词，每个都会在「范围限定」里多出一条
        「**自定义关键词：××（带这个关键词的那一组牌）**」。选它 = 只从带这个关键词的那批牌里随机出；
        哪张牌属于这一组 = 在「卡牌」页那张牌的「自定义关键词」里勾上它（随时可以改组）。
        两个注意：
        · 这一组**一张牌都没有**时，生成前的检查会**报错**拦住（不然这条效果什么都不做）；
        · 本体的随机候选会排除「基础 / 先古 / 事件」稀有度，所以起始的打击 / 防御不会出现在这一组里。
  · 想「先抽几张候选、让你挑一张生成」（本体「发现 Discovery」那种）
      → 「生成卡牌 + 按范围随机」时，效果底下多一栏「**多选1** ___ **张中选一张**」：
        · 默认 1 = 直接生成（就是原来的行为）；
        · 填 3 = 先随机抽 3 张候选（互不重复），你挑 1 张，**只生成选中的那一张** ——
          这时上面「数值」里的张数不生效（它就是候选张数），生成前的检查会给一句提示；
        · 候选不超过 3 张时用本体「发现」那个界面；超过 3 张时改用简单网格选牌界面
          （本体「抉择悖论」那种，因为本体那个界面最多只接受 3 张）；候选一张都没有时这条效果安全跳过。
  · 想「复制手里的某张牌」（复制一份 / 复制好几份）
      → 效果种类里有「**复制卡牌**」：
        · 「**数值**」= 从牌堆里**选几张**牌；效果底下多一栏「**复制的份数**」= 每一张复制几份；
        · 复制出来的牌进**手牌**；「选牌方式」可以自己选 / 随机，「从哪里选牌」可以手牌 / 抽牌堆 / 弃牌堆；
        · 例：数值 1 + 份数 2 = 选一张牌、复制两份（本体「二刀流 DualWield」就是「选 1 张、复制 N 份」）；
        · 复制出来的牌跟着原牌的升级 / 附魔走；牌组里的牌不能复制（本体限制）；
        · 只能用在卡牌 / 药水上 —— 遗物和自定义状态里没有「战斗里选牌」的上下文，生成时会留一句说明。
  · 想「从已经消耗掉的牌里把牌拿回来 / 对消耗牌堆做点什么」
      → 所有「从哪里选牌」的地方现在都有**四摞**：手牌 / 抽牌堆 / 弃牌堆 / **消耗牌堆**。
        消耗牌堆和另外三摞一样是「战斗牌堆」，所以：
        · 效果种类里多了一条「**从消耗牌堆拿牌到手牌**」（和「从抽牌堆 / 弃牌堆拿牌到手牌」并列）；
        · 「消耗 / 变化 / 升级 / 丢弃 / 复制 / 重放 / 给关键词」都能选消耗牌堆：
          变化 = 把消耗掉的牌变成别的牌；丢弃 = 挪回弃牌堆（洗牌后会回到抽牌堆）；
          复制 = 克隆一张已经消耗的牌；重放 = 让消耗掉的牌下次打出去时多打几次。
        · 「消耗卡牌」选消耗牌堆没有实际变化（那摞里的牌本来就已经消耗了），生成前的检查会提示一句。
  · 数值填 0
      → 所有效果种类的数值**都能填 0**，填 0 = 这条效果**不存在**：卡面描述里不写、代码里也不执行
        （不会被力量 / 敏捷加成）。以前有些种类似的下限是 1，现在全部放宽了。
        三个例外（0 有别的含义，照样生效）：
        · 「召唤伙伴」数值 0 = 用「召唤物」页里配置的血量；
        · 「给予卡牌关键词」数值 0 = 这张牌自己；
        · 「回合结束时自动打出」数值 0 = 这张牌自己。
  · 想「拿到更多的最大生命」（像本体「进食」那种）
      → 效果种类里那一条叫「**获得最大生命（负数 = 失去）**」（以前只写「最大生命」，不好找）。
  · 想让一张牌「重放」（打出去时连着打好几次）
      → 效果种类里有「**重放卡牌**」：数值 = 从牌堆里选几张（四摞都能选），
        效果底下多一栏「**重放次数**」= 每一张额外打出几次。
        本体机制是 CardModel.BaseReplayCount：**重放 1 次 = 打出去时连着打 2 次**
        （本体「转化 / 隐藏宝石 / 剑圣 / 士兵炖菜」都是这一句）。
        注意：只能给**别的**牌加 —— 自己这张牌的重放次数在本体里是打出之前就算好的，填给自己没有作用。
  · 想「回合结束时自动打出」
      → 效果种类里有「**回合结束时自动打出**」：
        · 数值填 **0** = 这张牌自己：打出它之后，本回合结束时再自动打出它一次；
        · 数值填 **1 以上** = 打出它的时候先按「选牌方式 / 从哪里选牌」挑好 N 张，
          本回合结束时逐张自动打出去（**不会在回合结束时弹选牌界面**，选择是在打出这张牌时做的）。
        · 只能用在卡牌 / 遗物 / 药水上；数值 0（这张牌自己）只有卡牌能用。
  · 条件里想写「斩杀」（像本体「进食 / 贪婪之手」那种「斩杀时，…」）
      → 条件选项里有「**斩杀（这一次攻击杀死了目标）**」：只能用在**卡牌**上，
        而且要写在「造成伤害」那一条效果**后面**（它判的是上一条攻击有没有把目标打死）——
        生成的是本体那套判据（AttackCommand.Results 里 WasTargetKilled + 目标允许触发斩杀），
        卡面会自动写成「[gold]斩杀[/gold]时，…」，并挂上本体的「斩杀」悬停说明。
        小怪 / 会复活的目标是打不死的（本体 MinionPower / ReattachPower 就是这么判的）。
  · 改了原版状态的名字（例：把「易伤」改成「破绽」），只想在自己的角色里看到新名字
      → 现在就是这么做的：新名字只写进我们自己的键（`<状态>_FORGE.title` 这种），
        本体那张本地化表**一个字都不动**；生成的补丁只在「这一局玩的是你的角色」时换名字，
        所以：**你自己的角色里**显示破绽（战斗中的状态图标、悬停提示都换），
        别的角色、主菜单的**百科**里永远是「易伤」——包括铁甲战士「战栗」的描述。
      → 以前那句「本体卡牌 / 遗物 / 药水描述里的旧名字也一起换掉」默认关掉了（它天生是全角色范围的，
        一开，所有角色提到这个状态的地方都会变成新名字）。真想让本体文本也跟着换，就在那条改写上勾它。
  · 想「重放」不会卡住 / 不会越叠越多
      → 「重放卡牌」现在照本体「隐藏宝石」的写法来：先挑出**还能重放的牌**
        （排除打不出去的、以及已经有重放的），池子空了就整条跳过（不会弹一个空的选牌界面等你），
        要的张数也不会超过池子里实际有的张数，预览是整批一次弹完。
  · 想让效果「反向」（获得力量 -3 = 失去 3 点力量、给予中毒 -5 = 扣除 5 层）
      → 所有「获得 / 施加」的数值都可以直接填**负数**（获得格挡 -5 = 失去 5 点格挡、
        获得能量 / 金币填负数 = 扣除、获得最大生命填负数 = 失去）。卡面描述会自动写成
        「失去 5 点格挡」「扣除 5 层中毒」这种反向的话。
      → 「施加增益/减益」填负数有两档（自己不用管，工具按状态自动选）：
        · **力量 / 敏捷 / 专注 / 尖啸 / 萎缩**这 5 个状态本体允许负层数 → 直接施加负数
          （本体「尖啸」扣敌人力量就是这么写的）—— 目标身上**本来 0 层**也能扣成 -2；
        · **其余状态**（虚弱 / 易伤 / 中毒…）层数不能为负 → 从目标**身上已有的层数**里扣，
          目标身上没有这个状态时什么都不做。
      → 两个组合不行（生成前的检查会拦住并说明）：
        ①「施加增益/减益」填负数又勾「下回合生效」（下回合那套只会加层数，扣层没有对应做法）。
        （注：「临时增益」填负数**可以**了 —— 那是「先失去 N 层、到点加回来」，见上面那一条。）
  · 怕「被打死了还触发回血」（多人模式下看着像复活）
      → 这三条时机的效果**致死的那一下不会触发**（V0.2.139 起）：
        「受到伤害时（每一下）」「自己失去生命时」「受到攻击后（连击只算一次）」。
        工具生成的守卫里带一句「自己已经死了就直接返回」，所以像
        「当你受到伤害或失去生命时，你回复 3 点生命」这种配置，被敌人打死的那一下不会再回血。
        单人模式一样生效（致死那一下不触发这只遗物 / 这个状态）—— 这是预期行为。
  · 想让某个状态的层数翻倍（例：把敌人身上的中毒翻倍）
      → 效果种类里有「**翻倍目标身上的状态层数**」：数值 = 倍数（2 = 翻倍，3 = 三倍，0 = 不生效），
        要翻倍哪个状态在「增益 / 减益」那一栏选，打谁按「作用对象」栏来。
        只能放在卡牌上（遗物 / 药水没有「选中的目标」）；目标身上没有那个状态时什么都不做。
  · 想「清掉敌人身上的格挡 / 状态」（像本体卡「暴露」）
      → 效果种类里有三条，都只放在卡牌上，作用对象按「作用对象」栏来：
        · **暴露**：清空目标的格挡 + 移除人工制品，再施加 N 层状态（施加哪个在「增益 / 减益」栏选，0 = 不生效）；
        · **清除指定状态**：把目标身上某一个状态整个清掉（哪个在「增益 / 减益」栏选）；
        · **清除所有减益**：目标身上的减益状态全清。
        目标身上没有那个状态时什么都不做。
  · 想让敌人「一段时间内拿不到格挡」
      → 效果种类里有「**禁止目标获得格挡**」：数值 = 层数（持续回合数），生成的是本体现成的
        `NoBlockPower`；填负数就是反向（把它扣掉，卡面写「解除…效果」）。作用对象按「作用对象」栏来。
  · 想让一张牌能「反复升级」（越升越强）
      → 「卡牌」页勾上「**可被无限升级**」：本体默认每张牌只能升 1 级（诅咒一级都不能升），
        勾上以后生成的是 `MaxUpgradeLevel => int.MaxValue`，可以一直升，卡面标题显示成「名字+N」。
        每一级都会再跑一遍升级逻辑，所以记得把「升级增量 / 升级后费用 / 升级后额外资源量费用 / 升级后关键词」填上；
        一处都没填的话，「配置检查」会提醒你「反复升级不会让数值变强」。
  · 想做「对自己造成伤害」这种自伤代价（例：打自己 5 点，换一次爆发）
      → 效果种类里「**造成伤害**」+ 作用对象选「自己」：这是**本体的普通伤害** ——
        **护盾（格挡）能挡**，而且不会被你的力量 / 易伤放大（卡面写的是「受到 N 点伤害」）。
        想「**无视护盾**直接扣血」（本体「祭品」「放血」那种代价）请换成效果种类「**失去生命**」：
        它生成的是本体的 `DamageProps.cardHpLoss`（带 `Unblockable`），护盾一点都不吃。
        ⚠ 这两个以前生成的是同一段代码（自伤也带 `Unblockable`），所以「造成伤害 + 自己」穿过护盾 ——
        这一版修好了：**能挡**用「造成伤害」、**不能挡**用「失去生命」。
        （顺带说一句：药水的目标如果是「自己」，里面那条「造成伤害」**不会执行** —— 现在配置检查会提醒你改目标。）
  · 想让状态「在我掉血的时候触发」
      → 触发时机里有「**自己失去生命时（每一下）**」（本体钩子 `AfterCurrentHpChanged`）：
        只管生命值掉没掉 —— 敌人的伤害、自己「失去生命」、自己「造成伤害」、直接扣血都算，回血不算。
        它比「自己受到伤害后（每一下）」更宽（两种都会触发；那条只看伤害管线，这条只看血量有没有真的少）。
        两个都是每一下都会触发一次。
      → ⚠ **「失去生命」不算「受到伤害」**：「自己受到伤害后（每一下）」和「自己造成伤害后（每一下）」
        都会排掉本体的 `DamageProps.cardHpLoss`（`Unblockable | Unpowered`）那种掉血 ——
        也就是**血祭 / 献祭代价 / 放血 / 中毒**这类「穿盾而且没有来源加成」的掉血。
        想接这类掉血请用「**自己失去生命时**」那条时机（那条才是为它准备的）。
        为什么以前会串：本体 `CreatureCmd.Damage` 里「受到伤害后」那个钩子是**无条件**广播的（不看 props），
        所以「失去生命」以前也会触发它。
        · **「对自己造成伤害」照旧算「受到伤害」**：它生成的是 `Unpowered | Move`（**格挡能挡**、不带 `Unblockable`），
          不会被排掉。想「无视格挡的自伤代价」请用效果种类「失去生命」。
        · 「敌人受到伤害后 / 敌人造成伤害后」**不动**：敌人侧没有「敌人失去生命」这条时机可以替代。
        · 遗物页 / 自定义状态页 / 锻造页三处的守卫是**同一句**，行为完全一致。
  · 想做「抽几张牌、把其中要花能量的牌丢掉」（本体「刮削 Scrape」那种）
      → 效果种类里有「**刮削（抽 N 张 → 对其中符合条件的牌执行选定的操作）**」：数值 = 抽几张（0 = 不生效）。
        下面两行可以自己定：**「其中符合条件的牌」**= 非 0 费（默认，本体「刮削」的判据；0 费牌留在手上）/
        不限（抽到的每一张都动手）/ 攻击 / 技能 / 能力 / 诅咒 / 状态 / 某个自定义关键词那一组（把关键词当卡的组用）；
        **「执行」**= 丢弃（进弃牌堆，洗牌后会回来）/ 消耗掉（本场战斗不再回来）/ 升级。
        卡面数字随升级变，卡牌 / 遗物 / 药水三处都能用。
        例：「抽 3 张，把其中所有攻击牌消耗掉」= 条件选「攻击牌」+ 操作选「消耗掉」；
        「抽 4 张，把其中带某个关键词的那组牌升级」= 条件选「自定义关键词：××」+ 操作选「升级」。
        条件选了自定义关键词、但一组牌都没有时会报错；条件和操作的选项认不出来时也会报错。
  · 想做「把手牌补满」（本体「迫降 CrashLanding」那种）
      → 效果种类里有「**用「目标卡」填满手牌**」：用「目标卡」那一栏选的卡把手牌补满，
        张数 = 手牌上限 - 当前手牌数（手牌满了就什么都不发生）。没选卡时会退成小刀（Shiv）并给警告。
        卡牌 / 遗物 / 药水三处都能用。
  · 想让「抽到的牌便宜 1 点」（减费类效果）
      → 效果种类里有「**抽到就减费**」：数值 = 持续回合数，这期间每次抽到的牌本场战斗费用 -1
        （X 费 / 不能打出的牌不动）；填负数就是反向扣层数（卡面写「解除…N 层」）。
        卡牌 / 遗物 / 药水三处都能用。
  · 想让敌人「一段时间内回不了血」
      → 效果种类里有「**禁止目标回复生命**」：数值 = 回合数，这期间目标回复量恒为 0；
        填负数就是反向解除（卡面写「解除…效果」）。本体没有治疗钩子，工具会自动给你生成一条补丁
        （同一个文件里，不用你管）。这一条只做在**卡牌**上。
  · 构建老是失败 / 报「引用的召唤物 ×找不到」「引用了不存在的自定义关键词」
      → 工具现在**每次构建都会自动做两件事**（在「② 一键构建 + 安装」里自动完成，不用你管）：
        · **固定英文类名**：卡牌 / 遗物 / 药水 / 召唤物 / 自定义状态里**留空**的英文类名、
          以及自定义关键词里**留空**的「英文标识」，第一次构建时会一次性写实并存进存档。
          以前它们是**按位置自动编号**的（<角色>Card9 / <角色>Pet2 / KEYWORD_3），
          你在中间插 / 删 / 拖动一条，后面那些就**集体改名** —— 效果里存的类名 / 键就失效了。
        · **修引用**：上一次构建会留下「类名表」（在输出目录里，`<ModId>.forge_classmap.json`）。
          这一次构建如果发现某个引用（目标卡 / 哪只召唤物 / 自定义状态 / 卡牌上勾的关键词 /
          「范围限定 = 关键词那一组」/ 给予关键词）已经对不上，就按**名字**自动改回原来那个模型，
          并在日志里写一行「引用的 ×× 已自动改成 ○○」。
        · 认不回来时还有兜底：`<角色>Pet2` 这种编号按「第 2 只召唤物」认、`KEYWORD_3` 按「第 3 个关键词」认，
          只剩一只召唤物时就认它。
      → 所以：现在**不需要**每次构建都去手工重排英文类名了。改完配置直接「一键构建 + 安装」即可；
        日志里那几行「已自动改成」就是这次帮你修好的引用，顺手核对一眼就行。
      → 另外修掉了一个老 bug：宠物效果里那个内部占位符 `__PETCMD__` 以前会漏进「诅咒 / 先古卡 / 遗物 / 药水」
        的生成代码里（编译报 CS0103「不存在名称 __PETCMD__」），现在统一替换好了。
  · 想控制「生成出来的牌放进哪一摞」
      → 「生成卡牌」那条效果的编辑器里有「**生成到（生成卡牌用）**」下拉，四选一：
        · 手牌（本体默认）：生成完直接进手牌；
        · 抽牌堆：进抽牌堆底，之后抽得到；
        · 弃牌堆：进弃牌堆，洗牌后会回到抽牌堆；
        · **消耗牌堆**：直接进消耗堆 —— 不经过手牌 / 抽牌堆（抽不到它），本场战斗结束也不会回来。
          适合「生成出来就立刻消耗掉」、或者只是拿它触发「消耗时 / 消耗堆里的牌」这类效果、做个计数。
        四摞都是本体的「战斗内牌堆」，卡牌 / 遗物 / 药水 / 自定义状态触发器里都能用；
        选消耗牌堆时生成前的检查会提示一句「不会再被抽到」。
  · 遗物 / 药水 / 额外资源量右栏的**效果栏太长了**，想精简
      → V0.2.137 起：这三页右侧效果栏里的每条效果**默认只显示一行摘要**（效果种类 + 数值 /
        升级增量 / 作用对象 / 条件…），左边一个小三角 ▶、右边写着「展开」。
      → **点那一行就展开**完整编辑区（再点一下收起）——展开区里用的还是原来那套编辑器，改值照旧；
        加 / 删效果之后新加的那条也是折叠态，想改就先点开它。
      → 折叠 / 展开只是**界面状态**（不写进存档），对生成结果、对老存档都没有任何影响。
      → ⚠ 卡牌页 / 诅咒页 / 先古卡页的效果编辑器**没有**这个折叠（保持原样）。
  · 遗物 / 药水想自己写描述
      → 遗物页和药水页的「自定义描述」框：留空 = 用自动生成那段，写了就追加在后面，
        勾「替换掉自动生成的描述」就只用你写的那段。
        描述框下面的「**填入参数…**」按钮会列出这条遗物 / 药水能用的数值占位符（例如 {Block}），
        点一下就插到光标处；卡牌那边的同一个按钮给的是 {Damage:diff()} 这种（升级后会显示升级值）。
  · 升级后那段文字**太绿了**，只想让某几个数值变绿（卡牌页「升级后的自定义描述」）
      → **自己写就行**：在这个框里直接写本体那套高亮写法 {Damage:diff()}（升级后按「升级前 → 升级后」
        的差异变绿），写 {Damage} 就是普通颜色。
      → 不用记语法：点上面的「**填入参数…**」按钮，卡牌那一栏给的就是**带 :diff() 的高亮写法**；
        遗物 / 药水不能升级，那边的「填入参数…」给的是不带 :diff() 的普通写法。
      → ⚠ 变量名别自己手写：候选里那些就是生成代码真的声明过的键。抄一个不存在的键（例如 {Value:diff()}）
        游戏里取不到变量，会把 {Value:diff()} **原样印在卡面上**。
      → ⚠ 写错时生成前的检查会报出来：写了 {X:diff()} 但那个变量这张牌**没声明过**（比如那条效果后来删了）
        → **错误**并点名是哪张牌；写了 :diff() 却整段一个 {} 占位符都没有（纯中文 + 直接写死的数字）
        → **警告**提醒你先用「填入参数…」把数字换成占位符。
      → ⚠ V0.2.135 那个「高亮字段…」多选弹窗**已经在 V0.2.137 撤掉**（改成让用户自己填）。
  · 想让自定义状态造成的伤害不算「你造成的伤害」      → 默认就是这样：状态触发器里造成的伤害一律不带归属（本体按 dealer 归因，工具传 null），
        不计入「你造成的伤害」统计，但照样吃格挡 / 免疫等规则。
  · 自定义描述里想要金色文字（[gold]）等富文本
      → 描述框里直接写 BBCode，和本体描述的写法一样：
        · `[gold]文字[/gold]` = 游戏的金色（本体写关键词 / 关键数字用的就是它）；
          还有 `[blue] [red] [green] [purple] [orange] [pink] [aqua]` 这几种本体颜色
          （数字常用 [blue]、警告常用 [red]）；
        · 加粗 `[b]…[/b]`、斜体 `[i]…[/i]`、居中 `[center]…[/center]`；
          动效 `[sine] [jitter] [scramble] [thinky_dots]`（本体主要用在事件文本里，卡面上也能用但比较吵）；
        · 可以和数值占位符套着用：`[gold]{Damage:diff()}[/gold]` = 「升级后的伤害，金色」；
          回车就是换行。
        · 必须成对闭合、区分大小写：写成 `[gol]` / `[god]` 这种游戏里会把方括号原样印出来；
          占位符的键必须是这条模型真正声明过的（用「填入参数…」按钮插最稳）。
        · 想让「升级后」那段里的**某几个数值**变绿（而不是整段绿）：卡牌页「升级后的自定义描述」框里
          **直接写** {Damage:diff()}（高亮）或 {Damage}（普通颜色）就行 —— V0.2.137 起不再有多选弹窗，
          点上面的「填入参数…」按钮给的就是带 :diff() 的高亮写法。
        · 放心：生成前工具会**自动体检 + 自动修**这些标签 —— 只差一个字母的拼写错误会被改成最接近的
          那个（`[god]` → `[gold]`）、没闭合的会在结尾补上、多余的闭合会删掉、交叉嵌套会理顺，
          改了什么会以「警告」写在生成日志里（本体对标签是严格的，写错会让游戏里那串方括号原样
          印出来，日志里还会报 Found end tag gold, expected god）。

          那个组现在只剩「复制的份数 / 重放次数」两格。）
        例：「造成 8 点伤害 + 命中次数写 X + 费用框写 X」= 天际钻头；「格挡 + 生效次数写 X + 费用框写 X」= 挽歌。
        ⚠ 老存档里勾过那三个开关、或者带 CostIsX / StarCostIsX / XPlusOnUpgrade 的：**读得回来、生成结果一个字不变**
        （老字段一个都没删，生成端先认它们）。
      → 费用框还能填**生成期就算得出来的式子**：`1+1`、`A+3`（A 必须是「自定义参数 / 组」页里
        「数值（固定数字）」来源的参数）。本体 base(cost, …) 要的是**编译期常量**，所以
        读血量 / 读状态那种运行时表达式在费用栏里**收不了** —— 「配置检查」会明确报错说清是哪一条。
      → 「额外资源量费用」框**留空** = 老规矩：按效果列表里的负数「花费额外资源量」自动算。
  · 升级之后想让费用变（2 费升 1 费、1 费升 0 费）
      → 「卡牌」页中间费用框**下面那一行**就是「升级后费用」（V0.2.131 从右边效果栏搬过来的）：
        留空 = 升级不改费用；填 0 / 1 / 2 就是升级后的绝对费用；填 `X+1` = X 费牌升级后 X 多 1
        （这是**整张牌**的设置）。生成时用本体自己的办法：OnUpgrade() 里 EnergyCost.UpgradeBy(差值)。
      → 同一行的右边是「**升级后额外资源量费用**」（绝对数）：填了就生成 OnUpgrade() 里的
        `UpgradeStarCostBy(差值)`（本体 CardModel 自带这个方法，和 EnergyCost.UpgradeBy 同一个思路）。
      → X 费用牌改不了绝对费用（本体遇到 X 费直接返回，工具会提示；想「升级后 X+1」就在这一栏写 `X+1`）；
        负费用的特殊牌不建议改（本体会夹到 0）。
  · 「对群数 / 命中次数」在「全体敌人」上是什么意思
      → 「**一次打全体、每个敌人各挨 N 下**」：生成的是本体的一次性群体命令
        `DamageCmd.Attack(…).TargetingAllOpponents(base.CombatState).WithHitCount(N)`。
        以前这个数字在**卡牌页**的「全体敌人」上会被整个忽略（只打 1 下），现在照你填的打
        （填 1 = 不写 WithHitCount，和以前一样）。
      → 「随机敌人」那一档仍然是「挑中的那些敌人各挨 N 下」；想「打完一轮再来一轮」请用「生效次数」。
  · 「数值」不是一个死数字，要按打出的那一刻算（**数值公式**）
      → 卡牌上那 5 种支持公式的效果（伤害 / 格挡 / 失去生命 / 回复生命 / 施加状态）**只有
        「数值（公式）」这一栏**了：那个固定数值框已经收起来（用户要求：只留公式）。
        **留空 = 0**（这条效果不显示也不执行）；写了公式 = 打出这张牌的时候现算，卡面上显示算出来的数字。
      → ⚠ **打开老存档时**，这些效果原来的固定数值会**自动转成公式**（例：伤害 7 → 公式 `7`），
        数值一个都不变，所以不会出现「看不见却还在生效」的数字。
      → **不支持完整公式的种类**：卡牌上「数值（公式）」那一栏照样摆着，但**只认光秃秃一个 `X`**
        （= V0.2.131 去掉的那个「数值 = X」勾选框：打出这张牌那一刻消耗掉的能量，费用框里也要写 `X`），
        写别的式子「配置检查」会报错说清原因；**遗物 / 药水 / 自定义状态上的效果照旧只有「数值」框**
        （公式只做在卡牌上，而且那几条链没有「打出这张牌」那一刻的上下文）。
       → 例：`M*3`（自己最大生命 ×3）、`max(1, N/2)`（N = 指定敌人身上的某个状态层数）、`X`（当前能量）。
      → 写法：数字、**参数名**（M / N…，一个字母，到「自定义参数 / 组」页定义它「从哪来」）、
        `X`（打出这张牌那一刻的当前能量）、`Y`（当前额外资源量）、`+ - * / %` 与括号，
        还有 `min / max / floor / ceil / round / abs`；最前面可以写一个 `=`（写 `=M*3` 也行）。
      → 📍 **在哪找这些内置量**：「卡牌」页选中一张牌 → 右边效果栏选中一条效果 →
        效果编辑器**最下面那块蓝色小框「可用量」**里就是全部名字和中文说明（一直显示，不用先填错）。
        三个公式框都能用：**数值公式**、**次数公式**、**条件里的数值公式**。
        只有**卡牌**上有这块清单（公式暂时只做在卡牌上；遗物 / 药水 / 状态里填了会被拦住）。
      → 另外还内置了一批「**实时只读量**」，不用定义、直接写（大小写不敏感）：
        · `Turn` 自己这一侧的第几回合 / `Round` 当前战斗轮数；
        · `HandCount` `DrawCount` `DiscardCount` `ExhaustCount` 手牌 / 抽牌堆 / 弃牌堆 / 消耗牌堆的张数；
        · `DiscardedThisTurn` `DiscardedThisCombat` 本回合 / 本场战斗**丢弃**了几张牌；
        · `ExhaustedThisTurn` `ExhaustedThisCombat` 本回合 / 本场战斗**消耗**了几张牌；
        · `GeneratedThisTurn` `GeneratedThisCombat` 本回合 / 本场战斗**生成**了几张牌
          （⚠ **复制出来的牌也算生成** —— 本体把复制记成同一个「生成」记录，所以没有单独的「复制张数」）；
        · `EnergySpentThisTurn` `EnergySpentThisCombat` 本回合 / 本场战斗**花掉**的能量；
        · `StarsGainedThisTurn` `StarsGainedThisCombat` 本回合 / 本场战斗**获得**的额外资源量；
        · `EnergyGainedThisTurn` `EnergyGainedThisCombat` 本回合 / 本场战斗**获得**的能量
          （⚠ 回合开始把能量**补满**的那部分不算「获得」—— 不然这两个读数每回合都会莫名多出 3 点）；
        · `PowersOnMe` 自己身上的状态数量（不算本体内部状态）。
        例：`Turn*2`（第 N 回合就打 2N 点）、`DiscardedThisTurn*3`、`HandCount + PowersOnMe`。
        数据几乎都是本体现成 API（战斗历史 / 牌堆 / 状态列表），**不需要额外补丁**；
        只有「获得的能量」本体没记（只有当前能量，没有「获得了多少」），用到它时工具会多写一个
        `cs/EnergyGainTracker.cs`（自己记 + 打在本体 `PlayerCombatState.GainEnergy` 上的补丁），
        **没用到就不会生成那个文件**；
        名字写错了会**报错拦住**并把完整名单列出来（不会当成 0 静默失效）。
        「本回合」用的是本体那套判据，所以**敌人回合里读到的是你上一个回合的数据**。
      → ⚠ 公式里引用的参数如果是「**指定敌人**」来源的（当前血量 / 最大生命 / 状态层数），
        这条效果就**必须是单体**（作用对象 =「指定敌人」）—— 「全体敌人」的牌打出时不选目标，
        那个参数会**永远是 0**、公式等于白写。生成前的检查会**报错拦住**并给出两种改法
        （把作用对象改成「指定敌人」，或把这个参数的「从谁身上取」改成「全部敌人 / 随机敌人」）。
        另外公式是**整张牌只算一次**的，所以「每个敌人各自的状态层数」做不到，自动的话所有敌人同一个数字。
      → **次数类**的四个字段也能写公式（「卡牌」页效果编辑器里那一块「次数公式」）：
        · **生效次数**（整条效果重复几遍）、**命中次数 / 对群数**（多段攻击的段数 / 随机挑几个敌人）、
          **复制的份数**（复制卡牌）、**重放次数**（重放卡牌）、**概率（%）**（勾了「概率生效」才有这一格）。
        · 写法 / 参数 / 内置只读量和「数值公式」完全一样；算出来的次数**夹到 1 ~ 20**
          （和固定值那条同一个上限，免得公式算出 999 把一局卡死）；卡面印的是公式本身
          （次数是打出去一瞬间才知道的，卡面没法预算）。
        · **命中次数公式三种作用对象都生效**：指定敌人 = 打同一个目标 N 下；全体敌人 = **每个**敌人各挨 N 下；
          随机敌人 = 挑 N 次。⚠ 老版本（V0.2.109 及以前）指定敌人 / 全体敌人这两条只认**固定**次数 > 1，
          写公式（固定值还是 1）时**整条都不生成、只打一下**，可卡面却印着「2+A 次」—— V0.2.110 修好了。
        · 和「= X / = 层数」那几个开关**不能同时用**（都是「改用算出来的值」），校验器会报错；
          次数公式也**只做在卡牌上**（遗物 / 药水 / 诅咒 / 状态下填了会报错拦住）。
        · 「概率」那一格和别的不太一样：没写公式时，同一张牌里勾了概率的效果是「**共用一次掷骰**、
          各占一段区间」（本体也是这个做法）；**写了公式的那条改成自己独立判一次**，
          所以「一条写公式 + 一条固定值」时两条不再互斥（生成前的检查会提示这一点）。
         · **想让两条概率效果各自判定**（不互斥）：V0.2.132 起，「概率」那一行底下多了一个勾选框
           「**不同效果的概率各自独立判定**」—— 勾上 = 这条**自己掷一次**，可能和别的概率效果同时中、
           也可能同时不中；不勾（默认）= 老行为（同一张牌里共用一次掷骰、各占一段区间）。
           这一档**只在卡牌链上**（遗物 / 药水 / 状态 / 锻造链那边没有这个开关，行为照旧）。
        · 不能写公式的地方（必须在生成时就定下来）：卡牌**费用**、**升级增量**、页面常量
          （初始血量 / 初始金币 / 额外资源量的初始值与上限…）。
      → **条件里的数值**也能写公式（「条件选项 → 数值 N / 数值 M」旁边那个框，**卡牌上才有**）：
        · 留空 = 用左边那个固定数字；写了 = 打出这张牌时现算，写法与「数值公式」一样
          （例：「手牌数不少于 N 张」写 `Turn` = 第几回合就要求几张）。
        · ⚠ 写了公式时「填负数 = 反向」看的是**公式折出来的常数**：公式是纯数字（例 `-2`，界面上把固定
          数值搬进公式栏之后就是这种）→ 照样按负数生成（力量这类允许负层数的状态直接扣成负的）；
          公式里有运行时量（`X` / `Turn` 这类，生成期算不出正负）→ 一律按「正面」生成，
          要反向请把负号写进公式（例 `0 - Turn`），或者清空公式用固定负值。
        · 公式里用到「指定敌人」来源的参数时，这条条件不写进「打不出去 / 描金边」，只包住那条效果
          （那两处还没有「打出的目标」）。
      → **只有这 5 种效果能写公式**：造成伤害 / 获得格挡 / 失去生命 / 回复生命 / 施加增益减益。
        其它种类（抽几张 / 生成几张 / 消耗几张这类）的数值必须在**生成的时候**就定下来
        （要提前分配卡面变量、算好选牌上限），所以那些种类上这一栏**根本不出现**；
        万一老配置里留着值，生成前的检查会报错说清原因（不会静默忽略）。
      → 这一版公式**只做在卡牌上**：遗物 / 药水 / 自定义状态的触发时机、诅咒牌上填了会**报错拦住** ——
        那几条链没有「打出这张牌」这一刻的上下文（拿不到「打出的那张牌 / 玩家选中的目标」）。
      → 卡面上显示的是**算出来的数字**（生成端给公式的 5 种效果各声明了一个「现算预览值」的动态变量，
        例：填 `M*3` → 卡面显示按当前属性算出来的「造成 24 点伤害」那种数字，
        力量 / 敏捷那些加成也照旧叠上去）；**升级增量对公式那条不生效**（公式取代了数值），
        校验器会给一句提示 —— 想让升级也变强，就把公式去掉、回到固定数值 + 升级增量。
      → 公式算出来的**正负要到打出时才知道**，所以生成端一律按「正面效果」写
        （伤害 / 格挡 / 回复 / 施加状态都不会反向）。想要「扣层数」那种语义，请用
        「施加增益 / 减益」填一个负数的固定数值。
      → 「从工程恢复存档」会把公式、以及公式用到的自定义参数一起认回来（参数靠生成代码里
        `decimal __pM = …` 那一行还原）；只有参数的「备注」那一栏恢复不了（它不参与生成）。
  · 升级之后关键字也想变（本体「残影」升级获得固有、「幻影 / 寒冰」升级失去虚无 / 消耗）
      → 「卡牌」页中间「升级后的关键字」那一块：6 个关键字各一行，三态可选
        「不变 / 升级后获得 / 升级后失去」，生成到 OnUpgrade() 里的 AddKeyword / RemoveKeyword。
        升级预览和实际升级后的关键字都由本体自己显示，不用写文本。
        （V0.2.131 起「升级后费用 / 升级后额外资源量费用」搬到了上面的费用栏下面 —— 它俩是**整张牌**的设置，
          和这里的「升级后关键字」不是同一块。）
  · 升级之后**自定义关键词**也想变（升级后才显示「命定」、或者升级后不再显示「虚空」）
      → 还是那一块**底下**：「自定义关键词：不变 / 升级后获得 / 升级后失去」两栏，
        候选就是你「自定义关键词」页里加的那些词；留空 = 不变（老存档就是空，产物一个字节都不变）。
        ⚠ **这两栏只影响显示，不是机制变化**：上面那 6 个**本体**关键字走 AddKeyword / RemoveKeyword
          会**真的改变卡牌状态**；而自定义关键词本来就是「卡面那行金色词 + 鼠标悬停说明 + card_keywords
          本地化键」拼出来的显示等价物（本体关键字是封闭枚举、模组加不了新值），游戏里没有任何按它判定的逻辑。
        生成出来：卡面描述那行用本体的 {IfUpgraded:show:升级后那段|没升级那段} 包起来，
          悬停说明按「有没有升级」加 / 不加那条；「从工程恢复存档」也认这两栏。
        引用了已经被删掉的关键词 → 生成前检查会**报错**并点名是哪张牌的哪一栏；
        诅咒 / 状态牌（升不了级）填了这两栏 → 会提示「永远不会生效」。
  · 想把本体的关键词换个说法（比如把「消耗」改叫「献祭」）
      → 「自定义关键词」页最上面那 7 行就是本体那 7 个关键词（消耗 / 虚无 / 固有 / 不能被抽出 / 保留 / 奇巧 / 永恒）：
        填「新显示名」（留空 = 不改），想连鼠标悬停里的说明一起改就再填「新说明」。
        生成后本体卡面上的金色词、以及本体卡牌 / 遗物 / 药水描述里出现的旧名字都会一起换掉。
        注意这是全局改动 —— 本体其他角色的牌上出现同一个关键词也会跟着改名。
  · 想要一个本体没有的关键字（比如「命定」），卡面上也能像「消耗 / 虚无」那样用金色标出来、鼠标移上去有说明
      → 到「自定义关键词」页「添加关键词」，填名字、英文标识（留空会自动编号）、说明；
        再到「卡牌」页勾选哪张牌用这个词（一张牌可以勾多个）。
        生成时会自动：把名字拼在这张牌描述的最前面、让鼠标悬停卡面时弹出「名字 + 说明」、
        把文案写进模组的 card_keywords.json（本体那张表逐键合并，不影响本体自己的关键字）。
        注意：本体的关键字是封闭枚举、模组加不了新值，所以走的是这套等价机制；
        升级后获得 / 失去这个词见上面那一条（V0.2.136 起支持）。
  · 想要「只这一回合」的保留 / 奇巧，或者给别的牌加个关键词
      → 效果种类选「**给予卡牌关键词**」：
        · **数值** = 给几张牌（**填 0 = 就是这张牌自己**）；
        · 数值 ≥ 1 时按「选牌方式」（自己选 / 随机）和「从哪里选牌」（手牌 / 抽牌堆 / 弃牌堆）挑；
        · 它下面新增的「**给予关键词**」里选给哪个关键词 —— 上面是本体的 7 个
          （消耗 / 虚无 / 固有 / 保留 / 不能被打出 / 奇巧 / 永恒），下面是你自己造的关键词；
        · 再下面勾「**是否为临时关键词**」= 只这一回合生效（回合结束自动去掉，卡面上那行字也一起消失）。
        例：数值 0 + 给「保留」+ 勾临时 = 以前那个「临时保留」；换成「奇巧」就是「临时奇巧」。
        给本体关键词时卡面上显示本体那两个字，给自定义关键词时显示你自己起的名字（本体卡也能给）。
  · 想让敌人「这一回合不行动」（击晕）
      → 效果种类选「**击晕（敌人本回合不行动）**」，作用对象选「指定敌人 / 所有敌人 / 随机 N 个敌人」。
        注意：它**不在**「增益 / 减益」那个下拉里 —— 本体里「击晕」不是一个状态（Power），
        而是「怪物意图」（本体卡「口哨」就是这么做的：CreatureCmd.Stun），所以单独列成一种效果。
        本回合被击晕的敌人该回合什么都不做（和本体一致）。卡牌 / 遗物 / 药水 / 自定义状态都能用。
  · 想要「本回合 +N 层某状态，回合结束就掉光」（比如本回合 +3 点力量）
      → 效果种类选「临时增益（本回合 +X，回合结束消失）」，数值填层数，
        「增益 / 减益」里选那个状态（自己 / 指定敌人 / 全体敌人都能选）。
        生成的是本体「临时力量 / 临时敏捷」那套：状态栏里出现「临时某某 +N」，回合结束自动消失；
        别的来源加的层数不受影响（只撤掉这次临时加的那 N 层）。
      → 效果种类下面那一行「**临时增益什么时候撤**」（只有选到它才显示）决定**什么时候掉光**：
        · 「本回合结束时撤掉」（默认）= 你这一回合结束就掉；
        · 「**下回合开始时才撤掉**」= **撑过这一回合和敌人的回合**，到你的下一个回合开始才掉
          —— 也就是「获得临时 5 点力量 → 下回合开始时失去 5 点力量」。
        两档可以同时用（同一个状态的两种写法会各自生成一个临时状态类，互不影响）；
        状态栏上的说明也会按你选的那一档写（「回合结束时消失」/「下回合开始时消失」）。
      → **数值填负数 = 让目标先「失去 N 层」，到点再加回来**（临时减益）。
        例：想让敌人「失去 5 点临时力量」→ 数值填 `-5`、「增益 / 减益」选力量、
        作用对象选敌人、「什么时候撤」选「下回合开始时才撤掉」。
        它和「施加增益/减益填负数」的区别：那个是**永久**扣掉、不会还原；这个到点会加回来。
        （范围是 -99 ~ 99。）
  · 想让某一张牌的伤害 / 格挡变高（本体「精准」强化小刀、「敏捷」加格挡那种）
      → 效果种类选「**强化指定卡牌（像「精准」，+N 伤害/格挡）**」：
        · 「**目标卡**」下拉里选要强化的那张牌（自己的牌和本体卡都能选，**必填**）；
        · 它下面新增的「**强化什么**」里选 伤害（像「精准」）/ 格挡（像「敏捷」）；
        · 「**数值**」= 加多少，**填负数就是削弱**那张牌（例：-2 = 你打出的这张牌少 2 点伤害）。
        生成的是挂在你身上的一张状态：只对**你打出的那张牌**生效，本场战斗内一直有效
        （战斗结束自动消失，不会改到存档里的卡牌）；状态栏里会显示「强化：某某」和它的层数。
        例：一张能力牌「你的戏法飞刀额外造成 3 点伤害」= 目标卡选戏法飞刀 + 伤害 + 数值 3。
        注意：它加的是「攻击伤害」和「卡牌格挡」（和本体「精准 / 敏捷」一致），
        对不是攻击牌的伤害（比如状态掉血）不生效。
  · 自动生成的卡面描述不合意，想自己写
      → 「卡牌」页「卡面预览」下面有「**自定义描述**」输入框（可以多行）：
        默认**追加**在自动描述后面（自动那句话还在，你在下面补一句）；
        勾上「**替换掉自动生成的描述**」就整段换成你写的（自动那句不生成）。
        自定义关键词那一行（如果你给这张牌勾了自定义关键词）仍然排在最前面。
        「从工程恢复存档」也会把你写的这段读回来（多行、追不追加都会还原）。
      · 不想从头写：描述框旁边有 **「自动填入」** —— 点一下就把这张牌**自动生成的那段**填进框里，
        你接着改就行（会顺手勾上「替换掉自动生成的描述」，不勾的话卡面上会和自动那段印两遍）。
      · **升级之后想换一段文字**（锻造卡最用得上：「升级前 / 升级后」两块布干的事不一样时）：

        游戏里按这张牌有没有升级自动显示对应那一版。第二个框旁边也有「填入参数…」和
        「自动填入（升级后）」。⚠ 描述里自己写竖线 `|` 会把这句话截断，生成时会换成全角「｜」并给你一条警告。
      · **锻造卡的卡面文字是自动从节点图写出来的**（例：「如果 指定单体敌人身上的虚弱层数 大于 3：
        对所有敌人造成 A+3 点伤害；否则：失去 5 点生命。」）—— 以前这种卡的卡面**一个字都没有**
        （效果在节点图里，效果栏是空的），现在不写自定义描述也有字了。
  · 想造一张「诅咒」（留在手里坑你的那种）
      → 到「**诅咒 / 先古 / 状态**」页，最上面那栏点「添加诅咒」：
        · 类型 / 稀有度固定 Curse；**费用默认 -1 = 打不出去**，生成时自动加上本体的「不能被打出」；
        · 费用也可以自己填（**三类牌的费用都能调**）：填 ≥ 0 → 这张牌**能打出去**，
          这时不再强制「不能被打出」（想让它照样打不出去就自己勾上那一项）；
          但它的效果仍然写在「你的回合结束时，如果它还在你的手牌里」，所以**打出去本身不做事** ——
          只是能把它从手里丢掉（想要一张 0 费「能打出去的诅咒」就填 0）。校验器会提示这一条；
          想让效果在打出时生效，请到「卡牌」页做一张普通牌。
        · 右边加的效果会在**你的回合结束时，如果这张牌还在你的手牌中**触发
          （本体「受伤 / 疑虑 / 苦恼 / 厄运」就是这一类）；
        · 想让它开局就在手里就勾「固有」；想让它删不掉就勾「永恒」；
        · 想让它打几场战斗后自己消失，就勾「战斗结束时，如果它还在牌组里就消失」（本体「罪恶」那套）。
        怎么让玩家拿到它：诅咒**不会**出现在战斗奖励 / 商店里 —— 用卡牌效果「生成卡牌」（放进手牌 / 抽牌堆 /
        弃牌堆）、「获得卡牌（全局）」加进牌组，或者「获得卡牌奖励」；这三处的「目标卡」下拉里能搜到你的诅咒。
        生成时按**稀有度**认它（不是按它在哪一栏），所以老存档里手改过稀有度的卡也对得上。
  · 想造一张「先古卡」（像本体丰饶 / 神化 / 幽灵形态那样的强力牌）
      → 同一个页面中间那栏点「添加先古卡」：和普通卡一样填费用 / 类型 / 效果 / 关键字 / 自定义关键词，
        只是稀有度**写死**是「先古」、而且不进战斗奖励 / 随机生成（本体里 Ancient 就是被排除的）。
        怎么让玩家拿到它：① 先古之民给的遗物 —— 本体「尘封的书」会从**你的卡池**里随机挑一张先古卡
        （你做的先古卡也在候选里）；② 或者你自己的效果（生成卡牌 / 获得卡牌（全局）/ 获得卡牌奖励）里选它。
        提示：先古卡是**能打出、能升级**的普通牌，升级增量 / 升级后费用 / 升级后关键字都能用。
  · 想造一张「状态卡」（本体伤口 / 灼伤 / 眩晕 / 粘液那种）
      → 「诅咒 / 先古 / 状态」页最下面那栏点「添加状态卡」：
        · 类型 / 稀有度写死「状态」，**费用可调**（本体那些状态牌是 0~1 费），效果和普通卡完全一样；
        · 默认**不能升级**（本体「粘液」就是这样）；想让它能升级就勾「可被无限升级」；
        · 这一栏和「卡牌」页是**同一份数据**：稀有度选「状态」的牌就住在这里，
          在哪边加 / 删 / 改都一样（所以别指望两边能存两份）。
        怎么让玩家拿到它：状态卡**不会**出现在战斗奖励 / 商店里（本体的奖励只抽 Common / Uncommon / Rare，
        商店也不给状态牌摆货架）—— 用「生成卡牌」（放进手牌 / 抽牌堆 / 弃牌堆）或「获得卡牌（全局）」。
  · 想让一张牌进本体的「**无色卡池**」（和本体那些无色牌放在一起）
      → 「卡牌」页勾上「**无色卡**」：
        · 卡框 / 能量图标用**本体无色那套**（card_frame_colorless / "colorless" 前缀）——
          这张牌的卡框颜色由本体无色卡池决定，「卡牌」页的卡框颜色对它不生效（设计如此）；
        · **不进你角色的卡池**：战斗奖励 / 商店抽的是你角色的卡池，所以它不会自己冒出来，
          只有「无色卡池」相关的来源（本体那些按无色卡池发牌的遗物 / 事件 / 药水）才会给到玩家 ——
          所以「加入卡池」那个勾对无色卡没作用（校验器会提示一句，不静默）；
        · 想主动发给玩家：用「生成卡牌」（放进手牌 / 抽牌堆 / 弃牌堆）、「获得卡牌（全局）」加进牌组，
          或者「获得卡牌奖励」——这三处的「目标卡」下拉里能搜到它。
        · **稀有度只能是 Common / Uncommon / Rare**：本体 CardFactory 对 Ancient / Event / Quest / Token
          有特殊处理，放进无色卡池会出怪事 —— 选那几档会被**报错拦住**。
        · **卡面素材放在 `images/packed/card_portraits/colorless/` 下**
          （本体是按「卡所在那个池」去找卡面的，无色卡的池 Title 就是 `colorless`）。
          ⚠ 老版本（V0.2.113 及以前）把无色卡的卡面写进了你角色自己的池目录，游戏按 `colorless/`
          去找 → 找不到，表现就是**这张牌在游戏里没有卡面**（V0.2.114 修好了）。
          普通卡 / 诅咒 / 先古卡照旧写在你自己的池目录里。
        做法：本体的 ColorlessCardPool 是 sealed 的、成员表硬编码，卡池成员只能靠
        `ModHelper.AddModelToPool(池类型, 卡类)` 在**游戏初始化之前**登记，所以生成器会在
        cs/ModEntry.cs 的 Initialize() 里为每张无色卡写一句登记（包在 try/catch 里，失败只记警告，
        不会连累角色注册）。回读就是从这句登记反认回来的。
  · 想给诅咒 / 先古卡换卡框颜色（RRGGBB）
      → 「诅咒 / 先古 / 状态」页诅咒和先古卡那两栏上面各有一行「**诅咒卡框 / 先古卡框**」：
        · 默认「跟角色配色（默认）」= 和以前一样（诅咒用本体的灰色诅咒框，先古卡用角色的卡框）；
        · 也可以直接选本体的框色（铁甲红 / 无色灰 / 诅咒紫灰 / 任务深蓝…）；
        · **先古卡**还可以选「自定义」，在下面的 **RRGGBB** 框里填 6 位十六进制（例如 8A5CF6），右边色块能预览；
          **诅咒没有「自定义颜色」这一项**（诅咒在本体里的外观就是固定的灰色卡池，染色没有意义）——
          老存档里存过诅咒自定义色的会被忽略、退回本体诅咒框（校验器会给一句提示）。
        生成时会按这个颜色算 HSV 写一份卡框材质，只有这一类牌用（角色自己的卡框颜色不受影响）。
        先古卡还会额外生成一个染色补丁：先古卡在游戏里**不显示普通的卡框**（显示的是先古边框 / 先古横幅
        那几张专用图），所以那个补丁会把这两张图的颜色乘上你要的颜色（选的是本体框色名时按那个框色染）——
        改了颜色记得**重新生成 + 构建 + 安装**才看得到。
        说明：能改的只有**卡牌边框**；牌堆底色和能量图标描边取的是「卡属于哪个卡池」，按类改不了
        （工具里就不给这两个框，免得填了没反应）。
  · 想让角色带一个「伙伴」（像亡灵缚者的奥斯提那样，有血、能帮你打）
      → 「召唤物」页点「添加召唤物」并勾上「启用这只召唤物」，填名字 / 英文类名 / 生命（可选上传一张 PNG 当它的样子）。

        牺牲换收益 / 施加状态 / 替主人承伤 开·关），全都在「卡牌」页的**效果种类**下拉里直接选；
        「牺牲伙伴」的收益有三档：格挡（给自己）/ 伤害（打敌人）/ **获得增益·减益**
        （层数一样按「固定 N / 最大生命 × 倍率 / 当前生命」算，状态挂在**你自己**身上；
        选哪个状态就是上面「增益 / 减益」那一栏，选了这一档会多出一行「状态（牺牲后获得）」）。
        三档都是**先算收益（或层数）、再杀宠物**：宠物死了就取不到它的生命值，所以顺序不能反。
        选到宠物效果时会多出「召唤物（哪一只）」下拉（留空 = 用第一只启用的）；
        下拉第一条「★ 全部召唤物」= 这条效果对**每一只启用的**各算一次
        （例：一张牌把三只全召出来，或让每一只都替你承伤；不在场的那只自动跳过）。
        放在遗物的「战斗开始时」触发就是开局自动召唤。
        注意：伙伴**每场战斗都要重新召唤**（战斗结束本体就会清空），敌人默认也打不到它 —— 想让它可以替你承伤，
        就在「召唤物」页勾上它的「替主人承伤」（可以勾多只：承伤的是列表里第一只活着的，它死后自动换下一只；
        本体的伤害重定向是链式的，所以由我们生成的守卫自己仲裁，行为确定）；
        「替主人承伤」勾选框和「伙伴替主人承伤（开 / 关）」效果是两回事：
        **勾选框** = 这只一召唤出来就自动开始承伤；**效果** = 打出那张牌（或触发那只遗物）之后它才开始承伤。
        两者可以只用其中一个（用了效果但没勾勾选框也完全有效，只是「开场不会自动承伤」）。
        另外：一张牌里**先召唤、再让它干活**（承伤 / 攻击 / 加血…）是支持的，
        不需要事先已经有一只 —— 召唤命令返回的那只会被后面的效果直接拿来用。
        没有上传图片时会用本体的占位图，能正常上场 / 攻击 / 死亡，只是长得不好看。

  · 窗口拉小了，卡牌属性下面的关键字 / 卡面看不到

  · 左下角的数字是什么
      → 状态栏右下角实时显示「卡牌：攻击 N ｜ 技能 N ｜ 能力 N ｜ 共 N 张」，按类型统计。
  · 一次想删好几个 / 误删了东西
      → **多选**：在任何列表里按住 **Ctrl 点**（一个个加）或 **Shift 点**（选一段）就能多选，

  ── 初始卡组：打击 / 防御 ──
  · 初始卡组里的「打击 ×5 + 防御 ×5」是什么？「角色」页那个勾选框呢？
      → 没有勾选框了。这两张是「卡牌」页列表里默认就有的**两张你自己的卡**，固定排在最上面
        （打击在前、防御在后）：
          · 英文类名固定成 Strike / Defend（别改，原因见下）；
          · 数值默认照抄本体：打击 1 费 6 伤害、防御 1 费 5 格挡，升级都 +3；稀有度 Basic；
          · 初始 5 张、不进奖励和商店；
          · 标了**本体卡标签** Strike / Defend（卡牌页「本体卡标签」那一行）。
      → 除了英文类名，**其它全都能改**：费用、类型、稀有度、数值、升级增量、效果、关键字、
        卡面立绘、名称与描述；想开局 4 张打击就把「初始份数」改成 4。整条删掉也行，
        点「＋打击/防御」按钮可以补回来（补在列表最上面）。
      → 为什么类名是 Strike / Defend：本体的模型 ID 只按**类名**算（忽略命名空间），
        自己再造一张叫 StrikeIronclad 的卡会和本体撞 ID，模组加载时抛
        DuplicateModelException（"conflict in mod content names"）；
        而 Strike / Defend 这两个裸名字本体没有（本体只有 StrikeIronclad / StrikeSilent…）。
        校验器会在卡牌类名和本体卡重名时直接报错。
      → 为什么要标 Strike / Defend 标签（重要）：本体那些「升级你的初始打击 / 防御」
        「只对打击牌生效」的遗物、事件、卡牌全按 CardTag 查牌
        （妮欧的护符 NeowsTalisman、叶敷剂 LeafyPoultice、大胶囊 LargeCapsule、幽灵种子 GhostSeed、
        完美打击 PerfectedStrike…），有些还会再加「稀有度 = Basic」。不标标签它们就找不到你的牌。
        给别的牌标上 Strike 也能吃到「完美打击」这类加成。

  ── 卡牌页的左侧序号 / 拖动换位置 / 英文类名 ──
  · 卡牌名最左边那一列数字是什么？
      → 是这一张卡**现在排第几位**（从上到下 1、2、3…），拖动换位置之后跟着重排 —— 序号不跟着卡牌走。
      → 序号按**每页列表各自**编号（和遗物 / 药水页一样）：**卡牌**列表（含最上面的本体卡 / 初始的
        打击与防御，它们就是第 1、2 号）、**诅咒卡**列表、**先古卡**列表**各自**从 1 数。
      → 例：一张普通牌在「卡牌」列表排第三行、英文类名留空 → 生成出来的类名就是 `<角色类名>Card3`。
      → 卡牌页**没有**遗物 / 药水页那种「每 5 个留几个灰色空槽」—— 卡牌要的就是 1..N 连续。
      → **拖动**某一行的文字往上 / 往下拖，会出现一条蓝线，松手就插到那条线的位置。
  · 英文类名留空（或本来就是工具自动生成的）会怎么样？
      → 重新「生成工程」/「一键构建」时，它按**它自己那一页列表的序号**重新生成名字，三页三套前缀：
        · 普通卡（含状态卡）：`<角色类名>Card<序号>`
        · 诅咒卡：`<角色类名>Curse<诅咒卡列表里的序号>`
        · 先古卡：`<角色类名>Ancient<先古卡列表里的序号>`
        拖到第 3 位就变成 …3；把那一栏**清空**再生成，也会按当前序号重新拼一个。
        （为什么要三套前缀：三页各自从 1 开始，都叫 `<角色类名>Card1` 会撞类名 —— 本体按类名注册模型，
          撞名会让模组直接加载不了。）
      → **你手填的类名一个字都不会动**（想让它跟着序号走就把那一栏清空）。
      → 「英文类名」下面那行小字会写清现在这张是「自动（跟序号走）」还是「你手填的」
        （卡牌页 / 诅咒页 / 状态卡页都有这一行）。
      → ⚠ V0.2.130 起口径变过一次（以前只数「你自己的卡」，之后连最上面的本体卡 / 初始打击防御一起数），
        **V0.2.137 起又改成本页各自 1..N + 三套前缀**（用户要求「和遗物左侧的排序一样」）——
        所以**既有存档里那些工具自动生成的类名会改号 / 换前缀**（诅咒卡、先古卡尤其明显：
        以前接着普通卡往下数，现在各自从 1 开始、换成 Curse / Ancient 前缀）—— 手填的绝不动。
        改号会连带改文件名、卡池引用、本地化键、卡面素材文件名、上传的卡面键，以及**别的模型里按类名
        存的卡牌引用**（效果里的「目标卡」、「转化为先古卡」的类名、锻造图的「目标卡」字段）
        —— 工具会**同一次全改好**，不用你手工重排。名字想固定不变就**手填**一个（例：`SevenSlash`）；
        手填一个**正好长得像自动编号**（`<角色类名>` + `Card` / `Curse` / `Ancient` + `<数字>`）
        而序号又对不上的，生成前的检查会**提示**你「下次会改名」。

  ── 遗物页 / 药水页（这两页现在是同一套版式）──
  · 左边那一列最前面的数字是什么？
      → 是这一条**现在排第几位**（从上到下 1、2、3…），拖动换位置之后跟着重排 —— 序号不跟着条目走。
      → 序号一次多留 5 个：不够 5 个时后面几行是**灰色空槽**（3 个 → 显示 1~5；加第 6 个 → 显示 6~10）。
        空槽只是占位：**选不中**（不会污染选中 / 删除 / 全选 / 生成），但可以当**拖放的落点**。
      → **拖动**某一行的文字往上 / 往下拖，会出现一条蓝线，松手就插到那条线的位置。
  · 英文类名留空（或本来就是工具自动生成的）会怎么样？
      → 重新「生成工程」/「一键构建」时，它按**左边那个序号**重新生成名字
        （`<角色类名>Relic<序号>` / `<角色类名>Potion<序号>`）：拖到第 1 位就变成 …1。
      → **你手填的类名一个字都不会动**（想让它跟着序号走就把那一栏清空）。
      → 「英文类名」下面那行小字会写清现在这条是「自动（跟序号走）」还是「你手填的」。
  · 药水页照着遗物页做了哪些、哪些没做？
      → 做了：左侧序号 + 每 5 个预留空槽 + 拖动换位置 + 自动类名跟序号走 +
        稀有度英文改中文（常见 / 罕见 / 稀有）+ 右侧效果栏（每条效果**默认折叠成一行摘要，
        点开才展开**编辑区、右下角能选「单条效果的条件」）+ 自定义描述。
      → 没做（**药水没有这个概念，硬塞会误导**）：遗物的「触发时机列表 / 关系开关 / 重置范围」
        一律没有；「范围界定 / 关键词」这类药水用不到的效果模块也不会凭空出现。
      → 药水**不支持**「概率生效」和「命中次数」：勾了 / 填了不会生成，生成前的检查会提示你。

  ── 遗物 / 药水 / 额外资源量右栏的**效果栏**（V0.2.137 起默认折叠）──
  · 每条效果默认只有一行，怎么改里面的数值？
      → 那一行就是**摘要**（效果种类 + 数值 / 升级增量 / 作用对象 / 条件…），左边有小三角 ▶。
        **点那一行**（整行都能点）就展开完整编辑区，改完再点一下收起。
      → 新加的效果（「添加效果」）也是折叠态，想改先点开它。
      → 折叠 / 展开只是**界面状态**：不写进存档、不影响生成结果、换存档也不会串。
      → ⚠ 卡牌页 / 诅咒页 / 先古卡页的效果编辑器**没有**折叠（保持原样）。

  ── 初始遗物 / 死亡文本 ──
  · 初始遗物从哪来？
      → 只按「遗物」页里勾了「起始遗物」的那些来；一只都没勾就是开局不带遗物。
  · 「死亡描述文本」「阵亡后台词」什么时候出现？
      → 死亡描述文本：显示在**死亡结算画面**上（角色立绘下面那句带引号的话）。本体那句是按遭遇
        随机取的通用文案，没有「每个角色一句」的键，所以生成时会打补丁：取文案那一步，
        如果是你的角色就换成你写的（日志里会写「死亡结算文案已替换为自定义文本」）。
      → 阵亡后台词：**自己阵亡的那一刻**冒一个 3 秒的对话气泡（日志里会写「角色阵亡，冒出阵亡后台词」）。
        本体里对应的键只在**联机**「回合结束 ping」时显示，那个键照旧写。
      → 两句都留空就不生成任何补丁。

  ── 自定义状态（能力）──
  · 想自己造一个状态给能力牌用（本体没有的那种）
      → 到「自定义状态」页：点「添加状态」，填名字（游戏里显示的状态名）和类型（增益/减益），
        再加「触发时机」，每个时机下面加「效果」（伤害 / 格挡 / 抽牌 / 能量 / 回复生命 / 施加状态 / 生成卡牌…）。
        三个例子：
          ① 每回合开始获得「等于层数」的格挡 → 触发时机「玩家回合开始时」+ 效果「获得格挡」
             并勾「数值 = 本状态的层数」（本体恶魔形态就是这个写法）；
          ② 每打出一张攻击牌就造成 2 点伤害 → 触发时机「打出一张牌后」+ 只对「攻击牌」生效 + 效果「造成伤害」；
          ③ 临时减益（每回合掉血、回合末消失）→ 触发时机「玩家回合结束时」+ 效果「失去生命」+ 勾「回合结束时移除」。
        还能配：图标（方形 PNG）、层数数字颜色、**覆盖血条颜色**、只叠一层、每回合衰减 N 层。
        做好后到「卡牌」页加一张能力牌（类型选 Power），效果选「施加增益/减益」——
        下拉列表最下面就是你造的状态；打出这张牌就永久获得它。
  · 想让这个状态像「中毒」那样在血条上盖一截颜色
      → 「覆盖血条颜色」那一栏填六位 RRGGBB（例：FF8800），留空 = 不覆盖。
        填了之后下面会多一个下拉「**从哪端开始覆盖**」：
        · **从右边开始**（默认，像本体中毒）：从「当前血量的右端」往左盖一截，红条右端跟着让位；
        · **从左边开始**：从血条最左端往右盖一截，红条左端跟着让位。
      → **每个状态各占一条、颜色各自独立**：身上同时有状态 A 和状态 B 时两条**都能看见**
        （A 一条、B 一条，各自染各自的色）。同一边有好几条时**按上面列表的顺序依次往里堆**，
        中间剩下那一段就是红条。
      → 每条的宽度 = **层数 / 最大生命 × 血条宽度**（也就是「层数当会失去的血量」）：
        3 层就占相当于 3 点血那么宽；两边加起来超过当前血量时，后面放不下的那几条**不画**
        （宁可少画，也不叠在一起糊成一片）。
      → 和本体中毒 / 灾厄共存：本体那两截先在，我们从它们**内侧**接着排（从左边开始的那条会让开灾厄）。
      → 为什么能随便换颜色：本体血条上红条 / 中毒 / 灾厄用的是**同一张纯白九宫格**，
        颜色全部来自节点自己的着色，所以换色是换一个数字的事（不用改贴图）。
      → 颜色写坏了（不是六位十六进制）生成前的检查会**报错拦住** —— 不会静默不上色。
      → 不填颜色 = 一个文件都不多、一行补丁都不打（老存档生成的模组完全不变）。
  · 「触发时机」下面那几句说明是干嘛的
      → 页面上有三处会跟着变（改触发时机、改效果种类 / 数值、加减效果都会立刻更新）：
        ① 「触发时机」下面那块灰底汇总：这个状态配了哪几条、每条做什么；
        ② 触发时机下拉框底下那句：「触发时机：玩家回合开始时 → 触发时做：获得 3 点格挡」；
        ③ 触发器列表里那一行（例：玩家回合结束时 → 伤害 5 → 单体敌人）。
      → 「描述」留空时游戏里显示自动写的那句；下面那行灰字「游戏里会自动显示：…」是实时预览。
        想自己写就填「描述」；「按触发时机重新生成描述」按钮会用当前配置重写一遍。
      → 触发时机里两个「附加条件」：
        · 「只对哪类牌生效」（选「打出一张牌后」时出现）：任意 / 攻击牌 / 技能牌 / 能力牌 /
          **诅咒 / 状态 / 关键词：XXX / 组：XXX**（V0.2.118 扩充：后两类就是你配的「自定义关键词」和「组」
          那一组牌）。⚠ 选了「组 / 关键词」但那一组里一张牌都没有 → 生成前**报错拦住**
          （不然那条时机永远不触发）。同一个状态可以放**好几条**「打出一张牌后」（各带不同筛选）；
        · 「盯哪个状态」（选「某个状态层数变化后」时出现）：留空 = 除自己以外任意状态层数一变就触发；
          选了某个状态就只在它的层数变化时触发（生成 `if (power is StrengthPower) { … }`）。
        · **遗物页**的触发时机选「打出一张牌后」时，**下面同样有「只对哪类牌生效」**（V0.2.120）：
          候选和状态页**同一份**（任意 / 攻击 / 技能 / 能力 / 诅咒 / 状态 / 关键词：XXX / 组：XXX），
          判据也是同一套；遗物的**描述**里会写清（例：「打出一张牌后（只对攻击牌生效）：…」），
          游戏里玩家能看出它挑牌。选「任意」= 老行为（生成结果一个字都不变）。
      → **「要和其他时机同时成立」**（V0.2.117）：把**参与的那几条时机都勾上**，它们就变成
        「都在同一个窗口里成立过才触发」；下面还能选**重置范围**（本回合 = 每回合重新凑 / 本场战斗 = 整场凑一次）。
        例：「本回合既打出过牌、又受到过伤害才获得 2 点格挡」→ 那两条时机都勾上，效果写在其中一条上。
        ⚠ **最后凑齐的那条**跑它自己的效果，然后这一轮的标记清掉 —— 一个窗口只触发一次，
        两条都写同样的效果**不会**触发两次。只有 1 条勾了 = 凑不齐（生成前会提示「不生效」）。
      → 层数和效果的关系：层数只是一个数字，默认**不会**让效果多跑几遍、也不会放大数值。想让层数起作用：
        · 「数值 = 本状态的层数」→ 1 次触发、数值等于层数（3 层 = 3 点格挡）；
        · 「生效次数 = 本状态的层数」→ 按层数重复执行整条效果（5 层 +「造成 2 点伤害」= 打 5 次共 10 点）；
        · 「命中次数 / 对群数 = 本状态的层数」→ 只对「随机敌人」这类按次数挑目标的效果有意义。
        三个都不勾 = 每次触发只跑一遍、用你填的固定数字。
      → 生成的东西：cs/Powers/<类名>.cs（按触发时机重写本体钩子）+ 本地化里的名字 / 描述 + 图标 / 颜色补丁。
        用的都是本体自己的钩子（AfterPlayerTurnStart / AfterCardPlayed / AfterCardExhausted …）；
        **只有「复制卡牌 / 重放卡牌 / 回合结束自动打出」这三种**仍然放不进状态触发器
        （它们要的是「打出这张牌」那一刻的上下文：这张牌本身、此刻弹选牌界面）——
        工具会在生成前拦住并说明原因。
      → **「升级卡牌」在状态里可以用**（本体储君的「暴政」就是状态里让玩家选牌的写法）：
        触发时机选「玩家回合开始时」+ 效果「升级卡牌」+ 「从哪里升级」选手牌，
        「自己选」= 弹选牌界面只列能升级的牌，「随机」= 本体 RNG 随机挑一张能升级的。
        「从牌堆拿牌到手牌」那三条同理，状态里也能用。
      → **新补上的三条**（以前会被误报「需要卡牌上下文」拦住，现在都能用）：
        · **清除目标的指定状态**（在「增益 / 减益」栏选要清哪个）—— 例：玩家回合开始时清掉自己身上的虚弱；
        · **清除目标的所有减益状态** —— 例：玩家回合开始时把自己身上的减益一次清光；
        · **牺牲伙伴换收益** —— 三档收益都能用：获得增益 / 减益、获得格挡、造成伤害。
          伙伴不在场时这一条会**静默跳过**（和卡牌上一样）。注意「收益 = 造成伤害」时
          「作用对象」别选「自己」（校验会拦住 —— 伤害要有敌方目标）；
          状态里没有「玩家选中的目标」，伤害会打你在这里选的**作用对象**（随机敌人 / 全体敌人 / 第一个敌人）。
      → ⚠ **「自己受到伤害后」/「自己失去生命时」+「失去生命 / 造成伤害」这个组合已经被保护了**：
        本体的伤害管线每打一下都会回调那两个钩子，而状态自己的「失去生命」也是走伤害管线 ——
        不拦的话就是「受伤 → 失去 1 点生命 → 又是一次受伤 → …」无限循环，一进战斗就被扣到死。
        现在生成端会自动给这类状态加一道**重入闸**（本状态自己的那次掉血不再触发自己），
        效果照旧生效、真实的下一次受伤照样触发，你不用做任何事。
  · 状态描述里怎么看到「什么条件下才生效」
      → 自动描述会带上条件，例：「自己造成伤害后：施加 [blue]10[/blue] 层冻伤
        （条件：拥有冰附魔至少 2 点，不满足时这条效果不生效）。」卡面上的条件本来就会写
        （「条件：生命值低于 50%（不满足时无法打出）」）。
  · 卡面 / 遗物 / 药水描述里的状态，鼠标移上去没有说明
      → 生成的卡牌 / 遗物 / 药水会自动声明 ExtraHoverTips：凡是这条效果「施加的状态」
        或「条件里盯的状态」，悬停时都会弹出说明 ——
          · 被改写的**本体状态**：弹出来的是你改的新名字 + 新描述；
          · **自定义状态**：弹它自己的名字和描述；
          · 「下回合生效」的走那个延迟状态类，一样有说明。
        药水那份是 public override，卡牌 / 遗物是 protected override（和本体写法一致）；
        没提到状态就不会生成这一段。
  · 想「战斗胜利后获得卡牌奖励」（像本体「王国资产」那样，挂在能力牌的状态上）
      → 「自定义状态」页：加一个状态 → 触发时机选「战斗胜利后」→ 效果选「获得卡牌奖励（N 选一）」；
        再回「卡牌」页加一张能力牌，效果选「施加增益/减益」选这个状态。打出这张牌之后，
        每场战斗打赢都会给一条奖励。
      → 打赢之后**结算界面多出一条「选一张卡」**，N 选一，选中直接进牌组；打输了不会给。
        走的是本体自己的战斗奖励（AfterCombatEnd + room.AddExtraReward + CardReward，
        本体「王国资产」「猎杀」就是这么写的）。
      → 想让「层数越高奖励越多」：在那条效果上勾「生效次数 = 本状态的层数」；只想固定一条就别勾。
      → 挂在别的触发时机（例如「玩家回合开始时」）也能用，但那是**当场**弹出选牌界面、选中立刻进牌组。
      → 想给遗物配同款奖励：在「遗物」页把触发时机选「战斗胜利时」，效果同样选「获得卡牌奖励」。

  ── 本体状态改写 / 先古之民 ──
  · 能改本体的状态吗（把「中毒」改名、换图标、把血条那截绿色换掉）
      → 能，到「本体状态改写」页：点「添加改写」，选状态（可以直接打字搜「中毒」），
        然后填新名字 / 新描述 / 上传图标 / 填血条颜色和层数数字颜色，再点「生成」。
        · 名字和描述：写在模组的 localization/zhs/powers.json 里，键和本体同名（如 POISON_POWER.title），
          本体加载模组本地化表时会覆盖自己那份，所以不用补丁；改名时顺手点一下
          「把描述里的旧名字一起换成新名字」。
        · 「本体卡牌 / 遗物 / 药水描述里的旧名字也一起换掉」（默认勾上）：本体那些写着
          「给予 N 层中毒」的卡面描述会一起变成你的新名字（只改描述键、不动卡名）。
          要读「解包后的原版工程」里的中文表才换得了卡面描述。
        · 换状态时右边会自动填好新状态的本体名字 / 描述，图标和颜色会清空。
        · 图标：换的是本体状态的图标（状态栏里那个小图，以及施加 / 闪烁特效里的大图）。
        · 血条颜色：本体血条上只有「中毒」和「灾厄」两截按状态显示颜色，两种画法都支持 ——
          中毒那截是纯颜色（本体原色 79C03C），直接换 self_modulate；灾厄那截本体是着色器
          （doom_bar.gdshader）用紫色渐变按噪声画的，工具会照同样结构（3 个色标、同样偏移、
          同样的明暗比）用你的颜色造一条渐变换上去（本体主色 834181）。
        · 层数数字颜色：可以按状态改（本体默认：减益红、其它米白）；本体「中毒」「灾厄」自己重写过
          这个颜色，所以补丁打在显示那一端（NPower.RefreshAmount）上。
        · 注意：这是全局改动 —— 本体其他角色身上的这个状态也会跟着变；
          一条都没添加时不会写出任何相关补丁与本地化键。
  · 「先古之民」页是干什么的
      → 给本体那些先古之民写你自己角色专属的对话。左边选先古之民，右边按「第几次到访 / 第几次」
        加对话段（从 1 开始），每段可以写好几行，还能单独给某一段填「继续」按钮上的字
        （不填就用本体的默认文字）。
      → 两个注意点：① 本体的「第一次见到」对话是全体角色共用的，会顶掉你写的第一段，
        稳妥起见从第 2 次开始写；②「建筑师」那一项里的次数指的是**通关次数**而不是到访次数。
        生成时日志里会有一行「已给先古之民 XXX 注入 N 段」。
  · 「先古之民」页的「把原本会给的遗物换成你要的」是干什么的
      → 本体每位先古之民会从他自己的候选表里筛选、洗牌，然后给你 3 个遗物选项（有时第 3 个是
        「尘封古书」）。界面把他原本会给的遗物全部列出来（左边那一列）。
      → 用法：左边点一个「原本的遗物」→ 按「② 替换掉选中的这个 →」→ 右边出现一条「替换记录」，
        在里面选「换成哪个遗物」（默认已经帮你挑了你自己做的那个；没有的话挑一个别的本体的）。
        每条记录下面那行会告诉你这条会不会生效：
          ✅ 会替换：这次选项里正好有它就直接换掉它；没抽到它就不动（不会顶掉别的选项）
          ⚠ 还没选「原本的遗物」—— 不知道要换掉哪一个，这条不会生效
          ⚠ 还没选要换成什么遗物 —— 这样生成出来不会有任何变化
          ⚠ 和原本的遗物是同一个 —— 等于没改
      → 生成时的做法：这次选项里正好有那个「原本的遗物」就换掉它；没抽到就什么都不做
        （不会顶掉别的选项）；要换成的遗物本来就在选项里就跳过。选项数还是 3 个。
        造选项用的是本体自己的 RelicOption 方法，行为与本体一致。
      → 拿不准为什么没生效时看游戏日志：每次替换都会写一行「选项：换之前 → 换之后（换了哪个、为什么）」，
        没抽到的那次会写「本次不替换」。
      → 注意：补丁挂在先古之民的事件上（本体的那几位事件是共用的），本体角色也会受影响；
        改了要重新生成 + 构建。

  ── 多人联机（跟朋友各玩各的角色）──
  · 先说结论：**「你只装你的角色、我只装我的角色」是连不上的**。本体握手时要求
    ①游戏版本一致 ②**影响玩法的模组列表完全一致**（id + 版本）③**模型 ID 库的哈希一致**。
    两个角色模组都往模型库里加东西，所以两条都不满足 → 报「模组不一致 / 版本不一致」。
    要一起玩：**每个人都装同一整套模组**（你的和他的都放进 mods）。
    非玩法模组（模组清单里 affects_gameplay 写成 false 的）可以不一样。
  · 「每个人看到的是自己那份」这件事，工具已经做到了这些（都在**运行时按「这一局本地玩家玩的是谁」**判断）：
      · 本体状态改名 / 换描述 / 换图标 / 换血条颜色 → 只在你自己玩我方角色时生效，别人那边照旧；
      · 额外资源量的计数器（图标 + 名字条）→ 按「这个计数器归谁」判断，你的计数器显示你的资源名；
      · 额外资源量的悬停提示（名字 + 说明）→ 写**我们自己的键**，计数器补丁换上去
        （以前是覆盖本体的「辉星」文案，两个模组会互相盖 —— 这一版改掉了）；
      · 卡牌 / 遗物 / 药水 / 状态 / 图标 / 场景 → 都带角色类名前缀，各用各的。
  · ⚠ **唯一要你自己注意的**：本体的「模型 ID」是**用类名算的**（不含命名空间）——
    两份模组只要有一个**同名类**，游戏加载模型库时会直接抛异常（表现：**游戏打不开**）。
    工具自动生成的类名都带角色前缀（`SparkleStrike`、`SparkleCard12`、`SparkleCurse1`、`SparkleAncient1`…），
    但你**手填的类名**
    （卡牌 / 遗物 / 药水 / 自定义状态 / 角色类名）要保证全世界不重名：
    最省事的做法是都带上你的角色名（两边角色名也别起成一样的、别都用默认的 MyCharacter）。
    左下角「配置检查」现在会提示「类名没带角色前缀」。
  · ⚠ 有两个功能**天生是全局的**，多人一起玩建议所有人配成一样、或者干脆不用：
    「本体卡牌 / 遗物 / 药水**描述**里的旧名字替换」和「本体**关键词**改名」——
    它们改的是本体的本地化键，两个模组都改同一个键就是谁后加载谁赢。

  ── 语义提醒 ──
  · 勾了「数值 = 本状态的层数」，游戏里给的却是层数、不是我填的数字
      → 那是这个勾选的语义：勾上之后生成的是 base.Amount（本状态的层数），「数值」里填的数字不生效；
        生成前的校验会把这句话直接写出来。想要固定数值就把勾去掉。
  · 「施加 30 层缓慢」，游戏里只看到「缓慢」、没有 30
      → 本体「缓慢」显示的数字**不是层数**：它显示的是「本回合已打出的牌数 × 10」
        （每打出一张牌，该敌人本回合受到的攻击伤害 +10%），跟层数无关；本体自己施加时也只施加 1 层。
        层数照旧记着，只是状态栏那个数字由它自己算。
      → 想直接给敌人上「受到伤害 +30%」，用效果里那一行：效果选「施加增益/减益」→ 状态选「缓慢」，
        下面会多出「直接把「缓慢」设成 ___ %」，填 30 就行（0 = 不设置）。生成时按本体做法只施加 1 层，
        再把内部数值写成 30%（并刷新状态栏）；描述会自动写成「施加冻伤（受到伤害 +30%）」。
        按 10% 一档折算（填 25 会按 30 处理），并且和原版一样**每次敌人回合开始会清零**。
      → 同一类「显示的数字不是层数、填层数没用」的状态（生成前的校验会一一提示）：
        SlothPower、TenderPower、PaleBlueDotPower、AutomationPower、CacophonyPower、PanachePower、
        WitheringPresencePower、MonologuePower、FeralPower、HardenedShellPower、OrbitPower、TagTeamPower。
        这些没有「直接设成 N%」的开关（数字按各自规则算）；想要加伤建议用显示数字就是层数的状态
        （例：易伤 / 中毒），或者自己在「自定义状态」页造一个。
