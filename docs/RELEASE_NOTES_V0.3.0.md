# V0.3.0 — 版本号升到 0.3（里程碑：编辑器扩展插件体系完成）

这一版**只改版本号**，功能与 V0.2.403 完全一致（自检 4790 PASS / 0 FAIL 不变）。
升到 0.3 的理由：从 V0.2.387 起，插件系统已经从「声明式表单 + 模板」扩成了**受控的编辑器扩展**体系，
需求书的第一/二/三期建议都落地了，够得上一个次版本号。

## 0.2.x 最后一段（374 → 403）都做了什么

### 声明式插件（只写 `plugin.json`）

* 嵌套列表**任意层**（可视化子表格、JSON 存储，兼容老的 `|` 文本）；
* 字段联动 `visibleWhen`（界面隐藏 + 生成按空值）、条件组合 `&& || !`；
* 页面间共享数据 `{页面id:栏位key}`；
* 插件自定义校验器 `checks`（页面级 + **行内**，带行号）、校验命中标记到行/栏位（`⚠`）；
* 主从布局 `layout:"master-detail"`（左列表 + 右详情 + 搜索 + 复制一行）。
