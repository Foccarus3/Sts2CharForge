# V0.2.205 —— 锻造区的「删除牌」填 0 = 删掉这张牌自己（以前填 0 什么都不发生）

> 用户原话：「锻造区，删除牌，数值填 0 不会删除自己」+ `godot (20).log`（日志里没有和这条相关的报错，纯行为问题）。

## 1. 为什么以前「填 0 什么都不发生」

`删除卡牌（全局：从牌组删牌）`（Kind = `RemoveCardGlobal`）和另外两个全局牌组效果
（`升级卡牌（全局）` / `变化卡牌（全局）`）都属于「数值 = 力量」那一类：

```csharp
// CSharpCodeGen.AmountIsStrength
or "AddCardGlobal" or "TransformCardGlobal" or "RemoveCardGlobal" or "UpgradeCardGlobal" ...
```

于是 数值 = 0 会走 `IsInertZero(e)` → **整条效果被丢掉**（卡面不写、代码一行都不生成）。
就算没被丢，生成端也是 `Math.Max(1, (int)e.Amount)` —— **0 被夹成 1 张**，变成「随机删 1 张 / 自己选 1 张」，
根本不是「删自己」。

## 2. 现在：数值 0 = 这张牌自己

`AmountZeroIsSelf` 收进这三个种类（和「丢弃卡牌 / 消耗卡牌 填 0 = 这张牌自己」同一套口径）：

| 种类 | 数值 0 生成的东西 |
| --- | --- |
| 删除卡牌（全局） | `foreach (c in PileType.Deck.GetPile(...).Cards.Where(c => c.IsRemovable && c.Id == this.Id)) await CardPileCmd.RemoveFromDeck(c);` |
| 升级卡牌（全局） | `… .Where(c => c.IsUpgradable && c.Id == this.Id) … CardCmd.Upgrade(c);` |
| 变化卡牌（全局） | `… .Where(c => c.Id == this.Id) … Transform（变成目标卡 / 随机卡）` |

要点：

- **按 ModelId 认牌**：战斗里打出的那张是副本，牌组里那份才是永久的那张；`c.Id == this.Id` 会把牌组里
  这张牌（同名副本、升级 / 未升级版本）都算上。
- **卡牌页和卡牌的锻造图都生效**（锻造图那边传的是 `ctx.CardSelfExpr`，生成出来就是 `this`）。
- **遗物 / 药水 / 状态的布上没有「这张牌」**：这两档退回老行为（0 当 1 张），并在生成的代码里写一行
  `// ⚠ 这块布上没有「这张牌」…数值 0 这里按 1 张处理` —— 不静默。
- 卡面 / 列表措辞也跟着改：卡面「把[gold]这张牌[/gold]从牌组里删掉（永久）。」、
  列表行尾「｜ 从牌组删掉这张牌自己（数值 0 = 这张牌自己）」。

## 3. ⚠ 对老存档的影响（一条，请看一眼）

老存档里如果**已经配了**「删除 / 升级 / 变化牌组」且数值是 0，以前的行为是「选 1 张」，
这一版起会变成「这张牌自己」。想保持原来的「选 N 张」请把数值填成 1 以上。

（对拍时发现 WhiteCloak 的 `WhiteCloakTensionMax` 就正好是这样一条：0 → 以前「选 1 张删掉」，
现在「删掉这张牌自己」。这是本次语义修正的必然结果。）
