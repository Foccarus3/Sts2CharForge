## 本版重点

### 新：英文类名 / 关键词标识自动「固定 + 修引用」

- **病根**：留空的英文类名（卡牌 / 遗物 / 药水 / 召唤物 / 自定义状态）和留空的自定义关键词「英文标识」
  是按**位置**自动编号的（`<角色>Card9`、`<角色>Pet2`、`KEYWORD_3`）。你只要在中间**插 / 删 / 拖动**一条，
  后面那些就**集体改名** —— 而效果里存的是**类名 / 键的字符串**（目标卡、哪只召唤物、自定义状态、
  卡牌上勾的关键词、`Keyword:XXX` 范围限定、给予关键词），于是引用要么直接失效
  （报「找不到 / 引用了不存在的自定义关键词」，构建失败），要么**静默指到别的模型上**。
- **现在**：每次构建都会（在配置校验之前）
  1. **固定类名**：把留空的类名 / 关键词键一次性写实并存进存档 —— 以后再加 / 删 / 拖动，已经固定的名字都不会再变；
  2. **修引用**：按上一次构建留下的「类名表」（输出目录里的 `<ModId>.forge_classmap.json`）把对不上的引用
     按**名字**改回原来那个模型，日志里写明「引用的 ×× 已自动改成 ○○」；认不回来时还有兜底
     （`<角色>Pet2` → 第 2 只召唤物、`KEYWORD_3` → 第 3 个关键词、只剩一只召唤物就认它）。
- 结论：**不需要**每次构建都去手工重排英文类名了，改完配置直接「一键构建 + 安装」。

### 修：一键构建必然失败 —— `CS0103: 当前上下文中不存在名称"__PETCMD__"`

- 「按生命值算」的宠物效果在动态变量里要写 `<宠物>Cmd`，生成时先写占位符再替换；
  以前**只有普通卡**那条路替换了，**诅咒 / 先古卡 / 遗物 / 药水**会把占位符原样写进代码 → 编译必失败。
  现在统一替换（找不到那只召唤物时退成固定 0 的普通变量），占位符不会再进生成代码。

### 修：其它几处「进游戏才发现 / 编译才失败」的问题

- 修「自己获得格挡后」「敌人回合开始时」「失去生命 / 失去最大生命 / 下回合额外资源量」这些触发时机
  漏造 `choiceContext` → 生成出来直接 `CS0103` 编译失败（每个触发时机各加了一条自检，以后同类漏项生成前就能拦住）。
- 修**商店黑屏**：卡池里某牌型的卡稀有度全是 Basic 时，进商店会抛异常（现在生成前拦住）。
- 修**预见卡卡死**（选牌界面提示语漏生成）。
- 修「同时装两个自建角色时，其中一个的能量图标消失」：不再改本体的图集精灵表。
- 修「金色富文本用不了」（标签拼错）。

## 本次更新（V0.2.0 之后累积）

### 新效果 / 新范围

- **牌堆四摞**：所有「从哪里选牌」的地方都支持 手牌 / 抽牌堆 / 弃牌堆 / **消耗牌堆**，
  并新增「从消耗牌堆拿牌到手牌」；「丢弃卡牌」也能从消耗牌堆选（等于把消耗掉的牌挪回弃牌堆）。
- **重放卡牌**：让选中的牌本场战斗内额外打出 N 次（本体 `BaseReplayCount` 机制，效果底下有「重放次数」栏）。
- **回合结束时自动打出**：数值 0 = 这张牌自己（回合结束时再自动打出一次）；数值 ≥ 1 = 打出时先选好 N 张，
  回合结束时逐张自动打出。
- **复制卡牌**（整张照抄）、**毒性爆发**、**大限已至**、**预见**、**升级卡牌**、**丢弃卡牌**、**击晕**、
  **透支能量（下回合少）**、**强化指定卡牌**（像「精准」）、**获得最大生命**。
- **生成卡牌**支持「多选 1」（在 N 张里选一张生成）与「生成到哪一摞」。
- **数值一律可填 0**：0 = 这条效果不生效（不显示、不执行）；三个例外保留特殊含义
  （召唤伙伴 0 = 用配置血量、给予关键词 0 = 这张牌自己、回合结束自动打出 0 = 这张牌自己）。

### 触发时机 / 条件

- 遗物触发时机新增「**获得时**」；「受到伤害时」拆成「每一下」与「受到攻击后（连击只算一次）」两个。
- 条件新增「**斩杀**」（本体 Fatal：这一次攻击杀死了目标，卡面照本体写成「[gold]斩杀[/gold]时，…」）、
  「抽牌堆被打乱洗过牌」、「生命区间」，并支持「填负数 = 反向」。
- 自定义关键词可以当作**卡的组**来用（范围限定里直接选「某个关键词那一组」）。

### 新的「诅咒 / 先古卡」页

- 自定义诅咒（含费用、关键字、回合结束在手牌里生效）与先古卡；先古卡卡面按竖图显示，
  诅咒 / 先古卡都能用 `RRGGBB` 单独换卡框颜色。

### 其它

- 临时保留 / 临时奇巧 / 临时增益（下回合生效）、给予卡牌关键词、模组预览图、
  遗物与药水的自定义描述、状态伤害不归因、Ctrl/Shift 多选一次删干净。
- 本地化：卡面描述里的富文本（`[gold]` 等本体颜色 / 动效 / 占位符）与自定义描述都写进了 `使用说明.txt`。

## 说明

- 已经用旧版生成的模组，建议用这一版**重新生成 + 重新安装**一次：
  英文类名被固定下来、引用也被修好，以后不会再有「改了配置就构建失败」。
- 存档格式没有变化，直接覆盖更新即可；你的存档在 `自定义角色存档\` 里，覆盖程序文件不会动它。
- 发布包里**不含任何存档**、也不含任何《杀戮尖塔 2》的游戏素材；程序运行时只读取你本机的游戏文件。
- 程序内嵌的效果库数据需要你自己用「效果库」页从本机解包工程生成（仓库不附带游戏文本）。

## 使用方法

1. 解压后运行「启动 Sts2CharForge_V0.2.35」（`.bat` 或 `.lnk`）
2. 第一次用请先看根目录的 `使用说明.txt`（含「！首次使用先点这个！」里的 GDRE 教程）
3. 详细功能说明见根目录 `README.md`
