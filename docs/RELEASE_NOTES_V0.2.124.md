# V0.2.124 更新说明

> 你报的「**遗物页现在有问题**」+ 需求文档《遗物、药水优化.md》里**遗物页那几条**（药水页留到下一版）。

## 一、先修：遗物页效果编辑器「看不见、点不到」

**现象**：遗物页右边那块效果编辑器几乎看不到、点不到；底下「单条效果的触发条件」完全够不着；整页还多一条没用的横向滚动条。

**根因**（用临时探针把遗物页渲染成 PNG + 打出每个控件的 `ActualWidth/Height/X/Y` 量出来的）：
V0.2.122 把整块效果编辑器塞进了效果列表的 `ItemTemplate`，而 **ListBox 默认允许横向滚动** →
虚拟化面板按**无限宽度**量每一行 → 行里的编辑器被排成 **8270px 宽、507px 高**，视口只有 414×160 →
编辑器（含底下的「条件」）被切掉、摸不到，还多出横向滚动条。

**修法**（纯布局，与生成语义无关）：给遗物页的两个列表加
`ScrollViewer.HorizontalScrollBarVisibility="Disabled"` + `HorizontalContentAlignment="Stretch"`，
行宽夹回 414（修后量到 410），并给「条件」单独一块独立可见的位置。

## 二、遗物页按需求重排（《遗物、药水优化.md》第 2~5 条）

| 需求 | 这版的做法 |
|---|---|
| 去掉左上角「关于额外资源量」的内容 | 那块整块搬到「额外资源量/状态」页底部（连「在游戏中隐藏」勾选框，它本来就属于那一页） |
| 左侧列表加**序号**（不随遗物移动） | 每行最左边一列显示序号，序号永远按**当前顺序** 1..N 重排 |
| **拖动遗物换位置** | 支持拖放：拖动后列表顺序真的变（落点 = 插到鼠标下面那一行的位置） |
| 没填英文类名的，重新生成时**按序号重算** | 生成前先认「自动名」（整串正好是 `<角色类名>Relic<数字>`）→ 按当前序号改成新名字；**用户手填的一个字不动**；保持「没填就还是留空」的语义，模型里不加存档字段（`Ordinal` / `LastAutoOrdinal` 都是 `[JsonIgnore]`，老存档序列化面零变化） |
| 稀有度**英改中** | 初始 / 常见 / 罕见 / 稀有 / 先古 / 商店（下拉、列表行、额外资源量摘要都跟着；存的值仍是英文 id） |
| 中间部分底下加**整只遗物的触发时机列表** | 就是多条触发时机那套（能加多条、每条各自配效果、能勾「要和其他时机同时成立」= 「全部满足才生效」），整块搬到中间栏、属性区之下 |
| 之下再加**自定义描述** | `自定义描述` + `替换掉自动生成的描述` 两栏，放在触发时机列表下面 |
| 右侧 = **效果栏**，右下角选**单条效果的触发条件** | 右栏显示当前那条时机的效果列表 + 添加/删除/撤回；**右下角独立一块「这条效果的条件」**（以前它是被切在 8270px 行里的） |

## 四、已知边界

- 若某处引用写的是「自动类名」（例：先古遗物替换的目标），把那只遗物拖到别的位置后重新生成，会让那条引用**报「找不到」并由校验器拦下**（改之前是**静默串到另一只遗物上**，更糟）。要彻底认回来需要给引用修复补一条「按旧名字找回」，留到后续版本。
