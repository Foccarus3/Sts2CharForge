# V0.2.385 — 主从布局：左侧搜索框 + 「复制一行」

补齐 V0.2.384 的两个小缺口（缺口文档第 5 节的体验部分）。

## 新增

* **搜索框**（左侧列表上方）：按行标签（那一行第一个非空标量值）过滤，**只影响显示**——
  内部用 `idxMap` 记着「显示项 → 真实行号」，所以选中、编辑、删除、上下移都作用在真正的行上；
* **「⧉ 复制」按钮**：把选中这一行复制一份插到它下面（整行深拷贝，包括子列表的 JSON），
  改完立刻落盘。

## 自检

**4732 PASS / 0 FAIL**（+2 条：主从布局确实有搜索框和「⧉ 复制」按钮 / 输入「格挡」后列表只剩 1 行）。
