# V0.3.113 — 先古 / 状态卡补「不能被打出」；插件规范强化禁 DLL

## 1. 先古卡 / 状态卡

「诅咒 / 先古 / 状态」页的详情面板里，先古卡和状态卡现在也有：

```text
不能被打出
```

和普通卡页一致，绑定 `CardSpec.Unplayable`，生成 `CardKeyword.Unplayable`。

- 诅咒页原本就有这个勾选；
- 先古 / 状态页这次补齐；
- 勾上后卡牌打出判定按本体 `Unplayable` 处理，和费用 -1 不冲突。

## 2. 插件规范 / AI 提示词

- `docs/插件开发规范.md` 顶部新增「0. 最高优先级：默认禁止 DLL」；
- 明确 `csFiles` 是源码、会编进模组 DLL，不是插件 DLL；
- 明确禁止 AI 生成 `.dll / .exe / .csproj / .sln / build 脚本`；
- `editorExtension` 是唯一例外，只能用户明确要求编辑器 UI 扩展时才用；
- `docs/插件AI提示词.md` 同步加硬规则。

## 3. 能量填 -1 的含义

效果「获得能量」数值填 **-1**：

```text
扣除当前 1 点能量（LoseEnergy）
```

不是“下回合少 1 点”。下回合少要用：

```text
透支能量（下回合少）
```

如果卡牌**费用**填 -1，那是另一件事：

```text
这张牌打不出去（Unplayable）
```
