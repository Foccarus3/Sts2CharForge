# V0.2.182 更新说明

> 你要求：「**参数占的面积太大了，能不能全删了，不占用生成器内的位置，然后每次打开生成器时，
> 打开一个参数参考小窗口，并且对里面的参数进行分类**」。

---

## 一、删掉的是什么

以前「可用量」清单是**内嵌**在效果编辑器里的 —— 一个蓝框，把 **80 条内置只读量**铺成一大片，
而且**摆了三份**：

| 位置 | 什么时候显示 |
|---|---|
| 卡牌页效果编辑器 | 选了「伤害 / 格挡 / 失去生命 / 回复生命 / 施加状态」这 5 种（能写公式的那些） |
| 遗物 / 药水 / 自定义状态效果编辑器 | 同上 |
| 锻造页【效果】模块 | 模块上「数值」那一栏能写公式时 |

**这三块整块删掉了**（连模板 `FormulaBuiltinList` 一起删，不留空占位）。
效果编辑器里现在干干净净，只剩本来就该填的栏位。

顺带把几处提示文案里那句「完整清单见效果编辑器下面那个『可用量』小框」也改成指向新窗口 ——
不然提示会指到一个已经不存在的东西。

## 二、新窗口：参数参考（每次打开生成器时自动弹）

`ParamReferenceWindow` —— 非模态（可以拖到一边继续干活，关掉就没了，主窗关掉时它一起走），
**左边分类、右边看这一类全部条目（含出处）**：

| 类别 | 内容 | 条数 |
|---|---|---|
| 内置实时读数（不用定义，直接写） | `FormulaBuiltins.All` 那张表 —— Turn / HandCount / DeckStatusCount / PlayedThisTurn / PowersOnMe… | **80** |
| 特殊变量 X / Y | X（当前能量）· Y（当前额外资源量）· XSpent · YSpent，都写清了语义 | 4 |
| 自定义参数（你这个存档定义的） | 按**当前存档**列：每个参数名 + 它从哪取值（例：`M` → 最大生命） | 按存档 |
| 参数取值来源（新建参数时选） | `ParamSources.All` 那份下拉候选 —— 固定数值 / 当前血量 / 最大生命 / 金币 / 能量 / 状态层数 / 各类实时读数 | 87 |
| 公式能写什么（语法） | 运算符 · 函数（min/max/floor/ceil/round/abs/clamp）· 内置量 · 参数名 · X/Y · 「纯数字那一档」的说明 | 6 |

数据源和生成端**同一份**（`FormulaBuiltins.All` / `ParamSources.All`），所以窗口里列出来的名字
就是生成时认的名字，不会出现「窗口里有、公式里不认」。

## 三、验证

* `--uicheck` **3802 PASS / 0 FAIL**。这一段自检都改成了新口径，并且是**钉住新行为**的：
  ① 效果编辑器里**不再**出现「可用量」；
  ② 参考窗按类分好了（≥5 类，每类都有标题 / 说明 / 条目）；
  ③ **80 条内置只读量一条不丢地进了参考窗**（逐条对 ID）；
  ④ 每个名字都带中文说明；⑤「获得的能量」那两条在；
  ⑥ X / Y / 参数名三种写法都有单独一类；
  ⑦「自定义参数」那一类**按存档走**（给一份带 `M` 的存档 → 那一类里就有 `M`）；
  ⑧「取值来源」那一类就是 `ParamSources` 那份候选（条数相等）；
  ⑨ 锻造链那个「真画出来了那几栏」的断言改成**要求「可用量」不出现**（防它悄悄回来）。
* 生成端**一个字节都没动**：这次只改界面 + 提示文案。

## 四、你要做的

更新到 V0.2.182 → 打开生成器，参考窗会自己弹出来（左边分类点着看）。
**生成结果不受影响**，所以不必重新构建模组；只有你想再打一次包时才需要重新生成 + 一键构建。
