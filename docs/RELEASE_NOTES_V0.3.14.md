# V0.3.14 — 变量页：公式里现在能直接用变量

接 V0.3.13（容器类生成端），这一步把**公式解析**接上了：公式里写变量名，会解析成生成出来的容器类。

## 改了什么

`ForgeFormula.InlineResolver` 的解析顺序加了一层（在 `X` / `Y`、内置读数之后，自定义参数之前）：

```
X / Y → 内置只读量 → **变量页里的变量** → 自定义参数 → 报「找不到」
```

实际效果：

| 你在公式里写 | 生成出来的代码 |
|---|---|
| `cnt + 2`（`cnt` 是变量页里的变量） | `SevenVars.cnt + 2` |
| `X*3` | 不变（还是能量那条） |
| `cnt` 但**没建**这个变量 | 不被误认（仍走「参数 / 内置」那条路；都没有才算找不到） |

## 自检

**4812 PASS / 0 FAIL**（+2 条）：

* `InlineResolver("cnt")` → 实测 `SevenVars.cnt`；
* 没建变量时同名标识符**不被误认**（返回 `(null)`，交给后面的参数/内置逻辑）。

## 目前的完整度（如实）

| 能力 | 状态 |
|---|---|
| 变量模型（名字规范 / 全局 / 允许负数 / 上限） | ✅ V0.3.12 |
| 容器类生成（两档重置 + 夹取） | ✅ V0.3.13 |
| 公式里**读**变量 | ✅ V0.3.14 |
| 写操作（`+ - = 清零`，四链 + 锻造节点） | ⏳ V0.3.15 |
| 容器类接进工程 + 战斗开始/开局重置调用 | ⏳ V0.3.15 |
| 变量页 UI（横幅 / 行内校验 / 试算） | ⏳ V0.3.16 |
| 循环引用检测、撞名校验 | ⏳ V0.3.15 |

也就是说：**变量现在能"算值"了，但还不能"改值"、也没有界面**——所以你暂时还用不到它，别急着建变量。
下一步（V0.3.15）会把「写操作 + 接进工程 + 重置调用 + 校验」一次做完，那时才算真的能用。
