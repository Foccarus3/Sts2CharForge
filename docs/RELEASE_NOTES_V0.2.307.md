# V0.2.307 — 「叠了三层，伤害还是 1 点」：状态层数要勾一下才会用

用户原话：

> 状态是生成一张牌造成一伤害，加了三层，但是还是1伤害

## 查了一下你的存档（`Dddddddog.json`）

那条状态是 **「墨水飞溅」**（`MoShuiFeiJian`）：触发时机「生成卡牌时」→ 造成 1 点伤害（随机敌人）。
把它生成出来是这样：

```csharp
if (other is null) break;
await CreatureCmd.Damage(choiceContext, other, 1m, ValueProp.Unpowered, null, null, null);
//                                      ↑ 固定 1 点：和层数没关系
```

而卡牌「墨水飞溅」给它叠的是 **1 层（升级后 3 层）** —— 所以你升级后看到 3 层、打出来还是 1 点。

**这是配置没勾，不是丢代码**：这个工具里「层数」不会自动乘到效果上（很多状态的层数只表示「还剩几次」，
自动乘上去反而会错）。要让层数起作用，状态那条效果上面有三个勾选框：

| 勾选框 | 效果 |
|---|---|
| **数值 = 本状态的层数** | 伤害 / 格挡 / 生成卡牌…按**当前层数**算：3 层 = 3 点伤害 |
| **生效次数 = 本状态的层数** | 这条效果按层数**重复执行**：3 层 = 打 3 次（每次 1 点） |
| **命中次数 / 对群数 = 本状态的层数** | 只对「随机敌人」有意义：层数 = 挑几个目标 |

勾上「数值 = 本状态的层数」之后，那条伤害生成的就是：

```csharp
await CreatureCmd.Damage(choiceContext, other, base.Amount, ValueProp.Unpowered, null, null, null);
//                                      ↑ 当前层数：3 层就是 3 点
```

（勾上之后效果里的「数值」框填什么都不用了。）

## 这一版改了什么

光在界面上写着不够 —— 你显然没注意到那三个勾（它们藏在效果编辑器上面）。所以现在**校验器会主动提示**：

> [提示] 自定义状态「墨水飞溅」的层数**现在对它的效果没有任何作用**：卡牌「墨水飞溅」会给它叠 1 层（升级后 3 层），
> 但状态里的效果没勾「数值 = 本状态的层数」也没勾「生效次数 = 本状态的层数」——所以叠到几层，效果都还是按固定数值来一次
> （例：伤害永远 1 点）。想让层数决定强度就勾「数值 = 本状态的层数」（3 层 = 3 点伤害）；想让层数决定次数就勾
> 「生效次数 = 本状态的层数」。（这两栏在「状态」页那条效果上面；勾上之后「数值」那一栏就不用了。）

**只在该提示的时候提示**（不刷屏）：

* 状态里已经勾了任一层数开关 → 不提；
* 全份配置里只按 1 层、升级也不加层的状态 → 不提（层数根本没变，提它没意义）；
* 用锻造节点图的状态 → 不提（图上那份由模块自己的「数值 = 层数」管）；
* 层数写成**认不出来的公式** → 不提（不乱猜）。

拿你这份存档跑：26 个状态里只有 4 条会提示（墨水飞溅 / 精进 / 滋养 / 彩色形态），另外 22 条要么只叠 1 层、
要么本来就勾了层数开关或者用图。

## 你要做的事

打开「状态」页 → 选「墨水飞溅」→ 上面那条「造成伤害」→ 勾 **「数值 = 本状态的层数」** → 重新生成。
这样卡面写的「1 点 / 升级后 3 点」就和实际一致了。
