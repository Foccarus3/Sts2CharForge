# MarketAdmin V0.3.76 — 检索已有插件并删除

## 新增

市场发布器顶栏：

```text
已有插件：[搜索框] [插件下拉]  版本：[下拉] [刷新已有插件]
```

- 从本地 `market/index.json` 读取所有已上架插件；
- 搜索匹配：名称 / id / 作者 / 关键词；
- 选择插件后自动填：
  - id
  - 名称
  - 作者
  - 简介
  - 许可证
- 版本下拉列出该插件的所有版本；
- 选好插件 / 版本后：
  - 「删除当前版本」只删这个版本；
  - 「删除整个插件」删整个条目和本地包。

删除后自动刷新「已有插件」列表。

## 安全

- 删除前备份 `market/index.json.bak`；
- 不自动 git；
- 不删除 GitHub Release 附件；
- 已安装用户不会被远程卸载。
