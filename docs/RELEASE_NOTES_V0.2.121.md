# V0.2.121 更新说明

## 一、修好：「升级增量」在打了「数值公式」的卡上完全没效果

**根因有两层，互相独立**（缺一层都还是没效果）：

1. **打出时用的是公式算出来的字面量，跟升级增量改的变量不搭界。**
   打了数值公式的卡（V0.2.112 起老存档的固定数值会自动迁成公式），生成出来的是
   `await DamageCmd.Attack((14m)) …` —— 而本体的升级增量是 `OnUpgrade` 里的
   `base.DynamicVars["Damage"].UpgradeValueBy(6m)`，改的是**那个动态变量**。
   打出时压根没读它 → 升级前后打出来一样多。
2. **就算去读变量也没用**：公式变量的 `UpdateCardPreview` 每次预览都会用公式把 `BaseValue` 重写一遍，
   `UpgradeValueBy` 加的那 6 被覆盖掉 → 连卡面数字都不会变。

**修法**：生成时把增量并进「打出时」的表达式，写法沿用本体习惯的「升级前后两个数」：

| 情况 | 现在生成的样子 |
|---|---|
| 公式是纯常数（老存档迁过来的固定值） | `DamageCmd.Attack((base.IsUpgraded ? 20m : 14m))` |
| 真·现算公式（例 `Turn*3`） | `DamageCmd.Attack((base.IsUpgraded ? ((…公式…)+ 3m) : (…公式…)))` |
| 公式变量（卡面用） | `new ForgeFormulaDamageVar(static (card, target) => (14m), 6m)`，预览时 `公式值 + (card.IsUpgraded ? 增量 : 0)` |

- **没有升级增量的卡，生成文本一个字都没变**（红线，自检里钉住了两条对照断言）；
- 格挡 / 失去生命 / 回复生命 / 施加状态**五条公式链都一起修了**（它们共用同一个发射器）；
- 顺手补了一个回读缺口：真·现算公式那条（公式里套了很多层括号）回读时会漏掉变量，
  又会刷「升级增量找不到对应效果」—— 现在改成按行取值，认得更稳。

**用你的存档验证过**（`SparkleMod.json`）：

- `SparkleCardBurst`（伤害 14、升级 +6）现在生成 `Attack((base.IsUpgraded ? 20m : 14m))` 与带增量的公式变量；
- 重新生成 → **真 `dotnet build` 0 错误**（装到临时目录，没碰你游戏的 mods）；
- `--recover` 回读：`Amount=14 / UpgradeAmount=6` 原样回来、**0 条「没认出来」**。

## 二、命中次数 `2+A`：代码侧没查出问题（证据如下）

你那张牌（`SparkleCard45`：伤害 5、命中次数 `2+A`）我逐层核过：

- 生成出来的是
  `.WithHitCount((int)System.Math.Clamp(((2m) + __pA), 1m, 20m))` —— 和本体多段攻击**同一套写法**
  （本体 40+ 张卡都是 `.WithHitCount(...)`，例如 `DaggerSpray` / `TwinStrike`）；
- `A` 按你「自定义参数」页里的定义 = **自己的最大能量数**，生成的绑定是
  `decimal __pA = (__fgPlayer?.MaxEnergy ?? 0m);` ✓ 没绑错；
- 卡面文案也是「对指定敌人造成 {Damage:diff()} 点伤害 **2+A 次**。」（描述里那个 2 没丢）；
- 游戏里装的 `mods\SparkleMod.dll` 与工程 `build\SparkleMod.dll` **SHA256 完全相同**，
  所以游戏跑的就是上面这段代码。

也就是说：**生成端没有丢掉那个 +2**，`2+A` 这段代码是照本体的用法发出去的。
要定位「游戏里只实现 A 次」，还差一步现场信息 —— 麻烦确认下面任意一条：

1. 那场战斗里你的**最大能量数**是多少（A = 最大能量数）？实际打了几下？
2. 把「命中次数」改成**固定数字**（例如 5）打一次：是真打 5 下、还是也不对？
   —— 这一步能把「公式路径的问题」和「命中次数本身」彻底分开；
3. 你是怎么看「几下」的：卡面数字 / 屏幕上伤害段数 / 伤害统计 mod 的显示？

> 另外提醒一句：敌人身上有**格挡**时，前几下的伤害会被吃掉（伤害统计上看不到），
> 有可能让「打了 5 下」看起来像「3 下」——如果那条记录是在有格挡的敌人身上看的，就不是 bug。
