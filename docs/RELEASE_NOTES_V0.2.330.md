# V0.2.330 — 参数「指定敌人最大生命」乘系数不生效（显示的是 B 本身）

用户原话：

> 设参数B为指定敌人的最大生命值，当造成参数B*0.3数值的伤害时，卡面描述显示的是B而非B*0.3

## 真因：`??` 的优先级把乘号吃掉了

「参数 = 某只敌人的最大生命」生成的是**带空合并**的片段：

```
(target)?.MaxHp ?? 0
```

公式 `B*0.3` 拼出来变成：

```csharp
(target)?.MaxHp ?? (0 * 0.3m)     // ← 实际是：有目标就取 MaxHp，0.3 只乘了那个兜底 0
```

也就是**乘系数完全没作用**，伤害 / 卡面数字就等于满血值 —— 你看到的「显示的是 B」。

代码里本来有一个「给带 `??` 的片段套括号」的保护，但它的判据是「首字符是不是 `(`」，
而 `(target)?.MaxHp ?? 0` 恰好**首字符是 `(`、整体却没被包**，于是被当成安全跳过了。

## 改法

把判据换成「**整体**被一对括号包着才算安全」：

```csharp
private static bool FullyWrapped(string rep)   // 首字符 '(' 且与它配对的那个 ')' 正好是最后一个字符
{
    ...
}
private static bool NeedsParens(string rep) =>
    rep.Contains("??") && !FullyWrapped(rep);
```

现在 `B*0.3` 生成：

```csharp
(((target)?.MaxHp ?? 0) * (0.3m))
```
