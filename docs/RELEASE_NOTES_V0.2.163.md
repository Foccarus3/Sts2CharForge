# V0.2.163 更新说明

> 回答你说的：「生成器是不是还不能选择所有手牌」→ **现在能了**。
> 「取几张」多出第四档 **「全部」**：**不弹选牌界面**，直接对那一摞里符合条件的每一张动手 ——
> 本体「恶魔之焰 FiendFire」消耗所有手牌就是这种。

## 一、「取几张」四档

选牌类效果（消耗 / 丢弃 / 升级 / 复制 / 重放 / 变化 / 回合结束自动打出 / 放置 / 给予关键词 /
从三摞拿牌 / 三种全局牌组，**共 15 种**）的「取几张」现在有四档：

| 取几张 | 生成的东西 | 表现 |
|---|---|---|
| 恰好 N 张（默认） | `new CardSelectorPrefs(prompt, N)` | 必须选满（老存档行为，一个字符都没变） |
| 最多 N 张 | `new CardSelectorPrefs(prompt, minCount: 0, maxCount: N)` | 可以少选（本体「净化」那种） |
| 任意张 | `new CardSelectorPrefs(prompt, 0, 999999999)` | 弹界面，想选几张都行（含全选） |
| **全部**（新） | `foreach (CardModel c in <那一摞>.Cards.Where(范围).ToList()) <动手>` | **不弹界面**，直接全动（恶魔之焰那种） |

卡面文案跟着档位走：`消耗 {Cards:diff()} 张手牌。` / `消耗 最多 … 张手牌。` / `消耗 任意张手牌。` /
**`消耗 所有手牌。`**。「全部」档还会把不生效的词（自己选 / 随机 / 牌顶）从卡面里去掉 ——
和 V0.2.161 同一条规矩：**不生效的栏位，文案里也不写**。

## 二、恶魔之焰那种牌在生成器里怎么配

1. 「卡牌」页建一张牌（例：2 费攻击 / 稀有 / 自带「消耗」关键词）；
2. 效果加一条 **「消耗卡牌」** → 「选牌方式 = 自己选」「从哪里选牌 = 手牌」→ **「取几张 = 全部」**；
3. 再加一条 **「造成伤害」**：数值 7（升级增量 3），**「命中次数公式」填 `HandCount`**（打之前手牌有几张）；
4. 生成出来就是：
   ```csharp
   // 全部：把手牌里符合条件的牌**全部**消耗（不弹选牌界面，本体「恶魔之焰」那种）
   foreach (CardModel c in PileType.Hand.GetPile(base.Owner).Cards.ToList()) await CardCmd.Exhaust(choiceContext, c);
   …
   await DamageCmd.Attack(7m + (base.IsUpgraded ? 3m : 0m)).WithHitCount(<HandCount 现算>).FromCard(this, cardPlay).Targeting(cardPlay.Target).…
   ```
   （「消耗所有手牌」和「每张造成 7 点」是两条效果，顺序按你排在效果列表里的顺序。
   本体那张是**先全消耗、再按消耗掉的张数打**，所以「消耗卡牌」要排在伤害前面。）

## 三、另外三件事

- **「全部」这一档不看「选牌方式」**（没有界面、也不是随机）：校验器会给一句提示；
  「升级增量」对它也没有落点（没有张数可显示），同样有一条提示 —— 都不静默忽略。
- **回读**：非默认档（最多 / 任意 / 全部）现在会写一行 `// CET:CountMode=…` 标记 ——
  「全部」那一档代码里**根本没有选牌语句**，逐行猜不出来，只能靠这行标记。
  顺手把「最多 / 任意」以前**回读不出来**（会退回「恰好 N 张」）的老缺口一起修了。
- 「全部」的具体写法按种类各按本体习惯：消耗/升级/删牌是逐张调用，丢弃/放置/拿牌是**整批**调用
  （`CardCmd.Discard(choiceContext, list)` / `CardPileCmd.Add(list, …)`），变化/复制/重放/给关键词是
  先拍快照再逐张处理（遍历中改集合会炸 —— 本体恶魔之焰也是先 `.ToList()`）。
  15 种全部**真编过**：拿真 Godot SDK + 游戏自己的 `sts2.dll` 编译，0 错误。
