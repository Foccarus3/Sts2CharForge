# V0.3.138 — 动画页的四项参数改成「每个动作单独设置」

## 需求

用户原话：

> 让动画页的参数调整每一个可以单独设置而不是共享一个设置

以前「缩放 / X 偏移 / Y 偏移 / 播放速度系数」是**7 个动作共用一套**（待机和攻击只能同一个偏移）；
现在每个动作各填各的，互不影响。

## 一、界面

四项数值框从「页面下方的全局设置区」搬进**每个动作自己的详情里**（选中哪个动作就是在调哪个动作）：

```text
这个动作的参数（每个动作单独设置）
  缩放（0 = 按静态立绘高度自动算）        [ 0.8    ]
  X 偏移（立绘像素，正数往右；相对瞄点）  [ 2      ]
  Y 偏移（立绘像素；0 = 自动…）           [ 3      ]
  播放速度系数（1 = 动图原速，2 = 双倍速）[ 2      ]
  [套到全部动作]  [这个动作跟随全局]
  这一格已单独设置（只影响这个动作）。全局默认：缩放 0、X 0、Y 0、速度 1×；点「这个动作跟随全局」可恢复。
```

- **没单独设过的动作 = 沿用全局默认**（就是改之前大家共用的那一套），所以老存档打开后行为一模一样；
- 改第一格时会按当前全局值给这个动作建一份覆盖（其余三项不变），之后只影响这个动作；
- **「套到全部动作」**= 把当前这四项复制给 7 个动作（想统一调整时用，之后仍可各自动）；
- **「这个动作跟随全局」**= 删掉这个动作的覆盖，回到全局默认；
- 总开关没勾时这一块整体收起来（和以前「设置区只在启用后显示」一致）；
- 预览（帧图位置 / 缩放的实时预览、下面那行「相对瞄点」读数、预览速度）都跟着**当前选中的动作**走；
- 「预览动画计划」的文本也改成按动作逐条写出它的缩放 / X / Y / 速度。

## 二、存档格式（老存档不用迁）

`AnimationSpec` 新增（可空）：

```json
"Animation": {
  "Enabled": true,
  "Idle": "...", "Attack": "...",
  "SlotParams": {
    "attack": { "Scale": 0.8, "XOffset": 2, "YOffset": 3, "SpeedScale": 2 }
  }
}
```

- `SlotParams` 的 key = 本体动画名（`idle_loop / attack / cast / hurt / die / overgrowth_loop / relaxed_loop`）；
- 四项都是**可空**：`null` / 缺项 = 这一项跟随全局（`Scale` / `XOffset` / `YOffset` / `SpeedScale`）；
- 老存档没有 `SlotParams` → 每个动作都跟随全局 → **生成结果和以前完全一样**（下面「逐字不变」那条有自检钉着）。

## 三、生成端

- `AnimFramesGen.BuildPlan`：给每个动作算一套生效值（单独设置优先；缩放 0 / Y 0 仍按原来的自动规则算），
  写进 `AnimPlan`（新增 Scale / XOffset / YOffset / SpeedScale 四个字段）；
- `FrameAnimGen.RegistrationLines`：
  - **一个动作都没单独设过** → 仍然写老的四个 `const float __anim*` + `Register(..., scale: __animScale, ...)`
    （老存档生成的 `ModEntry.cs` 逐字不变）；
  - 有动作单独设过 → 每个 `Register` 直接写它自己的字面量（例：`scale: 0.8f, xOffset: 2f, yOffset: 3f, speedScale: 2f`）；
- 运行时 `FrameAnimRuntime.cs`：
  - `AnimDef` 带上这个动作自己的缩放 / X / Y / 速度；
  - `Play()` 切动作时把**它自己的**位置 / 缩放 / 速度套到 `AnimatedSprite2D` 上（以前是角色级常量、只在挂载时摆一次）；
  - 速度改由 `AnimatedSprite2D.SpeedScale`（倍率）实现，不再去改共享的帧资源时长
    —— 以前那种写法里，两个动作共用同一张 GIF 时后播的会把先播的速度也改掉；
    `CurrentLoopSeconds` / 单次动画的计时都按速度换算回真实秒数。

⚠ 这一版**动画运行时模板变了**：已经开着逐帧动画的工程要重新生成一次（行为不变，只是把「角色级」换成「动作级」实现）。
没开逐帧动画的存档不受影响（不生成任何动画文件）。
