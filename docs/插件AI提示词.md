# 给 AI 用的提示词：给 Sts2CharForge 写插件

> 直接把 `=== 提示词开始 ===` 到 `=== 提示词结束 ===` 之间的内容发给 AI（Claude / GPT / DeepSeek 都行），
> 它就能按规范写出一个能用的插件。里面用的是**相对位置**（都以「程序目录」= 编辑器 exe 所在目录为基准），
> 换台机器 / 换安装位置都不用改。

---

=== 提示词开始 ===

你是「Sts2CharForge（杀戮尖塔2 自定义角色生成器）」的插件作者。请给我写一个插件。

## 1. 文件位置（这是硬信息，先按这些相对位置找，找不到再问我）

以**程序目录**为基准（= `Sts2CharForge.exe` 所在目录，也就是启动器旁边的 `程序文件` 文件夹）：

| 要找的东西 | 位置 |
|---|---|
| 插件要放的地方（每个插件一个子文件夹） | `程序目录\plugins\` |
| **插件开发规范（完整字段 / 占位符 / 打包规则 / 兼容约定）** | `程序目录\docs\插件开发规范.md` |
| 可以照抄的示例插件 | `程序目录\plugins\示例插件\plugin.json`（同目录下还有 `cs\PluginDemo.cs`） |
| 生成的模组工程长什么样 | 编辑器「构建 / 日志」页 →「打开输出目录」→ 存档名那个文件夹 |
| 生成出来的代码里能用的 using | 生成工程的 `cs\GlobalUsings.cs` |

另外两处按需：

* **本体（游戏）API 参考** —— 用编辑器「路径」页里填的「本体工程目录」（解包后的原版工程，含 `src\Core\Commands\`），
  例如 `src\Core\Commands\CreatureCmd.cs`、`PowerCmd.cs`、`CardPileCmd.cs`。生成出来的代码只能调用这里的 API。
* **编辑器源码**（想看它是怎么生成代码的、自带 65 种效果各长什么样）—— 只有开发机上才有：
  `Sts2CharForge.Core\Generation\CSharpCodeGen.cs`（搜 `case "Damage"` 之类）、`CustomPowerGen.cs`、`ForgeGraphGen.cs`。
  你没有源码也能写插件：规范文档 + 示例插件已经够用。

**写之前请完整读一遍 `程序目录\docs\插件开发规范.md`**；本提示词只是摘要，规范里才是准的。

## 2. 插件现在能做什么

✅ 已接入：**新的效果种类**（出现在卡牌 / 遗物 / 药水 / 自定义状态 / 锻造图的「效果种类」下拉里）、
**额外内容页**（Markdown，在编辑器「插件」页显示）、**自带 C# 文件随模组一起编译打包**。

✅ **自定义页框架**（V0.2.319）：`pages` 里可以声明 `fields`（text/number/bool/pick/multiline）、`target`（写到工程的相对路径）、`emit`（模板，占位符 = 字段名）—— 编辑器渲染成表单、存值、预览、生成时写成文件（随 mod 打包）。**这是给「编辑器本来不认识的内容」用的**（例如事件生成器）：编辑器不需要懂「事件」，你把页面和产物都定义好就行。
✅ 也都接了（V0.2.316）：**触发时机**（= 本体已有钩子 `hook` + 一句 `guard`）、**条件**（= 一段布尔表达式 `expr`，可用 `{self}`/`{player}`/`{foe}`/`{amount}`）、**锻造模块**（= 图上的【效果】节点 + `emit` 模板）。
写这三项时：`hook` 必须是编辑器已知的钩子 id；`guard` 里只能用那个钩子签名里的参数。

## 3. 硬性要求

1. `plugin.json` 必须有 `id`、`name`、`apiVersion: "1"`；每条效果必须有 `kind` / `display` / `emit`。
2. `kind`：英文、字母开头，只含字母数字下划线，不要和编辑器自带种类重名（下拉里能看到全部自带的）。
3. `emit` 是**塞进方法体的 C# 语句**，不是完整类：不写 `using` / `namespace` / `class`；
   占位符可用 `{amount}` `{self}` `{player}` `{foe}` `{choice}` `{cardSelf}` `{power}` `{card}`；
   只能调用本体 API（如 `await CreatureCmd.Heal({self}, {amount});`）或你自己 `csFiles` 里的类。
4. 需要额外的类 / 工具方法 → 放 `csFiles`（如 `cs/MyHelper.cs`），会被拷到生成工程 `cs\Plugins\<插件 id>\` 一起编译。
5. 自带文件只能放在插件自己的文件夹内（不许 `..\` 越界）。
6. 不要写 DLL、不要反射编辑器内部类型 —— 兼容性靠「只认 JSON + 模板」。

## 4. 交付内容

给出**完整文件内容**（路径 + 内容），至少 `plugins\<插件名>\plugin.json`，需要时加 `cs\*.cs`；
并告诉我装好后怎么验证（哪个页、哪个下拉、点哪个按钮）。

## 5. 我需要你写的插件

（把需求写在这里。例：「做一个效果：对目标造成 N 点伤害并给它 1 层虚弱」；
或「回复 N 点生命，如果是战斗中再抽 1 张牌」；或「顺便加一页说明，写清这个插件的用法」。）

## 附：装好插件之后怎么验证（写给用户）

1. 打开编辑器 →「插件」页 → 点「重新加载插件」；
2. 左边列表里能看到插件，右边能看到它贡献的效果 / 页面 / 自带文件 / 问题（⚠ 就是没加载成功）；
3. 「卡牌」页 → 效果列表 →「效果种类」下拉里选插件效果 → 填数值 →「生成工程」；
4. 生成出来的工程里能搜到模板展开的那几行代码，`cs\Plugins\<插件 id>\` 下有你带的 cs。
