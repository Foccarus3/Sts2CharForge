# V0.2.91 更新说明

> 队列第②项做完：**额外资源量那只隐藏遗物，现在在「遗物」页上能看见、也能给它加效果了**。

## 遗物页多了「额外资源量遗物（自动生成的隐藏起始遗物）」

只要你勾了「额外资源量 / 状态」页的「启用额外资源量」，遗物页左栏最上面就会出现这一块：

- **一个效果列表**（就是这只遗物上的效果，触发时机固定「**战斗开始时**」）+ 「添加效果 / 删除效果 / 撤回删除」；
- 选中其中一条，右边就是它的**完整参数面板**（和普通遗物的效果编辑器是同一块界面）；
- 这块只在启用资源量时显示 —— 没启用时那只遗物根本不会生成。

这只遗物本身就是额外资源量的载体（`<角色>ExtraResourceRelic`，稀有度 Starter、不占遗物栏的玩法位置）：
它负责「每场战斗开始时发放资源量」和「记录跨战斗继承」。你加的效果会和这两件事挂在同一只遗物上，
用的是**带 `choiceContext` 的「战斗开始时」钩子**，所以需要选牌 / 生成卡牌的效果也能用。

## 配套（这一版一起做的）

- **生成端**（V0.2.85 已完成）：效果写进 `<角色>ExtraResourceRelic` 的 `BeforeSideTurnStart`，
  并按需要声明 `CanonicalVars`；
- **回读**（V0.2.85 已完成）：`--recover` 从 `cs/ExtraResource.cs` 的 `BeforeSideTurnStart` 体里读回这张列表；
- **校验器**（这一版加的）：**没启用额外资源量**但遗物上留着效果 → 一条**警告**说清「那只遗物不会生成，
  这些效果一条都不会生效」（要么勾上启用，要么把效果挪到别的遗物 / 卡牌上）；
- **自检**：这块的显隐、列表绑定、以及上面那条警告都有断言。
