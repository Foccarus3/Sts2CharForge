# V0.2.329 — 「获得指定药水」选不到自己做的药水

用户原话：

> 卡牌效果选择获得指定药水时找不到我自制的药水

## 真因：药水下拉只灌了**本体**药水

「获得药水」的「目标药水」候选来自 `EffectCatalog.Potions` —— 那是**本体药水目录**（从游戏文件里读的，
65 瓶），自己做的药水根本没进去。连带两个后果：

1. 下拉里搜不到 / 选不到自制的那瓶；
2. 就算硬写进去，校验器 `HasPotion` 也只认本体 → 报「药水认不出来」。

（对比一下：「施加增益/减益」的下拉早就把**自定义状态**拼进去了，药水这边一直漏着。）

## 改法（和「自定义状态」同一套做法）

| 位置 | 改动 |
|---|---|
| `EffectCatalog` | 新增「自定义药水」登记表：`SetCustomPotions(...)` / `CustomPotionEntries` / **`AllPotionEntries`（本体 + 自制）**；`HasPotion` / `FindPotionZh` 都改成查合并后的表 |
| 「目标药水」下拉 | 灌 `EffectCatalog.AllPotionEntries` |
| 图上【获得药水】 | 药水候选同样换成 `AllPotionEntries` |
| 登记时机 | 和自定义状态一起刷新（`RefreshCustomPowerRegistry` 里顺手调 `RefreshCustomPotionRegistry`），存档一改就重新登记 |
| 生成端 | 早就按存档的药水表查类名（V0.2.317），所以选中的自制药水会生成 `PotionCmd.TryToProcure<自己的类>`，不带本体命名空间 |

## 验收

* 自检：**4548 PASS / 0 FAIL**，新增 5 条断言：
  * 自定义药水进了「目标药水」候选（本体 65 + 自制 1 = 66）；
  * 校验器认得出自定义药水；
  * 描述里显示自制的中文名；
  * 「获得药水」指向自制药水时**校验通过**；
  * 生成时用**自己的类名**（不套 `MegaCrit.Sts2.Core.Models.Potions.`）。
* 顺带把一条老断言改成「本体 + 自制」（以前写死比本体目录数量）。
* 只出更新包（`-NoBundle`）。

## 你要做的

重新打开生成器（让药水表重新登记）→ 到卡牌效果里点「目标药水」→ 现在列表末尾能看到
**你自己的药水（显示「名字  (类名)」）**。
