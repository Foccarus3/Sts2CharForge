# Sts2CharForge V0.2.0

> 版本号从 V0.1.14 进入 **0.2.x**：这一版集中修掉「进游戏才发现」的几类问题
> （牌组界面打不开、卡面印出占位符、多个模组装在一起游戏起不来），并给效果编辑器加了

## 本次更新

### 修：多个模组装在一起时游戏打不开（这一版最重要）

- **病根**：本体的 `ModelDb` 只按**类名**注册模型（忽略命名空间），两个模组各有一个
  `class Strike` / `class ExtraResourceRelic` / `class ForgeExtraTurnPower` 就会抛
  `DuplicateModelException`，表现就是**游戏直接起不来**。
- **改法**：生成器自己起的固定类名一律带**角色类名前缀** —— `<角色>Strike`、`<角色>Defend`、
  `<角色>ExtraResourceRelic`、`<角色>ForgeExtraTurnPower`、`<角色>ForgeDelayed<状态>`、
  `<角色>ForgePetGuardianPower`。你自己手填的英文类名**不动**（免得卡面素材与存档引用错位）。
- **新增「多模组撞车检查」**：校验时会扫同一个存档目录下**别的存档生成的工程**，把重名的模型类列出来
  （警告，不拦生成），并告诉你要同时装的话该改哪个存档的角色类名。
- 回读（从工程恢复存档）同步适配新类名，顺手修掉「`<角色>Strike` 被多算成一条本体卡引用」。

### 修：打开牌组一片空白

- 牺牲伙伴选「固定 N」又填了升级增量时，升级被写到**没有声明**的 `CalculationBase` 上，
  牌组界面造升级预览时抛 `KeyNotFoundException`，整个牌组列表渲染不出来。
- 现在升级写回它自己的变量，并且**生成后会自检**每个生成的卡 / 遗物 / 药水有没有「引用了未声明的动态变量」，
  发现就直接报错拦住（这类错编译期看不出来，只在游戏里炸）。

### 修：卡面印出 `{PetMissingHpDamage:diff()}` 这种占位符

- 卡面描述里的变量名改成本体**真正声明**的那个键：按生命值算的伙伴攻击 → `{CalculatedDamage:diff()}`，
  牺牲伙伴按生命值算的收益 → `{CalculatedBlock:diff()}`（固定值仍用 `{PetSacrificeBlock:diff()}`）。

### 新：「召唤物（哪一只）」增加「★ 全部召唤物」

- 一条效果对**每一只启用的**召唤物各算一次（生成时逐只展开，每只自己判在不在场，不在场的自动跳过）：
  例「一张牌把三只全召出来」「让每一只都替你承伤」。
- 「按生命值算」的那几种在「全部」档改成内联按每只自己的生命值计算（卡面不显示具体数值，避免误导）。

### 新 / 改：卡牌与效果

- **复制卡牌 = 整张照抄**：自定义关键词、卡牌关键字、标签、升级后关键字、每条效果的全部设置
  （数值、升级增量、召唤物、概率、条件）都会跟着复制 —— 以前只抄了一小半。
- 「添加效果」的新效果**数值与升级增量默认 0**（以前默认 6 / +3，加别的效果时得先清掉，容易漏）。
- 删掉「召唤物卡牌」选项卡与「这是召唤物卡」勾选（「卡牌」页本来就覆盖了那 12 个宠物效果）。

## 说明

- **升级到这一版后要重新生成并重新安装模组**：打击 / 防御等固定类名变了，旧 dll 里还是老名字；
  已经开着的存档局里的牌组引用会失效，请**开新局**。
- 想同时装多个自制模组：每个都想装的存档都要用这一版重新生成安装；如果两个存档用了**同一个角色类名**
  （或你手填了同一个英文类名 / 模组 ID 相同），校验时会直接告诉你撞了哪些名字，改掉其一再生成即可。
- 存档格式没有变化，直接覆盖更新即可；你的存档在 `自定义角色存档\` 里，覆盖程序文件不会动它。
- 发布包里**不含任何存档**、也不含任何《杀戮尖塔 2》的游戏素材；程序运行时只读取你本机的游戏文件。
- 程序内嵌的效果库数据需要你自己用「效果库」页从本机解包工程生成（仓库不附带游戏文本）。
