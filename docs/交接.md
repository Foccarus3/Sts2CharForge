## 四、**未完成的头号任务：`ThisCardDamage` 参与四则运算**

用户原话：**「自定义参数的『这张卡造成的伤害』不能进行 +-*/ 的计算吗」**，并已回「要」。
现在 `ThisCardDamage*0.5` 会被校验器**报错拦住**（不是不支持算术，是取值时机不对）。

### 已查明的事实

* 六条「这一次打出」的读数 + 字段映射：`CSharpCodeGen.cs:3522`

  ```csharp
  (ThisCardDamageId, ThisCardDamageField, "本张牌这一次打出造成的伤害"),
  (ThisCardBlockId,  ThisCardBlockField,  "本张牌这一次打出获得的格挡"), …
  ```
* 记账（每次攻击后累加）：`CSharpCodeGen.cs:9562`
  ```csharp
  if (atkVar is not null) ForgeThisCardDamage += (decimal)atkVar.Results.SelectMany(h => h).Sum(r => r.TotalDamage);
  ```
* 卡牌链会在 `OnPlay` **开头**把所有公式量取成快照局部变量：
  `ForgeGraphGen.EmitCardFormulaPrologue(...)`（调用点 `CSharpCodeGen.cs:5254 / 5881`，定义在 `ForgeGraphGen.cs:2419`）。
  快照跑在第一次攻击**之前** ⇒ 公式里读到 0。
* 拦住它的校验：`ProfileValidator.cs:2740` 附近（`IsExactReading` 判定），文案是「只能光秃秃地单独用」。
  `IsExactReading` 定义在 `CSharpCodeGen.cs:3655`。

### 要改的两处

1. **发射**：公式里出现这六条读数时**不走快照，当场取字段**（`ForgeThisCardDamage` 等）。
   *还差最后一步*：确认「读数 Id → 局部变量名」的映射在哪（`CardReadingsAll` 在 `ForgeGraphGen.cs:4440` 只做校验，不是发射点）。
   **下一步建议**：从 `EmitCardFormulaPrologue` 往下读它如何为 `Identifiers(root)` 里的每个名字声明局部变量（看它对 `X` / `Y` / 参数 / 内置读数分别怎么处理），把「六条读数」这一支改成直接返回字段名 —— 与 `InlineResolver`（`ForgeFormula.cs:991`）同一条路。
2. **校验**：`ProfileValidator.cs:2740` 把「混用」从 **错误** 降为 **提示**，文案写清「请把这条效果排在『造成伤害』之后，否则当场取到的是 0」。

### 验收标准（必须做到）

* 探针：`ThisCardDamage*0.5` → 生成 `ForgeThisCardDamage * 0.5m`（**不是**快照变量）；
