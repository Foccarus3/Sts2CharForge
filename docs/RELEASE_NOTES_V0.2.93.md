# V0.2.93 更新说明

> 队列第④项做完：**「诅咒 / 先古卡」页 → 「诅咒 / 先古 / 状态」** —— 状态卡并进来了，
> 而且诅咒 / 先古 / 状态这三类的**费用都能自己调**。

## 一、页签改名：诅咒 / 先古 / 状态

左栏从一个两行的列表变成**三个列表**（诅咒 / 先古卡 / 状态卡），右栏照旧是详情 + 效果编辑器。

- **状态卡**（本体「伤口 / 灼伤 / 眩晕 / 粘液」那种）现在有自己的列表：
  「添加状态卡 / 删除 / 多选 / 全选 / 撤回删除」和另外两栏一模一样，
  默认值就是类型 + 稀有度都「状态」、1 费；默认**不能升级**（本体粘液就是 `MaxUpgradeLevel => 0`），
  勾「可被无限升级」就生成能升级的状态卡。
- 这一栏**不复制数据**：状态卡就是「卡牌」页里稀有度选了「状态」的那些牌（住在 `Profile.Cards`），
  这一栏是它的镜像 —— 在哪边加 / 删 / 改稀有度，另一边立刻跟着变（自检里专门钉了这条）。
- 先古卡和状态卡**共用一块详情面板**（都是普通牌，只是稀有度写死），
  选中哪一栏就显示哪一栏的说明（「先古卡属性」/「状态卡属性」）；三个列表的选择互斥，卡面预览不会串。
- 状态卡的三条校验提醒：类型不是 `Status`（本体状态牌的类型都是 Status）、
  勾了「加入卡池」（它不会出现在奖励里）、被放进初始卡组（本体只有诅咒才这么干）。

## 二、三类牌的费用都能调

| 类型 | 以前 | 现在 |
|---|---|---|
| 先古卡 | 本来就能调 | 不变 |
| 状态卡 | 本来就能调（走普通卡那条路） | 不变，页面上也给了「费用」框 |
| **诅咒** | **写死 `base(-1, …)`，填什么都不起作用** | **照你填的写**：默认 `-1`（打不出去）；填 `≥ 0` → 这张牌**能打出去** |

诅咒费用填 ≥ 0 时的规则（生成 + 校验器 + 文档三处口径一致）：

- 构造函数写 `base(<你填的费用>, CardType.Curse, CardRarity.Curse, TargetType.None)`；
- **不再强制**「不能被打出」（费用 -1 时才强制）—— 想让它照样打不出去，在诅咒详情里自己勾那一项；
- 但它的效果**仍然**写在「你的回合结束时，如果它还在你的手牌里」（`OnTurnEndInHand`），
  所以**打出去本身不做事**，只是能把它从手里丢掉（0 费「能打出去的诅咒」就是这个用法）；
  校验器会给一条提示把这件事说清楚（想让效果在打出时生效，请到「卡牌」页做一张普通牌）；
- 回读认得回来：从工程读的是构造函数里那个数字（`0` 不会被退回 `-1`）。

**老存档 / 默认配置生成结果一个字符都不变**（默认费用就是 -1，走的是原来那条分支）。

## 三、顺手修掉一个误报：「进商店黑屏」

`MerchantMissingTypes`（那条「卡池里的某牌型一张都上不了商店 → 进商店黑屏」的错误）
以前是拿**所有**牌型去查的，可本体 `MerchantInventory._coloredCardTypes` 里只有
**攻击 / 技能 / 能力**三种会摆货架 —— 状态 / 诅咒 / 任务这几种类型本体根本不建货架。

所以以前「入池的状态卡」会被误报成「进商店黑屏」，而且报错里那句「把稀有度改成 Common」
对状态卡根本做不到（状态卡的稀有度只能是 Status）。现在这条检查只看那三种牌型；
对照断言仍在（攻击牌型只有 Basic 时照样报错）。错误文案里也写清了这一点。

## 四、配套（这一版一起做的）

- **生成端**：诅咒构造函数照用户填的费用写 + 费用 -1 才强制 `Unplayable`；状态卡走普通卡那条路（不变）；
- **回读**：0 费（或其它正数）诅咒的费用从左花括号那行读回来；状态卡按 `CardRarity.Status` 回读；
- **校验器**：诅咒费用 ≥ 0 的提示、诅咒费用为负但非 -1 的提示、状态卡三条提醒、
  「上不了商店」只查三种牌型；
- **界面**：页签改名 + 第三栏（状态卡列表）+ 诅咒详情的「费用」框与「不能被打出」勾选框；
- **自检**：20 条新断言（三栏绑定与数据镜像、稀有度改走改回、按组定位的删除 / 撤回、
  0 费诅咒的生成与回读、状态卡的三条校验、商店误报回归）。
