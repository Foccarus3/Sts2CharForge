# V0.3.116 — `{=表达式}` 变量名改成 SmartFormat 能识别的写法（后续在 V0.3.117 更正）

## 现象

生成后卡面显示：

```text
{__fgCardDesc0}{A+2}
```

`{=A}` 被替换成了变量，但游戏没有取值，原样印出花括号。

## 原因

V0.3.115 生成的显示变量叫：

```text
__fgCardDesc0
```

以双下划线开头。SmartFormat 的 selector 对这种名字解析不可靠，变量明明在 `DynamicVars` 里，格式化时仍按未知变量处理，于是原样输出。

## 修复

变量名改成：

```text
ForgeCardDesc0
```

不以下划线开头，和本体常见的 `Damage` / `Cards2` 同一类标识符。

- 描述里的替换结果变成 `{ForgeCardDesc0}`；
- `ForgeCardDescVar` 的声明名同步改；
- 诅咒卡也同步。

## 另外：`{A+2}` 不会生效

现在规定的写法是：

```text
{=表达式}
```

所以：

```text
{=A+2}    ✅ 会计算
{A+2}     ❌ 没有等号，不会被当成表达式
{A}       ❌ 没有等号
```

要写公式必须带 `=`。
