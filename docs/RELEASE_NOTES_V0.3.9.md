# V0.3.9 — 锻造图【状态】节点改成读「真实层数」

（按你的选择 A 做的）

## 改了什么

锻造图里的【状态】节点，以前对「**只叠一层（Single）**」的自定义状态会**夹成 0/1**：

```csharp
// 以前
decimal __fg1e802b = (ForgeFormulaRuntime.PowerAmount(__fgSelf, "ZouPower2") <= 0m ? 0m : 1m);
if ((__fg1e802b < 1) && …)        // ← 实际是「有没有这个状态」，不是层数
```

现在一律读**原值**（真实层数）：

```csharp
// 现在
decimal __fg1e802b = ForgeFormulaRuntime.PowerAmount(__fgSelf, "ZouPower2");   // fg:…【状态】（真实层数）
if ((__fg1e802b < 1) && …)        // ← 现在是层数 < 1
```

所以图上写「层数 `> 1`」「层数 `< 2`」这类判据**终于会按层数算**，不会被「有 1 层就算 1」糊掉。

## 为什么以前要夹取（历史原因，已权衡）

V0.2.246 是为了修「形态生效、效果没生效」：`PowerStackType.Single` 只是**不显示层数**，
`PowerCmd.Apply` 第二次照样把内部层数加到 2 —— 于是图上写「等于 1 层」在叠过两次后不再成立。
夹成 0/1 让它稳，但代价就是**「层数 > 1」永远不成立**（你这次遇到的）。

现在两个取舍换成：**层数语义优先**。如果你要的是「有没有这个状态」，有两条替代写法：

* 用【状态列表】节点（个数 `> 0`）；
* 或者关系符写 `>= 1`（层数 ≥ 1 就等于「有」）。
