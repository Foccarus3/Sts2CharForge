## 一、【指向对象】：牌选中谁 ≠ 效果打谁

按你的要求，【触发时机】后面**固定连着一个【指向对象】**（新建的布上自动放好、自动接好）。
它读作「**这张牌在游戏里选中谁**」：

- 决定**卡牌的目标类型**：「指定单体敌人」→ 打出时让玩家选一个敌人（`TargetType.AnyEnemy`
  → `cardPlay.Target` 真的有值）；「全部敌人 / 随机敌人」同理；「自己 / 召唤物…」→ 不需要选目标；
- 同时它是这条链上**「效果没自己接【对象】时」默认打谁**（老图的老规矩就是这个：打出时选中的那个目标，
  所以默认值取「指定单体敌人」时，效果那一边的行为**一个字都不变**）；
- 和【效果】左边那个「指向对象」口**不是一回事**—— 那个是「这条效果打谁」。
  **所以你举的例子成立**：牌让玩家选一个敌人（读它身上的虚弱），而效果打的是**全体**敌人；
- 它右边还多一个「指向对象」口（Object），可以像【对象】一样直接接到【效果】/【状态】上复用。

### ⚠ 装了这一版之后要留意的一件事

**老图里用到「指定单体敌人」的，配置检查会报一条错**，提示你补一个【指向对象】：

> 图里用了「指定单体敌人」，但这张牌的目标类型是「Self」—— 打出这张牌时**不会让玩家选敌人**，
> 所以「指定单体敌人」拿到的是**空目标**（读它的状态得 0、打它等于没打）。请加一个【指向对象】…

这不是新加的麻烦，而是**原来就坏着**：锻造卡的目标类型以前只按「效果里的作用对象」推，
图里的「指定单体敌人」根本没人声明，于是那张牌不会让玩家选目标 ——
打伤害时靠「取第一个敌人」兜底看起来像能用，但**读那个敌人身上的状态一律是 0**。
补上【指向对象】=「指定单体敌人」之后，这几张牌才第一次真的按你选的目标算。

（没用到「指定单体敌人」的老图：什么都不用做，行为一个字不变。）

## 二、【关系符】：把「哪个状态大于多少」写成条件

以前条件只有本体那些现成判据（手牌数 / 生命百分比 / 拥有某状态至少 N 层…），
没法表达「**那个单体敌人的虚弱 > 3**」这种。现在：

```
【if】的「条件」口 ← 【关系符】(大于) ← 左值：【状态】(虚弱) ← 「归属」← 【对象】(指定单体敌人)
                                    ← 右值：【数值】(3)
```

- 运算符 8 档：`大于 / 小于 / 等于 / 大于等于 / 小于等于 / 非 / 且 / 或`；
- 左值 / 右值两个口是**联合类型**：比较类接数值（【状态】/【数值】/【能量】），
  非 / 且 / 或接条件（【条件】/【且】/【或】/另一个【关系符】）；
- 右值不接线就用模块上填的那个数字；
- **可叠加**：「虚弱 > 3」且「易伤 > 0」= 两个【关系符】各比一条，再用一个【关系符】选「且」把两个结果合起来；
- 接错类型（该接数值的地方接了条件，反之亦然）→ 配置检查**报错**说清该接什么；
  生成端也不会写出编译不过的代码（退成「恒不成立」并在生成代码里写一句说明）。

## 三、照着你给的例子跑通了

「当单体敌人虚弱层数大于 3 时，对所有敌人造成『我自己身上易伤层数 + 3』数值的伤害，否则我失去 5 点生命」，
参数页设 A = 我身上的易伤层数。按你写的那套接线连出来，生成的代码是：

```csharp
public XxxCard() : base(1, CardType.Attack, CardRarity.Common, TargetType.AnyEnemy) { }   // ← 会选一个敌人

public async Task ForgeGraphOnPlay(PlayerChoiceContext choiceContext, CardPlay cardPlay)
{
    Player __fgPlayer = base.Owner;
    Creature __fgSelf = __fgPlayer.Creature;
    Creature? __fgTarget = cardPlay.Target;                                          // ← 【指向对象】的功劳
    decimal __pA = ForgeFormulaRuntime.PowerAmount(__fgSelf, "VulnerablePower");      // A = 我身上的易伤
    decimal __fg1 = ForgeFormulaRuntime.PowerAmount(__fgTarget, "WeakPower");         // 那个敌人的虚弱
    decimal __fg2 = (3m);
    if (((__fg1) > (__fg2)))
    {
        decimal __fg3 = (__pA + (3m));
        await DamageCmd.Attack(__fg3).FromCard(this, cardPlay).TargetingAllOpponents(base.CombatState).Execute(choiceContext);
    }
    else
    {
        foreach (Creature __fgFoe in ForgeFormulaRuntime.AllAllies(__fgPlayer))
            await CreatureCmd.Damage(choiceContext, __fgFoe, (5m), ValueProp.Unblockable | ValueProp.Unpowered | ValueProp.Move, this, cardPlay);
    }
}
```

「是」那支走的是本体的一次性群体命令（**一次打全体**），「否」那支是自己失去 5 点生命。

## 已知限制（说清楚，不藏着）

- 新建的布上【指向对象】默认「指定单体敌人」—— 做**自增益牌**请把它改成「自己」。
- 【指向对象】只对**卡牌**有意义（药水 / 遗物的目标由各自的页面决定），所以新建药水 / 遗物的布上不会自动加它。
- 一条链上放两个【指向对象】时，**后面那一个说了算**（生成代码里会写一句提示）。
- 积木视图里【关系符】的左右值会显示成块里的槽；【且】/【或】门那两条 A / B 线积木视图仍然不接管
  （写回时原样留着），要改请在节点图里改。
- 其余老限制照旧：节点图支持的效果种类是那一份名单（其它请放到卡牌页的「效果」列表）；
  自定义状态上那块布生成端还没接；「覆盖血条」的观感、卡面公式都还没在游戏里肉眼确认过。
