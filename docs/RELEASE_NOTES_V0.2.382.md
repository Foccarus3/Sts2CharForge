# V0.2.382 — `checks` 支持**行内子栏位校验**（`list` 规则）

上一版（V0.2.381）的自定义校验只能看页面级标量栏位；这一版可以逐行检查列表里的每一行。

## 写法

```json
"checks": [
  { "list": "moves", "when": "kind=attack", "field": "dmg",
    "rule": "int", "min": "1", "message": "攻击招式必须填伤害" }
]
```

* `list`：要逐行检查的 list 栏位（不写 = 老行为，检查页面级标量）；
* `when`：在**这一行内**求值（同 `visibleWhen` 的写法）；
* 命中时的问题带行号：`页「…」：招式 第 1 行：攻击招式必须填伤害`。

## 顺带修掉的两个坑（都是自检当场抓出来的）

1. `HasAnyPageValue`（「这页填过值了才报 required」那道闸）原来只看标量栏位 ——
   页面**只有 list** 时会永远判成「没填过」，行内校验一条都不跑。现在 list 里有任何一格非空也算填过。
2. 行数据不能从 `PageValueOf` 拿（list 的行存在 `rows.json`、不在页面 values 里），
   必须用 `PageRowsOf(...)`（返回的是**活的可变列表**）。测试数据也要通过它来写。

## 自检

**4726 PASS / 0 FAIL**（+2 条：`kind=attack` 且 `dmg=0` 的第 1 行被报出来、`kind=block` 那行不报）。

## 限制

* `when` 仍然只支持单栏位比较（不支持 `&&` / `||`）；
* 规则表形态，不支持脚本表达式。
