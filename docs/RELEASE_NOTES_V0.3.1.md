# V0.3.1 — 自定义状态的「触发次数 / 阈值」支持公式与自定义参数

## 现在能写

自定义状态页的触发时机那一行，除了原来的常数输入框，多了一个**公式框**：

```
触发次数 [ 3 ] [ 公式（可选）：2+1 或 {自定义参数} …]
```

* 填了公式 → **以公式为准**（忽略左边那个常数）；
* 计数族（每 N 次触发一次）→ `int __step = Math.Max(1, (int)(公式));` 再按它取模（0/负数会被夹到 1，不会除零）；
* 阈值族（受到伤害 ≥ N / 失去生命 ≥ N / 获得格挡 ≥ N）→ `数值 >= (decimal)(公式)`；
* 不填公式 → 生成文本**一个字符都不变**（老存档完全不受影响）。

## 公式能写什么（这次实测确认过的）

* 算术：`2+1`、`4*2`、`Max(1, X)` 这类；
* `X`（当前所有能量）/ `Y`（当前所有额外资源量）；
* 你在**自定义参数 / 公式变量**里声明过的参数名。

⚠ 实测发现：**裸写参数名的字母（如 `N+1`）在状态触发时机上求值为空**（回退成常数）——
那套 `M / N` 字母是**效果条件**那边的占位习惯，不自动等于你声明的参数。
所以这里请写**你真实声明的参数名**，或者直接写数字算式 / X / Y。

## 自检

## 已知限制（如实说）

* **「从工程恢复」还不会带回这个公式** —— 生成时会写一行 `// CET:TriggerAmountFormula=…` 标记，
  但回读侧还没解析它。也就是说：**你的 profile JSON 里存得住**（正常保存/打开都在），
  但如果「从已有工程恢复」重建 profile，这一栏会退回常数。下一步补回读。
* 公式解析失败（比如裸写 `N+1`）时**静默退回常数**，界面上不会有红字提示——下一步加校验提示。
