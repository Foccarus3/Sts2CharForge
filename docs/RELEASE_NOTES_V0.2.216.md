# V0.2.216 —— 「二形态时只剩 24 基础伤害」：三层「且」丢条件 + 漏接线的分支静默消失

> 来源：用户实测（附 `lihuazou.json` + 两份 `godot*.log`）：
> 「处于二形态时触发不了多效卡效果只能打24的基础效果」。

## 1. 用你这份存档复现出来的结论

「自适应攻击-毁灭」(ZouCard17) 升级前的图里有 **4 支**：兜底 24 / 巨钳形态 18+流血 2 / 手刃形态 5×4+能量 1 /
**长枪形态 27+锋利**。生成出来的却只有 3 支 —— 长枪那一支**整段消失**，而且兜底那支也**少了一个条件**，
于是「长枪形态（第二形态）」落回兜底：只有 24 点伤害。

查到两个真 bug：

### ① 三层「且」只用了两个条件（代码 bug）

「且」串「且」时（`且(且(A,B), C)`），第二个【且】的条件以前取的是**它 Out 口上接进来的那一块**
（= 第一个【且】），而不是它**自己**的条件 → 第三个条件（`长枪形态 == 1`）被整个丢掉：

```csharp
// 修前（C 丢了，所以「不是长枪形态」这个前提没了 → 长枪形态也进兜底）
if (巨钳<1) { if ((巨钳<1) && (手刃<1)) { 24 } }
// 修后
if (巨钳<1) { if ((巨钳<1) && (手刃<1)) { if (((巨钳<1) && (手刃<1)) && (长枪<1)) { 24 } } }
```
（嵌套里那点重复是无害的，语义就是 `A && B && C`。）

### ② 没接到【触发时机】的模块**静默消失**（这是「多效」没了的直接原因）

你那条「长枪形态」分支的【关系符】少了**左值（对象）那根线**（别的形态分支都接了 `指向对象 → 关系符左值`），
于是它从【触发时机】根本走不到 —— 生成时**一个字都不输出**，游戏里就只剩兜底伤害。
现在生成器会算「哪些会做事的模块没接上」并**写在生成代码里**：

```csharp
// ⚠ 图上有 3 块模块**没接到【触发时机】这条链上**，它们不会执行（大概率是漏画了一条线）：
//    · fg:bfa7cb…【造成伤害 27】
//    · fg:…【施加增益/减益 1】
//    · fg:…【如果】
//    常见原因：【关系符】的「对象 / 左值」没接线，或者【是 / 否】那一支忘记接线。
```

「配置检查」里也会多一条**警告**（不是错误：在布上留备用模块是正常用法，不该拦住生成）。

## 2. 你自己怎么修那张卡

1. 打开「自适应攻击-毁灭」的锻造图，找到那条 **27 伤害 + 锋利** 的分支；
2. 把它那个【关系符】的**左值口**接上【指向对象】（和 18 伤害 / 5×4 那两支一模一样）；
3. 重新生成 —— 包里那条「没接到触发时机」的警告消失，就说明接对了；长枪形态下就会走 27 + 锋利。
