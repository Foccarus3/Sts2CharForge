# MarketAdmin V0.3.75 — 市场插件 / 版本删除

## 新增

底栏：

```text
删除当前版本
删除整个插件
```

### 删除当前版本

- 用当前填的 `id` + `版本号`；
- 从 `market/index.json` 的 `versions[]` 删除该版本；
- 删除 `market/packages/<id>-<version>.zip`；
- 如果删完没有版本了，整个插件条目一起移除。

### 删除整个插件

- 删除整个插件条目；
- 删除该 id 在 `market/packages/` 下的所有本地包（包括索引里已经丢过版本的孤儿包）。

## 安全

- 两个按钮都先备份：
  ```text
  market/index.json.bak
  ```
- 不会自动提交 git；
- 不会删除 GitHub Release 上的附件；
- 删完仍需点「提交并推送 git」才会影响远程市场；
- 已安装用户不会被远程卸载。

## 验证

| 项 | 结果 |
|---|---|
| 删除指定版本 | 索引移除版本、包删除，旧版本保留 |
| 删除整个插件 | 条目 + 所有本地包删除 |
| 删除后索引 | 仍是合法 JSON |
| 自检 | `--selftest` exit 0 |
