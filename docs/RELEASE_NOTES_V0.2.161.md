# V0.2.161 更新说明

> 回答你报的：「为什么抽卡，获得能量之类的效果种类的**对象**没了，但是**显示的是对敌人**」。

## 一、真因：栏位藏了，文案没跟着改（显示在说假话）

V0.2.150 按种类裁剪了效果栏：**生成端不读「作用对象」的种类**（抽牌 / 获得能量 / 获得金币 /
生成卡牌 …）就不再显示那一行 —— 这是你要的。

但 `EffectSpec` 里那个字段的**默认值就是 `"Enemy"`**（老存档 / 新加一条效果都可能是它），
于是「藏起来的那一行」还活着，在两处文案里继续说话：

| 位置 | 修之前的样子 |
|---|---|
| 效果列表那一行（卡牌 / 遗物 / 药水 / 额外资源量四页共用 `EffectSpec.Display`） | 「抽牌 1 **→ 单体敌人**」「能量 1 **→ 单体敌人**」 |
| 自定义状态的描述（触发时机里挂的效果，`PowerTriggers` 生成的那句话） | 「打出一张牌时：抽 1 张牌**（对指定敌人）**」 |

生成端其实**一个字符都不读**它（所以效果没错，只是显示/描述在误导）。

## 二、修法：文案和显隐走**同一份判据**

规矩补上另一半：**界面上藏起来的栏位，文案里也不许写它**。

- `EffectSpec.Display`：只有 `EffectFieldPolicy.UsesTargetSide(Kind)` 为真（且不是「召唤伙伴 / 伙伴攻击」
  那种宠物效果）才追加 `→ 谁`；
- `PowerTriggers.EffectText`（状态描述）：同一份判据 —— 以前那里写的是「`TargetSide == "Self"` 就省略」，
  所以默认值 `"Enemy"` 一漏就印出「对指定敌人」。

修好之后：「抽牌 1」「能量 1」（不再带尾巴）；状态描述「…抽 1 张牌。」（不再带「（对指定敌人）」）。
该显示作用对象的种类**一个字都没少**：「伤害 6 → 单体敌人」「造成 4 点伤害（对指定敌人）」照旧。

## 三、验证

- `dotnet build Sts2CharForge.sln -c Debug` → **0 错误**；
- `--uicheck`：Debug **3502 PASS / 0 FAIL**，新增 6 条：
  - **全量双条件**：67 种效果逐个建一条 `TargetSide = "Enemy"` 的探针，断言「行尾出现 `→ 单体敌人`」
    **当且仅当**「作用对象那一行会显示」→「67 种逐条对」；
  - 「抽牌」「获得能量」的列表行不带「单体敌人」；**对照**：「造成伤害」照旧带；
  - 状态描述里「抽 1 张牌」不带「（对指定敌人）」；**对照**：「造成伤害」照旧带。
- **反向验证**：把 `Display` 的判据退回原样 → `--uicheck` **3 条 FAIL / PASS 3499**
  （`Draw / Energy / OverdraftEnergy / Gold / ExtraResource / CheapenDraw …` 一长串又印出「→ 单体敌人」，
  失败明细里就能看到「抽牌 1 → 单体敌人」）；改回来 → **3502 PASS / 0 FAIL**；
- **默认输出不变（红线①）**：`--samplegen` 与 V0.2.143 基线 **111 个文件逐字节一致**
  （只差 `ExampleMod.sln` 的随机 GUID —— 这次只改显示 / 描述文案，生成端一字未改）。
