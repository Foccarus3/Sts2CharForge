# V0.2.397 — 资源随生成输出（第二期收尾）

`ImportAsset` 只把资源复制进插件目录；这一版让资源能**跟着生成一起输出到工程**。

## 写法

```csharp
host.Generate(new[]
{
    new EditorOutputFile { Path = "Image/Hero.png", AssetPath = "assets/hero.png" },  // 复制资源
    new EditorOutputFile { Path = "Hero.cs", Content = "class Hero {}" },              // 写文本
});
```

* `AssetPath` = 相对**插件目录**的资源路径（通常就是 `ImportAsset` 返回的 `assets/xxx`）；
* 非空时忽略 `Content`，从插件目录**原样复制**（二进制安全）；
* 确认窗里会显示成 `【资源】Image/Hero.png （从插件目录复制）`，用户看得见「这次要拷哪些资源」。

## 校验

| 情况 | 行为 |
|---|---|
| 资源不存在 | 计划**不通过**（`资源不存在或越界：assets/…`），一个文件都不写 |
| 资源路径越界（`..` / 绝对路径 / 出插件目录） | 同上，计划不通过 |
| 资源在写盘阶段忽然消失 | 跳过该文件并记进 `Problems`（不会留下半截 `.tmp`） |
