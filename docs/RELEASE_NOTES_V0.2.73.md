# V0.2.73 更新说明

> 修别人报的「给召唤物上 buff 不生效」，并把**同一类问题**（节点图里「选了但什么都没做」）
> 整批变成「报错拦住」；另外补上节点图的「给伙伴施加状态」。

V0.2.72 的内容（覆盖血条每条状态各一条、可选左右）也都在这一版里。

## 别人报的：「给召唤物 buff 不生效」

**根因：节点图的【效果】下拉列的是「卡牌页效果栏」的**全量候选**，但节点图的生成端只接上了其中一部分。**
「给伙伴施加状态」正好是**没接上**的那一档：选了它，生成出来的代码里只留一行注释
（`// ⚠【效果】……节点图这一阶段还没接上这个种类`），**一行代码都没有** ——
所以生成、编译、进游戏全都不报错，就是没反应。

我数了一遍：**62 个效果种类里，节点图只接上了 30 个**，另外 32 个都是「选了等于白选」
（伙伴攻击 / 按生命值算的伙伴攻击 / 牺牲伙伴 / 召唤伙伴 / 强化指定卡牌 / 重放卡牌 /
回合结束时自动打出 / 刮削 / 毒性爆发 / 大限已至 / 填充手牌 / 给予关键词 / 牌组类效果 /
额外回合 / 抽到就减费 / 禁止回复生命 / 提高资源上限…）。

**这一版怎么处理（两件事）：**

1. **补上「给伙伴施加状态」**（就是别人要的那一条）。目标由【对象】模块决定：
   - 指定召唤物 = 按名称找那一只（找不到退回第一只）；
   - 全部召唤物 = 逐只都加；
   - 没接【对象】= 第一只。

   生成出来长这样（卡牌 / 遗物 / 药水都能用）：

   ```csharp
   foreach (Creature __fgPet in ForgeFormulaRuntime.SummonList(__fgPlayer)) { await PowerCmd.Apply<StrengthPower>(choiceContext, __fgPet, (4m), __fgSelf, this); }
   ```

2. **其余 31 个没接上的种类：配置检查直接报错拦住**，并在错误里：
   - 列出「节点图现在支持哪些」（不再让人一个个试）；
   - 指路「把它放到『卡牌 / 遗物 / 药水』页的『效果』列表里 —— 那边支持全部种类」。

   也就是说：**以后再也不会出现「选了、生成成功了、游戏里却没反应」**。

   顺带分清了两种「什么都没生成」的原因：**这个种类没接** vs **必填的东西没填**
   （状态 / 目标卡）。以前一律说「还没接上这个种类」，填漏了字段的人会被这句话带偏。

## 顺手修掉：整块布的图问题以前一个都不报

`ForgeGraphGen.Problems`（「这张布上没有【触发时机】」「【数值】的公式有问题」
「这条连线指向已删除的模块」…）写好了却**从来没被调用过**（死代码），
所以节点图里的问题一条都到不了「配置检查」。现在全部接进校验器：

| 图里的问题 | 现在报的级别 |
|---|---|
| 【效果】选了节点图没接上的种类 | **错误** |
| 【效果】需要状态 / 目标卡却没填 | **错误** |
| 【触发时机】认不出来 / 这块布的类型不对 | **错误** |
| 【数值】公式写错、用了没定义的参数 | **错误** |
| 自定义状态上画了布（生成端还没接那块布） | 警告 |
| 这块布上没有【触发时机】（整张图不会执行） | 警告 |
| 连线指向已删除的模块（保存时会自动清掉） | 提示 |

## 已知限制（说清楚，不藏着）

- **节点图**支持的是上面那 30 个种类；其余请用「卡牌 / 遗物 / 药水」页的「效果」列表（那边全都支持）。
- **自定义状态**上那块节点图生成端**还没接**（画了也不生成，现在会给警告）。
- 「覆盖血条」的观感、以及「数值公式」的卡面写法，都只对着本体源码核过 + 真编译过，
  **没有在游戏里肉眼确认过**。
- 本体的「自定义参数 → 给予能量 / 给予额外资源量」这两栏目前**只是配置项**，生成端还没有用它。
