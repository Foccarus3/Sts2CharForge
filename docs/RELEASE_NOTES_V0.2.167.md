# V0.2.167 更新说明

> 回答你问的「是不是好多效果在锻造中都用不了」——**不是「好多效果」，而是「效果种类」都支持、
> 但有一批「栏位」不生成**（工具会报错拦住而不是静默忽略）。你截图里拦住的正是其中一栏：
> 「生成 / 变化出来的卡的附加处理」。**这一版把那一栏（以及挨着的两项）在节点图里也实现了。**

## 一、先回答「哪些东西在节点图里用不了」

**效果种类**：节点图支持 28 种（造成伤害 / 获得格挡 / 抽牌 / 获得能量 / 回复生命 / 失去生命 /
获得最大生命 / 获得金币 / 获得额外资源量 / 施加·扣除状态 / 临时增益 / 翻倍状态层数 / 清除指定状态 /
清除全部减益 / 禁止获得格挡 / 击晕 / 结束回合 / 生成卡牌 / 消耗卡牌 / 丢弃卡牌 / 升级卡牌 / 变化卡牌 /
复制卡牌 / 从三摞各拿牌到手牌 / 预见 / 获得药水 / 获得卡牌奖励 / 给伙伴施加状态）。
**别的种类**选了会报错 —— 因为节点图的发射器没有实现它们（不是静默失效）。

**栏位**（种类支持、但某些栏位以前不生成，会报错拦住）：

| 栏位 | 以前 | 现在 |
|---|---|---|
| **生成 / 变化出来的卡的附加处理**（直接升级 / 免费 / 仅本回合免费 / 仅本回合升级） | ❌ 报错 | ✅ **V0.2.167 支持** |
| **生成 / 变化出来的卡：加上关键词** | ❌ 报错 | ✅ **V0.2.167 支持** |
| **复制的份数**（复制卡牌每张复制几份） | ❌ 报错 | ✅ **V0.2.167 支持** |
| 取卡方式 = 按范围随机 / 范围限定 / 多选1 / 从范围里自己挑一张 | ❌ 报错 | ❌（节点图的「生成 / 变化卡牌」只能生成「目标卡」那一栏指定的那张） |
| 取几张 = 最多 N / 任意张 / 全部 | ❌ 报错 | ❌（节点图按「恰好 N 张」选牌） |
| 从哪里选牌 = 抽牌堆 / 弃牌堆 / 消耗牌堆 | ❌ 报错 | ❌（节点图的选牌类效果只从手牌挑） |
| 直接把「缓慢」设成 N% | ❌ 报错 | ❌ |
| 下回合生效（除 格挡 / 抽牌 / 施加状态 三种） | ⚠ 警告 | ⚠ 警告（别的种类会被当成立即生效） |
| 升级增量 / = X / = 本状态层数 / 条件选项 | ❌ 报错 | ❌（节点图里用【数值】【条件】模块表达） |

> 也就是说：**种类是齐的、栏位有缺口**，而且每个缺口都**报错说清怎么改**（不会静默少生成）。

## 二、这一版新支持的三项（你截图里那批卡就能过了）

实现方式（顺带解释为什么以前不行）：这几栏**只存在新编辑器那份 `EffectSpec` 上**，
而 `ForgeEffectBridge.MirrorToFields` **不回写**它们（只回写老字段：种类 / 数值 / 次数 / 概率 /
目标卡 / 生成到 / 药水 / 下回合…），所以老的节点图发射器根本读不到 —— 只能报错拦住。

现在生成端**直接读 spec**，并且**复用卡牌那条链的实现**（`CSharpCodeGen.EmitSpawnModifiers` /
`EmitTempUpgradePowerApply`，那两份早就按「链」参数化过了），所以：

- 语义 / 卡面文案和「卡牌」页那套**完全一致**（直接升级 = `CardCmd.Upgrade`；免费 = `SetToFreeThisCombat`；
  仅本回合免费 = `SetToFreeThisTurn`；仅本回合升级 = 挂本体那套「回合结束降回来」的 Power + `Track`）；
- 生成卡牌 / 变化卡牌 / 复制卡牌三条路都接上了（变化卡要接住本体返回的 `cardAdded` —— 变化是新建一张）；
- 「仅本回合升级」用到的 `TempUpgradePower.cs` 现在**节点图里用到也会生成**（漏了就是 CS0246）；
- **没勾这几项的老图，生成文本逐字不变**（还是那一句 `CreateCard` + `AddGeneratedCardToCombat`）。

## 三、同批一起带上的另一批修复（工作区里已做好、一起发）

- **`PowerRemoval.cs` 花括号配平**（以前多一个 `}` → CS1022）；
- **同一钩子上多个触发时机只生成一个 override**（`PowerChanged + PowerReached` → 一个
  `AfterPowerAmountChanged`；`DamageReceived + EnemyDamaged` / `DamageDealt + EnemyDealtDamage` /
  `BlockGained + EnemyBlockGained` 同理 —— 以前是 CS0111「已经定义了一个具有相同参数类型的成员」）；
- **`BoostCard` / 从弃牌堆拿牌 在「敌人回合开始时」会自己造 `choiceContext`**（以前 CS0103）；
- **「生成卡牌」的目标卡不存在时提前报出来**（以前拖到编译期 CS0246）；
- **「获得时」+ 打敌人 → 报错拦住**（本体开局没有战斗，会 NRE / 卡在出发界面）；
- **纯小写英文类名提示**（CS8981）、**输出目录在游戏 `mods\` 里时警告**、
  **`sts2.dll` 版本漂移检测**（比对本体方法签名，形参个数不同 = 漂移）、
  **锻造图「逐个敌人」在开调试日志时不再在作用域外引用 `__fgFoe`**。
