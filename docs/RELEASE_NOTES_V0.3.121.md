# V0.3.121 — 先古卡支持「升级后的自定义描述」

## 新增

「诅咒 / 先古 / 状态」页的先古卡详情里，现在和普通卡牌页一样有两栏：

```text
自定义描述
升级后的自定义描述（留空 = 和上面那段一样）
```

下面还有：

```text
自动填入
自动填入（升级后）
```

## 生成行为

和普通卡牌完全共用现有逻辑：

- 只填「自定义描述」→ 升级前后都用这段；
- 两段都填 → 生成：

```text
{IfUpgraded:show:升级后那段|升级前那段}
```

- 勾「替换掉自动生成的描述」→ 卡面只保留你写的；
- 不勾 → 自动描述 + 你写的这段。

## 生效方式

更新到 V0.3.121，先古卡的这两栏会出现在详情页。  
不需要重新生成旧工程才会显示；但要让升级后的文字进游戏，需要重新生成并重装 DLL/PCK。
