# V0.3.15 — 变量页：接进工程 + 校验（重名 / 撞参数 / 循环引用）

## 一、变量容器类现在会真的出现在生成工程里

建了变量后，生成时写出 `cs/<角色>Vars.cs`，构建日志里多一行：

```
已生成变量容器：cs/SevenVars.cs（N 个变量）
```

没有变量时**一个文件都不写**（老存档输出不受影响）。

## 二、校验（生成前就拦住）

`ProfileValidator` 新增（只在「有变量」时才跑）：

| 情况 | 级别 | 提示 |
|---|---|---|
| 名字不合格（超 12 位 / 非字母数字下划线 / 保留名） | 错误 | 变量「X」名字不合格：… |
| **重名** | 错误 | 变量名重复：「cnt」定义了两次（生成出来会冲突） |
| 和**自定义参数**同名 | 错误 | 公式里写这个名字时不知道该算哪个，请改名 |
| **循环引用**（a = b + 1，b = a + 1） | 错误 | 变量「a」的公式存在循环引用，求值会死循环 |

## 三、踩到的一个坑（写进交接了）

循环检测**不能用** `ForgeFormula.TryParse`：它对「还没定义的标识符」直接返回 `null`，
于是 `a = b + 1` 根本解析不出来、循环永远查不到（自检第一次就是 `循环=False`）。
现在改成**从公式原文用正则抽标识符**，自检 `循环=True`。
