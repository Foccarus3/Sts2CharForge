# V0.2.203 —— 锻造图也能用「本回合这张牌自己费用变 0」了（「处决」那条报错）

> 用户原话（截图里的两条错误）：
> `卡牌「处决」（升级前/升级后）：【效果】选的「本回合这张牌自己费用变 0」节点图里还没接上…`

## 1. 为什么以前会被拦

「本回合这张牌自己费用变 0」在本体里**不是一条效果**，而是**这张牌自己的行为**：

```csharp
base.SetToFreeThisTurn();   // = EnergyCost.SetThisTurnOrUntilPlayed(0) + SetStarCostThisTurn(0)
```

也就是「能量费 + 额外资源量费，本回合都变 0，打出之后恢复」（本体「子弹时间」那套）。
早期节点图的【效果】模块**没有「这张牌」这个概念**（状态 / 遗物 / 药水那几块布上根本不存在），
所以这一档被单列进「卡牌专属、节点图做不了」并**报错拦住**（宁可不生成，也不静默）。

## 2. 现在：卡牌那张布上真的能生成

- `ForgeGraphGen.SupportedEffectKinds` 收进 `CheapenSelf`；
- `EmitEffect` 里新增：`ctx.Scope == "Card"` 时生成

```csharp
this.SetToFreeThisTurn();   // 本回合这张牌自己费用变 0（本体 CardModel.SetToFreeThisTurn：能量费 + 额外资源量费一起）
```

—— 和「卡牌页效果列表」里那一档生成的是**同一句**（那边是 `base.SetToFreeThisTurn()`，卡牌类里 `this` / `base` 等价）。

- **状态 / 遗物 / 药水**的布上仍然不支持（那三块布没有「这张牌」），但报错换成了说得清的一句：
  「这一档是**这张牌自己**的行为…只有「卡牌」的锻造图里有「这张牌」—— 请把这一块删掉，或者到「卡牌」页那张牌上配」。
  生成时写进代码的注释也从笼统的「还没接上」改成「这一档是卡牌自己的行为」。
- 抽到就减费那一档（`CheapenSelfOnDraw`）**仍然不支持**：它要挂到卡自己的 `AfterCardDrawn` 钩子上，节点图的【效果】模块目前表达不了。

## 3. 你那边怎么处理「处决」

存档不用改。用这一版重新生成一次工程即可 —— 那块【效果】会真的生成 `this.SetToFreeThisTurn();`
（以前是「报错 + 生成一行注释」）。
