# V0.2.134 更新说明

> 这一版做了你点的 ②：**锻造节点图现在能从工程恢复**（以前 `--recover` / 界面「从工程恢复」只能拿回效果与时机，**锻造卡的整张图是空的**）。

## 一、怎么做的

生成时把每块**非空的**锻造图，以一行机器可读的标记写进生成出来的类里：

```
// CET:ForgeGraph=<版本>:<Base64(图的紧凑 JSON)>
```

- 一个条目**每块布一行**（卡牌「升级前 / 升级后」各一行；遗物 / 药水各一行），位置在 `// ===== 锻造节点图…` 那一行前面；
- JSON 里含：节点（Id / 种类 / 坐标 / 每一栏字段 / 【效果】模块里的整套效果配置 / 是否来自老字段）、连线、备注 —— 也就是说**V0.2.128 的公式原文、V0.2.129 的效果编辑器配置、V0.2.132 的新档位，都跟着一起回来**；
- **只在图非空时才写**（图空 → 一个字符都不加）；
- 标记带**版本号**：以后格式变了就 +1，回读端遇到**不认识的版本会明确报错**（不会静默把图丢掉）；Base64 损坏同样报错。生成端还加了**生成后自检**：标记必须当场能解开，解不开就**中止生成**。

## 二、代价（重要，请知悉）

让图能恢复的唯一办法就是把图写进产物，所以：

| | 结果 |
|---|---|
| **没有锻造图的存档**（含示例存档） | 生成结果**逐字节不变**（`--samplegen` 113 个文件只有 `.sln` 的随机 GUID 不同） |
| **有锻造图的存档** | 那几个锻造卡/遗物/药水的 `.cs` **多出标记行**（标记行 + 一个空行），**其余文件一字未改** |

实测你的两份存档（逐行核对：把标记行与空行去掉后，与上一版**逐行完全相同**）：

| 存档 | 多出标记的文件 | 标记行 |
|---|---|---|
| `DarkVinci.json` | 双闪 / 闪光 / 引线 / 厚涂形态 / 光合 / 海潮 | 各 2 行（升级前 + 升级后） |
| `SparkleMod.json` | 卡 41 / 卡 42 | 2 行 / 1 行 |

（一行标记约 5~18 KB，所以一份有图的存档大约会多出一两百 KB。）

## 三、恢复效果（用你的 `DarkVinci.json` 实测）

从生成出来的工程恢复：**6 张锻造图全部认回**，日志逐张报出模块/连线数（双闪 11/9、闪光 9/6、引线 17/15、厚涂形态 5/3、光合 11/9、海潮 7/5），`IsForged` **6/6**、「升级前 + 升级后」图块 **6 + 6**，并与源存档**逐字段比对一致**（节点、坐标、每一栏、效果配置、连线）。

顺手修掉一个真 bug：恢复出来的存档以前 **端口版本是 0** → 下次一打开会被当成老存档**再迁移一次**，把【if】的是/否两条线挪位（实测 6 张图各丢一条线、换一条线）。现在认到标记就抬到当前端口版本。

## 四、验证

- `dotnet build Sts2CharForge.sln -c Debug --no-incremental` → **0 错误**；
- `--uicheck`：Debug **3134 PASS / 0 FAIL**、发布版 **3134 PASS / 0 FAIL**（V0.2.133 是 3115，**新增 19 条**）；
- 生成对拍：`--samplegen` **113 个文件只有 `.sln` 不同**；`DarkVinci` 124 个文件 = 117 逐行相同 + 6 只多标记 + 1 `.sln`；`SparkleMod` 303 个 = 300 + 2 + 1；
- 往返：干净探针「生成 → 恢复 → 再生成」**64 个文件只有 `.sln` 不同**（图标记本身逐字节幂等）；老工程（没有标记）恢复时**图 0 张、报错条数与改动前逐条相同**。

## 五、已知边界（留给你定）

1. **「组」仍然不能从工程恢复**（`CardGroups` / 卡牌引用的组）：恢复出来组是**空**的 → 如果有效果写着「范围限定 = 某个组」，**再生成会被校验器拦下**并说清（你的 `DarkVinci` 就命中这条：「染色」引用的那个组现在是空的，去「卡牌」页把牌重新勾进那个组即可）。**要不要单开一版把「组」也写进产物**（做法与图标记同一套）？
2. **恢复后再生成还不逐字节一致**（你的 `DarkVinci` 有 21 个文件不同）：全是**既有**回读缺口 —— 卡牌升级增量映射（就是那条 `变量 Cards2`）、组、状态外观覆盖。图标记本身已证到逐字节幂等。**要不要排一版把这 3 处一起修**？
3. 界面**没有**显式提示「这张图是从标记恢复的」（只在恢复日志 / 状态栏 / 确认框报了张数），需要的话我加。
4. 那条 `染色: 升级增量找不到对应效果（变量 Cards2）` 的既有缺口**仍在**（你上次没勾，我就没动）。
