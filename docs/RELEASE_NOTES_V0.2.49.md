## ⑧ 「牺牲召唤物：收益」多了「获得增益 / 减益」

原来只能换**伤害**或**格挡**，现在多一档：**牺牲伙伴换状态层数**。
- 收益公式沿用原来那三种（固定 N / 最大生命 × 倍率 / 当前生命）——**算的就是层数**；
- 状态的选法复用「给予状态」那个下拉（能力 / 减益都行，含自定义状态）；
- 生成顺序是**先算层数 → 再杀伙伴 → 最后把状态挂到自己身上**（先算是因为伙伴得活着才取得到它的生命值）；
- 卡面会写清（例：「若小石头存活：它死去，然后你获得 9 层力量。」）。

## ⑦ 生成 / 变化出来的卡也能带关键词

在「生成 / 变化出来的卡：…」那几个勾选框（升级、免费、仅本回合…）旁边，多了一个**关键词下拉**：
- 可选本体 7 个关键词（消耗 / 虚无 / 固有 / 保留 / 狡诈 / 永恒 …）或**你自己定义的关键词**；
- 只影响生成 / 变化出来的那张卡，不影响原卡；
- 「（不加关键词）」是默认值 —— 不选它，生成结果和以前**一模一样**。

## ⑥ 自定义状态的触发器支持「范围」+「生成出来的卡如何处理」

以前在**自定义状态**的触发器里选「生成卡牌」只能指定一张卡；现在和卡牌那边一样能用：
- **按范围随机**（攻击 / 技能 / 能力 / 诅咒 / 状态 / 自定义关键词那一组）；
- **生成 / 变化出来的卡的附加处理**（升级 / 免费 / 本回合升级 / 本回合免费 / **带上关键词**）；
- **范围界定**（消耗 / 丢弃 / 升级 / 给关键词…这些"选牌类"效果的范围，包括按自定义关键词那一组筛）。

## ⑨ 新效果「获得药水（指定 / 随机）」

- **指定药水**：多一栏**可搜索的「目标药水」**（和「目标卡」一样的搜索框，输入中文名即可，内置本体 65 种药水）；
- **随机药水**：战斗里随机一瓶、战斗外随机一瓶，范围跟本体「炼制药水」一致；
- **药水栏满的时候什么都不发生**（不丢弃、不替换、不弹提示），三处都会写明这件事：生成的代码里、卡面描述里、以及生成前的「问题」提示里。

## ⑩ 条件新增「卡牌时机」+ 6 个子时机

选「卡牌时机」后会出现子时机下拉，**被消耗 / 被生成 / 被保留 / 被丢弃 / 被变化 / 被给予自定义关键词**（参考本体「战鼓」的做法）。
这一条和别的条件**机制不同**：别的条件是"打出这张牌时判断一次"，而「卡牌时机」是把这些效果**挂到卡自己的钩子上**，所以：
- 效果真的会在「这张牌被消耗 / 被保留 / 被变化…」的那一刻触发，而不是打出时；
- **同一个时机的多条效果会合并进同一个钩子**，按你列表里的顺序依次执行；
- 只对**普通卡牌**开放（遗物 / 药水 / 自定义状态上不存在「这张牌被消耗」，选了会报错并说明原因）；
- 这些效果**不能用**「打出的目标 / X / 需要伙伴已在场」（因为那一刻没有"打出"这个上下文），生成前会逐个报错告诉你；
- 「被生成」覆盖的是**战斗里**生成卡牌（牌组级生成没有可 await 的时机，本体也没人用那个钩子）；
- 「被给予自定义关键词」只在本工具生成的那条给关键词链路上生效（本体没有这个事件，别的模组给关键词不会触发）。

## 说明

- 存档格式**向后兼容**：老存档照常打开、照常生成，生成结果与旧版**逐字一致**（这五条都做过「改前 / 改后逐文件哈希」的回归验证，唯一差异是每次生成都会随机的新工程 GUID）。
- 「动画」页右下角加了署名「由TのG制作」——逐帧动画这一页的玩法与文案吸收自 TのG 的改造版，工具本身是按本仓库风格重写的。
- 发布包里**不含任何存档**、也不含任何《杀戮尖塔 2》的游戏素材。
- 程序内嵌的效果库数据需要你自己用「效果库」页从本机解包工程生成（仓库不附带游戏文本）。
