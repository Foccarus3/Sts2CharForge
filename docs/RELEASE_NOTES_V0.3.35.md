# V0.3.35 — 锻造卡自定义描述「填入参数…」没有数值

## 现象

锻造卡图上【效果】= 造成 20 点伤害，卡牌页的「自定义描述」点「填入参数…」，
菜单里只有「能量图标」，没有 20 / 伤害数值。

## 真因

「填入参数…」的候选来自 `CSharpCodeGen.ParamHints(card.Effects, isCard)`。
锻造卡的效果在**节点图**里，`CardSpec.Effects` 是空的；而且锻造卡**不声明 DynamicVars**
（图上的数字是字面量 / 公式），所以不能用普通卡那种 `{Damage:diff()}` 占位符。
结果 `ParamHints` 返回空，只剩界面额外加的「能量图标」。

## 修法

锻造卡（`ForgeGraph != null`）点「填入参数…」时，额外从节点图里收集每条【效果】的数值：

- 固定数字 → 直接插入字面量，例如 `20`；
- 数值公式 → 插入公式原文，例如 `A+3`；
- 升级前 / 升级后不同 → 插入本体的 `{IfUpgraded:show:30|20}`（30 = 升级后，20 = 升级前）。

菜单项示例：

```
20  — 锻造图【效果】造成伤害：20
```

自定义描述里写「造成 20 点伤害。」即可，不需要 `{Damage:diff()}`（锻造卡没有这个动态变量）。

## 验证

| 项 | 结果 |
|---|---|
| 20 点伤害的锻造卡 → 菜单有 `20` | PASS |
| 升级前后 20 / 30 → 菜单有 `{IfUpgraded:show:30|20}` | PASS |
| 开发版 `--uicheck` | **4884 PASS / 0 FAIL**（+2 条 V0.3.35 断言） |
| 部署版 `--uicheck` | **4883 PASS / 0 FAIL** |

⚠ 需要重新生成工程；旧工程里的卡面描述不会自动改。
