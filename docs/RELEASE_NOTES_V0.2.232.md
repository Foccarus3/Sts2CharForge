# V0.2.232 —— 修「没看到**会被下一个自定义音频顶替**那个勾」

> 来源：你回「没看到会被下一个自定义音频顶替（不勾 = 允许几段音频叠着响）这个」。

## 1. 真因：换效果种类时没「通知」那一行

那个勾的显隐绑的是 `EffectSpec.ShowSfxReplaceRow`（= 「这条效果是不是『播放音频文件』」），
而它是**从 `Kind` 算出来的**。问题在 `EffectSpec.Kind` 的 setter：它每次换种类都会把一堆「跟着种类变」的
属性挨个 `Raise(...)` 通知界面（`IsPlaySfx` / `IsPlaySoundFile` / `ShowScrapeOptions` / `UsesPotionOptions` …），
**偏偏漏了 `ShowSfxReplaceRow`** ——

- WPF 的绑定只在第一次求值 / 收到 `PropertyChanged` 时重算；
- 所以你新建一条效果（默认是「造成伤害」）→ 把种类改成「播放音频文件（我上传的）」时，
  「音频文件」那一行会当场出现（它通知了），而**新加的那个勾不会**（没人通知它）——
  一直是 `Collapsed`，看起来就是「根本没有这一栏」。

## 2. 改法（一行）

```csharp
// V0.2.155：「音频文件」那一行（播放上传的音频）
Raise(nameof(IsPlaySoundFile));
// V0.2.232：音频底下那个「会被下一个自定义音频顶替」的勾也是按种类显隐的 ——
// 不通知的话把效果种类改成「播放音频文件」时它不会出现（用户实测报的「没看到这个」）。
Raise(nameof(ShowSfxReplaceRow));
```

生成端一个字节都没动（这次只改了界面通知），老存档对拍依旧是「只差 `.sln`」。

## 3. 怎么用（这次真的能看到）

1. 随便选一条效果（或新加一条）→「效果种类」选 **播放音频文件（我上传的）**；
2. 「音频文件」那一行下面就会出现：
   ```
   ☐ 会被下一个自定义音频顶替（不勾 = 允许几段音频叠着响）
   ```
   （前提：你之前在「美术资源」页「音效 / 音频」区上传过音频；否则「音频文件」下拉是空的，
   那个勾照样在，只是没有音频可放。）
3. 勾上 → 重新生成 → 这段音频会在下一段自定义音频开始时被停掉。

## 4. 验收

- 自检新增 3 条（`--uicheck` **4203 PASS / 0 FAIL**）：
  ① 把种类从「造成伤害」改成「播放音频文件」时**必须**发出 `ShowSfxReplaceRow` 的通知（修之前这条必红）；
  ② 换回别的种类时同样通知、并且 `ShowSfxReplaceRow` 变回 false；
  ③ 界面树上确实绑着 `ShowSfxReplaceRow`（那一行真的在模板里）。
