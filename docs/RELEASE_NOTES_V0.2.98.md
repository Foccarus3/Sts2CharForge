## 一、概率（%）也能写公式

勾了「概率生效」的效果，编辑器里多一格「概率（%）」的公式：

- 留空 = 用上面那个固定百分比；写了 = 打出这张牌时现算（写法与「数值公式」完全一样）；
- 生成出来：`if (__chanceRoll < (double)(<现算的百分比>)) { … }`；
- 例：`Turn * 10`（第 1 回合 10%、第 5 回合 50%、第 10 回合 100%）。

## 二、概率公式的语义和别的不一样（文档 + 校验器都写明了）

本体原本的做法是：同一张牌里勾了概率的效果**共用一次掷骰**、**各占一段区间**
（例：第一条 40%、第二条 60% → 掷出 0~39.999 只跑第一条，40~99.999 只跑第二条）。

写了公式的那条**退出这个区间划分**、改成**自己独立判一次** —— 因为那段区间是**生成时**按固定百分比
算出来的，运行时才知道的公式算不出区间。所以「一条写公式 + 一条固定值」时两条不再互斥，
**校验器会给一句提示**说清这一点（想要原来那种「互斥」观感就把这几条都改成固定百分比）。

没写公式的效果**一个字符都不变**：照旧走「共用一次掷骰 + 区间划分」那条路。

## 三、界面写明「哪些地方不能写公式」

「次数公式」那一块的说明里补了一句：**卡牌费用 / 升级增量 / 页面常量（初始血量、初始金币、
额外资源量的初始值与上限…）不能写公式** —— 那些必须在生成时就定下来（本体的构造函数要的是编译期常量）。

## 四、配套（这一版一起做的）

- **存档字段**：`EffectSpec.ChanceFormula`（复用 `CountFormulas` 字典，键 `Chance`）
  + 界面显隐 `ShowChanceFormulaBox`（勾了「概率生效」才出现）+ `ChanceText` 印公式；
- **生成**：`ChanceSlices` 把写了公式的那几条排除出区间划分；`EffectConditionGuard` 对它们生成
  `__chanceRoll < (double)(…)`；卡牌时机钩子里同样处理；有公式时也会生成掷骰那一行；
  守卫注释里写「现算，自己独立判一次」；
- **回读**：复用 `CET:CountFormulas=Chance=<公式>`（同一张牌里多条效果的公式不会串）；
- **校验器**：概率公式与同组固定概率混用时给提示（语义变化说清楚）；
- **自检**：10 条新断言（独立判一次、固定那条照旧走区间、标记、无概率的卡逐字不变、混用提示、
  说明里写了「不能写公式的地方」、生成 → 回读往返）；
- **探针**：`_tmp\selfreturnprobe`（`RunChanceFormula`）→ 生成 → 真 `dotnet build` **0 错误** →
  回读公式原样、0 条「没认出来」。
