# V0.2.358 — 插件「启用/禁用」开关 + 页面值按存档隔离

B 组剩下的两条用户体感最强的，一起做了。

## 1. 启用 / 禁用开关

* 「插件」页选中插件 → 「信息」页顶部有 **启用这个插件** 勾选框；
* 关掉 = 它的**效果种类 / 触发时机 / 条件 / 页面全部不生效**（下拉里看不到），`csFiles` / `assetFiles` **也不随 mod 打包**；
* **插件文件一个都不动**：开关存在 `plugins\_enabled.json`，只记「关掉的」那些 id → 新装的插件默认启用、
  卸载插件也不会留下死记录；
* 切换后自动重新加载插件并重建页签（不需要手动点「重新加载插件」）。

## 2. 页面值按存档隔离

| | 以前 | 现在 |
|---|---|---|
| 标量值 | `plugins/<id>/values.json` | `plugins/<id>/profiles/<存档 key>/values.json` |
| 行数据 | `plugins/<id>/rows.json` | `plugins/<id>/profiles/<存档 key>/rows.json` |

* 存档 key = 当前存档文件名（去扩展名 + 非法字符换成 `_`），没打开存档时是 `default`；
* **老文件仍然会读**：新位置没有文件时读老位置当初值（老文件不删不搬）→ 升级后旧值不丢；
* 换存档时插件页会自动重建（值和引用型下拉都跟着换）。
