# V0.2.389 — 编辑器扩展接上主界面入口（插件详情里的「编辑器扩展」页签）

V0.2.388 能把插件页面渲染成界面了，但**没有入口**——这一版补上。

## 现在怎么用

1. 插件在 `plugin.json` 里声明：

```json
"editorExtension": { "entry": "EnemyForge.Editor.EnemyForgeEditorExtension, EnemyForgeEditor",
                     "apiVersion": "1" }
```

2. 启动时扫描完插件后，主程序会把声明了扩展的插件逐个加载（**老插件不进入这条路径**，
   任何一个扩展加载失败都只影响它自己，不会挡住普通插件功能）；
3. 打开「插件」页 → 选中那个插件 → 右边多出 **「编辑器扩展」** 页签：
   * 顶部显示审核信息（入口、API 版本、加载状态、最近日志）；
   * 「重新加载扩展」/「禁用编辑器扩展」两个按钮；
   * 下面是插件自己造的界面（每个 `IEditorPage` 一个 Tab）。

## 隔离

* 页面 `Build()` 抛异常 → 那一页显示「页面创建失败（已隔离）」，其它页照常；
* 按钮 / 输入回调抛异常 → 只弹一条提示，不把异常抛回主程序；
* 禁用扩展后重新加载 → 状态变「已禁用」，界面清空，其它功能照常。

## 一个小坑（记进交接）

改老断言行时我用「按行号替换」把两行 `Check(...)` 叠在了一起（旧行没删干净），编译报 `CS1026`。
教训还是那条：**先 `read` 出那几行，再 `edit` 精确替换**；不要用行号拼字符串。
