# V0.2.137 更新说明

> 这一版做的是你当天报的**四条**，外加一个**根因修复**（命令行工具不再「自作主张」往游戏目录装东西）。

## 一、修掉：额外资源量页「添加效果」点了没反应

**根因**：那个按钮走的是公用处理器，它靠「列表的数据上下文」找效果集合，而那个查找函数（`EffectsOf`）只认**卡牌 / 遗物 / 药水 / 自定义状态**，**漏了「额外资源量」** → 直接返回空 → 只弹一句「请先在左边选中要编辑的条目」，什么也不做。**「删除效果」同一个病**。

修好后：点「添加效果」真的加一条并自动选中（默认「造成伤害 / 数值 0 / 单体敌人」，和你其它页一致）；「删除效果」能删、「撤回删除」能恢复。顺手查出并修掉**另外 3 处同类漏网**：删除的归属/撤回栈没带「额外资源量」、页面刷新漏刷这一栏、该页「撤回删除」按钮缺 ToolTip 与启用状态。

自检也改了做法：这一页的断言现在**真的去点按钮**（上一版只验了「列表绑对了、条件框在」，所以漏了这个 bug）。

## 二、卡牌左侧序号：改成和遗物页一样

以前卡牌页有**三套号**（列表显示的号、类名小字里的号、自动英文类名用的号），互不一致 —— 这就是你觉得「排序有点问题」的原因。现在统一成**一套**：

- **每页列表各自 1..N**（普通卡 / 诅咒卡 / 先古卡各自从 1 开始），序号＝**列表里的位置**，拖动或增删后立刻重算；
- **自动英文类名跟这个号走**，并给三类各自的前缀避免撞名：普通卡 `<角色>Card<n>`、诅咒卡 `<角色>Curse<n>`、先古卡 `<角色>Ancient<n>`；
- 老规矩不变：**手填的类名一个字不动**、**留空的仍然留空只记序号**、**幂等**；改号时**同一次**把按类名保存的引用一起搬到新名字（效果里的「目标卡」、「转化为先古卡」的清单、锻造图的「目标卡」、你上传过的卡面图）；
- 界面上三个页面都补了那一行小字；校验器那句「你手填的类名长得像自动编号，下次生成会改名」也改成会写清**是哪一页第几位**。

## 三、高亮：按你说的改成「你自己填」

撤掉了上一版加的「高亮字段…」按钮、弹窗和汇总行。现在就是**当普通文字写**：

- 在「**升级后的自定义描述**」里直接写 `{Damage:diff()}` → 这个值按「升级前 → 升级后」的差异**变绿**；写 `{Damage}` → 保持普通颜色；
- 「**填入参数…**」菜单里给出的就是**带 `:diff()` 的高亮写法**（核过：卡牌链给 `{Damage:diff()}`，遗物 / 药水链给普通写法），所以你不用记语法，点菜单插进去就行；
- 校验器那三条保护**都保留**：写了 `{X:diff()}` 但这个字段不存在 → **错误**拦住；只写 `{X}` 不存在 → 警告；写了 `:diff()` 却一个占位符都没有 → 警告。

## 四、遗物 / 药水右侧效果栏：默认折叠成一行

以前每条效果都把**整块编辑器**摊在列表里，一行很高、一眼看不完。现在：

- 每条效果默认只占**一行摘要**（带 ▶ 小三角）：显示效果种类与关键参数，例如「造成伤害 6（升级 +3）」；
- **点这一行才展开**完整编辑区（展开用的还是原来那套编辑器，没重写），再点收起；
- 作用范围：**遗物页右栏、药水页右栏、额外资源量页右栏**（三处同一套版式）；卡牌 / 诅咒 / 先古卡页的编辑器没动；
- 老坑没踩回来：行宽仍然不超过列表宽（实测折叠态 410 ≤ 414），横向滚动仍然禁用。

## 五、顺带修掉的根因：命令行工具不再「自己往游戏目录装」

这一版之前，`forge --build`（**没给** `--install`）会**退回用存档里记着的「安装目录」**去装 —— 我们的探针因此两次把测试模组装进了你的游戏目录（都已清理）。现在：

- **不给 `--install` 就绝不安装**（只生成 + 编译 + 导出 pck），存档里那个字段**只给图形界面用**；
- 新增自检 `forge --buildcheck`：造一个「存档里写着陷阱目录」的场景，验证①不给 `--install` 时那个目录**一个文件都不多**、②显式给了才真装；
- 用法说明（`--help`、README、使用说明）都写明：**要装到游戏必须显式给 `--install <mods 目录>`**。

我在本机用 `_tmp` 下的临时目录实测过：显式 `--install _tmp\...` → 3 个文件（dll/pck/json）**只落在那个目录**，游戏目录**没有任何变化**。
