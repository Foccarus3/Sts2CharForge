# V0.2.364 — 清除指定状态：加「调试日志」+ 修两个会让它静默失效的坑

你报「清除指定状态清不掉百分比易伤」。我把这条链从头查了一遍，**生成的语句本身是对的**：

```csharp
// 用你的存档跑生成（ClearPowerOne + 百分比易伤）
if (cardPlay is not null && cardPlay.Target is not null) {
    PowerModel? __clrPower = cardPlay.Target.GetPower<SevenPercentVulnPower>();
    if (__clrPower is not null) await PowerCmd.Remove(__clrPower);
}
```

也就是说：代码会去清「目标身上那个**类名完全对应**的状态」。所以清不掉只可能是两种情况：
**① 身上挂的状态是另一个类**（比如你自己另建了一个同名的自定义状态，或它是用「临时状态」施加的）；
**② 这句根本没执行**（目标为 null / 在钩子里被 NRE 掉）。

这两种在日志里都看不出来 —— 所以这一版主要做**让它们看得出来**，顺手修掉查到的两个真坑。

## 新增：清除状态的调试日志

存档里打开「生成调试日志」后，清除指定状态会在执行前后各打一行到游戏日志：

```
[模组调试] 卡牌「XX」→ 清除目标「史莱姆」；要清的类=SevenPercentVulnPower；找到=没有；
           目标身上现有状态=[SevenPercentVulnPower2=50，VulnerablePower=2]
[模组调试] … 清完之后=[VulnerablePower=2]
```

* **要清的类** vs **身上现有状态**：一眼看出是不是"类名对不上"（比如你要清的是内置的
  `…PercentVulnPower`，而身上挂的是你自建的 `…PercentVulnPower2` 或临时状态类 `…TempVulnPower`）；
* 「找到=没有」+ 列表里也没有类似名字 → 说明那个状态压根不在这个目标身上（清错对象了）。

> 开关在「角色」页的「生成调试日志」；开完要**重新生成 + 重新构建安装**才会生效。
> 关着时生成文本和以前**逐字节一致**（自检里有这条红线检查）。

## 顺手修掉的两个真坑

1. **组里存的是「百分比别名」时会 CS0246**：「自定义参数 / 组」里如果填的是 `PercentVuln` 这种别名，
   `GetPower<PercentVuln>()` 不是合法类型 → 整个工程编译不过。现在和别的发射点一样**先归一成类名**。
2. **卡牌时机钩子里会 NRE（效果整条消失）**：卡牌时机（被消耗 / 被丢弃 / 被保留…）里 `cardPlay` 只是个
   `CardPlay? cardPlay = null` 的占位，原来那句 `if (cardPlay.Target is not null)` 自己就 NRE 了
   → 现在写成 `if (cardPlay is not null && cardPlay.Target is not null)`（OnPlay 里行为不变）。
