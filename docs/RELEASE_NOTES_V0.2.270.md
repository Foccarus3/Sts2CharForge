# V0.2.270 — 锻造页布上【触发时机】节点也能选「层数变化方向」

（上一版 V0.2.269 补的是**锻造页左边那个遗物属性面板**，你说的是布上的【触发时机】节点。）

## 这次补的两处

### ① 布上【触发时机】节点新增一栏「层数变化方向（层数变化时用）」
* 只有把「触发时机」选成「**某个状态层数变化后**」时才出现（旁边就是老的「盯哪个状态 / 到达 N 层」）；
* 候选：上升 / 下降都算（默认）／只在上升时触发／只在下降时触发；
* 写进节点字段 `PowerDirection`（空 = 都算，**老图不受影响**）。

### ② 这一栏在两种布上都真的生效
| 布的档次 | 怎么生效 |
|---|---|
| 状态档（锻造状态） | 节点转成 `PowerTriggerSpec.PowerDirection` → 生成的 `amount > 0m` / `amount < 0m` 判定 |
| 遗物档 | 写进遗物触发钩子：`RelicSpec.TriggerPowerDirection` 空着时**退回读布上节点**的 `PowerDirection`（以前布上选了等于没选 —— 静默失效，现在不会了） |

另外：从「自定义状态」页把时机搬到布上时（`ForgePowerGraph`）也会把这个方向一起带过去，不会悄悄变回「升降都算」。

## 现在「层数变化方向」这一栏在四处都有

1. 遗物页 · 时机编辑器（V0.2.266）
2. 自定义状态页 · 时机编辑器（V0.2.266）
3. 锻造页 · 左边遗物属性面板（V0.2.268）
4. **锻造页 · 布上【触发时机】节点（V0.2.270）**
