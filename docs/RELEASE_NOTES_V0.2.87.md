# V0.2.87 更新说明

> 这一版先修「**下回合生效**」那个**假勾选框**（你问「生成卡牌之类的效果不能下回合生效吗」时暴露出来的）：
> 有 8 个种类界面上摆着勾选框、生成端却根本没有延迟分支 —— 勾了等于没勾。
> 真做「下回合生成」要新增一个延迟状态，在下一版。

## 「下回合生效」的真实支持范围（对着生成端所有延迟分支核对过）

| 支持 | 挂的东西 |
|---|---|
| 获得格挡 | 本体 `BlockNextTurnPower` |
| 抽牌 | 本体 `DrawCardsNextTurnPower` |
| 获得能量（负数也行） | 本体 `EnergyNextTurnPower`；负数是工具生成的「下回合少 N 点」欠费状态 |
| 获得额外资源量 | 本体 `StarNextTurnPower` |
| 施加 / 扣除状态 | 工具生成的 `<角色>ForgeDelayed<状态>`（回合开始时施加层数再自毁） |

**只有这五种**。以前 `EffectKindOption.SupportsNextTurn` 对下面 8 个种类也写着「支持」，
但生成端一个延迟分支都没有：**透支能量 / 翻倍状态层数 / 暴露 / 清除指定状态 / 清除全部减益 /
禁止获得格挡 / 禁止回复生命 / 伙伴攻击** —— 勾上之后什么都不会延迟，属于静默失效。

这一版改成：

- **单一判据** `EffectCatalog.HonorsNextTurn(kind)`（界面显隐和校验器都读它，不再看那个会写错的字段）；
- **勾选框只在那五种上显示**（别的种类这一行不显示 = 根本勾不上，不会再出现「勾了没反应」），
  文案也改成「下回合生效（抽牌 / 格挡 / 能量 / 额外资源量 / 增益减益）」；
- 老存档里如果已经给不支持的种类的勾了，**校验器报错并说清**（列出真正支持的五种）。

## 「生成卡牌」的下回合生效 = 下一版

它需要**新增一个延迟状态**（暂定 `<角色>ForgeDelayedGenerate<N>`：层数 = 张数，在 `AfterPlayerTurnStart`
里调用现成的那套生成卡牌发射器 —— `AddToCombatAndPreview` / `CardFactory.GetDistinctForCombat`
以及「池子空了不卡死」那几条守卫，然后自毁），并把**变化卡牌 / 复制卡牌 / 全局加牌**一起接进同一条延迟链。
这是下一版的第一件事。

## 队列（剩下的）

1. 「下回合生效」：把生成 / 变化 / 复制 / 全局加牌接进延迟链（含回读标记与自检）；
2. 额外资源量那只隐藏遗物在**遗物页的界面**（效果列表 + 添加/删除；数据、生成、回读已完成）；
3. 无色卡（进本体无色池 + 本体无色卡框，不受自定义卡框影响）；
4. 诅咒 / 先古 / 状态合并页（状态卡并入 + 三类都能调费用）；
5. 遗物 / 状态新触发时机（每一下攻击、每点能量 / 资源、状态到 N 层、生成卡牌时）；
6. 参数监听（回合数、本回合 / 本场战斗的丢弃 / 消耗 / 生成 / 复制数、获得的能量与资源、身上状态数）；
7. 「所有能填数值的地方都能写公式」（次数类先行）。
