# V0.2.374 — 插件页支持**一层嵌套 list**（不再只能复刻单层列表）

那位插件作者的判断是对的：以前 `list` 的**子栏位里再放 `list` 会直接被判「嵌套列表 v1 不支持」**，
所以像老界面那种「招式 → 每个招式下面还有若干步骤 / 数值条」的结构，用一个嵌套 list 复刻不出来。

这一版支持**一层**嵌套。

## 怎么写

```json
"fields": [
  { "key": "moves", "label": "招式", "type": "list",
    "fields": [
      { "key": "name", "label": "名字", "type": "text" },
      { "key": "steps", "label": "步骤", "type": "list",
        "fields": [
          { "key": "label", "label": "段名", "type": "text" },
          { "key": "value", "label": "数值", "type": "text" }
        ] }
    ] }
]
```

模板：

```
{moves}
{name}：
{steps}  - {label}:{value}
{/steps}
{/moves}
```

## 嵌套数据在界面上怎么填

子列表那一格是**多行文本框**：**一行 = 一条子数据**，子栏位按声明顺序用 `|` 分隔。例如：

```
第一段|3
第二段|5
```

* 界面上直接改这段文本就行（旁边提示会写明顺序）；
* 块里可用子栏位 + `{index}`（从 1 起）/ `{index0}`（从 0 起），和单层 list 一致；
* 空行会被跳过。

## 限制（说清楚，不装作没有）

* **只支持一层嵌套**：嵌套 list 自己的子栏位不能再是 list（会报「只支持一层嵌套」）；
* 子列表的数据是**文本行**，所以子栏位值里不能出现 `|` 和换行（要放长文本请放到父行的普通栏位里）；
* 没写 `fields` 的嵌套 list、以及 `target` 里用 list，仍会被报成页面问题（不会静默失效）。
