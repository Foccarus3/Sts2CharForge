# V0.3.71 — 构建日志第一行显示生成器版本

## 需求

用户拿旧环境包生成后，日志里只有游戏版本，没有工具版本，容易误判：

```text
[警告] 你这份游戏的版本是 v0.113.1，本工具按 v0.111.0 写的
```

现在生成日志第一行固定输出：

```text
生成器版本：V0.3.71（支持游戏 v0.113.0）
```

## 实现

`ModGenerator.BuildVersion()`：

- 优先读入口程序集的 `AssemblyInformationalVersion`（App.csproj 的 `V0.x.y`）；
- 单文件 / 读不到时退回 exe 的 `ProductVersion`；
- 再失败返回「未知」。

`ModGenerator.Generate` 在写任何配置警告之前先 `Log(...)`，所以构建日志 / 导出日志的顶部就能看到。

## 验证

| 项 | 结果 |
|---|---|
| 生成日志第一行 | `生成器版本：V0.3.71（支持游戏 v0.113.0）` |
| 旧环境包 | 会显示旧版本号，不再只能靠游戏版本警告判断 |
| 开发版 `--uicheck` | **4915 PASS / 0 FAIL** |
| 部署版 `--uicheck` | **4914 PASS / 0 FAIL** |
