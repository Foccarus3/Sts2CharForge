# V0.2.304 — 锻造页【条件】模块：没用的栏位不再一直摊着

## 问题（交接文档里的待办①）

V0.2.300 给锻造页的【条件】模块补上了「指定敌人的意图为（）」需要的那个**意图下拉**，
但**显隐**没跟上：`数值 N` / `数值 M` / `状态` / `关键词` / `范围` / `意图` 六栏是**常显**的 ——
不管你把「条件」选成哪一档，六栏一起摊在模块上，用户根本看不出哪一栏跟自己选的条件有关系。
（`ForgeGraphCatalog` 里那几句「只有对应的条件才显示」当时其实没有对应代码。）

## 改法：判据和四处条件编辑器**同一份**

卡牌 / 遗物 / 药水 / 状态页的条件编辑器一直是按 `ConditionSpec.NeedsAmount` / `NeedsAmount2` /
`NeedsPower` / `NeedsKeyword` / `NeedsScope` / `NeedsIntent` 显隐的（这些属性读
`EffectCatalog.FindCondition(kind)` 上的 `Needs*`）。锻造页现在**直接复用同一份判据**：

| 栏位 | 什么时候显示 |
|---|---|
| 数值 N | 这条条件真的读 N（手牌数 / 生命百分比 / 状态层数 / 预见次数…） |
| 数值 M（生命区间用） | 只有「生命值在 N%~M% 之间」 |
| 状态（拥有某状态用） | 「拥有某状态至少 N 层」「某状态层数刚好达到 N 层」 |
| 关键词 | 「上一张打出的牌带有某关键词」 |
| 范围 | 「上一张打出的牌是某种范围的牌」 |
| 意图 | 「指定敌人的意图为（）」 |

「条件」下拉自己、「不满足时」照旧永远显示（后者本来就只在卡牌档上出现）。
**只藏界面，数据照旧留着**：换回对应条件时之前填过的值还在（和【效果】模块那套一个口径）。

条件换成对应档位时会立刻重建这块模块（`Cond` 那一栏本来就会 `Rebuild()`），所以下拉一改，下面该冒出来的栏位当场冒出来。
