# V0.2.341 — 「每 N 张牌触发一次」整体晚一张（手刃形态：两张不给、第三张才给）

你报的：手刃形态写着「每打出两张牌，获得一点临时力量临时敏捷」，实际要打到**第三张**才给。

## 真因（两条，都对着本体源码核过）

### ① 计数漏了「正在打出的这一张」

本体 `CardModel.Play` 的顺序是：

```
await Hook.BeforeCardPlayed(...)      ←「打出一张牌时」这条时机挂在这里
History.CardPlayStarted(...)          ← 这一张**这时**才进历史
OnPlay(...)
History.CardPlayFinished(...)
Hook.AfterCardPlayed(...)
```

生成端从 V0.2.173 起一直当「CardPlaysStarted 已经含这一张」（注释原话），实际**不含**。
于是「每累计 N 次触发一次」整体晚一张：N=2 要打 3 张、N=3 要打 4 张。
状态链还有基准值抵消一半，遗物链是**纯晚一张**，肉眼就能看出来。

### ② 状态链基准值的哨兵 `-1` 撞上合法值

`__cntCardPlayedTurn` 用 `-1` 表示「还没记过」。但「本回合第 1 张牌」算出来的基准**正好就是 -1**
（历史累计 0 → 基准 = 0 - 1 = -1）→ 下一张牌又把它当成「还没记过」再重置一次，**本回合第一张被吞掉**。

两条叠加的效果就是你看到的：每回合要第 3、5、7 张才触发，而不是第 2、4、6 张。

## 修法

* `CSharpCodeGen.CountExpr("CardPlayed", …)`：计数改成 `(历史累计 + 1)` —— 把正在打出的这一张补上。
  「只对哪类牌生效」时，补的这一张也要按**同一个筛选**判：
  `+ (cardPlay.Card.Type == CardType.Skill ? 1 : 0)`（不然「只对技能牌、每 2 张」打攻击牌也会给技能计数 +1）。
* 状态链基准值哨兵 `-1` → `int.MinValue`（`-1` 是合法基准），换回合不再吞掉第一张；
  字段名一个字符不变（老工程只有哨兵值和那行条件变了）。
* 「一张牌结算完毕时」**不动** —— 本体是先记 `CardPlayFinished` 再调钩子，本来就含这一张。

## 现在的行为（每 2 张，状态已经在身上）

**第 2、4、6 张触发**（修之前是第 3、5、7 张）。
状态是本回合某张牌施加的：那张牌算进基准（不参与计数），之后**再打两张**触发（和 V0.2.173 定的口径一致）。

## 关于「第二张是技能才行」

生成的 `yinsushouren.cs` 里**没有任何牌型判据** —— 整份文件搜不到 `CardType`，计数就是：

```csharp
int __cnt = (CombatManager.Instance.History.CardPlaysStarted
    .Count(e => e.Actor == base.Owner && e.HappenedThisTurn(base.Owner.CombatState)) + 1);
```

所以「只有技能牌才算」这条我在代码里对不上，也就没法凭猜去改。
先把「晚一张」修掉；如果你那边改完还是**只有技能牌能触发**，请给我一段精确的用牌顺序
（哪几张、什么类型、手刃形态是第几张牌施加的 / 是不是遗物给的），我再按那条线查。
