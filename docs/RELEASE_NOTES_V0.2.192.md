# V0.2.192 更新说明

> 你要的：**在锻造页加一个「状态列表」**。这一版加好了 —— 是一种**新模块**（叫【状态列表】），
> 不是参考窗口：它把「某个单位身上的一群状态」当成一个**数值**送出去，接上【关系符】就能写判断。

## 一、【状态列表】是什么

**模块位置**：锻造页 → 「加模块」/积木调色板 → **【状态列表】**（和【状态】【数值】同一类「取值」）。

```
      ┌───────────────┐
对象 ─→│ 归属   状态列表 │─→ 数值 ──→ 【关系符】/【效果】的「数值」口
      └───────────────┘
```

三栏设置：

| 栏 | 可选 |
|---|---|
| **看哪些状态** | 全部状态 / **只看增益** / **只看减益** / 只看指定状态 |
| **指定的那个状态**（只在选「只看指定状态」时出现） | 可打字搜索（本体 200+ + 你的自定义状态） |
| **算哪一个** | **状态数（有几个）** / **层数合计（加起来多少层）** |

「归属」左边接【对象】（不接 = 打出牌时选中的那个目标），和【状态】模块同一套接法。

## 二、能写出来的判断（举例）

| 想表达 | 怎么搭 |
|---|---|
| **身上有任意减益** | 【状态列表】(只看减益 · 状态数) →【关系符】「大于」0 |
| **身上状态数 ≥ N** | 【状态列表】(全部状态 · 状态数) →【关系符】「大于等于」N |
| **身上有易伤**（不管几层） | 【状态列表】(只看指定状态=易伤 · 状态数) →【关系符】「大于」0 |
| **身上减益层数一共多少** | 【状态列表】(只看减益 · 层数合计) → 直接接到【效果】的「数值」口（比如「每层减益造成 1 点伤害」） |
| 「敌人身上有 3 种以上减益才…」 | 【状态列表】(只看减益 · 状态数) →【关系符】「大于」3 → 结果接到【if】的「条件」口 |

卡面文案也会跟着写出来（例：`如果 自己身上的状态数量 大于 3：抽 1 张牌。`／`自己身上的易伤层数合计`）。

## 三、顺手做的两件事

* **校验器**：
  * 选了「只看指定状态」却**没选状态** → **错误**（说清这一块不会生成任何代码）；
  * 「数值」出口**没接线** → **警告**（搭了一块但没人用，等于白搭 —— 提示接到【关系符】或【效果】的数值口）。
* **连线规则**同步放宽：能接数值的那些口（【数值】模块的接入点、【效果】的数值口、【关系符】的左右值）现在**也收【状态列表】**；
  反过来把它接到执行链入口上照样会被拦住并说明原因。

## 五、用法提醒

* 【状态列表】的「数值」出口是个**数值**：直接接【if】的「条件」口会被连线规则拦住
  （那个口要「成立/不成立」）—— 中间过一道【关系符】就行（这也是本体自己的写法）。
* 想读**某一个**状态的层数（不筛选），仍然用老的【状态】模块。
* 记得**重新生成 + 一键构建 + 替换 mod**。
