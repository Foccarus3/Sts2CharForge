# V0.3.49 — 命中次数 0 不再固定打 1 下

## 现象

V0.3.48 之后，Y 已经能正确读到 0；但没有额外资源量时，「锻造卡 3」**仍然造成 1 次伤害**。

## 真因

锻造图【效果】的命中次数公式生成的是：

```csharp
int __fgHits = Math.Max(1, (int)(__Y));   // 以前
```

Y = 0 时被夹成 **1**，于是 `WithHitCount(1)` 固定打一下。

## 修法

公式命中次数允许 0：

```csharp
int __fgHits = Math.Max(0, (int)(__Y));   // 0 = 不打
```

另外，固定值命中次数填 **0** 时直接跳过这条效果（不再生成一次默认攻击）。

## 验证

| 项 | 结果 |
|---|---|
| 公式 Y=0 → 命中 0 次 | PASS |
| 固定命中次数 0 → 整条效果不执行 | PASS |
| 开发版 `--uicheck` | **4901 PASS / 0 FAIL** |
| 部署版 `--uicheck` | **4900 PASS / 0 FAIL** |

⚠ 需要重新生成工程；旧工程里还是 `Math.Max(1, ...)`。
