# V0.2.258 — 「或者清空一个组」和「目标状态」叠在一起了

## 你报的

> 指定状态的目标状态和选组的选项重叠在一起

## 原因

效果编辑器那个网格是**两列**（左边标签 / 右边控件）。V0.2.255 我把「或者清空一个组」这一栏塞进了
「增益 / 减益」那一行的**第 3、4 列**（`Grid.Column="2"/"3"`）——
WPF 里列号越界会**折回最后一列**，于是它正好压在「增益 / 减益」那个状态下拉上面，看起来就是两行字挤在一起。

## 改法

* 给那个网格**多加一行**，把「或者清空一个组」放到**单独一行**（第 0 列标签 / 第 1 列下拉），
  和上面「增益 / 减益」彻底分开；
* 这一行仍然只在效果种类 = **清除指定状态** 时出现，其它效果完全看不到它（不占视觉空间、不占高度）；
* 顺带把「组」下拉的提示写清楚：留空 = 只清上面选的那一个状态；两边都填时**组优先**。

## 验收

* 生成端零改动（只改界面 XAML），自检 **4352 PASS / 0 FAIL**。
* 实机截图核对：效果编辑器里「增益 / 减益」行只有一个下拉，不再有第二行字压在上面；
  选「清除指定状态」后，「或者清空一个组」出现在下面**独立的一行**。
