# V0.2.400 — 逐帧自动播放（FPS）— 第三期完成

第三期最后一个小项：逐帧预览能按帧率自动轮播。

## 新增（`IEditorFramePreview`）

```csharp
double Fps { get; set; }   // 1–60（越界自动夹；≤0 当 8）
bool   IsPlaying { get; }
void   Play();             // 从当前帧开始按 Fps 轮播，到最后一帧回到第一帧
void   Stop();             // 停在哪一帧就留在哪一帧
```

界面上加了自动播放的能力（计时器按 `1000/Fps` 毫秒推进一帧）；帧数 ≤ 1 时 `Play()` 什么都不做（避免无意义空转）。

## 自检

**4786 PASS / 0 FAIL**（+4 条）：
`Fps=200` 被夹到 60 / 初始不在播放 / `Play()` 后 `IsPlaying=True` / `Stop()` 后回到 `False`。

## 说明

自动播放的**动画效果**（帧真的在动）依赖 WPF 计时器，自检环境无消息泵，所以自检只验证状态机与夹取；
视觉上的轮播要你在界面上看。这条限制照实写在这里，不假装自检覆盖了视觉效果。
