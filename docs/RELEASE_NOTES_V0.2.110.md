# V0.2.110 更新说明

> 这批需求里的第 ④ 条：**命中次数的公式不生效**（你举的例子是「填 `2+A`、A = 我身上易伤层数，
> 游戏里只打一次，卡面描述也没有次数」）。查清了：**生成端少写了一句 `.WithHitCount(...)`**。

## 一、根因：写公式时那段代码根本没生成

生成伤害的三条分支里，只有**随机敌人**那条无条件把「命中次数」写进 `WithHitCount`；
**指定敌人**和**全体敌人**那两条是这么判的：

```csharp
bool multi = (useX && e.RepeatIsX) || e.RepeatCount > 1;   // ← 只认「固定次数 > 1 / = X」
```

而写公式时那个**固定值**通常还是 1 —— 于是 `multi` 为 false，生成出来就是：

```csharp
await DamageCmd.Attack(base.DynamicVars.Damage.BaseValue)
  .FromCard(this, cardPlay).Targeting(cardPlay.Target)      // ← 没有 .WithHitCount(...)
```

**打一下**，但卡面印的却是「对指定敌人造成 5 点伤害 **2+A** 次」—— 两处对不上，看起来就像「公式不生效」。
现在判据变成：

```csharp
bool multi = (useX && e.RepeatIsX) || e.RepeatCount > 1 || !string.IsNullOrWhiteSpace(e.RepeatFormula);
```

| 作用对象 | 生成出来 |
|---|---|
| 指定敌人 | `.WithHitCount((int)Math.Clamp(((2m) + __pA), 1m, 20m))`（打同一个目标 N 下） |
| 全体敌人 | `.TargetingAllOpponents(base.CombatState).WithHitCount(...)`（**每个**敌人各挨 N 下） |
| 随机敌人 | 逐个挑目标、挑 N 次（这条一直是好的，所以以前没被发现） |

其中 `__pA` 就是参数 A：

```csharp
decimal __pA = ForgeFormulaRuntime.PowerAmount(__fgSelf, "VulnerablePower");   // A = 自己身上的易伤层数
```

- **固定 1 次且没写公式时照旧一个字符都不多**（红线：老存档生成的代码逐字不变）；
- 卡面那边本来就是对的（会印「2+A 次」）—— 所以这次修完，**卡面**和**实际打出去的次数**终于一致了；
  如果你之前看到「卡面也没有次数」，多半是那份存档配的是别的字段（例如「生效次数」，
  那个印成「重复 N 次：…」）或者工程还没重新生成，升级后再看一眼。
