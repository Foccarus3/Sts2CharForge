# V0.3.36 — 效果列表支持拖动换顺序

## 顺序规则

- **卡牌 / 遗物 / 药水 / 诅咒 / 先古 / 自定义状态 / 额外资源量**的效果栏：
  **从上到下**就是生成顺序（`OnPlay` 里按列表顺序一条条写）。
- **锻造图**：按节点图**连线先后**执行；要改顺序就重新接线，不是按节点在画布上的位置。

## 这次改了什么

以前效果列表只能靠增删来调整顺序，没法直观地拖。现在：

- 在任意效果列表里按住某一条效果，往上 / 往下拖；
- 拖到另一条上松手 → 插到那一条的位置；
- 拖到列表空白处 → 放到最后；
- 拖完状态栏会提示「已把效果「…」移到第 N 位」。

只改列表顺序，不复制效果对象；生成端读的就是这个顺序。

## 锻造图

锻造图不走效果列表的拖动：它是按连线链执行的：

```text
触发时机 → 效果1 → 效果2 → …
```

想调整先后，删掉旧连线，按新顺序重新接。分叉（【if】/ 多出口）里各分支内部的顺序同样由连线决定。
