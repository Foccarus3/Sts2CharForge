## 修：原版状态改名只在你自己的角色上生效

**病根**：改名原来靠**覆盖本体的本地化键**（`VULNERABLE_POWER.title` 这种），
而本地化表是**全局**的 —— 一覆盖，所有角色、百科、任何提到这个状态的地方都会变成新名字；
另外那条「本体卡牌 / 遗物 / 药水描述里的旧名字也一起换掉」还默认开着，会**全局改写本体文本**
（铁甲战士「战栗」描述里那个字面量 `[gold]易伤[/gold]` 就是这么变成破绽的）。

**改法**：

- 新名字 / 新描述写进**我们自己的键** `<SLUG>_FORGE.title / .description / .smartDescription`，
  本体的键**一个字都不动**；本体文本替换改为**默认关**（要开得在那条改写上自己勾，它会明确告诉你那是全角色范围）。
- 生成 `ForgePowerRename` 补丁（Postfix `PowerModel.Title / Description / SmartDescription`），
  **只在「这一局玩的是我方角色」时**才返回我们的键。判定用本体公开链：
  `RunManager.Instance.IsInProgress` → `DebugOnlyGetState()` → `LocalContext.GetMe(state)?.Character is <你的角色类>`
  （本体的百科页也是这么判的）；主菜单 / 别的角色一律原名。
- 图标 / 大图标 / 层数颜色 / 血条颜色四个补丁**同样**加了这把开关。

**结果**：你自己的角色里显示破绽（战斗中的状态图标、悬停提示都换），
百科里铁甲战士的「战栗」、别的角色的任何文本，永远还是「易伤」。

## 修：「重放卡牌」打出后卡死

按本体「隐藏宝石 HiddenGem」的防御写法重写生成代码：

- 先算**候选池**：去掉「打不出去」的牌（Unplayable / 状态 / 诅咒）与**已经有重放**的牌
  （本体是 `c.GetEnchantedReplayCount() < 1`）—— 不然重放会一层层累乘，玩起来像卡死；
- 池子空了就**整条跳过**（本体是 `if (list.Count == 0) return;`），不会拿着空选牌界面等玩家；
- 要的张数**永不大于池子**（`Math.Min(N, pool.Count)`），选牌界面永远能满足；
- 预览改用 `CardCmd.Preview(列表)` **整批一次**（本体自带的重载），不再一张一张弹；
- 从工程回读（`--recover`）同步识别新增的这几行实现。

## 说明

- 存档格式没有变化，直接覆盖更新即可；你的存档在 `自定义角色存档\` 里，覆盖程序文件不会动它。
- 发布包里**不含任何存档**、也不含任何《杀戮尖塔 2》的游戏素材；程序运行时只读取你本机的游戏文件。
- 程序内嵌的效果库数据需要你自己用「效果库」页从本机解包工程生成（仓库不附带游戏文本）。
