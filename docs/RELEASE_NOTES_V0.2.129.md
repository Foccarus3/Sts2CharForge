# V0.2.129 更新说明

> 这一版做的是《锻造优化.md》的**第 3 条**：锻造页【效果】模块**换成卡牌页那一套效果编辑器** ——
> 两边的「可填写项」从此是**同一份**，不会再一边加字段、另一边忘了加。

## 一、【效果】模块现在就是卡牌那套编辑器

以前【效果】模块是**自己一套 13 栏**（效果种类 / 数值 / 生效次数 / 命中次数 / 概率 / 目标卡 / 生成到 / 选牌方式 / 目标药水 / 取药方式 / 放到哪一摞 / 反转 / 下回合生效），界面上还只按效果种类藏掉其中三组 —— 和卡牌页对不上。

现在【效果】模块直接挂**卡牌页同一个编辑器模板**，于是这些栏位都有了（按效果种类与档位出现，和卡牌页一致）：

作用对象、取几张、范围限定、范围界定、从范围里自己挑一张、多选 1、生成/变化出来的卡 4 个附加处理、加关键词、给予关键词 / 临时关键词、强化什么、放到哪一摞、召唤物（哪一只）、复制的份数、重放次数、取药方式 / 目标药水、（刮削）其中符合条件的牌 / 执行、缓慢直接设成 N%、牺牲伙伴那组、可用量清单…

- **「作用对象」这次是真生效的**：以前节点图里只能靠【对象】模块接线或靠「这张牌选中的目标」；现在编辑器里的「作用对象」也能决定打谁，并且**卡面文案会跟着改**（顺手修掉一个老 bug：代码打全体、卡面却写「对指定敌人」）。
- **数值 / 生效次数 / 命中次数 / 概率**：在锻造链里仍然是**能直接写公式的文本框**（V0.2.128 的能力一个不少），所以卡牌页那两个独立的「数值（公式）」「次数公式」框在锻造链不重复摆。
- **卡牌专属的栏位**（升级增量、升级后费用、`数值=X` 那几个开关、条件选项）在锻造链不摆 —— 锻造图的费用/升级是【能量】模块与升级那块布的事。

## 二、老存档安全（这一版最要紧的部分）

- 打开老存档时**自动迁移**：把【效果】模块原来那套 13 栏字段读进一份效果配置（数值/次数/概率写的是公式的话，**原文一字不改**地留着）；
- **幂等**：迁移过的存档再打开、再保存，**逐字节一致**（实测 109333/109333 字节）；迁移**从不回写**老字段；
- **老存档生成结果逐字不变**：生成端读的仍是老字段，迁移过的模块在**你没有动过它**之前**永远不回写**（实测：迁移后生成一遍，老字段 JSON 与迁移前逐模块相等）。**只有你在新编辑器里真的改了**，它才接管并回写；
- 实测：`--samplegen` 112 个文件里 **111 个逐文件 SHA256 一致**；**含锻造图的老形状存档** 159 个文件里 **158 个一致**（两处唯一差异都是 `ExampleMod.sln` 的随机 GUID）。

## 三、不再有「填了却什么也不发生」

编辑器上**摆出来但节点图暂时不生成**的栏位，校验器会**逐条报出来**（哪个模块、哪一栏、为什么），不会静默忽略。**只提醒不拦**的只有一种：「下回合生效」用在格挡 / 抽牌 / 施加状态以外的效果上（老存档里可能勾过，报错会让它突然生成不出来）。

⚠ **效果种类仍是 30/65 支持**：剩下 35 种（宠物那一组、全局加牌/变化/删除/升级牌组、放置卡牌、刮削抽牌、若干特殊状态类）**现在选了会被校验器明确拦住**（不会静默生成空代码）。补齐这批发射器建议**单开一版**。

## 五、已知边界（留给你定）

1. **35/65 种效果**：编辑器已经能选，生成端还没接（校验器拦住）。要补齐请单独说一声，我按批次排；
2. **「作用对象」的优先级**：显式接线的【对象】模块 > 改过的「作用对象」> 老规矩（这张牌选中的目标）；接线盖住「作用对象」时只给提示。要不要改成「作用对象永远优先」？
3. **「从哪里选牌」**节点图目前只支持手牌（选抽牌堆/弃牌堆会被拦住）；
4. **概率语义**：卡牌链是「同一张牌里勾概率的效果共用一次掷骰、各占区间」，节点图是**每条各自判一次**（编辑器里已写明）；
5. **锻造节点图仍然不能被「从工程恢复」还原**（老问题，已在 `docs/QUEUE.md` 的「已知未修」里记录，建议单开一版）。
