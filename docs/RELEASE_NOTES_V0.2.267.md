# V0.2.267 — 自定义参数页：「指定敌人」+「自己的当前格挡」那种稀里糊涂的显示

## 你报的

> 自定义参数页监听格挡时在其他参数选择指定敌人，再选择监听格挡，会出现使人稀里糊涂的 UI 错误

截图里 C 那一行读作「**指定敌人的自己当前格挡**」——「自己当前格挡」本来就只可能是自己身上的，
前面挂个「指定敌人的」纯属自相矛盾。

## 三个原因，一起修了

1. **「从谁身上取」那一栏被藏起来，但旧的「指定敌人」还留着**
   以前「要不要选目标」是手写的枚举判断，`MyBlock`（自己的当前格挡）这类实时读数**不在**里面 ——
   于是那一栏不显示、用户改不了，可底层 `Target` 还是上一次选过的「指定敌人」，列表就照着印。

2. **列表那句话不看来源是哪一类**，一律 `{目标}的{来源}` → 拼出「指定敌人的自己当前格挡」。

3. **反过来漏了一个：**「减益的个数（几种负面效果）」其实**需要**目标，但它不在那个枚举里 →
   下拉被藏了（你截图里 B 那一行能显示「指定敌人的减益的个数」，但当时没法改）。

## 现在的规则（只有一份判据）

`ParamSources.SelfOnly(id)` = 「这个来源生成出来根本用不到目标」：
固定数值 / 金币数 / 能量数 / 最大能量数 + 「数值公式」那张实时读数表里的每一条（回合数、手牌张数、自己的当前格挡…）。

| 情况 | 现在 |
|---|---|
| 自己的当前格挡（自己专属） | **不显示**「从谁身上取」；`Target` 一律按「自己」算；列表只写「自己当前格挡」 |
| 当前血量 / 最大生命 / 状态层数 / 减益的个数 | 照常显示「从谁身上取」，列表照常写「指定敌人的…」 |
| 先把来源设成「当前血量 + 指定敌人」，再改成「自己的当前格挡」 | **自动收回「自己」**（不会再留一个看不见的旧选择） |
| 金币 / 能量 / 手牌张数这类名字里没有「自己」的 | 文案照旧「自己的金币数」（老存档逐字不变） |

顺手：状态页「某个状态层数变化后」的列表那一行，现在会把 V0.2.266 加的方向也说出来
（「（只在上升时）」/「（只在下降时）」），不然看不出那条只管掉层。
