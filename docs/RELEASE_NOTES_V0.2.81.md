# V0.2.81 更新说明

> 这一版是你那批需求里的**前几项**（都是小而明确的），剩下的大件（诅咒 / 先古 / 状态合并页、
> 无色卡、遗物侧新触发时机、参数监听）在下一版里做 —— 详见文末「还没做的」。
> 另外顺手修了两个 bug：自定义状态下「每消耗一个能量」漏守卫、卡面「打不出」的叉被换成了资源图标。

## ① 「抽到这张牌后，本场战斗内这张牌的费用 -1」——新效果，没有回合数限制

你问的「效果中抽到费用-1 怎么是本回合抽到的**其他牌**费用减」——那是**原来那条**效果的语义，
不是 bug：效果种类「**抽到就减费**」是给自己挂一个 **N 回合**的状态，这期间**每抽到一张牌、那张牌**
本场战斗费用 -1（所以抽到谁就给谁减）。

这一版加了一条**新的**，专门做你要的那件事：

- 效果种类：**抽到这张牌时它本场战斗的费用 -N（可叠加；0 = 不生效）**
- 数值 = 每次抽到减多少（默认 1），抽到几次叠几次，**只作用在这张牌自己身上**；
- 生成的是卡自己的钩子（照抄本体卡「王者一击 KinglyKick」）：

  ```csharp
  public override Task AfterCardDrawn(PlayerChoiceContext choiceContext, CardModel card, bool fromHandDraw) {
      if (card == this) base.EnergyCost.AddThisCombat(-1);
      return Task.CompletedTask;
  }
  ```

- 用 `AddThisCombat(-N)` 而不是「读当前费用再 SetThisCombat」：本体的费用是「基础费 + 本场加成」，
  这样记账抽到几次叠几次、不会被别的改费效果冲掉，而且本体自己会夹住下限（费用不会变负）。
- **值 0 = 这条效果不存在**（卡面不写、代码也不生成）；它没有可升级的数值，
  所以「升级增量」填了不生效（配置检查会提醒）。
- 卡面描述：「抽到时：这张牌本场战斗的费用 -1。」；从工程回读按 `CET:Effect=CheapenSelfOnDraw` 认回来。

顺带把**旧那条**的措辞改清楚了（避免再混）：「抽到就减费：挂 N 回合状态，这期间每抽到一张牌、
那张牌费用 -1（负数 = 扣层数）」。

## ② 复制出来的卡也能「免费打出 / 升级」

「复制卡牌」现在也有「**复制出来的卡怎么处理**」那一栏，和「生成卡牌 / 变化卡牌」完全同一套：

- 直接升级（`CardCmd.Upgrade`）/ 免费打出（`SetToFreeThisCombat`）/ 仅本回合免费（`SetToFreeThisTurn`）
  / 仅本回合升级（生成的 `ForgeTempUpgradePower`，回合结束降回来）/ 加上关键词（本体关键词或自定义关键词）；
- 生成顺序：`CreateClone()` → 升级 / 免费 → 再 `AddGeneratedCardToCombat` 进手牌（顺序反了等于没改）；
- 这些设置和「范围界定」一起写在生成代码的标记行里，从工程回读原样认回来。

## ③ 像「致死性」这种效果怎么做（不用新种类）

本体「**致死性 Lethality**」是亡灵缚者的 Power 牌：给自己挂 50 层 `LethalityPower`（升级 75），
机制 = **本回合打出的第一张攻击牌 ×(1 + 层数/100)**（不是「斩杀」，那是另一个关键词 `FATAL`）。

`LethalityPower` 本来就在效果库的状态列表里，所以直接用「**施加增益/减益**」：
状态选 `LethalityPower`、数值 50（升级增量 25）、作用对象「自己」、卡牌类型 Power / 稀有度 Uncommon。
工具里没有通用的「伤害倍率」效果（`BoostCard` 是加法且只对某一张卡），
凡是本体现成状态实现的机制，都建议这么引用。

## ④ 顺手修的 bug

- **自定义状态「每消耗一个能量」漏了守卫**：本体这条钩子（`AfterEnergySpent`）**不带 Player 参数**，
  而且**每打出一张牌都会调一次（0 费也调）**。以前的生成代码没有判断「是不是我方角色花的」——
  联机时**别人打牌也会触发你的状态**。现在生成
  `if (amount <= 0 || card?.Owner?.Creature != base.Owner) return;`。
- 同一条钩子的语义也修正了：「每消耗一个能量 / 每消耗一个额外资源量」现在**按点数各触发一次**
  （以前是「一张牌触发一次」，X 费牌花光能量也只触发一次）——因为本体的 `amount` 是
  「这一张牌一共花了多少」，所以生成的是 `for (int i = 0; i < amount; i++)` 包住效果。
- **卡面「打不出」的叉被换成了资源图标**：额外资源量换图标时，以前连 `%UnplayableStarIcon` 一起换了 ——
  那个节点不是星星，是本体「这张牌打不出去」的**叉号**。现在只换 `%StarIcon`（星费那个图标）。

## ⑤ 「数值 0」的例外名单（回答你的第二个问题）

「数值 0 = 这条效果不显示也不执行」是通用规矩，但下面这些种类的 0 **有别的含义**，
工具里是**显式排除**的，不会被当成「没填」丢掉：

| 效果种类 | 数值 0 的含义 |
|---|---|
| 召唤伙伴 | 用「召唤物」页里配置的血量 |
| 给予卡牌关键词 | 这张牌自己 |
| 回合结束时自动打出 | 这张牌自己 |
| 按生命值算的三条伙伴攻击 / 牺牲伙伴 | 0 是常态（力度来自公式） |
| 将此牌放回手牌 / 抽到这张牌时费用 -N | 0 = 关（升级增量对它也没意义） |

「**消耗卡牌 / 丢弃卡牌**」**从来没有**「填 0 = 消耗 / 丢弃自己」这一档：它们一直是「数值 = 张数，
0 = 不生效」。想「消耗这张牌自己」请用卡牌页的「**消耗**」关键词（本体 `CardKeyword.Exhaust`）；
「丢弃这张牌自己」目前没有对应种类（要的话下一版加一档「数值 0 = 这张牌自己」，很直接）。
