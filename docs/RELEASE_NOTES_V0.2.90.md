## 「下回合生效」完整名单（这一版补齐）

| 类别 | 支持的效果 | 挂的东西 |
|---|---|---|
| 状态类（5） | 获得格挡 / 抽牌 / 获得能量（可负数）/ 获得额外资源量 / 施加·扣除状态 | 本体现成的「下回合」状态，或工具生成的 `<角色>ForgeDelayed<状态>` |
| 生成类（7） | **生成卡牌 / 复制卡牌 / 变化卡牌** / 获得卡牌（全局）/ 变化卡牌（全局）/ 删除卡牌（全局）/ 升级牌组里的牌（全局） | 工具生成的 `<角色>ForgeDelayed<Gen\|Copy\|Trans\|AddGlobal\|TransGlobal\|RemoveGlobal\|UpGlobal><卡类名>`：**层数 = 张数**，回合开始时调用**同一套发射器** |

  （校验器也会报错说明），不会再出现「勾了没反应」。
- 生成类的那几种目前只做在**卡牌**上（遗物 / 药水 / 自定义状态还没有延迟链）——
  勾了会被配置检查拦住并说明，不静默改成「立刻执行」。

## 这一版改的（变化卡牌）

`EmitTransformCard` / `EmitTransformBody` 现在和生成卡牌一样接受「玩家表达式」：

- `playerExpr`（默认 `base.Owner`；延迟状态里传 `base.Owner.Player`）
- `creatureExpr`（默认 `base.Owner.Creature`；延迟状态里传 `base.Owner`）
- `sourceExpr`（「选牌来源」实参：卡牌链 `this`，延迟状态 / 遗物 / 药水 `null`）
- `combatStateExpr`（默认 `base.CombatState`；延迟状态里没有 CardModel 的 `CombatState`，传 `base.Owner.CombatState`）

**默认档（卡牌链）生成出来的文本一个字符都没变** —— 参数默认值就是老写法，
所以老存档生成结果不受影响（`combatStateExpr` 特意留成参数就是为了这个）。

回读：生成类延迟状态一律走
`// CET:SpawnPick=…`（范围 / 张数模式 / 附加处理）+ `// CET:Effect=<Kind> … CET:NextTurn=1`（种类 / 数值 /
复制份数 / 选牌方式 / 哪一摞）两行标记，实现那两句在跳过名单里 —— 探针实测：
生成卡牌 / 复制卡牌 / 变化卡牌 / 全局加牌四种都能原样回读，0 条「没认出来」，且生成的工程真 `dotnet build` 0 错误。
