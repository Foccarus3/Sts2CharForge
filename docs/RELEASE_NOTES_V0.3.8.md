# V0.3.8 — 「多人卡」勾选框放错了地方（已挪到「卡牌」页）

## 你截图里的问题

> ☐ 作为初始牌 / 初始份数 / ☐ 无色卡 / ☑ 加入卡池 / ☐ 可被无限升级

—— 这是「**卡牌**」页那份模板，而 V0.3.7 我把勾选框加到了「**锻造**」页那份卡牌模板里
（那份模板里只有「加入卡池 / 卡牌关键字」，没有「作为初始牌 / 无色卡」这一套），所以你在卡牌页看不到它。

## 改法

把勾选框补到「卡牌」页的模板里，位置就在「加入卡池」下面、可被无限升级上面：

> ☐ **多人卡（只会在多人游戏中出现）**

并且和邻居一样带 `IsEnabled="{Binding ValueEditable}"`（本体卡「打击 / 防御」这类不可编辑的牌上会灰掉）。

锻造页那份模板里那一份**保留**（同一个模型对象，两边都能勾，互相同步）。

## 生成逻辑没变（V0.3.7 就是对的）

勾上 → 卡牌类里多一行：

```csharp
public override CardMultiplayerConstraint MultiplayerConstraint => CardMultiplayerConstraint.MultiplayerOnly;
```

不勾 → 一行都不写（老存档输出逐字不变）。
