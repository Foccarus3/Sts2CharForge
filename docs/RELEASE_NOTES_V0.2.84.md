# V0.2.84 更新说明

> 这一版就一件事：卡牌效果的「**作用对象**」多了「**指定队友 / 全部队友**」（你说的「选择队友」）。
> 用的是本体现成的目标类型，不是自己拼的。

## 为什么这次能做（上次的说明是错的）

之前 `README` 里写着「指定队友 = 目前等同于自己（本体是单人游戏，没有可以被指定的对象）」——
**那句是错的**。本体 `TargetType` 枚举里本来就有队友档：

```csharp
AnyPlayer,   // 任意玩家（含自己）：多人时弹目标选择，单人时不弹
AnyAlly,     // 任意队友（== 不含自己）：多人时弹目标选择；单人你看不到这一档
AllAllies,   // 全部队友：不弹选择
```

本体卡 `BelieveInYou`（0 费技能）用的就是 `AnyAlly`，`BladeSymphony`（2 费技能）用的是 `AllAllies`；
目标选择的判定在 `PlayCardAction.cs:78`（`AnyEnemy || AnyAlly` 都要弹选择）、
`CardModel.cs:1742`（`AnyAlly` 且活着的玩家单位 ≤ 1 → **打不出去**）。

## 做了些什么

| 作用对象 | 卡牌 `TargetType` | 生成的效果 |
|---|---|---|
| **指定队友** | `AnyAlly` | `cardPlay.Target`（和「指定敌人」**同一个字段**，只是这张牌的 TargetType 不同） |
| **全部队友** | `AllAllies` | `foreach (Creature ally in base.Owner.Creature.CombatState.PlayerCreatures.Where(c => c.IsAlive && c != base.Owner.Creature))` 逐个动手 |

- 支持的种类：**造成伤害 / 施加增益减益 / 临时增益 / 获得格挡 / 回复生命 / 失去生命 / 最大生命**；
- 卡面描述跟着写「对指定队友…」「对所有队友…」「让指定队友…」（以前这两档会被印成「对自己」）；
- **回读**：这两档生成出来的语句和「指定敌人」一模一样（都是 `cardPlay.Target`），所以生成时会多写一行
  `// CET:TargetSide=Ally|AllAllies`，`--recover` 靠它还原（探针实测：两档都认得回来，没认出来的语句为 0）；
- **生成工程真 `dotnet build` 0 错误**（探针里真的编译了带队友目标的工程）。

## 会拦住你的三种情况（都是「说清楚」而不是静默）

1. **遗物 / 药水 + 「指定队友」→ 报错**：那里没有「玩家选中的目标」（本体只有卡牌会在打出时弹目标选择）。
   「全部队友」在遗物 / 药水上可以用（它不挑目标）。
2. **同一张牌里既有「指定队友」又有打敌人的效果 → 报错**：一张牌只有一个 `TargetType`，
   生成时只能选一个（会按「指定敌人」处理，队友那几条拿到错误目标），请拆成两张牌。
3. **还没实现队友目标的种类（例：抽牌 / 生成卡牌…）→ 报错并列出支持名单**：
   以前那种「选了没实现的对象就悄悄按『对自己』生成」是最坑的，现在直接拦。

另外给了一条**提示**：本体规则里 `AnyAlly` 在**单人**游戏里是打不出去的（场上活着的玩家单位只有你一个），
所以单人调试这类牌时要临时把它改成「自己」——配置检查里会写明。

> 锻造页节点图【对象】模块里的「指定队友」**还是**等同「自己」（那一套走 `ForgeFormulaRuntime`，
> 目前没有队友档）；这一版做的是**卡牌页效果**的作用对象。
