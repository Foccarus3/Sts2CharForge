# V0.3.52 — 自定义关键词那一行不再自动补句号

## 现象

卡面描述最前面的自定义关键词行生成成：

```text
[gold]命定[/gold]。
[gold]回响[/gold]。
```

用户要求去掉关键词后面的句号。

## 修法

`KeywordGen.CardTextFor` 不再自动拼 `。`：

```csharp
string line = $"[gold]{name}[/gold]";
```

多条关键词仍然一行一个：

```text
[gold]命定[/gold]
[gold]回响[/gold]
```

本体自带关键词（消耗 / 虚无等）和效果描述里的句号不受影响；
关键词的悬停说明仍然使用用户填写的原文，不额外加标点。

## 验证

| 项 | 结果 |
|---|---|
| 自定义关键词行不再带句号 | PASS |
| 多条关键词仍按引用顺序一行一个 | PASS |
| 开发版 `--uicheck` | **4906 PASS / 0 FAIL** |
| 部署版 `--uicheck` | **4905 PASS / 0 FAIL** |

⚠ 需要重新生成工程；旧工程里已经写进 `cards.json` 的句号不会自动消失。
