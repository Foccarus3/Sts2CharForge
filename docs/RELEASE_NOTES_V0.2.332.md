## ① 动画设置只保留四项

界面只剩：**播放速度系数 / 缩放 / X 偏移 / Y 偏移**。

其它 8 项（手动裁剪框、抠背景+容差、剥浅色描边+亮度阈值、最近邻过滤、每帧时长秒、篝火·商店保持动画）
已从界面撤掉，模型里退化成**只读默认值**（老存档里的值不再被读取，`[JsonIgnore]`），生成固定用：

| 项 | 固定值 |
|---|---|
| 裁剪框 | 自动（所有动作所有帧的并集） |
| 抠背景 / 剥描边 | 不做（只裁切） |
| 纹理过滤 | 最近邻（像素画必须） |
| 每帧时长 | 用动图自己的延时取平均 |
| 篝火 / 商店保持 | 不保持（本体默认行为） |

## ② 预览图：真的循环播放 GIF

- 用 Core 里那个 GIF 解码器解出**每一帧 + 每帧延时**，在 WPF 里用 `DispatcherTimer` 逐帧播（不依赖系统 GIF 解码）；
- **按「播放速度系数」播**：间隔 = 每帧延时 ÷ 系数；
- 旁边有「暂停预览 / 播放预览」按钮（你担心卡顿就点它停下，只影响预览，不影响生成）；
- 预览框尺寸 = 动图自己的画布尺寸，下面一行小字显示「N 帧 · 速度 × · 缩放 · X · Y」。

## ③ 血条中心瞄点（在预览图上，跟着数值变）

按你实机截图量出来的比例（**血条在脚下**，不是头顶）：

| 量 | 数值（你那张 539×438 截图里） |
|---|---|
| 血条红色填充 | x 45..390、y 363..372 → 中心 y ≈ 367.5 |
| 按 56/70 反推容器 | 宽 ≈ 432 → 容器中心 x ≈ 261 |
| 角色可见高度 | ≈ 315px（发顶 35 → 脚底 350） |
| 脚底到血条中心 | ≈ 17px = **内容高的 5.4%** |

所以瞄点画成：

* **竖虚线**：内容包围盒中心 **+ X 偏移**；
* **红色血条占位条 + 中心点**：`内容底边 + 5.4% 内容高 + Y 偏移`；
* 缩放一改，预览图（以及瞄点相对素材的位置）立刻跟着变；X / Y 一改，虚线与血条条一起平移。

## 说明两点

1. 瞄点纵向那个 **5.4%** 是从你截图量的比例，会随素材高度自动缩放；换角色若觉得偏了，
   告我一句「往上/下多少」我就调常量。
2. 抠底 / 剥描边 / 手动裁剪框这些**去掉了就没有替代入口**了 —— 如果你的素材需要抠底色，
   先在外部把 GIF 的底色清成透明再导进来（生成器只负责裁切 + 写帧）。
