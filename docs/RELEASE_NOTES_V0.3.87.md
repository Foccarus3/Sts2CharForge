# V0.3.87 — 自定义状态描述可填参数；`{Amount2}` 显示层数×2

## 1. 「填入参数…」按钮

「自定义状态」页描述框下面新增：

```text
填入参数…
```

可插入：

```text
{Amount}   当前层数
{Amount2}  当前层数 × 2
```

不用再手打占位符。

## 2. 层数 ×2 显示 8

描述写：

```text
每层获得 2 点增伤，当前共 {Amount2} 点。
```

当这个状态有 **4 层**时，游戏里显示：

```text
每层获得 2 点增伤，当前共 8 点。
```

实现：

- 自定义状态的 `Description` 现在会额外塞一个 `Amount2 = Amount * 2`；
- 不再写只认 `Amount` 的 `smartDescription`，否则战斗里会走旧路。

## 3. 实际效果也要 8

描述只是显示。要让效果真的施加 8：

- 效果「施加状态」数值填 `2`；
- 勾「生效次数 = 本状态的层数」；
- 4 层时就是 2 × 4 = 8。

或者加两条同样的效果，每条“数值 = 本状态层数”，合计也是 8。

## 注意

- `{Amount}` / `{Amount2}` 只作用于自定义状态的描述；卡牌 / 遗物 / 药水仍用它们各自的效果变量。
- 旧工程需要重新生成后才会出现 `Amount2` 变量。
