# V0.2.365 — 「从哪里选牌」新增「全部牌堆」（四摞一起，散射炮那种）

按你的澄清把两个概念分清了：

| 栏位 | 含义 |
|---|---|
| **选牌方式 = 全部** | 选定那一摞里的**全部**符合条件的牌（不弹选牌界面） |
| **从哪里选牌**（本次新增一档） | **全部牌堆** = 抽牌堆 + 弃牌堆 + 手牌 + 消耗堆，一次扫四摞 |

也就是说：想要「散射炮」那种效果 → **从哪里选牌 = 全部牌堆** + **选牌方式 = 全部**。

## 生成出来是什么样

```csharp
// 从哪里选牌 = 全部牌堆，选牌方式 = 全部
foreach (CardModel c in base.Owner.PlayerCombatState.AllCards.ToList()) { … }
```

用的是本体自己的 `PlayerCombatState.AllCards`（四摞的合集，和本体内部扫四摞是同一个口径）。
单摞那几种生成的文本**逐字不变**（自检里有这条回归断言）。

## 一个必须拦住的组合

**全部牌堆 + 选牌方式 = 自己选**：本体没有「跨四摞一起挑」的选牌界面（选牌界面是按摞的），
这条生成出来只会退回手牌 —— 属于静默错。现在校验器直接报**错误**并说明两条出路：

> … 想要散射炮那种「四摞里全拿」请把「选牌方式」改成「全部」；只想挑某一摞就把「从哪里选牌」改成那一摞。
