# V0.2.353 — 选牌方式加了「全选（All）」：卡牌页 + 锻造页都有

照你说的做的：**选牌方式**里多一档 `All`（全选）—— 和本体「散射炮」那种一样，
**不挑、不随机**，把「从哪一摞」选中那一摞里、符合「范围限定」的牌**全部**拿走。
四摞都支持：手牌 / 抽牌堆 / 弃牌堆 / 消耗牌堆。

## 改了什么

| 位置 | 改动 |
|---|---|
| 选牌方式下拉（卡牌 / 遗物 / 药水共用的那份） | `Random / Chosen / **All**`，显示「全选」 |
| 锻造页【效果】模块的「取牌方式」 | `自己选 / 随机 / **全选（这一摞里符合条件的全部）**` |
| 语义 | `EffectSpec.CountIsAll` 现在**两个入口都认**：`取几张 = 全部`（老入口）或 `选牌方式 = 全选`（新入口）。生成端那 15 处「全部分支」一个字都不用改，自动走对 |
| 锻造图 ⇄ 卡牌页 | `ForgeEffectBridge` 双向带上 `All`（以前只认 Random，其它一律写成 Chosen —— 所以图上选全选会掉回自己选） |

## 用起来是什么效果

比如「丢弃卡牌 + 选牌方式 = 全选 + 从弃牌堆」→ 生成：

```csharp
// 全部：把弃牌堆里符合条件的牌**全部**丢进弃牌堆（不弹选牌界面）
var __fgAll = PileType.Discard.GetPile(base.Owner).Cards.Where(...).ToList();
```

配合「范围限定」就是你举的散射炮那种：**全选 + 范围限定 = 状态牌 + 从抽牌堆** → 抽牌堆里所有状态牌一次性处理。
「取几张」那一栏在全选时会被忽略（不弹界面、也没有张数概念）。
