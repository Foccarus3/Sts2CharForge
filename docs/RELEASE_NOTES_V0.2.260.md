# V0.2.260 — 先古卡 / 遗物页新增三个勾：古老牙齿、尘封魔典、欧洛巴斯之触

## 你要的

> 在先古卡页中间部分的先古属性底下新增勾选"替换古老牙齿所替换的初始卡牌"，新增勾选"作为尘封魔典给的先古卡"
> 和遗物页的中间遗物属性底下新增勾选"替换欧洛巴斯之触所替换的初始遗物"

三个勾都加好了，而且**真的生效**（不是只写进存档）：

| 页面 | 勾选 | 生成出来的作用 |
|---|---|---|
| 先古卡页 ·「先古卡属性」下 | **替换古老牙齿所替换的初始卡牌** | 拿到「古老牙齿」时，把你的**初始卡**换成这张先古卡 |
| 先古卡页 ·「先古卡属性」下 | **作为尘封魔典给的先古卡** | 拿到「尘封魔典」时，直接给这张先古卡（本体原本是随机挑一张） |
| 遗物页 ·「遗物属性」下 | **替换欧洛巴斯之触所替换的初始遗物** | 拿到「欧洛巴斯之触」时，把**初始遗物**换成这一只 |

## 为什么要打补丁（本体那三件道具只认它自己的表）

* **古老牙齿 `ArchaicTooth`**：本体表只写了原版 5 个角色的初始卡 → 先古卡（打击→破击、中和→压制…）。
  你们的角色不在表里，所以以前拿到古老牙齿只会得到一张「**怀疑 Doubt**」。
  补丁用本体自带的 `SetupForTests(初始卡, 先古卡)` 把两张卡直接定好，只对本模组角色生效。
  这里「初始卡」= 卡牌页里勾了「初始牌」的**第一张**（按「初始卡组」从上往下）。
* **尘封魔典 `DustyTome`**：本体是从你的卡池里**随机**挑一张先古卡（还会排掉古老牙齿换出来的那 5 张）。
  勾了就直接 `AncientCard = 这张卡`。
* **欧洛巴斯之触 `TouchOfOrobas`**：本体表同样只认原版初始遗物（燃烧之血→黑血、蛇之戒→龙之戒…），
  你们的初始遗物不在表里 → 只会得到「**头环 Circlet**」。勾了就用 `SetupForTests(初始遗物, 这只遗物)`。

三个前缀都写成 `if (player.Character is not 本模组角色) return true;` ——
**玩别的角色时这三件道具的行为和原版完全一致**。

## 不静默

* 同一种勾**勾多张** → **错误**（古老牙齿 / 尘封魔典 / 欧洛巴斯之触每次只给一个东西，请各留一个）；
* 「替换古老牙齿…」勾在**不是先古卡**的牌上 → **警告**（生成端只对先古卡写这个补丁）；
* 勾了古老牙齿但**初始卡组里一张牌都没有** → **警告**（没有可替换的卡，补丁不会生成）；
* 「替换欧洛巴斯…」勾的遗物稀有度不是先古 / 初始 → **提示**（效果照旧生效，只是容易看懵）。
