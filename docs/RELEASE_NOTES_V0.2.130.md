# V0.2.130 更新说明

> 这一版做的是《卡牌页优化.md》的**第 1 条**（左侧序号 / 拖动换位 / 按序号自动英文类名 —— 你标了「关键」的那条）与**中间 ③**（去掉「卡面显示牌堆张数」）。

## 一、卡牌页左侧：序号 + 拖动 + 自动英文类名

- **序号列**：卡牌名最左侧从上到下 **1..N**，**按列表里全部行编号**（含本体卡 / 初始打击防御），序号是**位置号、不跟着卡牌移动**；
- **拖动卡牌项换位置**；
- **自动英文类名跟着序号走**（生成 / 构建 / 安装之前先做这一步）：

| 你的操作 | 结果 |
|---|---|
| 手填了英文类名 | **一个字都不动**（永远按你写的） |
| 类名是工具以前自动生成的（`<角色类名>Card<数字>` 形状） | **按它现在的左侧序号重命名**（拖到哪就跟到哪） |
| 类名留空 | **仍然留空**，只记下「这个位置对应的号」——生成时才拼出名字（这样才分得清「工具生成」和「你手打」） |

你要的那条链路现在成立：**把某张牌的英文类名删掉 → 点一键生成构建安装 → 它按左侧序号拿到新名字**（例：Sparkle 存档里排第 3 的「面具虚影」→ 删掉类名再生成 = `SparkleCard3`）。

**同一批还会跟着改的引用**（不然会指向不存在的类）：效果里的「目标卡」、 「转化为先古卡」的类名清单、锻造图【效果】模块的「目标卡」、以及**你上传过的卡面图**（按类名存的那份）—— 都在同一次改号里一起搬过去。

## 二、老存档第一次用新版本会发生什么

- 打开老存档**不会立刻改任何东西**；**下一次生成 / 构建 / 安装时**，工具会按上面的表格把「工具自动生成过的类名」重排到新序号，并**同一次**把所有按类名保存的引用改掉（避免出现「引用跑到同名新主人身上」的情况）；
- **幂等**：同一份存档连跑两次「加载 → 生成」，第二次一个字节都不变（实测 89 个文件里 88 个逐字节一致，只差 `.sln` 那个每次都会变的随机 GUID）；
- 举例（探针存档）：老自动名卡 `CardProbeCard7 → CardProbeCard4`、留空的卡第一次生成拿到 `CardProbeCard5`、`CardProbeCard3 → CardProbeCard5` 之类的位移 —— **内容本身没变，只是类名 / 文件名跟着序号走**（已把「旧名 → 新名」映射套回旧版本的全部产物逐字节核对，只剩 `.sln` 的 GUID 差异）；
- 手打了一个**正好长得像** `<角色类名>Card<数字>` 的名字，也会被按序号改（形状判据的固有代价，和遗物 / 药水页一致）。校验器会给**提示**（不拦）告诉你下一次生成会把它改成什么。

## 三、去掉「卡面显示牌堆张数」

卡牌页那个勾选框（`{DrawPile}` / `{DiscardPile}` / `{ExhaustPile}`）连同生成端的三个占位符与辅助文件**整块删掉**（「填入参数…」菜单里那三个也不再有）。

- 老存档里这个字段会被直接忽略、**不报错**（实测：真写一份带该字段的 JSON 加载，正常）；
- 老存档的**自定义描述里如果残留**这三个占位符，会**原样保留**（不动你写的文本；本体替换不了它们，卡面就按字面显示）—— 想要「自动帮你删掉」说一声。

## 五、已知边界（留给你定）

1. 诅咒卡 / 先古卡列表界面上**不显示序号**，它们的自动编号接在普通卡之后 —— 以后要给这两页也加序号列，口径要一起定；
2. 自定义描述里残留的牌堆占位符**没有自动清理**（见第三节）；
3. 「上传的卡面跟着类名搬」是我**多做**的一条（你没提），但不搬的话改名后会静默退回占位图 —— 如果你觉得越界，说一声去掉；
4. 卡牌页**没有做「每 5 个一块空槽」**（那是遗物 / 药水页的版式，卡牌页要的是 1..N 连续序号）。
