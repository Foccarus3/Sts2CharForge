# V0.2.373 — 悬停卡面三处修正（组生成弹小刀 / 图上的效果不算 / 状态完全不弹）

你两张图对应三个问题，都修了。

## ① 用「组」生成卡牌，悬停却弹**小刀**

原因：`MentionedCardClass` 在「生成卡牌」这一档，只要 `SpawnCardId` 空就当成「小刀」
（因为生成端留空时的兜底确实是 Shiv）。但你现在是**选了组 / 范围**去随机生成，
出来的根本不是小刀 → 弹小刀就是错的。

改法：只有「明确点名一张卡」或「**什么都没填**（真的是兜底小刀）」才弹小刀；
选了组 / 范围（`SpawnFilter` 非空）或取牌方式 = 随机 → **不弹那张卡面**（而不是弹错的小刀）。

> 注：这一档只在「生成卡牌 / 加进牌组」判（这两栏才在界面上显示）；
> `FillHand` 界面不显示这两栏，保持老行为（否则 V0.2.150 那组「界面藏了但生成端在读」的逐条对拍会红）。

## ② 锻造图上「生成某张卡」，悬停什么都不弹（如「改造现实」）

原因：卡牌的悬停卡面提示只看 `c.Effects`（效果列表），**锻造图上的效果一条都不看**。

改法：新增 `CardHoverEffects(c)` = 效果列表 + 升级前那张布 + 升级后那张布，
卡牌（普通 / 诅咒 / 先古）的 `ExtraHoverTips` 都改用它。

## ③ 自定义状态完全不弹卡面（状态里「将 N 张 X 加入手牌」看不出 X 是什么）

原因：`CustomPowerGen` 以前**完全没有** `ExtraHoverTips` —— 只有卡 / 遗物 / 药水会弹。

改法：状态现在也生成 `ExtraHoverTips`，来源 = **它的触发效果 + 它锻造图上的效果**，
和卡牌同一套 `HoverTipsOverride`（含「斩杀」那条本体提示）。
