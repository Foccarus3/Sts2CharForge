# Sts2CharForge V0.0.10

> 这一版**没有改玩法**，做的是一次「仓库与打包的隐私清理」：源码与打包脚本里不再出现开发机的目录结构，
> 包内附带的使用说明与 README 和仓库同步。

## 下载哪个

| 你的情况 | 下载这个 |
| --- | --- |
| 第一次用 | `Sts2CharForge-bundle-V0.0.10.zip`（显示为「整合包」，约 371 MB）—— 程序 + 环境包（Godot 4.5.1 mono / 便携 .NET SDK 9）+ GDRE 解包工具 + 图文教程 |
| 已经有旧版整合包 | `Sts2CharForge-update-V0.0.10.zip`（显示为「更新包」，约 60 MB）—— **只有程序文件 + 启动器**，解压覆盖到原来的根目录即可，环境包 / 教程 / GDRE 工具都不用动 |

> 为什么文件名是英文：GitHub 会把资产名里的中文清洗成 `._`（而且「整合包 / 更新包」清洗后是同一个名字，会互相撞名），
> 所以 GitHub 上用 ASCII 文件名、中文名放在资产的 label 上；本地打包产物的文件名仍然是中文。

## 本次更新

这一版是清理与一致性修复，界面和生成逻辑与 V0.0.9 完全相同：

- **仓库**：删掉 4 个 WPF 编译临时文件（`*_wpftmp.csproj`，里面写着开发机的绝对路径），并在 `.gitignore` 里拦住这一类文件，以后不会再被提交
- **打包脚本**：不再写死开发机的绝对路径，改成「环境变量 `STS2FORGE_APP` → 仓库同级目录 → 用户目录」推导；公开仓库里不再出现开发者的目录结构
- **示例配置**：新建存档用的内置示例，模组 ID 从私人模组名改成 `ExampleMod`；源码注释里的私人存档名换成中性示例
- **包内文档**：整合包里附带的 `README.md` 与 `使用说明.txt` 重新生成，和仓库当前内容一致（V0.0.9 的包里还是旧版文档）

## 说明

- 存档格式没有变化，直接覆盖更新即可；你的存档在 `自定义角色存档\` 里，覆盖程序文件不会动它
- 发布包里**不含任何存档**、也不含任何《杀戮尖塔 2》的游戏素材；程序运行时只读取你本机的游戏文件
- 程序内嵌的效果库数据需要你自己用「效果库」页从本机解包工程生成（仓库不附带游戏文本）

## 使用方法

1. 解压后运行「启动 Sts2CharForge_V0.0.10」（`.bat` 或 `.lnk`）
2. 第一次用请先看根目录的 `使用说明.txt`（含「！首次使用先点这个！」里的 GDRE 教程）
3. 详细功能说明见根目录 `README.md`
