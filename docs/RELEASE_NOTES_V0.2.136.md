## 一、升级后的关键字底下：新增「自定义关键词」那两栏

位置：卡牌页「升级后的关键字」那一块**底下**，两栏 —— **升级后获得 / 升级后失去**（候选就是你这个角色的自定义关键词列表）。

- 卡面描述里那行 `[gold]词名[/gold]。` 会按升级前后分叉（用本体 `{IfUpgraded:show:…}`）：获得 = 升级后才出现，失去 = 升级后不再出现；
- 鼠标悬停说明（`ExtraHoverTips`）也跟着按「有没有升级」条件展开；
- **只在真填了这两栏时**才换写法 —— 没填的卡，生成的描述与悬停说明**与以前逐字节相同**（我复核过：示例存档 112 个文件、你自己的两份存档副本，全部只差 `.sln` 的随机 GUID）。

> ⚠ **界面上一句必须说清的话（我写在那一栏旁边了）**：这两栏**只影响显示，不是机制变化**。
> 自定义关键词本来就不是本体的 `CardKeyword` 枚举（那个枚举是封闭的，模组加不了新值），它只有三块：卡面那行字、鼠标悬停的说明、`card_keywords` 本地化键 —— **游戏侧没有任何「按自定义关键词判定」的逻辑**。
> 对比：上面那栏「**升级后的关键字**」是本体关键词，走 `AddKeyword / RemoveKeyword`，那才会真的改卡牌状态。

回读用新标记（`// CET:UpgradeKeywordAdd=` / `=Remove=`，**只在真填了才写**、两个标记各自一行）；诅咒 / 状态牌（升不了级）也照写，否则往返会把词搬进「一直都有」那栏。引用写中文名（例：`命定`）会被**规范成英文键**（`FATE`）—— 这是预期行为。

## 二、卡牌「类型 / 稀有度」改中文

三处下拉（锻造卡属性模板、卡牌页中间栏、诅咒 / 先古 / 状态页）**加上卡牌列表那一行**（`七的重压 ｜ 攻击 / 普通 / 1 费`）现在都显示中文：

| | 中文（**取自游戏本体**的 `CARD_TYPE.*` / `CARD_RARITY.*`） |
|---|---|
| 类型 | 攻击 / 技能 / 能力 / 状态 / 诅咒 / 任务 |
| 稀有度 | **基础** / **普通** / 罕见 / 稀有 / 先古 / 状态 / 诅咒 |

- **档位一个没加、一个没减**（`Event` / `Token` 是本体内部档，工具从来没给过 —— 和药水页同样处理）；存档里存的**仍然是英文 id**（`CardType.Power` / `CardRarity.Uncommon`），所以**老存档与生成结果零影响**；
- ⚠ **一处措辞与遗物页故意不同**：本体卡牌稀有度写的是「**基础 / 普通**」，而遗物页用的是「初始 / 常见」（那是 `RelicRarity` 的词）。这里按「**以游戏为准**」取了游戏本体的词。**你要三页统一成「初始 / 常见」的话，改两个显示名即可（一行）**，说一声就行。

## 五、已知边界

1. 「同一条自定义关键词既填『升级后获得』又填『升级后失去』」这种自相矛盾的配置：校验器给**警告**，往返也不会把它搬成「一直都有」，但**表达不了「它本来就一直有」**——那种配置本来就该勾普通那一栏；
2. 「升级后获得 / 失去自定义关键词」**只影响显示**是本体机制决定的（封闭枚举），界面上已写明；如果你要的是「机制层面的获得」，需要本体支持；
3. 卡牌稀有度用词与遗物页不同（见第二节 ⚠），要统一说一声（一行改动）。
