> 这一版两件事：**新增「逐帧动画」**（把 GIF 动图拆成帧动画，替代战斗 / 篝火 / 商店立绘）＋ **「刮削」泛化**

## 新：逐帧动画（动图拆帧）

「美术资源」页旁边多了一个「**动画**」页：传 GIF 动图，工具在**生成时**把它们拆成帧，替代
**战斗 / 篝火 / 商店**三处的静态立绘（游戏引擎读不了 GIF，所以帧图在生成阶段就落成 PNG + Godot 的
`SpriteFrames` 资源，再由生成的运行时把本体的动画请求翻成逐帧播放）。

- **7 个动作**：待机（循环）/ 攻击 / 施法 / 受伤 / 死亡 / 篝火 / 商店。**待机是回退目标、必须有** ——
  其它动作没素材时都会退回它；没传待机会在生成前报错拦住。
- **7 个动作共用一个裁剪框**（取所有动作所有帧的并集），所以换动作时角色不跳位置；想自己控制就填「手动裁剪框」。
- 可选处理：**抠背景**（把纯色底变透明）＋ 容差、**剥掉浅色描边**（素材在轮廓外留了一圈不透明浅色边时用）、
  **最近的过滤**（像素画推荐；线性过滤在缩放时会混出源里没有的颜色、边缘发糊）、**播放速度系数**、
  **缩放**（0 = 按静态立绘高度自动算）、**每帧时长秒**（0 = 用动图自己的延时）、
  **篝火 / 商店里保持专属动画**（默认不勾：本体过一会儿会发一次「回待机」）。
- 「**预览动画计划**」：真解一遍动图，把裁剪框 / 帧数 / 每帧时长 / 缩放 / 位置 / 提示行都列出来，**不写文件**。
- 「**一键启用逐帧动画**」：素材已经放了但忘了勾总开关时，那一行会提示你，点一下就好。
- **不勾总开关 = 和以前完全一样**：生成结果逐字不变，也不会留下任何动画文件（老存档直接兼容）。

## 新：「刮削」泛化（抽 N 张 → 对其中符合条件的牌动手）

原来「刮削（抽 N 张，丢弃其中所有非 0 费牌）」是写死的，现在**条件和操作都能选**：

- **条件**：非 0 费（默认，本体「刮削」的判据）/ 不限 / 攻击 / 技能 / 能力 / 诅咒 / 状态 /
  **自定义关键词那一组**（把关键词当「卡的组」用，和「范围限定 / 范围界定」同一套）；
- **操作**：丢弃（默认，进弃牌堆）/ 消耗 / 升级；
- 卡面描述会跟着写清（例：「抽 3 张牌，把其中「攻击」的牌消耗掉。」）；
- **默认档（非 0 费 + 丢弃）生成的代码与旧版逐字相同**（112 个生成文件里 111 个字节完全一致，
  唯一差异是 `.sln` 里每次随机的新 project GUID）。

## 说明

- 逐帧动画吸收自一份**只有二进制**的改造版：我们把它当参考实现跑起来导出全部产物，重写后与它
  **逐字节对齐**（帧 PNG / `.png.import` / `.tres` / 清单 / 运行时 / 补丁全文），
  另外**修正了它那个其实没生效的「最近邻」开关**（现在关掉会真的写 `filter: Linear`）。
  也顺带查明并写进文档：它那个「按首帧自动对齐」在它的实现里是**空转**的（本工具不暴露这个开关）。
- 存档格式没有变化；你的存档在 `自定义角色存档\` 里，覆盖程序文件不会动它。
- 发布包里**不含任何存档**、也不含任何《杀戮尖塔 2》的游戏素材。
- 程序内嵌的效果库数据需要你自己用「效果库」页从本机解包工程生成（仓库不附带游戏文本）。
