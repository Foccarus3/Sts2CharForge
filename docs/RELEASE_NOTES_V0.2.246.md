# V0.2.246 — 「形态生效、效果没生效」：`Single` 状态里那个**藏起来的层数**

## 用户报的

「一层没事，二层 boss 的时候多效卡又识别不了形态一，形态生效，效果没生效」+ 两份 godot 日志。

分层看：**「形态生效」= 图标确实在你身上**；**「效果没生效」= 那段效果整段被跳过**。
不是牌坏了，是**判据算成了假**。

## 查证（用你那份 `lihuazou.json` 逐条对内）

「多效卡」是锻造节点图做的（`IsForged = true`），图里的分支是：

```
【触发时机：打出时】→【如果】条件输入 ←【关系符 等于 1】←【状态：手刃形态】
                                  └ 是 →【效果：造成 3×4 伤害】
```

生成出来是这样（`ZouCard10「自适应攻击-破坏」`）：

```csharp
decimal __fgbe22a7 = ForgeFormulaRuntime.PowerAmount(__fgSelf, "yinsushouren");   // 手刃形态
if (((__fgbe22a7) == (1)))
{
    … 3 点 × 4 下 …
}
```

问题就在这个 **`== 1`** 上。

**本体 `PowerStackType.Single` 的注释写的是「Amount is hidden, and is always 1」，但它只是"不显示"：**

* `PowerCmd.Apply` 第二次施加同一个 `Single` 状态时，走的是 `ModifyAmount(+1)` → `SetAmount(2)`；
* `SetAmount`（`PowerModel.cs`）对 `Single` **没有任何夹取**，内部层数真的变成 **2**；
* 界面上层数是隐藏的 ⇒ **你看到的还是「形态生效」**（图标在），但 `== 1` 已经不成立 ⇒ 整段效果被跳过。

「一层没事」很可能是那时形态正好 1 层；到了二层，中间多施加过一次（形态牌 / 遗物 / 复制牌 / 事件），
内部层数变 2 —— 从此这张卡在该形态下**什么都不做**。

## 修法（生成端）

读「**只叠一层**」（`CustomPowerSpec.Single`）的自定义状态时，**按语义夹成 0 / 1** ——
有它就是 1 层、没有就是 0：

```csharp
decimal __fgbe22a7 = (ForgeFormulaRuntime.PowerAmount(__fgSelf, "yinsushouren") <= 0m ? 0m : 1m);
if (((__fgbe22a7) == (1)))   // 现在「等于 1 层」永远对得上
```

* 不碰模型本身（层数照旧记着），所以**衰减 / 移除 / 效果里"扣 N 层"全不受影响**；
* 「小于 1」（判没有）也照旧正确；
* 只对**勾了「只叠一层」的自定义状态**生效，可叠层的状态（流血 / 锋利…）一个字节都不变。

顺带把另一处**会静默判错**的图写法报出来（提示级、不拦生成）：

> 【状态】节点**左边没接【对象】**时，卡牌 / 遗物 / 药水的默认归属是「**打出时选中的那个敌人**」，
> 不是自己。想判「我身上有没有它」请拖一块【对象】（选「自己」）接到它左边。

你的 `ZouCard10`（升级前）里那块判「巨钳形态」的【状态】就没接【对象】→ 生成出来读的是
`PowerAmount(__fgTarget, "ZouPowerju")`（敌人身上的巨钳形态，永远是 0）。
它现在会被这条提示点名；要判自己就接一块【对象】→「自己」。

## 你这边要做的

1. 用新版重新生成一次模组即可 —— `Single` 状态的 `== 1` 已经自动改对，**不用改图**；
2. 「巨钳形态」那一块如果本意是"我身上有没有巨钳形态"，把【对象】（自己）接到【状态】左边
   （不接的话它读的是敌人的）。
