# V0.2.85 更新说明

> 两条都是你刚报的问题，都修了。

## ① 「在锻造里怎么不能填范围了」

**根因是我上一版改蠢了**：为了让「数值 0 = 这张牌自己」那几档（给予关键词 / 回合结束自动打出 / 丢弃卡牌）
别让人以为「范围界定」还在生效，我把那几行按数值 0 给**藏起来**了 —— 而新加的效果**数值默认就是 0**，
于是你加一条「丢弃卡牌」之类的效果，范围和选牌那几行直接不见了，想填都没地方填。

现在改成：

- **界面只管种类**：「范围界定 / 选牌方式 / 从哪里选」这几行只要这个种类用得到就**一直显示**，不跟数值变；
- 「这一档填了也不会生效」改成**校验器的提示**说清楚（例：数值 0 = 丢弃这张牌自己那一档不挑牌，
  你填的范围界定 / 从哪里丢弃不会生效，想要范围界定就把数值改成 1 以上）。

## ② 锻造卡在锻造页改了能量，卡牌页还是显示 0

**原因**：锻造卡的费用由「锻造页左上角那块固定【能量】模块」决定，所以卡牌页把
「费用 / X 费用 / 额外资源量费用」那一栏整块藏掉了 —— 结果你回卡牌页看到的还是
`CardSpec.Cost` 那个**没人再改的旧数字**（默认 0），和锻造页上填的对不上。

现在卡牌页会多一行**只读**提示（选中锻造卡时才出现）：

```
费用：2 点能量（由锻造页左上角【能量】模块决定，卡牌页不重复显示这一栏）
```

它直接读【能量】模块上的数字，所以锻造页改了、回卡牌页就是新的；
同时填了「额外资源量消耗」的话也会一起写出来。

## 进行中：额外资源量的那只隐藏遗物放进「遗物」页

你要的「把额外资源量的初始遗物放到遗物页、可以在里面加效果」已经在做了，这一版落地了**数据 + 生成 + 回读**：

- 额外资源量页多了「这只遗物上的效果」这份数据（存档里是 `ExtraResource.Effects`）；
- 生成时这些效果会挂在那只 `<角色>ExtraResourceRelic` 的「**战斗开始时**」钩子上
  （用带 `choiceContext` 的 `BeforeSideTurnStart`，需要选牌 / 生成卡牌的效果也能用）；
- 回读（`--recover`）会把它们读回同一份数据。

**还没接的**：遗物页上那一块界面（效果列表 + 添加 / 删除按钮）。下一版补上 ——
在那之前，这版生成出来的遗物行为和以前**完全一样**（没有效果就是空的那一份数据）。
