# V0.2.89 更新说明

> 两件事：① 你问的「生成范围组里的卡，怎么不能在组里选择，只能随机」——现在**可以自己挑了**；
> ② 「下回合生效」把**复制卡牌**也接上（队列①只剩「变化卡牌（战斗内）」）。

## ① 生成卡牌：可以从范围里**自己挑一张**了

以前「生成卡牌」只有「指定卡」和「按范围随机」两档，按范围那档要么随机出 N 张、要么（多选1）
先随机抽 M 张候选再让你挑 —— **没法直接挑这一组里的某一张**。

现在在「按范围随机」这一档下面多了一个勾选框：

> **从范围里自己挑一张（候选 = 这一组里的全部卡，不再随机抽）**

- 勾上之后，选牌界面直接列出这一组范围里的**所有卡**（最多 60 张，再多界面摆不下），你想拿哪张拿哪张；
- 选完照样吃「生成出来的卡怎么处理」那一整套（升级 / 免费 / 仅本回合 / 加关键词 / 放入哪一摞）；
- 实现用的是本体自己的两条选牌路：候选 ≤ 3 张走 `CardSelectCmd.FromChooseACardScreen`，
  > 3 张走 `CardSelectCmd.FromSimpleGrid`（本体「抉择悖论 ChoicesParadox」用的就是它）——
  这两条的切换和「多选1」一致，所以界面和手感跟本体一样；
- 范围里一张都没有时整条**安全跳过**（不会弹空选牌界面、也不会卡死）；
- 回读：勾选状态写在生成代码的标记行里（`CET:Chosen=1`），`--recover` 原样认回来。

## ② 「下回合生效」支持复制卡牌

`EmitCopyCard` 现在和生成卡牌一样接受「玩家表达式」，所以它能放进延迟状态里：

```csharp
public override async Task AfterPlayerTurnStart(PlayerChoiceContext choiceContext, Player player)
{
    if (player != base.Owner.Player || base.Amount <= 0) return;
    // 从手牌选 1 张 → 克隆 2 份 →（吃「复制出来的卡怎么处理」）→ 放进手牌
    ...
    await PowerCmd.Remove(this);
}
```

现在「下回合生效」的完整名单：获得格挡 / 抽牌 / 获得能量 / 获得额外资源量 / 施加扣除状态 /
**生成卡牌 / 复制卡牌** / 获得·变化·删除·升级牌组里的牌（全局）。
**只剩「变化卡牌（战斗内）」**（它的 `SpawnPoolExpr` / `EmitTransformBody` 里 `base.Owner` 还是写死的，
要先参数化），配置检查会拦住它并说明。

## 顺手修的

- `Lit.Identifier` 传空 fallback 时会 `IndexOutOfRange`（`s = fallback` 之后仍取 `s[0]`）——
  「复制卡牌」的延迟状态类名（没有目标卡）正好会走到这条路上，已修成「空就直接返回 fallback」。
- 生成类延迟状态的**回读**改成靠 `CET:Effect=` + `CET:NextTurn=1` 两行标记（复制份数 / 选牌方式 /
  哪一摞 / 数值都能一起带回来），并且把「挂延迟状态」那句实现行加进跳过名单（不会再被当成第二条效果）。
