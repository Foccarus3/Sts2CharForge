# V0.3.3 — 修「清除指定状态」的调试日志把 C# 打断（编译 CS1003）

## 你的报错

```
SparkleCard44.cs(24,267): error CS1003: 语法错误，应输入“,”
```

打开那一行是：

```csharp
Godot.GD.Print("… 要清的类=" SparklePercentVulnPower "；找到=" + …);
                                     ↑ 这里多了一对引号，字符串在它前面就结束了
```

## 根因

`DebugLogGen` 里拼「清除指定状态」那条调试日志时，类名用了 `Lit.Str(powerType)`
—— 那会额外生成一对引号，而它本来就在**字符串字面量内部**，于是字符串被提前截断、
后面的 `SparklePercentVulnPower` 变成裸标识符 → 编译器报「应输入 ,」。

**只要开了「生成调试日志」+ 卡上用了「清除指定状态」，就一定编译不过**，和百分比状态本身无关
（普通状态也一样，只是你这张牌正好是清除 `PercentVuln`）。

## 改法

把字符串里的 `{Lit.Str(powerType)}` 换成 `{powerType}`（类名本身就是合法标识符，不需要再加引号）。

## 自检

**4796 PASS / 0 FAIL**（+1 条：开了调试日志 + 「清除指定状态」时，生成出来的那行里类名在字符串**内部**，
不会出现 `"；要清的类="` 这种把字符串截断的写法）。

## 你需要做的

更新到 **V0.3.3** → 重新「一键构建 + 安装」。这次 `SparkleCard44.cs` 应该能编译过。
