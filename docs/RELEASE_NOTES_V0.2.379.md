# V0.2.379 — `visibleWhen` 界面隐藏补齐（字段联动，缺口文档第 8 节）

上一版只有生成端生效，这一版把**界面**补上了。

## 现在完整的表现

`plugin.json` 里给栏位加：

```json
{ "key": "kind", "label": "类型", "type": "pick", "options": ["attack", "block"] },
{ "key": "dmg",  "label": "伤害", "type": "number", "visibleWhen": "kind=attack" }
```

* 类型选 **attack** → 「伤害」栏出现；选 **block** → 这一栏**不画**（改完控制栏位后重进这页会刷新）；
* 生成端同样处理：条件不成立时该占位符按**空值**参与模板，不会把上次的数值带进生成结果；
* list 行内的子栏位也支持（条件看**同一行**的其它子栏位）。

## 判据（同一份，界面与生成共用）

`PluginRegistry.FieldVisible(field, get)`：

* `"kind"` —— 有值 / 非 `0` / 非 `false` / 非 `否` 才显示；
* `"kind=attack"`、`"kind!=attack"` —— 等值 / 不等（忽略大小写、去首尾空格）。

## 自检

**4718 PASS / 0 FAIL**（+2 条：`kind=attack` 画出「伤害」栏、`kind=block` 时不画（0 个）/ 生成结果里 `{dmg}` 为空）。

## 已知限制

* 改动控制栏位后**重进这页**才会刷新（当前页面表单不是实时重建——真正实时需要把整页重画，留作下一次）；
* 可见条件只支持「另一个栏位」的比较，不支持 `&&` / `||` 组合表达式。
