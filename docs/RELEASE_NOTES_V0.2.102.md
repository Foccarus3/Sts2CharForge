## 一、触发时机「花掉能量后 / 花掉额外资源量后」多了两栏

- **花掉多少点触发**：留空 / 0 = 每花掉 1 点就触发一次（老行为，一个字符都不变）；
  填 N = **每累计花掉 N 点触发一次**（例：填 3 = 每 3 点触发一次）。
- **统计范围**：**本回合**（每个回合重新计数）/ **本场战斗**（整场累计，换战斗重新算）。

生成出来的代码（**不需要自己记计数器、也不加补丁** —— 直接读本体的战斗历史）：

```csharp
// 数值：每累计花掉 3 点触发一次（范围：本回合）
int __spentBefore = (int)CombatManager.Instance.History.Entries
    .OfType<MegaCrit.Sts2.Core.Combat.History.Entries.EnergySpentEntry>()
    .Where(e => e.Actor == base.Owner.Creature && e.HappenedThisTurn(base.Owner.Creature.CombatState))
    .Sum(e => e.Amount) - amount;      // 本体是「先记账、再调钩子」，所以减掉这一次就是「之前花了多少」
for (int __EnergySpentIdx = 0; __EnergySpentIdx < amount; __EnergySpentIdx++) {
    if ((__spentBefore + __EnergySpentIdx + 1) % 3 != 0) continue;   // 每累计 3 点触发一次
    …这条效果…
}
```

- 额外资源量走 `StarsModifiedEntry` 里 `Amount < 0` 的那几条（负数是花掉）；
- 自定义状态那边同一套（只是把「自己」换成 `base.Owner`、循环变量名不同）；
- 「本回合」用本体那套判据（`HappenedThisTurn`）；「本场战斗」就是整场的累计。
