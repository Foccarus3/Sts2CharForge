## 一、自定义状态用「生成卡牌」会让战斗卡死（真因 + 修法）

**现象**（游戏日志 `%APPDATA%\SlayTheSpire2\logs\godot.log`）：

```
[ERROR] Combat #1 turn loop died while its combat is in progress; the combat is stuck
        until the room is restarted:
        System.InvalidOperationException: No selection screen prompt for POWER.SPARKLE_POWER6.
   at MegaCrit.Sts2.Core.Models.PowerModel.get_SelectionScreenPrompt()
   at SparkleMod.SparklePower6.AfterPlayerTurnStart(PlayerChoiceContext choiceContext, Player player)
```

**真因**：状态的「生成卡牌」（按范围随机 + 多选1 候选 > 3，或「从范围里自己挑一张」）生成出来的代码要弹
本体的**网格选牌界面**，而那句提示语是从本地化表里取的；本体 `PowerModel.SelectionScreenPrompt`
**键不存在就直接抛异常**。工具给卡牌 / 遗物 / 药水三条链都写了这条本地化，**只有自定义状态这条链从来没写** →
异常抛在战斗回合钩子里 → 本轮 turn loop 直接死掉 → **战斗卡住，只能重开房间**。

**修法**（都在生成端）：

1. 自定义状态的效果里只要有「要弹选牌界面」的，就补一条 `<状态>.selectionScreenPrompt`；
2. 判据补上「生成卡牌 + **从范围里自己挑一张**」和「**放置卡牌** + 取牌方式 = 自己选」这两档
   （它们的候选 / 取牌走的是同一条网格界面，以前连名单都没进，**卡牌上用「放置卡牌 + 自己选」也会卡死**）；
3. 锻造卡 / 锻造药水 / 锻造遗物的效果在**节点图**上（不在效果列表里），以前判断时看不到 → 现在一起算。

自检里新增了一条**按效果种类机械扫描**的断言：把每一种效果都按「最想弹选牌界面」的参数配一遍，
分别生成卡牌链与自定义状态链的代码，只要代码里出现 `base.SelectionScreenPrompt`，
「要生成提示语」的名单就必须认得它 —— 以后谁再加一条这种效果，漏了会当场 FAIL。

## 二、遗物 / 药水 / 额外资源量右侧效果栏：和卡牌页同一个版式

- 上面是**一行摘要列表**（每行就是这条效果的关键内容：效果种类 + 数值 / 作用对象 / 条件…）；
- **点上面任意一条 → 下面那块共享编辑区里就是它**（完整编辑器，改值照旧）；加 / 删效果之后新加的那条会自动选中；
- **这条效果自己的「条件选项」就在编辑区里**（以前三页是右下角单独一块，已撤掉）；
- 没选中效果时，编辑区里只有一句「点上面一条效果 → 就在这块里改它」；
- ⚠ 你之前要的那套「每条效果折叠成一行、点开才展开」已经撤掉：版式和卡牌页不一致，
  而且「整行是一颗按钮」会把列表的点击吃掉（就是上一版那个「条件选完存不住」的真因）。
- 顺手修掉两处被这次改版暴露出来的老毛病：编辑器里几段超长说明文字以前**一行不换行**、横向跑出面板看不全；
  以及没选中效果时会**凭空冒出几行开关**（绑定的数据是空的，显示成了默认可见）。
- 卡牌页 / 诅咒页 / 先古卡页**没有动**（它们本来就是这个版式）。
