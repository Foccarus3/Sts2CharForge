# V0.2.268 — 锻造页的遗物属性面板补上「层数变化方向」

## 你报的

> 触发时机「某个状态层数变化后」没看到栏「层数变化方向」

## 原因

V0.2.266 我把那一栏加到了**两个**地方（遗物页的时机编辑器、状态页的时机编辑器），
但**锻造页**「锻造遗物」那个属性面板是**另一个 DataTemplate**（`DataType="{x:Type profile:RelicSpec}"`），
它里面只有「触发时机」一个下拉 —— 漏了方向那一栏。你多半就是在这里选到「某个状态层数变化后」的。

## 现在三处都有

| 位置 | 数据上下文 | 那一栏 |
|---|---|---|
| 遗物页 · 时机列表的编辑器 | `RelicTriggerSpec`（`ShowPowerDirectionField`） | V0.2.266 起已有 |
| 状态页 · 时机列表的编辑器 | `PowerTriggerSpec`（`ShowPowerDirectionField`） | V0.2.266 起已有 |
| **锻造页 · 遗物属性面板** | `RelicSpec`（**新增的** `ShowTriggerPowerDirection`） | **V0.2.268 补上** |

* 三处的显隐判据一致：只有触发时机是「某个状态层数变化后」才出现；
* 锻造页那一栏写的是 `TriggerPowerDirection`（和「触发时机」那个 `Trigger` 一样代理到第 1 条时机）；
* 换触发时机时会**当场**显隐（不会像以前那样得重新点一次左边列表才看得到）。
