# V0.2.214 —— 丢弃 / 消耗（以及升级·复制·重放·给关键词·三摞拿牌·预见）能选「只对这张卡」了

> 来源：用户实测「这个是丢弃消耗卡牌无法选择目标卡或者组」。

## 1. 现状与缺口

这些「从牌堆里挑牌」的效果以前只有一栏 **范围界定（哪些牌能选）**，候选是：
不限 / 攻击 / 技能 / 能力 / 诅咒 / 状态 / **自定义关键词那一组** / **卡牌组**。
也就是说「按类型」「按组」是有的，但**没有「就这一张卡」** —— 想「只丢弃『打击』」只能自己先建一个
只含打击的卡牌组，用户找不到这个做法。

## 2. 新增「只对这张卡（指定）」

在下面这些效果上多一行（就在「范围界定」下面）：

> 丢弃卡牌 / 消耗卡牌 / 升级卡牌 / 复制卡牌 / 重放卡牌 / 给予卡牌关键词 /
> 从抽牌堆·弃牌堆·消耗牌堆拿牌 / 预见

- 可搜索的卡牌列表（和「目标卡」同一份候选，本体卡 + 你自己的卡都在）；
- 留空 = 不限（和以前一模一样）；
- 和「范围界定」是**与**的关系：两个都填就都要满足（例：范围=攻击 + 只对打击 → 只动攻击里的打击）。

生成出来的效果：

```csharp
// 消耗·自己选：当成选牌过滤条件
…CardSelectCmd.FromHand(…, filter: c => c.Id == ModelDb.Card<…Strike>().Id, source: this)…

// 丢弃·随机 + 范围=攻击：两个条件用 && 拼在一起
…NextItem(PileType.Draw.GetPile(base.Owner).Cards.Where(c => (c.Type == CardType.Attack) && (c.Id == ModelDb.Card<…Strike>().Id)))…

// 消耗·取几张=全部：候选池先筛
foreach (CardModel c in PileType.Hand.GetPile(base.Owner).Cards.Where(c => c.Id == ModelDb.Card<…Strike>().Id).ToList()) …
```

配套：

- 卡面描述会补一句「（只对打击）」/「（只限攻击牌，只对打击）」；
- 生成时标记行追加 ` CET:OnlyCard=<卡类名>` —— **从工程恢复存档**时认得出这一栏；
- 列表摘要显示「｜ 只对：打击」；
- **变化卡牌不显示这一行**（它有自己的「变化哪些牌（范围）/ 只变化这张卡」两行，语义是「变哪些」）；
  这两行内部也统一到同一个字段（`ScopeCardId`），V0.2.213 存的旧键名 `TransformCardId` 仍能读回来
  （读到就搬到新字段，写出去只用新键名，不会两个键都落盘）。

## 3. 红线（老存档逐字不变）

- 「只对这张卡」空值时：标记行不多一个键、选牌语句仍是 `filter: null`、候选池不多 `.Where`；
- 新字段用 `[JsonIgnore(WhenWritingDefault)]` + 可空类型：空值**不写进 JSON** ——
  锻造图节点里嵌的那份 `EffectSpec` 因此一个键都不多；
- 对拍：示例 **113** / WhiteCloak **412** 个文件 **0 差异**（只差 `.sln` 的 GUID）；
- 你那份 `AinodiMod.json` 重新生成：429 个文件里**只有 `.sln` 的 GUID 不同**。
