# V0.3.88 — 自定义状态描述支持任意公式 `{=...}`

## 弃用固定 `{Amount2}`

V0.3.87 的 `{Amount2}` 只能表示「层数 ×2」，不够泛用。

V0.3.88 改成通用写法：

```text
{=表达式}
```

表达式里可以用：

- `Amount`：当前状态层数
- 自定义参数：`M` / `N` 等
- 变量页里的变量：`cnt` 等
- `X` / `Y`
- 内置只读量：`Turn` / `HandCount` / `PowersOnMe` …

## 例子：4 层显示 8

描述写：

```text
每层获得 2 点增伤，当前共 {=Amount*2} 点。
```

生成后，状态有 4 层时显示：

```text
每层获得 2 点增伤，当前共 8 点。
```

也可以写：

```text
每层造成 {=M*3} 点伤害，当前 {=Amount*M} 点。
```

## 实现方式

生成时扫描描述里的：

```text
{=...}
```

把每条表达式编译成运行时变量：

```csharp
__loc.Add("__fgPowerDesc0", ((base.Amount) * (2m)));
```

描述文本变成：

```text
…当前共 {__fgPowerDesc0} 点。
```

于是游戏里显示实时算出来的数字。

## 「填入参数…」

自定义状态描述框下面新增按钮，插入：

```text
{Amount}
{=Amount*2}
```

后者可以自己改成 `M*3` / `cnt+1` 等。

## 注意

- 描述公式只负责**显示**；实际效果要 2 × 层数，仍然用「数值 2 + 生效次数 = 本状态层数」或两条效果。
- 公式写错时保留原文，生成日志 / 校验器会提示。
- 旧工程需重新生成。
