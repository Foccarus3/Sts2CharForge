# V0.2.272 — 「仅状态牌」过滤 / 状态牌变 0 费 / 独立概率

## 你报的三条

> 1. 从消耗牌堆拿牌限制了仅状态牌，还是可以拿其他的牌
> 2. 开了这个效果会让状态牌变成 0 费，牌为「守望过去」
> 3. 独立概率生效好像也有的问题

我拿你的 `Shadow.json` 跑了一遍生成，三条都定位到了：

## ① 状态牌变 0 费（已修）

```
状态「守望过去」(TheShadowPower9)：CostReduceScope = "Status"，CostReduceAmount = 0
生成出来：  modifiedCost = 0m;      ← 所有状态牌 0 费
```

旧的语义是「**填 0 = 这类牌全部变成 0 费**」（照腐化 / 刺破帷幕设计的），但界面上数字框留空 / 留 0 太常见了。

**新语义**：
| 填什么 | 效果 |
|---|---|
| `0`（留空也是 0） | **不修正**（一行代码都不生成） |
| `1` / `2`… | 这类牌费用 -N（最低 0） |
| **负数**（例 `-1`） | 变成 0 费（腐化那种） |

你那个状态填的是 0 → 现在不会再改任何费用了。

## ② 独立概率（已修）

存档里那条效果是：

```
ChanceEnabled = false，ChancePercent = 50，ChanceIndependent = false
```

界面把「概率百分比」和「概率生效」做成了两栏 —— 只填 50 不勾勾选，生成端就整段跳过（看起来就是「概率没生效」）。
现在读存档时**自动归一化**：填了 1~99 的百分比、或者写了概率公式 → 一律视为开启。

用你的存档重新生成，已经能看到掷骰那一行了：

```csharp
double __chanceRoll = base.Owner.Player.RunState.Rng.Niche.NextDouble() * 100.0;   // 概率生效：同组效果共用这一次掷骰
```

## ③ 仅状态牌过滤（部分修，还需你配合一次）

生成端拿到的谓词是空的，所以 `CardSelectCmd.FromCombatPile(...)` 少传了第 5 个参数 `filter`：

```csharp
// 现在生成的（没有过滤）：
CardSelectCmd.FromCombatPile(choiceContext, PileType.Exhaust.GetPile(...), base.Owner.Player, new CardSelectorPrefs(...))
```

根因：这张牌和这个状态都是**锻造图**做的，生成端读的是**布上【效果】模块**的字段；
你设的「范围界定 = 状态」存在**侧栏那条效果**里，两边没同步（你存档里 474 个布上范围字段全是空的）。

这一版加了兜底：布上字段空、而模块上绑着的效果有范围 → 用效果里的。**但你这份存档里那个模块没有绑定效果对象**，
所以兜底没命中。**这一条请你在布上验证一下**：

> 「锻造」页 → 那块布 → 选中那个【效果】模块 → 把「**范围**」也选成「状态」→ 重新生成

两条路都填上之后过滤立刻生效。如果布上那个模块根本没有「范围」这一栏，告诉我，我把它做成和侧栏同一个字段（这样就只需要填一处）。
