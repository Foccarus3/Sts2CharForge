# V0.2.154 更新说明

> 回答你问的：「**能不能加一个播放音频的效果在效果种类里**」。能 —— 这一版加好了。

## 一、新效果种类：**播放音效（本体音效库）**

效果种类下拉最下面多了一条「播放音效（本体音效库）」。它的做法很直接：
本体所有声音都走 FMOD，工具生成的就是本体自己那一句

```csharp
SfxCmd.Play("event:/sfx/block_gain", 1f);   // 播放本体音效：获得格挡（默认音量）
```

- **「音效」那一栏**：选一个本体音效。候选表是**本体源码里真实用过的事件**（55 条，都配了中文名）：
  攻击命中 / 被打中 / 格挡 / 回复 / 增益 / 减益 / 能量 / 金币 / 卡牌打出与变化 / 遗物触发 / 附魔 /
  宝箱 / 地图 / 界面点击 / 伙伴攻击 / 各角色招牌音（旋风斩、超能光束、飞刀…）/ 几首音乐。
  那一栏是**可搜索下拉**：打中文名能筛，想用候选外的也能**直接打字填任意 `event:/…` 路径**。
- **「数值」那一栏在这条效果上 = 音量%**：留空 / 0 = **100%**（正常音量），50 = 一半，150 = `1.5f`。
  ⚠ 这是唯一一个「0 有意义（= 100%）」的种类 —— 填 0 不会像别的种类那样被当成「这条效果不生效」。
- **四条链都能用**：卡牌 / 遗物 / 药水 / 自定义状态的触发时机（`SfxCmd` 是静态的，
  不需要玩家选目标、也不需要 choiceContext，所以哪里有「效果」哪里就能放）。
- **卡面 / 状态描述**会写成「播放音效：中文名」（音量不是 100% 时补一句「（音量 150%）」）。
- **校验器**：没选音效 → 错误；填的东西不像事件路径（不是 `event:/…`）→ 错误；
  路径合理但不在候选表里 → **只给提示**（候选只是「本体用过的一批」，不是全集；路径不存在时
  游戏里只是不放声音，不会崩）。音量 > 200% 给一句警告。
- **回读**：生成时会写一行 `// CET:Sfx=路径 CET:SfxVolume=音量`，
  「从工程恢复存档」能把这条件效果原样认回来（自检里跑了一遍完整「生成 → 回读」）。

## 二、没做的（说清楚，免得你白等）

**放你自己的音频文件**（例：某个角色的语音 / 自定义 BGM）这一版**没做**，因为那是另一条链路：
本体播声音必须走 FMOD，而**自建 FMOD 事件需要 bank** —— 本体的 `banks/desktop/*.bank` 里存的是
事件 GUID（我把 42MB 的 bank 全文扫过一遍，一个 `event:/` 字符串都没有），模组没法凭路径凭空注册一个新事件。
要放自己的音频只有绕开 FMOD、用 Godot 自己的 `AudioStreamPlayer` 加载 `res://` 下的音频文件 ——
那要新加「上传音频素材 → 打进模组 → Godot 导入」这一整套（和现在上传卡面 PNG 那条链路类似，工程量不小）。

**你说要做我就做**（我会先做一版给你实测：上传音频文件 + 「播放我上传的音频」效果，音量沿用这一版的口径）。
