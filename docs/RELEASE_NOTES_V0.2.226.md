# V0.2.226 —— 「复制卡牌」能复制自己 / 自己选从哪一摞复制 / 复制到哪一摞

> 来源：用户要求「复制效果能够复制自己或者可以选择从哪里选择复制并且到哪里」。

## 1. 数值 0 = 复制**这张牌自己**（新）

「复制卡牌」的**数值**以前最小就是 1（只能去某一摞牌里挑一张来克隆），填 0 会被当成「不生效」整条丢掉 ——
想「把这张牌再复制一份」根本做不到。现在和「消耗 / 丢弃 / 升级卡牌」同一套口径：

| 数值 | 行为 |
| --- | --- |
| **0** | 复制**这张牌自己** N 份（「复制的份数」= 那份数） |
| 1~5 | 老行为：{自己选 / 随机}从「从哪里选牌」那一摞里拿 N 张，每张复制「复制的份数」份 |

- 生成的实现（卡牌 / 卡牌的锻造图）：

```csharp
// 数值 0 = 这张牌自己：把它本身复制 2 份，放进牌顶
for (int __copyIdx = 0; __copyIdx < 2; __copyIdx++) {
    CardModel __selfClone = this.CreateClone();
    await CardPileCmd.AddGeneratedCardToCombat(__selfClone, PileType.Draw, base.Owner, CardPilePosition.Top);
}
```

- 为什么能克隆自己：本体 `CardModel.CreateClone()` 只在**牌不在战斗牌堆**时才抛异常；打出这张牌时它还在手牌里
  （战斗牌堆），所以合法 —— 本体「二刀流 DualWield」也是这个做法；
- 卡面文案：`复制这张牌本身 2 份到牌顶。`（份数 = 1 时写「一份」）；
- **只有在卡牌上有意义**：遗物 / 药水 / 自定义状态没有「这张牌」，填 0 时校验器给**警告**并说明「这条不会做任何事」，
  不会悄悄什么都不做。

## 2. 「放到哪一摞」也对复制卡牌生效（新）

「复制卡牌」以前**死写** `PileType.Hand`（复制出来的牌只能进手牌）。现在和「放置卡牌」共用同一栏：

| 「放到哪一摞」 | 生成 |
| --- | --- |
| 手牌（默认） | `AddGeneratedCardToCombat(…, PileType.Hand, 玩家)` —— **老文本一个字都不变** |
| 抽牌堆 | `PileType.Draw` |
| 弃牌堆 | `PileType.Discard` |
| 消耗牌堆 | `PileType.Exhaust` |
| 牌顶 | `PileType.Draw` + `CardPilePosition.Top`（抽牌堆最上面） |

- 卡牌 / 遗物 / 药水 / 自定义状态页的**效果栏**、锻造页的**【效果】模块**都能选到这一栏
  （判据是同一份 `EffectSpec.KindUsesPlaceTo`，不会出现「卡牌页有、锻造页没有」）；
- 卡面文案跟着写「…放到弃牌堆」；
- 数值 0（复制自己）时这一栏照样生效：「复制这张牌自己一份放到牌顶」是合法组合。

## 3. 回读 / 老存档

- 标记行多带一项：`CET:PlaceTo=…`（**只在不是手牌时**写）—— 回读时「复制到哪一摞」能原样带回来，
  默认手牌的老存档标记行与以前逐字一致；
- 「复制自己」那段的实现行（`__selfClone` / `__copyIdx`）已加入回读的「整段跳过」名单，
  回读不会多出没认出来的语句；
- 校验器：「复制卡牌」的张数范围从「1~5」放宽成「0 或 1~5」（0 = 这张牌自己）。
