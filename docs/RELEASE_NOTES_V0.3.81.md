# V0.3.81 — 主菜单百科大全显示其他模组角色

## 问题

外面（主菜单）的「百科大全」里：

- 自己角色的卡池能看到；
- 别人的模组角色 / 卡牌看不到，像是没加载。

## 原因

本体 `NCardLibrary` 只给 **5 个官方角色**建了「角色 → 卡池筛选器」表。

以前的补丁只补**本模组自己**的角色：

```csharp
if (me is null) me = ModelDb.Character<我们的角色>();
...
map[me] = filter;
```

其他 mod 角色如果没自己写这个图鉴补丁，就没有筛选器；他们的卡只能藏在「杂项」里，外面看起来就是“看不到别人的模组”。

## 修复

主菜单（没有进行中的局）时，补丁会：

1. 先补自己角色的筛选器；
2. 再遍历：

```csharp
foreach (CharacterModel ch in ModelDb.AllCharacters)
```

3. 给**还没有筛选器**的角色各补一个卡池按钮：

```csharp
pools[extra] = (CardModel c) => ReferenceEquals(c.Pool, ch.CardPool);
map[ch] = extra;
```

4. 官方 5 个角色 / 已经补过的模组角色自动跳过；
5. 某一个角色补失败只跳过它，不影响其他角色。

所以主菜单百科里现在会出现：

```text
铁甲战士 / 静默猎手 / ... / 我们的角色 / 其他模组角色
```

点其他模组角色的按钮，就能看到他们的卡。

## 注意

- 这是**新生成的补丁**；旧模组 DLL 不会自动变，必须重新生成。
- 只在**主菜单百科**补其他角色；局内仍然只处理自己的角色，避免干扰本体 / 其他模组。
- 其他模组如果是**共享卡池**（不属于某个角色），仍可能只在「杂项」里显示；这次先解决“模组角色看不到”的主要情况。
