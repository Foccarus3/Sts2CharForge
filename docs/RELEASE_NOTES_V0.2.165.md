# V0.2.165 更新说明

> 回答你报的：「点卡牌页查看卡牌，然后再点先古页查看先古牌，先古牌的卡面会消失，
> 并且比例变成卡牌页的比例而不是竖图的比例」。

## 一、真因：三个卡牌页共用一套「卡面预览」，互斥时只清了列表、没清镜像

「卡牌 / 诅咒 / 先古卡」三页共用同一套卡面预览属性，取「当前这张卡」的判据是：

```csharp
private CardSpec? ActivePortraitCard() => CardUiSelection ?? SpecialCardOf();
```

而 **卡牌页那个列表镜像的语义是「点空槽行时保持上一张」**（`SlotRowMirror.UiSelection`，V0.2.140 定的）。
三栏互斥那里只做了一句 `CardList.SelectedItem = null` ——

- 对诅咒 / 先古两栏用的是 `ClearSelection()`（列表 + 镜像一起清，没问题）；
- 对**卡牌页**只清了列表选中项，**镜像的 `CardUiSelection` 不会松手**（正是「保持上一张」那条规则）。

于是切到先古页、点了先古卡之后：`CardUiSelection` 还是卡牌页那张 ⇒ 预览拿到的是**上一张普通卡**：

- 预览框仍是普通卡的 **1000×760 横图**比例（不是先古卡的 606×852 竖框、也不按「拉满」显示）；
- 卡面图也按**那张普通卡**的 key 去找（先古卡的卡面存在另一个 key 上）⇒ 找不到图 = 你看到的「**卡面消失**」。

（自检里先量到的就是这一幕：`当前预览卡=自检比例卡 / 1000×760 / Uniform`。）

## 二、修法：互斥的**两个方向**都连镜像一起清

- `ClearCardPageSelectionForPortrait()`：选中诅咒 / 先古 / 状态卡时调用 —— `CardList.SelectedItem = null`
  **加上** `_cardMirror.ClearSelection()`（并通知 `CardUiSelection`）；
- `ClearSpecialCardSelections()`：反方向 —— 在**卡牌页**选中一张真卡时，把诅咒 / 先古 / 状态三栏的选中也清掉
  （以前只清了「先古 → 卡牌」这一半，另一半一样会串）。

修好之后（同一个自检、同一套操作）：卡牌页普通卡 **1000×760 / Uniform** → 切先古页选先古卡
**606×852 / Fill**、预览取的是**先古卡那张** → 再切回卡牌页又变回 **1000×760**。

## 三、验证

- `dotnet build Sts2CharForge.sln -c Debug` → **0 错误**；
- `--uicheck`：Debug **3665 PASS / 0 FAIL**，新增 4 条：
  - （准备）卡牌页选中普通卡 → 预览框 1000×760、`Stretch.Uniform`；
  - 切到「诅咒 / 先古 / 状态」页并选中先古卡 → 预览框 **606×852**、`Stretch.Fill`；
  - 预览取的是**先古卡**那张（取错就会「卡面消失」）；
  - 反方向：从先古页切回卡牌页选卡 → 变回 1000×760。
- **反向验证**：修之前这两条断言就是 FAIL，失败明细里印的就是 `当前预览卡=自检比例卡 / 1000×760 / Uniform`
  （= 你看到的现象）；修完即 4 条全绿。
- **默认输出不变（红线①）**：`--samplegen` 与 V0.2.143 基线 **111 个文件逐字节一致**
  （这次只动界面选中逻辑）。
