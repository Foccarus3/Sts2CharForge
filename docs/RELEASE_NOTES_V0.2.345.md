# V0.2.345 — 动画页：缩放 / 偏移能填小数了；预览里实时显示「相对瞄点偏了多少」

你提的两条：

## ① 缩放等四项为什么之前填不进小数

这四个框原来直接把 `TextBox.Text` 绑到 `double`（`Scale` / `XOffset` / `YOffset` / `SpeedScale`）。
打小数的时候必然会先出现 `"0."` 这种**中间态**，`double` 解析失败 → WPF 判定这次改动无效
（源不更新，有些输入法下光标还会跳回去），于是小数经常「填不进去」。

现在改成工具里别处早就用过的写法（`CardSpec.CostText` 那套）：**文本属性照收，只有解析成功才写回数值**。

```csharp
[JsonIgnore] public string ScaleText
{
    get => _scaleText ?? NumText(_scale);          // 没改过 → 显示当前数值
    set { _scaleText = value; if (TryNum(value, out double v)) Scale = v; }   // 解析失败就保持原值
}
```

* `"0.85"` 和 `"0,85"` 都认（系统把小数点设成逗号的机器也能填）；
* 乱写（`abc`）/ 清空 → **不改数值**，保持上一次的合法值；
* 数值本身还是 `double`，存进存档读回来还是小数（自检里有一条 JSON 往返断言）。

## ② 偏移实时显示「相对瞄点」的位置

瞄点 = 本体血条中心（预览里那个**蓝点 + 十字**）。以前只有预览图会按偏移挪，
数字只藏在上面那行小字里、而且改数值时**预览根本不刷新**（`OnAnimSettingChanged` 只刷新了诊断文字）。

现在：

* 预览下面新增一行常驻绿字（改数值立刻变，**没有素材时也显示**）：
  `相对瞄点：X +12.5 px（向右） · Y -30 px（向上）   —— 蓝点 = 瞄点（血条中心），红圈 = 动画锚点`
  * Y 填 0 是「自动」那一档，所以写 `0 = 自动（脚落在静态立绘底边）`，不会让人以为「偏 0 就没对齐」；
* 画布上从瞄点拉一条**红色直角虚线**到动画的锚点，两段各标一个数字（`+12.5` / `-30`），锚点画成红圈；
* 改**缩放 / X / Y / 速度**时预览立刻重画（速度还会重启动画定时器，立刻按新倍速播）。
