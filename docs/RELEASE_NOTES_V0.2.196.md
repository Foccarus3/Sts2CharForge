# V0.2.196 —— 「数值公式」里也能写条件了（比较 / 逻辑 / 三元，布尔当数值用）

> 用户原话：贴了一整段 C# 例子（`((2 > 1) ? 1 : 0) * 2`、三个数里正数个数、及格加权、符号函数、
> `(a > 0 && b > 0) ? 1 : 0`、`Convert.ToInt32(2 > 1) * 2` …）+ 一句「能不能让生成器使用上述」。

## 1. 现在公式里能写什么

以前只有 `+ - * / % ( )`、`min / max / floor / ceil / round / abs` 和那些内置读数。这一版加了三类：

* **比较**：`>` `<` `>=` `<=` `==` `!=`
* **逻辑**：`&&` `||` `!`
* **三元**：`条件 ? 成立时 : 不成立时`（可以嵌套）

以及两条「照 C# 写也认」的：

* `Math.Abs(x)` / `Math.Max(1, N/2)` —— `Math.` 前缀自动剥掉（等价于 `abs(x)` / `max(1, N/2)`）；
* `Convert.ToInt32(条件)` —— 条件按真 1 / 假 0，数值原样取整；
* 字面量 `true` / `false`（= 1 / 0）。

**布尔当数值用 → 真取 1、假取 0**（就是用户例子里那句 `? 1 : 0`）：

| 公式 | 生成出来的 C# |
|---|---|
| `(a > 0) * 5` | `((__pA > (0m)) ? 1m : 0m) * (5m)` |
| `(a>0?1:0) + (b>0?1:0) + (c>0?1:0)` | 三个 1/0 相加（三个数里正数个数） |
| `x > 0 ? 1 : x < 0 ? -1 : 0` | 嵌套三元（符号函数） |
| `f ? 1 : 0`（f 是 0/1 的参数） | `((__pF != 0m) ? 1m : 0m)` —— 数字当条件用 = 「不等于 0」 |
| `Math.Abs(x)` | `System.Math.Abs(__X)` |
| `Convert.ToInt32(Turn % 2 == 0) * 4 + 2` | `System.Math.Truncate((… ? 1m : 0m)) * 4m + 2m` |

## 2. 写错了照样是中文报错，不是丢给 dotnet

* 三元少写冒号 → 「三元运算少了一个冒号：写成「条件 ? 成立时 : 不成立时」（例：a > 0 ? 1 : 0）。」
* 比较 / 逻辑写一半、括号不配、不认识的名字 → 都是原来的那套中文提示（提示文案里也补上了新语法）。

## 3. 常量折叠也跟着支持

公式里全是常数时（例：`((2 > 1) ? 1 : 0) * 2`），生成期就算出 2 —— 所以像
「卡牌费用 / 升级后费用」这种**必须是编译期常量**的地方也能写条件式（写成常数就折好，写运行时读数会照旧报错）。

## 4. 用得到的地方（全都自动生效）

卡牌 / 遗物 / 药水 / 自定义状态的效果数值、次数、命中次数、概率；卡牌费用类公式；
**锻造节点图**里【数值】模块的公式、【效果】模块的「数值」栏、【条件】模块的数值栏；
以及所有「条件数值公式」（条件里的 N / M 也能写条件式了）。

## 5. 老存档不受影响

只写数字 / 四则运算 / 那几个函数的老公式，**生成文本一个字符都不变**（`2*3` 仍然是 `((2m) * (3m))`）；
示例配置 113 个文件、WhiteCloak 存档（31 只自定义状态）412 个文件逐文件对拍，只差 `.sln` 里的随机 GUID。
