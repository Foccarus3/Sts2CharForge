# V0.2.104 更新说明

> 你说「在遗物和状态那边看不到在哪填入触发时机的数值」—— 对，上一版那两栏**只在「花掉能量后 / 花掉额外资源量后」
> 和「某状态层数到达 N / 变化」这几种时机下出现**，别的时机（打牌 / 消耗 / 生成 / 受伤…）还没有。
> 这一版把你之前勾的那批**做出来了**，数值栏现在跟着触发时机走、**这些时机下都会出现**。

## 一、触发时机下面现在会按时机显示「数值」那一栏

| 触发时机 | 那一栏的标题 | 含义 | 还能选范围 |
|---|---|---|---|
| 打出一张牌后 | 每累计几次触发 | 每累计 N 张牌触发一次 | 本回合 / 本场战斗 |
| 消耗一张牌后 / 弃掉一张牌后 / 抽一张牌后 | 每累计几次触发 | 每累计 N 张触发一次 | 本回合 / 本场战斗 |
| 生成卡牌时 | 每累计几次触发 | 每累计 N 张触发一次 | 本回合 / 本场战斗 |
| 花掉能量后 / 花掉额外资源量后 | 花掉多少点触发 | 每累计花掉 N 点触发一次 | 本回合 / 本场战斗 |
| 自己受到伤害后 / 自己造成伤害后 | 伤害至少多少才触发 | `result.UnblockedDamage ≥ N` 才触发 | — |
| 自己失去生命时 | 失去生命至少多少才触发 | `-delta ≥ N` 才触发 | — |
| 自己获得格挡后 | 获得格挡至少多少才触发 | 获得的格挡 ≥ N 才触发 | — |
| 某个状态层数到达 N 层时 | 到达 N 层 | 层数跨过 N 那一下 | — |
| 某个状态层数变化后 | （盯哪个状态） | 任意层数变化 | — |

**留空 / 填 0 = 老行为**（每次都触发 / 每 1 点），一个字符都不变；填了才有额外守卫。

生成出来长这样（遗物「每打出 3 张牌」）：

```csharp
if (CombatManager.Instance.History.CardPlaysFinished
        .Count(e => e.Actor == base.Owner.Creature && e.HappenedThisTurn(base.Owner.Creature.CombatState)) % 3 != 0) return;
// CET:TriggerAmount=3m CET:TriggerScope=Turn
```

- 计数族同样**不需要自己记计数器**：本体是「先记账、再调钩子」，所以历史里的累计数已经包含这一次，
  `累计 % N == 0` 就是「每 N 次」；
- **自定义状态那边同一套**（多条触发时机共用一个钩子时，各自包一层 `if (累计 % N == 0) { … }`）；
- 回读靠 `// CET:TriggerAmount=Nm CET:TriggerScope=Turn|Combat` 那行标记（守卫以后改写法也不丢配置）。

## 二、还没做的一条

**「一个敌人死亡后」** 的数值（第 N 个 / 每 N 个）：本体战斗历史里**没有死亡记录**，
所以它得由工具**自己记一个计数器**（遗物 / 状态各自一个私有字段 + 战斗开始清零）。
要做的话下一版一起做（连同你上次问的「获得能量」记录器）—— 这两个都是「需要自己记一份」的类型。
