# V0.2.250 — 锻造页【效果】模块补上「范围」：现在能选**组**和**特定关键词**了

## 用户报的

> 这个范围怎么不能选组或者特定关键词

## 查证（确实是工具缺一栏，不是你的配置问题）

* 卡牌 / 遗物 / 药水 / 自定义状态页的效果编辑器里，那一行叫「**范围界定（哪些牌能选）**」，
  候选是**按当前存档动态取**的（`EffectCatalog.SpawnFiltersFor`）——里面有「自定义关键词：…」和「组：…」；
* 但**锻造页的【效果】模块压根没有这一栏**（`ForgeGraphCatalog` 里效果模块的字段表里没有 `SpawnFilter`）。
  于是你在锻造卡上做「减少卡牌费用」时，根本找不到地方选「哪一类牌 / 哪个组」；
* 而且锻造卡是你主要的做法（`IsForged`），所以这个缺口对你来说就是「这个范围不能选组 / 关键词」。

## 这次补了什么

1. **锻造页【效果】模块新增两栏**：
   * 「**范围（哪一类牌 / 哪个组）**」—— 候选 = 不限 / 攻击 / 技能 / 能力 / 诅咒 / 状态 / 任务 /
     **自定义关键词：…（把某个关键词当成一套卡的组）** / **组：…（你在「组」页建的那些）**；
   * 「**只持续本回合（减少卡牌费用用）**」—— 不勾 = 本场战斗一直有效（腐化），勾上 = 玩家回合结束自动撤掉。
2. 这两栏**只在真的读它的效果上出现**（判据和卡牌页同一份 `EffectFieldPolicy.UsesCardScopeFilter`）：
   造成伤害 / 获得格挡这些不显示，消耗 / 丢弃 / 升级 / 给关键词 / 减少卡牌费用… 才显示。
3. 节点图现在**支持「减少卡牌费用」这条效果**（加进 `ForgeGraphGen.SupportedEffectKinds`）——
   以前在图上选它会被校验器拦下（「节点图里还没接上」）。生成端走 `__fgPlayer` 那套上下文，
   和卡牌页共用同一个发射器（`CSharpCodeGen.EmitCostDownPublic`）。
4. 候选是**动态**取的（`ForgeCanvasView` 里给 `SpawnFilter` 单独走 `EffectCatalog.SpawnFiltersFor(Owner)`）——
   所以你在「组」页新建一个组、或者在「自定义关键词」页加一个关键词，回到锻造页就能直接选到。
