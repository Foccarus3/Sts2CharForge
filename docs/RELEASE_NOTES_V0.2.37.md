## 新：「获得类」数值填负数 = 反向

凡是「获得 / 施加」的数值都能直接填负数，生成的代码换成对应的反向命令（本体对非正数基本都直接返回，
所以每一条都换成反向命令，不是把负数塞给本体）：

| 效果 | 填 -N 时生成的 | 为什么 |
| --- | --- | --- |
| 获得格挡 | `CreatureCmd.LoseBlock(...)` | 本体 `GainBlock` 对非正数什么都不做 |
| 施加增益/减益 | 先 `GetPower<T>()` 取目标身上那份实例，再 `PowerCmd.ModifyAmount(-N)` | 本体 `Apply` 对负数会**新建一个负层数的状态**；扣层数要用 `ModifyAmount`。目标身上没有这个状态时什么都不做 |
| 获得能量 | `PlayerCmd.LoseEnergy(N)` | `GainEnergy` 第一句就是 `if (!(amount > 0m)) return;` |
| 获得金币 | `PlayerCmd.LoseGold(N)` | 同上 |
| 获得最大生命 | `CreatureCmd.LoseMaxHp(...)` | — |
| 回复生命 | 走「失去生命」 | — |

- 卡面描述也写成反向的话：「失去 5 点格挡。」「失去 3 层力量。」（给自己）/「扣除 5 层中毒。」（给敌人）。
- 两个组合做不到，生成前的检查会**直接拦住并说清原因**：
  「施加增益/减益 + 负数 + 下回合生效」、以及「临时增益 + 负数」（它的机制是「本回合 +X、回合结束撤掉」）。
- 从工程回读（`--recover`）也认这些负数写法，负数层数 / 格挡会原样带回来。

## 说明

- 存档格式没有变化，直接覆盖更新即可；你的存档在 `自定义角色存档\` 里，覆盖程序文件不会动它。
- 发布包里**不含任何存档**、也不含任何《杀戮尖塔 2》的游戏素材。
- 程序内嵌的效果库数据需要你自己用「效果库」页从本机解包工程生成（仓库不附带游戏文本）。
