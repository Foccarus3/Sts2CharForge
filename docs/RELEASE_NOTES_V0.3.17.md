# V0.3.17 — 变量页：界面（横幅 / 行内校验 / 试算 / 自动起名）

接 V0.3.16（重置 + 写操作），这一版把**变量页**做出来。到这一版，变量功能才算对普通用户可用：
建变量 → 在效果里选「变量（+ / - / = / 清零）」→ 战斗开始自动复位。

## 一、新页签「变量」

位置：**「自定义参数 / 组」右边**（原来的「锻造」及之后的页签各往后挪一位）。
自检里那条「选项卡顺序」断言已同步改成：角色 0 / 召唤物 1 / 额外资源量 2 / 卡牌 3 /
自定义参数组 4 / **变量 5** / 锻造 6 / 遗物 7 / 药水 8 / 诅咒先古 9 / 关键词 10 / 先民 11 /
本体状态 12 / 自定义状态 13 / 美术 14。

## 二、页面内容

### 常驻横幅

* 命名规则：字母 / 数字 / 下划线，1~12 位，不能以数字开头；X / Y 与内置读数名不能用。
* 作用域：不勾「全局」= 每场战斗开始时复位；勾上 = 本局内跨战斗保留（新开一局清零，不是跨局存档）。

### 左边：变量列表

* **新建变量**：自动挑一个没被占用的短名字（a、b…，被占了就 a2、b2…）；
* **删除**：确认后删；用到它的效果会变成「变量页里找不到」，校验器会报错（不静默）；
* 列表行显示 `cnt = 2` / `run_pts = cnt + 1 [本局]`。

### 右边：详情（选中变量后）

| 栏位 | 说明 |
|---|---|
| 变量名 | **行内校验**（红字）：不合规范 / 重名 / 和自定义参数撞名，当场说清 |
| 初值 / 取值公式 | 可写常数、别的变量、参数、X / Y、内置读数；旁边「…」插入菜单 |
| 全局 | 本局内跨战斗保留（新开一局清零） |
| 允许负数 | 不勾 = 夹到 ≥ 0 |
| 上限 | 文本绑定：填得进、清得掉；留空 = 不封顶；乱写保持原值 |
| 备注 | 只给自己看，不参与生成 |

右侧还有：

* **这个变量**：生成出来的类（`<角色>Vars`）和怎么用；
* **重置**：实时显示「每场战斗开始时复位为 2 / 新开一局时复位为 3」；初值公式含运行时量时明确说「复位为 0」；
* **试算**：写一个公式，按所有变量的**当前初值**算一次（例：`cnt + 1` → `= 3`）；含 X / 内置读数的算式明确说「算不出来」；
* **当前所有变量**：一行一个，带作用域与复位值。

## 三、配套的小改动

* `VarSpec.MaxText`（`[JsonIgnore]`）：上限的文本代理，照 `AnimationSpec.ScaleText` 的老写法 ——
  文本照收，**只有解析成功才写回 int**（清空 = 不封顶，乱写 = 保持原值），不会出现「填不进 / 清不掉」。
* `ForgeVarsGen.TryEvalFormula`：试算求值（变量取初值、固定值参数取它填的数；其余返回「不是常数」）。
* `ForgeVarsGen.ResetPreview`：重置说明（界面与校验器共用一份口径）。
* `MainWindow.VarChoices` / `VarWriteOps`：效果编辑器里「变量 / 怎么改」两行的候选，换存档时刷新。
* 观感截图模式 `--varshot`（开发用，写到 exe 旁的 `varshot.png`，不参与生成 / 不写存档）。

## 五、仍然要说明的边界

* **多人联机**：变量是生成类里的**静态字段**，本体没有同步机制；联机时各台机器各算各的。
  这一版仍是「单机正确」，联机状态等实测后再收口（候选：遗物 Amount 编码 / 每回合广播 / 挂玩家模型）。
* 初值公式里写 **X / Y / 内置读数 / 自定义参数**：战斗开始时没有这些值，重置按 0（界面与校验器都会说清）。
* 变量名改名后，已经选了旧名字的效果**不会自动跟着改**；校验器会报「不在变量页里」，请重新选。
