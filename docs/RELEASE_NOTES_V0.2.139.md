# V0.2.139 更新说明

> 这一版修你报的两条：**多人模式被打死后靠回血「复活」**、**填负值的「施加增益/减益」不生效**。

## 一、多人模式：致死那一下不再靠回血复活

**原因**：「受到伤害后 / 失去生命时 / 受到攻击后」这三条时机的守卫里**没有「自己已经死了就别再跑」** —— 而本体这几个钩子是**无条件广播**的（致死那一下照样进），于是效果里的「回复生命 3」把血拉了回来；多人模式下队友还活着，你就"复活"了。

**改法**：三条时机 × **三条链（自定义状态 / 遗物 / 锻造）= 9 处**，在「确认挨打的是自己」之后、**跑效果之前**加一句本体现成的死亡判断：

- 自定义状态链：`if (base.Owner.IsDead) return;`
- 遗物链 / 锻造链：`if (base.Owner.Creature.IsDead) return;`

单人下同样生效（致死那一下不再触发）——这是预期语义，不是副作用。

## 二、负值「施加增益/减益」：现在按本体语义分两档

**先说根因（跟你那条"不生效"对得上）**：改动前，负值走哪条路**取决于这张卡有没有走过「公式迁移」** ——

| 卡的状态 | 改动前生成什么 | 结果 |
|---|---|---|
| **没有**走过公式迁移（例如刚在界面里新填、直接生成） | `{ 取目标身上已有的该状态；if (非空) ModifyAmount(-N); }` | 目标身上**本来没有**这个状态时**静默什么都不做** ← 你遇到的就是这条 |
| **走过** `ProfileFactory.Load` 的迁移（打开存档 / 示例存档会迁） | `PowerCmd.Apply<T>(目标, -N)`（本体「尖啸」写法） | 一直是对的 |

**现在两条路输出完全一致**，并且按本体语义分档：

- **允许负层数的 5 种**（力量 / 敏捷 / 专注 / 尖啸 / 萎缩）→ `PowerCmd.Apply<T>(目标, 负值)` —— 本体「尖啸」扣敌人力量就是这么写的，**0 层也能扣成负数、也不怕身上没有**；
- **不允许负层数的**（虚弱 / 易伤…）→ 仍是「从目标身上已有的层数里扣」（`GetPower` + `ModifyAmount`）。

**顺手修掉两个真 bug**：
1. 改动前在**已迁移**的卡上，「虚弱 -1」会被生成成 `Apply<WeakPower>(…, -1)` → **凭空给目标挂一个负层数的状态**；现在正确回到「扣已有层数」；
2. 锻造链原来自己内联了一套负数逻辑，而且**符号是反的**（`ModifyAmount(amount)` 里 amount 本身就是负的 = 反而**加**层数）；现在并入同一份实现。

**回读也同步修好**：以前只认「取实例再扣」那种形态、而且会把 `-2` 读回成 `0`；现在也认 `Apply(…, 负值)` 与 `-((2m))` 这种负数公式形态，力量 -2 / 敏捷 -3 / 虚弱 -1 都能原样带回。
