# V0.3.132 — 深色模式真正覆盖白底控件 / 参数参考可选中

## 这次不是只改根节点

V0.3.131 只做了「遍历可视树 + 系统色」，但 WPF 默认模板里还有大量控件用自己的浅色画刷，所以截图里仍会出现白底输入框、白底标签页，以及在白底上显示白字。

V0.3.132 改成**主题色资源 + DynamicResource**：

```text
UiWindowBg / UiChromeBg / UiFieldBg / UiFieldFg
UiBorder / UiText / UiMuted / UiAccent
```

- `Field` 输入框、`Pick` 下拉框、按钮、复选框、ListBox、TabControl / TabItem、GroupBox、StatusBar 全部引用这些动态资源；
- 深色切换只改资源颜色，模板里的输入框 / 下拉框 / 标签页会一起更新；
- 切回浅色时恢复原始颜色；
- 仍保留系统色覆盖和可视树兜底，用于局部硬编码颜色。

## 参数参考窗

- 窗口背景、分类列表、条目、分隔线、说明、按钮全部使用同一套动态主题色；
- 主窗切深色 / 浅色时，已经打开的参考窗同步；
- 不再出现「主窗浅色、参考窗一直深色」。

## 参数参考文字可选中

条目里的参数 ID 和说明已从 `TextBlock` 改成只读 `TextBox`：

```text
鼠标拖动选中 → Ctrl+C 复制
```

样式 `SelectableText` 保持透明背景 / 无边框，看起来仍像普通文字。
