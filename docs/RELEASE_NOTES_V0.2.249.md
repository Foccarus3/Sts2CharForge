# V0.2.249 — 「减少指定卡牌类别的费用」改成**效果种类**（你要的位置）

## 你的纠正

> 不是给自定义状态，而是增加在效果种类中。

所以这一版把它做成「效果」下拉里的**一条效果种类**：任何地方能加效果，就能加它（卡牌 / 遗物 / 药水 / 自定义状态的触发时机）。

## 怎么用

「效果」→ 效果种类选：

> **减少指定卡牌类别的费用（像腐化 / 刺破帷幕：「范围」选哪一类牌，数值 = 减几费；填 0 = 变成 0 费）**

配三样东西：

| 栏位 | 说明 |
|---|---|
| **范围界定（哪些牌能选）** | 就是「哪一类牌」：不限 / 攻击 / 技能 / 能力 / 诅咒 / 状态 / 任务 / **自定义关键词那一组** / **每个组**（和别处范围同一份候选） |
| **数值** | 减几费。**填 0 = 直接变成 0 费**（腐化那种）；填 1 = 减 1 费 |
| **持续时间** | 不勾 = 本场战斗一直有效（腐化）；勾「只持续本回合」= 玩家回合结束时自动撤掉 |

（V0.2.248 在「自定义状态」页也加了一块「费用修正」，两种方式都在；这条新的效果种类**不需要**你先建一个状态。）

## 生成的是什么

效果本身 = 挂一只**带载荷的内部状态** `{角色}ForgeCostDownPower`（写在 `cs/CostDownPower.cs`，只有用到这条效果才生成这个文件）。它覆写的是本体同一个钩子：

```csharp
public override bool TryModifyEnergyCostInCombatLate(CardModel card, decimal originalCost, out decimal modifiedCost)
{
    modifiedCost = originalCost;
    if (card.Owner?.Creature != base.Owner) return false;   // 只改你自己的牌
    if (!Matches(card)) return false;                       // 范围：内置档按 Type/Rarity，组/关键词组按 ModelId 名单
    modifiedCost = Reduce <= 0m ? 0m : System.Math.Max(0m, originalCost - Reduce);   // 最低 0 费
    return true;
}
```

* **腐化 Corruption / 刺破帷幕 Veilpiercer / 免费攻击 FreeAttackPower** 用的是同一个钩子；
* 为什么必须挂一只状态：费用是**每次要价时现算**的，直接改某张牌的费用只能改已经存在的那张，改不了之后抽到的牌 —— 状态在场，之后每张抽到的也照同一判据减；
* 载荷是运行时的（`Reduce` / `ScopeKind` / `Ids[]` / `ThisTurn`），所以同一个类能给不同范围、不同数额、不同持续时间复用；
* 施加时走 `ModelDb.Power<T>().ToMutable()` 造可变副本（直接 `new` 会撞本体的 `DuplicateModelException` → 卡牌浮空，这个坑 `TempKeywordPower` 里已经踩过）。

## 不静默

* **没选范围** → 校验器**警告**「一张牌都不会减（这条效果等于没写）」；
* 范围选了**空组** → **警告**「一类牌都匹配不到，减费不会生效」；
* 数值填 **0** → **提示**「费用变成 0（腐化那种）；想减 1 费请填 1」；
* 这条效果**不支持「下回合生效」**（延迟那条链里没有 `base.Owner.Creature`，勾了会生成出编不过的代码）—— 所以界面上这一条不显示那个勾选框，自检里也钉住了「68 种里只有 11 种不支持，其中就有它」。
