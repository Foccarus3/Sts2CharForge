# V0.2.274 — 次数算出来是 0 时不再「多打一段」

## 你报的

> X 费牌在 0 费时打出会直接触发一段效果，大于 0 费就是正常按 X 算段数，
> 好像不止是能量的问题，所有自定义参数在取值等于 0 的时候都会额外触发一次效果

## 原因

所有「次数类」公式（**生效次数 / 命中次数 / 复制份数 / 重放次数**）在生成时都被夹成 **1 ~ 20**：

```csharp
// 老代码：0 也被抬成 1 → 因此多打一段 / 多重放一次
for (int i = 0; i < (int)System.Math.Clamp(__pM, 1m, 20m); i++)
```

那个 `1m` 下界是为了防「公式算出 999 卡死一局」写的上界保护一起加的，结果把 **0** 也抬成了 1：
X = 0（0 费打出）、或者自定义参数 = 0 时，本来该「一次都不执行」，却执行了 1 次 —— 就是你看到的多触发一段。

## 修法

下界从 **1** 改成 **0**，循环上界保持 20：

```csharp
// 现在：0 就是 0 次（不执行），不会再多打一段
for (int i = 0; i < (int)System.Math.Clamp(__pM, 0m, 20m); i++)
```

覆盖的四处（都用同一个夹取）：
* 生效次数公式（卡牌 / 遗物 / 药水 / 自定义状态 / 锻造【效果】五条链）
* 命中次数公式（`WithHitCount`）
* 复制份数公式
* 重放次数公式

用你的场景验过：参数 `M = 0`、生效次数写 `M` → 生成

```csharp
for (int i = 0; i < (int)System.Math.Clamp(__pM, 0m, 20m); i++) {
```

`M = 0` → 循环 0 次（一次都不执行）。
