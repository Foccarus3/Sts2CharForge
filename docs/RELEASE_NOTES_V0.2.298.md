# V0.2.298 — 锻造页的「数值」栏也能实时看到算出来的数

## 接上了

锻造页每个数字栏（【数值】模块、效果模块的「数值 / 次数 / 命中」等）下面，现在多了一行小字，**边输边算**：

| 你输入 | 下面那行小字 | 框的颜色 |
|---|---|---|
| `6` | `= 6` | 常规 |
| `(1+2)*3` | `= 9` | 常规 |
| `A+3`（A 是固定数值参数） | `= 7` | 常规 |
| `X` / `HandCount*2` / `阶段层数` | `＝触发时现算：X*2` | 蓝框（对应原来那条「运行时才算」） |
| 费用栏写 `X` / `Y` | `= 打出时消耗全部能量 / 额外资源量` | 绿框 |
| `M*`（写错） | `⚠ 公式写到一半就没了（多半是少了一个数字或右括号）。` | 红框 + 红字 |

## 和上一版的关系

* V0.2.297 接的是**效果编辑器**（卡牌 / 遗物 / 药水 / 自定义状态共用的那份模板）里「数值（公式）」那栏下面的小字；
* V0.2.298 接的是**锻造页**的每一个数字栏 —— 两处共用同一个求值器 `ForgeFormula.Preview`，口径一致：
  - 有固定值的参数才当常量，其它来源（最大生命 / 敌人层数 / 手牌数…）一律算运行时量；
  - 纯数字 / 能折成常数的式子当场折出来；
  - 语法错把错因写在框下面，同时保留原来的红框 + ToolTip。
