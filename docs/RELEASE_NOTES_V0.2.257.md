# V0.2.257 — 「还是无法选进组」：右边那个状态列表**全是空的**（没通知刷新）

## 你报的

> 还是无法选进组

## 真因（这次找到根上了）

「组」页右边「这个组里有哪些状态」这个列表的内容是**按当前选中的组**算出来的，
但切换组的时候我只通知了「这个组里有哪些牌」那一栏，**没通知状态那一栏** ——
于是它一直停在「程序刚启动、还没选组」时算的那一次（**空列表**）。

所以 V0.2.256 你把窗口调大之后能看到右边那一块**标题**，但**里面一行都没有**，自然「无法选进组」。

## 改了三处

1. **切组就刷新**：`OnGroupSelectionChanged` 里补 `Raise("GroupPowerRows")`；
   组增删 / 改名 / 成员变化也会通知（`RaiseGroupsChanged`、`OnGroupSpecChanged`）。
2. **写进当前存档里那个组**：勾选时按 **Id** 在 `存档.CardGroups` 里重新找一次再写 ——
   界面上的列表偶尔还持有上一份存档的组实例，往旧实例上写等于白写（这次一并堵掉）。
3. **勾了有反馈**：状态栏会显示「已把状态「争锋」加入组「给 1」（组里现在有 1 个状态）。」，
   勾上 / 取消立刻看得见，不会再出现「点了没反应也不知道成没成」。

## 实机验证（用你这份存档 `examplemod.json`）

* 组页右侧现在列出：`（你自己的状态）争锋 / 红龙的财宝 / 枯荣共息` + `（本体）一心化万 / 下回合召唤 …`（共 246 行，可滚动）；
* 勾「争锋」→ 状态栏报「组里现在有 1 个状态」→ 点「保存配置」→ 存档里：

```json
"CardGroups": [
  { "Id": "4ae147…", "Name": "给 1", "Note": "技力牌", "PowerIds": [ "NecrassPower1" ] },
  { "Id": "b9698e…", "Name": "给 2", "Note": "稀有牌", "PowerIds": [] }
]
```

（注意：保存时会按模组 ID 把存档改名成 `examplemod.json`，这是原有行为 —— 别去看旧的 `Shot.json`，
那份是没改过的原文件。）

## 验收

  重新生成行仍显示已勾选 / 取消勾选能去掉）。
