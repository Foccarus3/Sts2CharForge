# V0.2.343 — 锻造页多了三类**卡**的列表：先古牌 / 诅咒牌 / 状态牌

你要求的：「锻造列表增加先古、诅咒、状态牌的列表」。

## 界面

「锻造」页左上角「要锻造哪一类」现在是 7 档：

```
（不选）
卡牌列表          ← 老样子：只列在锻造页「添加」出来的那些（IsForged）
先古牌列表        ← 新：「诅咒 / 先古 / 状态」页里的**先古卡**（全列，不过滤）
诅咒牌列表        ← 新：同上那页里的**诅咒卡**
状态牌列表        ← 新：同上那页里的**状态卡**（稀有度 = 状态）
药水列表
遗物列表
状态列表（自定义状态）  ← 老「状态列表」（能力牌用的自定义状态），加了括号免得和「状态牌列表」混
```

* 这三档列的是**真卡**（不是「锻造出来的副本」），所以在名单里看到的就是你存档里那几张；
  选中后右边那块布直接编它的锻造图（升级前 / 升级后两块都在）。
* 「添加」建的是同款新卡并顺手给一块布（先古卡：稀有度 = 先古；诅咒：`-1` 费 + 不能被打出；状态牌：类型 / 稀有度 = 状态），
  名字前面带 `*`，一眼看出是这一页建的。
* 「删除」删的是**真卡**（从 `AncientCards` / `Curses` / `Cards` 里按「哪个集合里有它就删哪个」），
  和「状态列表」那一档同一个口径（自检里连着删完会核对数量）。

## 生成端

* **先古卡 / 状态卡**本来就由 `CardSource` 生成，一直吃锻造图 —— 这一版只是把它们摆到锻造页，不需要改生成。
* **诅咒**是另一条链（`CurseSource`：`CardType.Curse` + `-1` 费 + 不能被打出 + 「在手上回合结束时」），
  以前**完全不读**锻造图。这一版接上：
  * 图非空 → 生成 `TimingFields` + `CardHooks(...)`（被消耗 / 被丢弃 / 被抽到这类时机由它自己写 override）；
  * 图上有「卡牌被打出时」→ 补一个 `OnPlay` 去调 `ForgeGraphOnPlay`（**只有费用 ≥ 0、能打出去的诅咒**才跑得到）；
  * **老那套「在手上回合结束时」照旧生成**（图表达不了那个时机，不能被顶掉）—— 两套并存，钩子名不冲突。
