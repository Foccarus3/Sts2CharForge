# Sts2CharForge V0.1.0

> 版本号从 V0.0.10 进入 **0.1.x**。这一版是「整理后的正式版本」：程序功能与 V0.0.10 相同，
> 变的是版本号本身的定位 —— 仓库与打包脚本里的本机路径、用户名、私人模组名已经清理干净，
> 发布流程也固化成了一个脚本。

## 下载哪个

| 你的情况 | 下载这个 |
| --- | --- |
| 第一次用 | `Sts2CharForge-bundle-V0.1.0.zip`（显示为「整合包」，约 371 MB）—— 程序 + 环境包（Godot 4.5.1 mono / 便携 .NET SDK 9）+ GDRE 解包工具 + 图文教程 |
| 已经有旧版整合包 | `Sts2CharForge-update-V0.1.0.zip`（显示为「更新包」，约 60 MB）—— **只有程序文件 + 启动器**，解压覆盖到原来的根目录即可，环境包 / 教程 / GDRE 工具都不用动 |

> 为什么文件名是英文：GitHub 会把资产名里的中文清洗成 `._`（而且「整合包 / 更新包」清洗后是同一个名字，会互相撞名），
> 所以 GitHub 上用 ASCII 文件名、中文名放在资产的 label 上；本地打包产物的文件名仍然是中文。

## 本次更新

- **版本号 V0.0.10 → V0.1.0**：界面与生成逻辑没有变化，这是定位上的升级（0.0.x 收尾、0.1 系列起点）
- **发布流程固化**：`tools\release_all.ps1` 一条命令完成「升版本号 → 编译 → 打整合包 + 更新包 → 发 GitHub Release」，不用再手敲四条命令
- **仓库清理**（V0.0.10 已包含）：删掉含本机绝对路径的 WPF 编译临时文件、打包脚本不再写死本机路径（改为按脚本位置动态推导）、源码与文档里的私人模组名换成中性示例
- **文档口径**：`README.md` 与 `使用说明.txt` 只讲功能与用法，不再记录版本变更；版本信息只出现在本文件和 GitHub Release 里

## 说明

- 存档格式没有变化，直接覆盖更新即可；你的存档在 `自定义角色存档\` 里，覆盖程序文件不会动它
- 发布包里**不含任何存档**、也不含任何《杀戮尖塔 2》的游戏素材；程序运行时只读取你本机的游戏文件
- 程序内嵌的效果库数据需要你自己用「效果库」页从本机解包工程生成（仓库不附带游戏文本）

## 使用方法

1. 解压后运行「启动 Sts2CharForge_V0.1.0」（`.bat` 或 `.lnk`）
2. 第一次用请先看根目录的 `使用说明.txt`（含「！首次使用先点这个！」里的 GDRE 教程）
3. 详细功能说明见根目录 `README.md`
