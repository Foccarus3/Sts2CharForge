# 自定义描述示例：颜色 + 特效全览（约 100 字）

> 一段**短**的展示文本：不讲究内容，只要求把本体认识的颜色和动效在一屏里都过一遍，用来肉眼验收标签。
> 用法：卡牌页 →「自定义描述」，勾上「替换」，整段粘进去。
>
> 正文 96 字符（89 个汉字）/ 连标签共 460 字符；**15 个本体特效标签（8 色 + 7 动效）+ 9 个排版类标签全部用到**。
> 标签清单与规则见 [富文本标签速查.md](富文本标签速查.md)。

```text
[b]加粗[/b][i]斜体[/i][u]下划线[/u][s]划掉[/s][code]等宽[/code][font_size=18]放大[/font_size][lb]方括号[rb]
[center]八种颜色、七种特效，一次看全[/center]
```

## 版本 B：卡面可读版（真卡日常用这个）

```text
造成[orange]8[/orange]点伤害，然后[blue]抽一张牌[/blue]。
若你本回合[sine]失去过生命[/sine]，改为[red]抽两张[/red]，并[green]获得1点格挡[/green]。
[gold]斩杀[/gold]时：[purple]永久[/purple]获得1点力量。[fade_in]（它记得每一个颜色。）[/fade_in]
```

> 想让数字走升级逻辑，把 `8` 换成占位符 `{Damage:diff()}`（前提是这张牌真的有效果「造成伤害」，
> 否则游戏里找不到这个变量）。

## 注意事项

1. 这段是**标签验收样品**：`[jitter]` / `[scramble]` / `[sine]` 会一直动，真卡请只用 B 那种长度 + 颜色；
2. `[font_size=18]` 会压过卡面的自动字号计算，卡面观感可能变怪，验收完就删掉；
3. **不要写竖线 `|`**（升级前后描述不同时，生成端用 `{IfUpgraded:…|…}` 拆句，自己写会把句子截断）；
4. **不要手写中括号**：想显示方括号用 `[lb]` / `[rb]`；
5. **`{}` 里必须是真实存在的动态变量名**，写错游戏里会找不到（用界面上的「填入参数…」插进去最稳）；
6. 生成器会自动补闭合、理顺交叉嵌套、把只差一个字母的拼错标签改对（例如 `[god]` → `[gold]`），
   并在校验 / 生成日志里报一句；完全陌生的标签不会生效——游戏里会把方括号**原样印出来**。
