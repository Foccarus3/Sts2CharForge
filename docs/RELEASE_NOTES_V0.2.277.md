# V0.2.277 — 自定义描述里「能量」两个字可以直接换成能量图标

## 你要的

> 就只需要在自定义描述能够填入能量图标，比如获得 2 点能量，在卡牌描述中能量的显示是图标而不是单纯「能量」二字

## 用法（一步）

卡牌（或遗物 / 药水）的「自定义描述」框里点 **「填入参数…」**，菜单最下面多了一条：

```
{能量图标} — 能量图标（换成一个你角色颜色的能量图标；可以写在「获得 2 点」后面）
```

写好样子就是：

```
获得 2 点{能量图标}
```

生成出来（真·卡面文案）：

```json
"UI_ENERGY_ICON_CARD.description": "获得 2 点[img]res://images/packed/sprite_fonts/seven_energy_icon.png[/img]"
```

* `seven` 是**你角色的**能量颜色前缀（生成时按 `Naming.EnergyColor` 算出来的，不是写死铁甲战士的 `ironclad`）；
* 图标文件本身就随模组打包（`ArtGenerator` 会把 `*_energy_icon.png` 按你的颜色复制进工程），所以不用另外传图；
* 卡 / 遗物 / 药水**三种自定义描述都支持**；
* 没写这个占位符的存档 —— 生成结果**一个字都不变**。

## 为什么不用本体那个 `{Energy:energyIcons()}`

本体那个写法（ADRENALINE / ALIGNMENT 用的）要求描述变量里**真的有 `Energy`**，只有带能量效果才满足；
不满足时卡面会**原样印出花括号**。而你要的只是「把这几个字换成图标」，所以工具在**生成期**就把
`{能量图标}` 换成了真正的 `[img]…` 标记 —— 任何卡、任何时机都能用。
