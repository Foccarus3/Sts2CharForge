# V0.2.251 — 条件「上一张打出的牌是某种范围的牌」：范围可以填组（图上也能填，且会校验）

## 你要的这条条件

> 条件增加「上一张打出的牌是某种范围的牌」，范围可以填组

这条条件**V0.2.247 就有了**（条件 id `LastCardScope`），范围那一栏和「范围界定」是**同一份候选**：
不限 / 攻击 / 技能 / 能力 / 诅咒 / 状态 / 任务 / **自定义关键词：…** / **组：…**。
两处都能用：

* 「卡牌 / 遗物 / 药水 / 自定义状态」页 → 效果下面的「条件选项」→ 条件选它 → 出现「**牌的范围**」那一行；
* **锻造页【条件】模块** → 「条件」选它 → 模块上出现「**范围（上一张打出的牌是某种范围的牌用）**」那一栏。

生成出来（范围 = 组时会把组里每张牌展开成判据）：

```csharp
CombatManager.Instance.History.CardPlaysFinished
    .LastOrDefault(e => e.CardPlay.Player == base.Owner)?.CardPlay.Card.Id == ModelDb.Card<组里某张卡>().Id
```

## 这一版补的三件事（都是「让你能选到 / 选错会说出来」）

1. **下拉名字改了，好找**：条件名现在直接写着
   「上一张打出的牌是某种范围的牌（范围可填：攻击 / 技能 / 能力 / 诅咒 / 状态 / 任务 / 自定义关键词 / 组）」，
   锻造模块上那一栏也叫「范围（上一张打出的牌是某种范围的牌用）」。
2. **候选不再可能为空**：锻造页那两栏（条件的「范围」、效果的「范围」）取候选时多了一层兜底
   （`Owner ?? EffectCatalog.DisplayProfile`）—— 以前万一画布比存档先建好，候选只剩内置那几档，**看不到组和自定义关键词**。
3. **图上也会校验这两条条件**（以前图上只走 `ConditionExpr`，没人检查填全了没）：
   * 「上一张打出的牌**带有某关键词**」没选关键词 → **错误**（生成出来恒不成立，那条链一次都不会执行）；
   * 「上一张打出的牌是某种范围的牌」**范围留空** → **提示**（= 任意牌，等于没判）；
   * 范围选了**空组**（组里一张牌都没勾）→ **警告**（永远不成立，去「组」页勾几张牌）。
