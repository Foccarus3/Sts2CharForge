# V0.2.356 — 插件页支持「引用型栏位」：从存档里挑卡 / 状态 / 遗物 / 药水 / 伙伴 / 组

上一轮列的 B 组缺口里最值钱的那条：**插件页以前只能填字面值**，想引用「存档里的某张卡」只能让用户手抄类名
（抄错就静默生成不出东西）。这一版加了 `type = "ref"`。

## 用法

```json
"fields": [
  { "key": "Card",  "label": "挑一张卡",       "type": "ref", "refKind": "card" },
  { "key": "Power", "label": "挑一个自定义状态", "type": "ref", "refKind": "power" }
]
```

| `refKind` | 下拉里列什么 | 存的值 |
|---|---|---|
| `card` | 存档里全部卡（普通 / 诅咒 / 先古 / 状态牌） | 生成端用的**类名**（留空自动编号的也按同一口径算） |
| `power` | 自定义状态 | 类名（留空自动 = `<角色>Power<N>`） |
| `relic` / `potion` / `pet` | 遗物 / 药水 / 伙伴 | 类名 |
| `group` | 「自定义参数 / 组」里的组 | 组 Id |

emit 里当普通字符串用：`public const string CardClass = "{Card}";`

## 几个「不许静默」的细节

* **换存档自动重建这些下拉**（下拉里必须是当前存档的对象）——`Profile` setter 里重建插件页；
* 值在存档里已经找不到 → 下拉显示 **`（找不到：<旧类名>）`** 并选中它（不会静默变成空）；
* `refKind` 写错 → 报「页面问题」（不会给你一个永远空的下拉）；
* 状态 / 伙伴这类**类名留空的**，按生成端同一个口径算（`<角色>Power<N>` 等）—— 否则自动命名的一个都挑不到
  （这是自检里当场抓到的：一开始只认「填了类名」的，`power` 候选项直接是 0）；
* 列表字段（`list`）的**子栏位**也能用 `ref`（招式表里每行引用一个状态这种）。
