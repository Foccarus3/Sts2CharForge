# V0.2.78 更新说明

> 两件事：
> ① 你要的**卡牌自定义描述「自动填入」** + **「升级后的自定义描述」**（锻造卡最用得上）；
> ② 你问的**「升级卡牌的升级增量没用吗」** —— 分两种情况，其中一种是**真的没用**（而且以前是静默的），这一版给它补上了警告。

## ① 卡牌自定义描述：自动填入 + 升级后单独一段

### 「自动填入」按钮（卡牌页 → 自定义描述下面）

点一下就把**这张牌自动生成的那段描述**填进框里，你接着改就行，不用自己从头写。
填完顺手勾上「替换掉自动生成的描述」—— 不勾的话卡面上会「自动那段 + 你填的这段」印两遍。

### 「升级后的自定义描述」（卡牌页第二个框）

写**升级之后**卡面上显示的文字；**留空 = 和上面那段一样**（老存档一个字都不变）。
填了就生成本体那套升级分支语法：

```
{IfUpgraded:show:升级后那段|没升级那段}
```

游戏里按这张牌有没有升级自动显示对应那一版（本体 `ShowIfUpgradedFormatter`，本体自己几十张卡都在用）。
「填入参数…」和「自动填入」两个按钮第二个框也都有。

- 锻造卡最用得上：**「升级前 / 升级后」两块布干的事不一样**时（例：升级前打 6、升级后抽 2 张），
  一句话说不清，就给升级后单独写一段；
- 普通卡也能填（升级后换一句风味文字）；
- ⚠ 描述里自己写的**字面量 `|`（竖线）**会把 `IfUpgraded` 那句话截断（本体是按 `|` 切分选项的）：
  生成时会换成全角「｜」（看起来几乎一样），并在「配置检查」里给一条警告说清。
- 回读（`--recover`）靠生成代码里新加的一行 `// CET:UpgradedCustomDescription=…` 标记，原样带回来。

### 顺带补掉一个大坑：**锻造卡的卡面描述以前是空的**

普通卡的卡面文字是效果栏自动写的；锻造卡的效果在节点图里、效果栏是空的，于是生成出来的
`.description` 是**空串**（你的存档里 `SparkleCard401.description = []` 就是这个）——
除非你自己写自定义描述，否则卡面上一个字都没有。

现在锻造卡的自动描述**从节点图写出来**，例（你自己的那张卡）：

```
如果 指定单体敌人身上的分心层数 大于 3：对所有敌人造成 A+3 点伤害；否则：失去 5 点生命。
```

- 口径和生成端完全一致：从【触发时机】顺出口走、【对象】/【指向对象】决定「打谁」、
  【if】两支是「是 / 否」、【条件】/【且】/【或】当成一道门；【数值】模块的公式**直接写在卡面上**（`A+3`）；
- 非「卡牌被打出时」的时机写成抬头（例：「这张牌被消耗时：…」）；
- 「自动填入」按钮填的就是这一段（和生成时用的**同一段代码**，不会两边不一样）。

## ② 「升级卡牌」的升级增量有没有用

**分两种，名字很像但结果相反**：

| 效果种类 | 升级增量 | 为什么 |
|---|---|---|
| **升级卡牌**（战斗内，从手牌 / 牌堆挑 N 张升级） | **有用** | 它声明了 `Cards` 变量，`OnUpgrade()` 里会写 `base.DynamicVars["Cards"].UpgradeValueBy(增量)`，卡面写 `{Cards:diff()}` —— 升级后多升级一张 |
| **升级卡牌（全局）**（升级牌组里的牌） | **没用** | 张数在生成时是写死的循环次数，没有可以升级的数值 |

生成出来的样子（实测 dump）：

```csharp
// 升级卡牌（战斗内）
protected override IEnumerable<DynamicVar> CanonicalVars => [ new CardsVar(1), … ];
protected override void OnUpgrade() { base.DynamicVars["Cards"].UpgradeValueBy(1m); }
// 卡面：自己选升级 {Cards:diff()} 张手牌（升级不了的牌不会出现在选择里）。

// 升级卡牌（全局）：没有 Cards 变量、没有 OnUpgrade、卡面写死「1 张」——升级增量无处可落
```

**这一版补的**：这种情况以前是**静默忽略**（填了没反应、也没人说）。现在「配置检查」会警告：

> 第 1 条「升级卡牌（全局：升级牌组里的牌）」填了「升级增量」2，但这个种类**没有可以升级的数值**
> （它的数字在生成时是写死的，或者根本没有数字）—— 升级增量不会生效，请清成 0。要「升级后才变强」，
> 请用有数值的效果（造成伤害 / 格挡 / 抽牌…），或者锻造卡那样给「升级后」单独画一张节点图。

同一类「填了也没用」的还有：**获得卡牌（全局）/ 变化卡牌（全局）/ 删除卡牌（全局）**、获得卡牌奖励、
给予卡牌关键词、获得药水、结束回合、额外获得一回合、回合结束时自动打出 —— 现在这 10 个都会警告。
（「造成伤害」这种有数字的照旧有用，不会误报。）

> 顺带说一句：**锻造卡（节点图）的【效果】模块没有「升级增量」这一栏**——
> 「升级后变强」的做法是给「升级后」那块布单独画一遍（右上角有「一键复制『升级前』的内容」）。
> 现在两块布不一样时，卡面文字也会自动跟着变成升级前 / 升级后两段。
