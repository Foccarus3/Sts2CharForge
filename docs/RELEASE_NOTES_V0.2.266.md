# V0.2.266 — 「某个状态层数变化后」可以细分「上升」还是「下降」

## 你要的

> 发时机的某个状态层数变化后能不能细分是上升了还是下降

能。触发时机「**某个状态层数变化后**」多了一栏 **「层数变化方向」**：

| 选项 | 含义 |
|---|---|
| **上升 / 下降都算（默认）** | 老行为（层数一变就触发，不管加减） |
| **只在上升时触发** | 加层数才触发；掉层数不触发 |
| **只在下降时触发** | 掉层数才触发；加层数不触发 |

位置：**遗物页**和**自定义状态页**的触发时机编辑器里都有（那一栏只在选中「某个状态层数变化后」时出现，
单独一行，不会和「盯哪个状态」挤在一起）。

## 生成出来的区别

`AfterPowerAmountChanged(..., decimal amount, ...)` 里的 `amount` 就是**这次变化的增量**（加为正、掉为负），
所以判据直接接在那条守卫后面，不新增任何运行时开销：

```csharp
// 状态链（只要上升）
if ((power != this && power.Owner == base.Owner) && (power is StrengthPower) && amount > 0m) {
    // …这一条时机的效果
}

// 遗物链（只要下降）
if (amount >= 0m) return;   // 只要「层数下降」那一下（上升 / 不变都不算）
```

* 不选方向 = **一个字符都不多写**（老存档生成结果逐字不变）；
* 层数没变（`amount == 0`）两种情况都不算触发。
