# V0.3.11 — 把「图片 / 资源放哪里」写进 AI 提示词与插件开发规范

按你的要求，把 V0.3.10 定下的资产路径规则**写进给 AI 用的提示词**（也给插件作者看的那份规范）。

## 改了两份文档

### 1. `docs\插件AI提示词.md` —— 新增 **§24「图片 / 资源文件放哪里（硬规则）」**

内容（直接会被 AI 读到）：

* **① 原图只放插件自己的 `assets\`**：用 `host.ImportAsset(源路径, "名字.png")` →
  复制到 `plugins\<插件id>\assets\名字.png`，返回**相对路径** `assets/名字.png`；
  存进插件数据时要存**相对路径**，禁止绝对路径；禁止把图写进工程根 / `cs\`。
* **② 工程里的 `plugin_assets\<插件id>\` 是副本**：生成时自动复制；用
  `EditorOutputFile { Path = …, AssetPath = "assets/名字.png" }` 让工具负责复制；
  **V0.3.10 起清理旧工程会保留 `plugin_assets\`**。
* **③ 交付前自检表**：存的是相对路径吗 / 图在 `plugins\<id>\assets\` 吗 /
  连续生成两次图还在吗 / 生成的 cs 里怎么引用。

### 2. `docs\插件开发规范.md` —— §1 目录结构下面新增

````
### 图片 / 资源文件（V0.3.10 起是硬规则）
| plugins\<插件id>\assets\… | 原图（ImportAsset 写入，返回 assets/名字.png） | 构建时不会清 |
| <工程>\plugin_assets\<插件id>\… | 工程内副本（生成时复制） | 不会清（V0.3.10 起） |
````

并写明：只存相对路径、不要写进工程根 / `cs\`、保留的是固定目录名 `plugin_assets`。

## 验证

* 打包后的 `程序文件\docs\插件AI提示词.md` 里**能搜到** §24（已核对：1 处命中）；
* 部署版自检与版本号见日志（V0.3.11）。

## 为什么放在「AI 提示词」里

那份文件开头就写了「把 `=== 提示词开始 ===` 到 `=== 提示词结束 ===` 之间整段发给 AI」，
所以只要写进去，**AI 帮你写插件时就会按这个路径存图**，不会再出现「构建一次图片就没了」。
插件作者自己看的那份规范也同步更新了。
