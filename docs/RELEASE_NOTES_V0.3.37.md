# V0.3.37 — 「界面缩放」挪到「保存配置」右边

## 改了什么

顶部工具栏原来的顺序是：

```text
新建配置 / 打开配置 / 保存配置 / 一键生成 / 仅生成工程 / 安装目录输入框 / 选择… / 界面缩放
```

「界面缩放」在最右边，小屏幕或窄窗口下会被超长的安装目录输入框挤出可见区域，点不到。

现在：

```text
新建配置 / 打开配置 / 保存配置 / 界面缩放 / 一键生成 / 仅生成工程 / 安装目录输入框 / 选择…
```

- 缩放下拉在「保存配置」右侧；
- 小屏 / 窄窗口也能直接看到、点到；
- 仍然自动记住手动选过的档位（`%LOCALAPPDATA%\Sts2CharForge\ui-scale.txt`）。
