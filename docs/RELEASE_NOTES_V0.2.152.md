# V0.2.152 更新说明

> 回答你报的两条：
> ①「为什么我状态层数达到了，却没生成卡牌」②「自定义状态的某个层数到达 N 时，在游戏中怎么也是 N，
> 而不是填的数」。

## 一、真因：这一档**界面上根本没有 N 输入框**

「触发时机」选到「**某个状态层数到达 N 层时**」时，工具本该在下面出现一个填 N 的框 ——
但判据 `TriggerSupportsAmount` 漏了这一档，于是：

- **N 永远停在默认值 1**：生成出来的是「层数**跨过 1** 那一下触发」（`power.Amount >= 1 && power.Amount - amount < 1`）。
  你按 1 层 → 2 层 → 3 层这样涨上去，它只在你拿到第一层的那一刻触发过一次，**到 N 层时当然不会再触发** →
  这就是①「层数达到了却没生成卡牌」；
- 状态描述（游戏里鼠标悬停那段文字）里印的是下拉菜单那个**字母 N** ——
  「某个状态层数到达 **N** 层时」，你填的数根本没地方写、也没地方显示 → 这就是②「在游戏中怎么也是 N」。

修法：

1. `TriggerSupportsAmount` 补上这一档 → **自定义状态 / 遗物两边的触发时机里都会出现 N 输入框**，
   标题写的是「**到达 N 层（层数跨过这一层那一下触发）**」，下面一行说明写清
   「填 N = 层数跨过 N 那一下才触发（N=3 时：从 0/1/2 涨到 3 或更多的那一次；已经是 3 层再加一层不会重复触发）」；
2. 触发时机那一行 + 游戏里的状态描述里**把填的层数写出来**（「某个状态层数到达 3 层时（盯：自己的××状态）：生成 2 张牌」），
   不再印字母 N；
3. 顺带修一条**盯自己这个状态永远不触发**的坑：生成出来的守卫以前无条件写 `power != this`
   （= 排除这只状态自己）—— 你盯「自己身上的这只状态」时它就永远不成立。
   现在**显式盯到自己这只状态**时会放行（留空 = 任意状态 / 盯别的状态时仍排除自己，免得自己给自己叠层）。
   自己触发自己不会死循环：「跨过 N 那一下」这个判据本身就挡住了（4 层时 `4-1=3` 不 `< 3`，不会重复触发）。

## 二、如果你还看到「数值变成层数」

那是另一个开关：自定义状态页最上面那三个勾选框里的「**数值 = 本状态的层数**」。
勾上之后效果里的「数值」框填什么都**不用**了 —— 用的是触发那一刻的**当前层数**
（所以「生成卡牌」会按当时的层数生成那么多张、伤害也按层数算）。
这一版把这点**直接写在那三个勾选框下面那行灰字里**（以前只在勾选框自己的悬停提示里）。
想用固定数字，把那个勾去掉。
