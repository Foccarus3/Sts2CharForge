# V0.2.333 — 动画页：四个数值改成滑条；预览以「血条中心」为原点；修「改了看不出效果」

## 修的两个问题

1. **「只有点了『预览动画计划』才看到偏移」**：预览的帧列表只在 `SyncAnim()`（保存 / 生成 / 点计划）时才建，
   界面刚打开时列表是空的 → 拖了滑条也不重画。现在**界面一加载 + 切换动作**就重建一次预览。
2. **「偏移会超出预览框」**：原来是给图片套 `RenderTransform`，而外面是 `Viewbox`（它按**布局尺寸**缩放，
   `RenderTransform` 不改布局）→ 图被放大/平移后直接溢出边框被裁掉。
   现在直接改**布局**：画布尺寸 = 帧尺寸 × 缩放 + 血条那一条留白，图片按锚点摆放 —— 永远在框内。

## 四项改成滑条（拖动即时生效）

| 滑条 | 范围 | 说明 |
|---|---|---|
| 缩放 | 0 ~ 5 | 0 = 自动（静态立绘高 ÷ 待机内容高） |
| X 偏移 | -300 ~ 300 像素 | 正数往右，0 = 居中 |
| Y 偏移 | -300 ~ 300 像素 | 0 = 自动（脚落在静态立绘底边） |
| 播放速度系数 | 0.1 ~ 4 | 1 = 原速，2 = 双倍速（预览按它循环播） |

右边实时显示当前数值。

## X/Y 偏移和缩放都相对「血条中心」

预览里的锚点改成：**图片自己的锚点（水平中心 + 脚底再往下 5.4% 内容高）对准血条中心**
（蓝虚线与红条的交点），然后：

* **缩放** → 图以血条中心为原点长大 / 缩小（脚不会被拽跑）；
* **X/Y 偏移** → 图相对血条中心的位移（所以 0/0 就是「动画的目标位置正好压在血条中心上」）。
