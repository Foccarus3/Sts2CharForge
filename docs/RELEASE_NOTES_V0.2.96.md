# V0.2.96 更新说明

> 队列第⑦项**第一批**做完：**次数类的四种数值也能写公式了** —— 生效次数、命中次数 / 对群数、
> 复制的份数、重放次数。写法和「数值公式」完全一样，算出来的次数夹到 1 ~ 20。

## 一、「卡牌」页的效果编辑器多了一块「次数公式」

| 字段 | 用在哪 | 生成出来是什么 |
|---|---|---|
| 生效次数 | 整条效果重复几遍 | `for (int i = 0; i < (int)Math.Clamp(<公式>, 1m, 20m); i++)` |
| 命中次数 / 对群数 | 多段攻击的段数 / 随机挑几个敌人 | `.WithHitCount((int)Math.Clamp(<公式>, 1m, 20m))` |
| 复制的份数 | 「复制卡牌」每张复制几份 | `for (int __copyIdx = 0; __copyIdx < (int)Math.Clamp(<公式>, 1m, 20m); __copyIdx++)` |
| 重放次数 | 「重放卡牌」每张额外打出几次 | `__replayCard.BaseReplayCount += (int)Math.Clamp(<公式>, 1m, 20m);` |

- 写法、参数（`M`/`N`/`X`/`Y`）、内置只读量（`Turn`/`HandCount`/`DiscardedThisTurn`/`PowersOnMe`…）
  和「数值公式」**完全一样** —— 同一套解析器、同一份错误提示；
- 算出来的次数一律**夹到 1 ~ 20**（和固定值那条同样的上限，免得公式算出 999 把一局卡死）；
- 卡面印的是**公式本身**（「重复 Turn 次」「对随机敌人 2 + HandCount 次」），不是那个占位数字；
- 效果列表里那一行会追加「｜ 次数公式 生效次数=Turn / 命中次数=…」；
- 和「= X / = 层数」那几个开关**不能同时用**（都是「改用算出来的值」），校验器会报错。

## 二、只做在卡牌上（和「数值公式」同一条规矩）

次数公式求值要 `__fgPlayer` / `__fgSelf` 那两个局部变量，只有卡牌那条链（以及锻造布上的执行点）会先算它们。
所以遗物 / 药水 / 诅咒 / 自定义状态的触发时机里填了会**报错拦住**，并说明原因 —— 不静默失效。

## 三、为什么「概率」没有公式

本体的概率是「同一张牌里勾了概率的效果**共用一次掷骰**、各占一段区间」
（`ChanceSlices` 按固定百分比算出每条的区间），区间是**生成时**算好的，塞不进运行时表达式。
要做的话得改掉「共用一次掷骰」这个语义，所以这一批先不做 —— 队列里留着。

## 四、配套（这一版一起做的）

- **存档字段**：`EffectSpec.CountFormulas`（一个字典，键 = `Times` / `Repeat` / `Copies` / `Replay`）
  + 四个真属性（`TimesFormula` / `RepeatFormula` / `CopiesFormula` / `ReplayFormula`）
  + 四个「这一行要不要显示」的 bool（界面显隐跟着「= X / = 层数」和效果种类变）；
- **生成**：`CSharpCodeGen.CountFormulaExpr`（复用 `ForgeFormula.CardResolver`）+ 四处发射器改用表达式
  （环上界 / `WithHitCount` / `__copyIdx` / `BaseReplayCount`）；
  卡牌公式的「用到才声明 `__fgPlayer`」那套现在把次数公式也算进去
  （`EmitCardFormulaPrologue` / `AnyCardFormula`），所以**不需要手写变量声明**；
- **回读**：生成时写 `// CET:CountFormulas=Times=<公式>|Repeat=<公式>|…`，`--recover` 按它原样认回来；
- **卡面**：四种次数的文案都改成「有公式就印公式」；
- **校验器**：只做在卡牌上、与「= X / = 层数」互斥、公式能解析、名字要么是自定义参数要么是内置只读量；
- **自检**：17 条新断言（生成出来的表达式逐条钉住、卡面文案、回读往返、
  三条校验器规则、**默认档逐字不变**的红线）；
- **探针**：`_tmp\selfreturnprobe`（`RunCountFormulas`）→ 生成 → 真 `dotnet build` **0 错误** →
  回读四个公式原样、0 条「没认出来」。
