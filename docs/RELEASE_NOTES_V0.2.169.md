# V0.2.169 更新说明

> **这一版把今天修的东西正式收成一个新版本号**（V0.2.168 那个包被反复覆盖了好几次，编号一直没动 —— 是我的问题）。
> V0.2.168 那批逐条写得很细，见 docs/RELEASE_NOTES_V0.2.168.md；这里只列**从 V0.2.167 之后一共修了什么**。

## 一、V0.2.168 那批（内容不变，只是换到 V0.2.169 这个号上）

1. 一块布上可以放**多块【触发时机】**（每块配自己那条链；撞同一个本体钩子会报错拦住）；
2. 状态页「某个状态被移除时」盯**敌人**身上那份自己**完全不触发**（生成端守卫写错）；
3. 卡牌档「被消耗 / 被丢弃 / 被抽到」缺归属守卫（任何一张牌都会触发这张图的链）；
4. 开着「生成调试日志」时锻造图那张卡**编译不过**（日志行尾注释吃掉了后面的语句）；
5. 「次数填 X / Y」在 X 费 / Y 费的牌上只生效一次（改成按「这张牌花掉的那部分」算）；
6. 描述栏里**打回车换行会报错**（CRLF 里的裸 \r 截断 C# 注释）；
7. 状态的「每累计 N 次」把**上状态之前**发生的事也算进去（改成每个实例自己记基准）；
8. 「透镜」不认你的格挡牌（按效果自动声明 GainsBlock）；
9. 「无限升级」升级后不加数值（改成 + 增量 × 当前升级层数）；
10. 遗物两条【触发时机】选「全部满足」时要**触发两次**（改成每段都检查标记，谁凑齐谁跑）。

## 二、这一版新加的（今天追加的几条）

11. **自定义状态里能放「召唤伙伴」**（以前被生成拦住；状态钩子没有 choiceContext 时生成端自己造一个）；
12. 节点图里**「从哪里选牌」**四摞都能用（手牌 / 抽牌堆 / 弃牌堆 / 消耗牌堆 + 牌顶）；
13. 节点图补上 **7 档**卡牌页早就支持的效果：删除卡牌（全局）/ 添加卡牌到牌组 / 变化卡牌（全局）/
    升级卡牌（全局）/ 毒性爆发 / 播放音效 / 播放上传的音频；
14. 节点图里也能用**「强化指定卡牌」**（那条「用到才生成」的判断以前不扫锻造图 → 会 CS0246，所以一直故意拦着）。
