# V0.3.19 — 变量试算框跟着公式走 + 初值里的固定值参数能折

这一版修的是用户截图里那个「公式写 `A+3`，试算框却还是 `0`，点试算得 0」的问题。

## 一、试算框改了公式后不跟着换（真因）

变量页的「试算」框只在**选中变量**时同步一次公式（`OnVarSelectionChanged` → `VarTrialFormula = v.Formula`）。
之后你在「初值 / 取值公式」里把 `0` 改成 `A+3`，试算框仍停在 `0` —— 点「试算」算的是旧公式 `0`，所以 `= 0`。
这不是求值算错，是**界面没同步**。

修法：

* `OnVarSpecChanged` 监听当前选中变量的 `Formula`：如果试算框还停在旧公式上，就跟着换成新公式；
* 公式一改就清空上一次的试算结果，不再让旧结果挂着骗人；
* 自检 +4 条：选中时同步 / 改公式当场同步 / 改完点试算得 `= 5` / 不存在的名字显示「算不出来」。

## 二、初值公式里的「固定数值」参数现在能折

以前 `TryInitialValue` 只认变量，完全不管自定义参数 ——
`a = A+3` 即使 `A` 是「固定数值 = 3」的参数，也会判成「折不出常数」→ 复位 0。

现在初值求值和「试算」共用同一份 `ResolveConst`：

* 变量 → 递归取初值；
* 自定义参数且**取值来源 = 固定数值** → 取它填的数；
* X / Y / 内置读数 / 非固定值参数（最大生命、金币、牌数…）→ 仍按 0，并在界面 / 校验器里说清。

所以 `A` 是固定数值 3 时，`a = A+3` 的初值 / 重置值都是 **6**。

## 三、注意：变量名区分大小写

`a` 和 `A` 是两个不同的名字：

* `A` 是自定义参数（或变量）时，`A+3` 才能算；
* 如果只建了变量 `a`、没建参数 `A`，试算会明确显示
  **「算不出来：「A」不是常数」**，不会再有假的 0；
* 想让变量引用自己（`a + 3`）属于循环引用，校验器会报错 —— 初值不能自己引用自己。
