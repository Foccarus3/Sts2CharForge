# V0.2.151 更新说明

> 回答你报的四条（附了截图）：
> ①「次数公式怎么不见了」②「转变为先古卡和先古遗物怎么选不了范围」
> ③「放置卡牌效果怎么没反应」④「有一部分的UI有问题，会变得如图所示」。

## 一、真因：效果栏的**标签列**把输入列吃掉了

①③④ 其实是**同一个**毛病，和截图完全对得上。

效果栏是一个两列 Grid：第一列是**标签列**（`Width="Auto"` —— 文字多长，这一列就多宽），
第二列是**输入列**（`Width="*"` —— 只能吃剩下的宽度）。而「从哪里选牌」那一行的标签当时写的是：

```
从哪里选牌（消耗 / 变化 / 复制…；选「牌顶」= 抽牌堆最上面那张，不用挑）      ← 34 个字
```

实测（自检里量的）：**标签列被它撑到 570px，输入列只剩 0px** —— 那一整列的输入框全被压成一条缝：

- 「选牌方式」「从哪里选牌」下拉变成一个点不动的细条 → 放置卡牌时选不了「从哪一摞拿 / 放到哪一摞」，
  所以你看着像**「放置卡牌效果没反应」**（③）；
- 「生效次数（公式）」那一格被挤出可视区 → 你看着像**「次数公式怎么不见了」**（①）；
- 换到别的种类（消耗 / 丢弃 / 升级 / 变化 / 复制 / 重放 / 回合结束自动打出 / 给予关键词）也是同一副样子（④）。

**修法**：那一行的标签改回短标签（「从哪里选牌」/「从哪里丢弃」/「从哪里升级」），
详细说明（牌顶是什么意思、三摞牌分别走本体哪个 API）**本来就在那一行下拉的悬停提示里**，一个字没丢。
「选牌方式」那一行的标签同样收短（「消耗 / 变化 / 丢弃用」那句挪进悬停提示）。
自检补了两条守卫（**实测版式**）：卡牌页真的挂上效果栏之后，量那个 Grid 的两列宽度 ——
标签列 ≤ 360 且输入列 ≥ 140；再把所有种类的标签长度也钉住（≤ 8 个字）。
现在实测：**标签列 108px / 输入列 275px**。
反向验证：把长标签改回去 → 自检立刻 **2 条 FAIL**（`标签列=570 / 输入列=0`），改回即 0 FAIL。

## 二、「转化为先古卡」的范围：以前只列自己建的「组」

配对表左边那一栏（「这一行要换哪些牌」）以前**只列你在「自定义参数 / 组」页建的组** ——
一个组都没建时下拉是空的，看着就是「选不了范围」（②）。

生成端其实早就支持「范围限定」那一整套判据（`EmitAncientTranscend` 用的是同一个 `SpawnPoolCond`），
只是界面没给出来。现在那一栏改成和「范围限定」**同一份候选**：

- 内置类型：**攻击 / 技能 / 能力 / 诅咒 / 状态**（不用先建组，选完就能用）；
- 再加上你自己的**「组」**和**自定义关键词组**（原来那两种还在）。

**故意不放「不限」**：一行「不限」会把牌组里能换的牌全换掉，那不是点一行配对表想要的结果
（想全换就按类型选，或者把牌分到一个组里）。那一行下面的红字提示也跟着改成「左边选范围（攻击 / 技能 /
能力 / 诅咒 / 状态，或你在「自定义参数 / 组」页建的组）」。

「转化为先古遗物」的「要换掉哪个遗物」本来就有范围（不限 / 只换初始遗物 / 按遗物类名）——
如果你那台机器上这个下拉也是空的，把截图发我，我再查一遍（它的候选来自本体遗物类名表，
读不到解包工程 / 游戏目录时才会是空的）。
