# V0.2.117 更新说明

> 这批需求里的第 ⑩ 条：**多个触发时机可勾选「同时满足才触发」**（按你选的做法：同一状态的几条时机勾上 +
> 选重置范围「本回合 / 本场战斗」）。

## 一、怎么用

「自定义状态」页 → 选中一个状态 → 在**某一条触发时机**那一块里，勾上：

> ☑ **要和其他时机同时成立（都成立才触发）**

把**参与的那几条时机都勾上**，它们就变成「**都在同一个窗口里成立过**才触发」。下面还会多一行
「**重置范围**」：

| 重置范围 | 意思 |
|---|---|
| **本回合**（默认） | 每个回合重新凑一次（换回合自动清零） |
| **本场战斗** | 整场战斗里凑齐一次就够（状态本来就是每场战斗一个新实例，天然重置） |

例：想做「本回合既打出过牌、又受到过伤害，才获得 2 点格挡」→ 加两条时机：「打出一张牌后」+
「自己受到伤害后」**都勾上**，效果写在其中一条上（比如格挡写在「打出一张牌后」那条）。

**语义（说清楚，免得踩坑）**：参与的那几条时机各自照常判断自己那件事；每成立一条就打个标记，
**最后凑齐的那一条**会跑它自己的效果，然后把这一轮的标记清掉 —— 所以**一个窗口只触发一次**，
「两条上都写同样的效果」也**不会**触发两次。想「凑齐后做一件事」，效果写在其中一条上最省事。

## 二、生成出来是什么样

```csharp
// 「要和其他时机同时成立」：这几条时机各自照常判断自己那件事，谁成立了就打个标记；
// 最后凑齐的那一条才会跑它自己的效果，然后把这一轮的标记清掉（一个窗口只触发一次）。
// 窗口 = 本回合（换回合按回合号自动清零）。
private bool __andHit0, __andHit1;
private int __andTurn;   // 上一次记下的回合数（变了就清标记 = 本回合窗口）

// 每条参与时机的钩子里：
if (base.Owner.Player?.PlayerCombatState is { } __andPcs && __andPcs.TurnNumber != __andTurn) {
    __andTurn = __andPcs.TurnNumber;   // 新的一回合：把「同时成立」的标记清掉
    __andHit0 = false; __andHit1 = false;
}
// CET:RequireAll=1 CET:AndScope=Turn
__andHit0 = true;
// 参与的那几条时机在同一个窗口里都成立过了
if (__andHit0 && __andHit1) {
    ...这条时机自己的效果...
    __andHit0 = false; __andHit1 = false;   // 这一轮用掉了，下个窗口重新凑
}
```

- 标记只在**那条时机真的成立**的时候才打（在它自己的守卫 / 数值门槛里面），所以「打出一张牌后」
  只在真的打牌时算成立；
- 「本回合」按**回合号**自动清零，不需要额外的重置钩子；「本场战斗」连回合号都不需要；
- **没勾这个设置的状态生成结果一个字符都不变**（红线照旧）：一个 `__andHit` 都不会出现。

## 三、校验 / 回读

- 校验器：**只有 1 条时机勾了它** → 提示「没有别的时机和它凑，这条设置**不生效**」（照旧每次都触发）；
- 回读：每条参与时机的实现里写了 `// CET:RequireAll=1 CET:AndScope=<范围>`，
  从工程恢复时按它把「勾选」和「重置范围」原样认回来。
