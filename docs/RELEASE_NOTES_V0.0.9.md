# Sts2CharForge V0.0.9

杀戮尖塔 2 自定义角色生成器。这一版主要修「图标 / 美术怎么都不生效」这类问题，全部改动都在工具与生成的模组代码里，**不动游戏本体**。

> 本工具不含任何游戏素材：生成模组时会读取你本机已购买安装的游戏（安装目录 + 你自行解包的原版工程）里的资源。默认使用中性占位图。

| 已经有旧版整合包 | `Sts2CharForge-update-V0.0.9.zip`（显示为「更新包」，约 60 MB）—— **只有程序文件 + 启动器**，解压覆盖到原来的根目录即可，环境包 / 教程 / GDRE 工具都不用动 |

## 这一版修了什么

**1. 额外资源量（自定义资源计数器）还是本体的星星图标**
补丁加了三层兜底：① 计数器建好、设置归属两个时机之外，**每帧对比一次贴图**，别的模组（BaseLib / RitsuLib 会接管节点）把它改回本体星星时会再贴回来；② 归属判断除了标记还会**反射读本体记的 player**，`Initialize` 那条补丁没走到也认得出来；③ 战斗界面建立时按「谁在用本体那颗星星的贴图」整屏兜底，**跟计数器是什么类无关**，只改我们自己角色的战斗界面。

**2. 上传了自己的能量图标，左侧那个能量球还是本体美术**
以前只把本体 5 层球贴图按你上传图的**色相**重新着色 —— 上传图本来就偏橙时改完几乎没区别。现在**直接把球体换成你上传的图**（缩到 128×128），本体另外 4 层隐藏，粒子光效仍按色相着色。

**3. 某张牌（例如「大奖」）的描述字体变得非常小**
卡牌描述里的能量图标是**内联图片**，本体规定 24×24，游戏按原图尺寸绘制。上传 512×512 会被原样塞进 `sprite_fonts`，内联图把整段描述撑爆，字号自适应就把字缩成蚂蚁字。现在**自动缩放**：文字内联 24×24、`ui_atlas` 精灵 74×74、能量球 128×128、额外资源量的内联小图标也 24×24。任意尺寸的上传图都不会再撑爆排版。

**4. 上传的美术图片，重开生成器就变回「占位」、要重新上传**
两个原因叠加：
- 选完图片以前只改内存，不点「保存配置」就关程序 → 全丢。现在**选完立刻写进存档**（角色美术槽位、逐张卡面、遗物 / 药水 / 状态图标、额外资源量图标都一样），清除与撤回也立刻落盘。
- 更隐蔽的一个：载入存档时顺序写反了（先 `SyncArt` 把界面槽位写回配置、再 `RefreshAll` 把配置读进界面），于是刚载入的存档里的 7 个美术路径会被上一个存档的空白值**当场覆盖**；而「逐张卡面」在另一个字段里不会被覆盖 —— 所以现象是「卡面还在、那 7 个槽位每次打开都变回占位」。现在改成「先把槽位读进界面、再写回配置」。

**5. 「保存配置」还要选路径**
现在直接保存进**当前打开的那份存档**，不再弹路径选择。只有「模组 ID」和当前存档文件名不一样时才问一次要不要改名，答「否」就仍然保存进原文件、本次运行不再问。关窗口时那句「要保存吗」也走同一条路。「另存为新存档…」保留路径选择（那是显式另存）。

**6. 其它**
- 「用当前配置覆盖该存档」覆盖完会把「当前存档」切到被覆盖的那一份（以前接着点保存会写回上一份）。
- exe 文件属性里的中文以前是乱码（csproj 被双重编码），已修。
- 「环境自检」报告现在会列出「美术资源槽位 + 每张卡面」的已上传状态，自查图标问题时一眼能看出。

## 用法速览

1. 解压后运行「启动 Sts2CharForge_V0.0.9」（`.bat` 或 `.lnk`）
2. 首次在「环境自检」页按提示指定：解包后的原版工程目录（用 `！首次使用先点这个！` 里的 GDRE 工具解包）
3. 配好角色 / 卡牌 / 遗物 / 药水 / 美术 →「① 一键生成 · 构建 · 安装」
4. 存档在根目录「自定义角色存档」里（跟程序分开，覆盖更新程序不会碰到它）
