# V0.2.286 — 「猩红创痕」变化效果数值 0 卡死

## 你报的

> 猩红创痕这张牌 / 变化效果数值给 0 会卡死

## 定位（用你的 `CarmenMod.json` 复现）

「猩红创痕」`CarmenCrimsonScar` 的**锻造图**里有一块【变化卡牌】模块，**数值 = 0**，生成出来是：

```csharp
var __fgSel761114 = (await CardSelectCmd.FromHand(context: choiceContext, player: __fgPlayer,
        prefs: new CardSelectorPrefs(base.SelectionScreenPrompt, (int)((0m))), ...)).ToList();
```

`CardSelectorPrefs(提示, 0)` —— 本体这个选择界面会**一直等一个不可能成立的确认**（要选 0 张、但界面最小是 1 张），
所以点下去就卡死。升不升级两份图里各有一块，所以两种状态都会卡。

## 修法

锻造图的这条路上加了守卫：**「取几张」是字面 0 → 这个效果模块整块跳过**（写一句注释，不弹界面、不做事）：

```csharp
// fg:15d3c5febd704a8ca63de45d99f269b0【变化卡牌】取 0 张：这条效果什么都不做（选 0 张会让本体的选择框一直等待 → 卡死）
```

范围有讲究（自检抓到并纠正了一次）：

| 生效 | 不生效 |
|---|---|
| 【变化卡牌】【变化卡牌（全局）】【升级卡牌】【刮削】 —— 这几档 0 张必然要弹选择框 | 【复制卡牌】【生成卡牌】—— 这两档 **0 有专门含义**（= 这张牌自己），跳过就错了（V0.2.226 的断言当场报出来） |

只认**字面 0**（`0` / `0m` / `(0m)` / `(int)((0m))`）；公式和变量一律不算，生成文本与旧版逐字一致。
