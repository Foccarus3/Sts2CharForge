# V0.2.213 —— 「变化卡牌」补上「取几张」+ 能限定「只变化哪些牌（类型 / 组 / 指定的那张卡）」

> 来源：用户实测「变化卡牌没有取几张这个选项，也没法选择目标卡或者组内的牌进行变化」。

## 1. 两件真事，各修一处

### ① 锻造页上「变化卡牌」看不到「取几张」

`ShowCountModeRow`（「取几张」那一行的显隐）以前分两条链判：

```csharp
IsForgeChain ? UsesCountMode : EffectFieldPolicy.UsesCountMode(Kind)
```

`UsesCountMode` 是**旧的 6 种清单**（消耗 / 丢弃 / 升级 / 从三摞拿牌），里面**没有**变化卡牌 ——
可锻造链的生成端读的就是同一个 `CountMode`（`ForgeGraphGen.CountModeMarker` + 共用的选牌 prefs）。
结果：锻造页上「变化卡牌 / 复制 / 重放 / 放置卡牌 / 给予关键词 / 三种全局牌组」都填不了「取几张」，
而卡牌页上这些是有的。现在两条链按**同一份判据**摆（`EffectFieldPolicy.UsesCountMode`）。

### ② 变化卡牌没法限定「挑哪几张去变」

以前「变化卡牌」只有「从哪里选牌 + 取几张 + 自己选/随机」，**整摞牌**里挑到谁全看玩家；
而且它上面那个「范围限定（随机出什么）」管的是**变成什么**，不能拿来当「变哪些」用
（同一个字段两重意思会让老存档静默变行为）。

现在新增两栏（**只**在「变化卡牌」上出现，就在「范围界定」下面）：

| 栏位 | 含义 | 候选 |
| --- | --- | --- |
| **变化哪些牌（范围）** | 只把这一档的牌拿去变 | 不限 / 攻击 / 技能 / 能力 / 诅咒 / 状态 / 每个「自定义关键词」那一组 / 每个**卡牌组** |
| **只变化这张卡** | 只变这一张（填了它就以它为准，上面那一栏不生效） | 可搜索的卡牌列表（和「目标卡」同一份候选） |

生成出来的效果（三条挑牌路径全都套上）：

```csharp
// 自己选：直接把范围当成选牌过滤条件
var toTransform = (await CardSelectCmd.FromHand(context: choiceContext, player: base.Owner,
    prefs: new CardSelectorPrefs(CardSelectorPrefs.TransformSelectionPrompt, 1),
    filter: c => c.Type == CardType.Attack, source: this)).ToList();

// 取几张 = 全部：在候选牌上先筛
foreach (CardModel c in PileType.Draw.GetPile(base.Owner).Cards
    .Where(c => c.Id == ModelDb.Card<…Accuracy>().Id).ToList()) { … }
```

「从范围里自己挑一张（变成什么）」那条路同样生效。**两栏都空 = 和以前一模一样**
（生成文本逐字不变，回归红线，对拍已证）。

其它配套：

- 卡面描述会补一句「（只变化：攻击）」/「（只变化打击）」，玩家看得出它只动某一类牌；
- 生成时写一行 `// CET:ChangePick=… CET:ChangeCard=…` 标记 —— **从工程恢复存档**时认得出这两栏
  （它们是生成期折成显式条件的，从代码反推不回来）；
- 列表摘要也会显示「｜ 只变化：…」。

## 3. 用法提醒

- 「只变化某一张卡」= 「只变化这张卡」选它；
- 「只变化某一组牌」= 「变化哪些牌（范围）」选那个**卡牌组**（卡牌页可以给牌勾「卡牌组」）；
- 「把牌组里的攻击牌全变掉」= 从哪里选牌 = 手牌 / 抽牌堆、**取几张 = 全部**、变化哪些牌 = 攻击。
