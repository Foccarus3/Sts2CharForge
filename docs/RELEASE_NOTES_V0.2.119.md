## 一、修好：选「放置卡牌」时编辑器底下全都无法选择和填写

**根因**：效果编辑器那块模板的 Grid 只声明了 **15 行**（0~14），而「召唤物（哪一只）」在 `Grid.Row=15`、
新加的「放到哪一摞」在 `Grid.Row=16` —— **越界的行会被 WPF 夹到最后一行**，于是这几块控件**叠在同一格里**，
上面的把下面的输入挡掉了（点不到、也填不了）。

**修法**：把行定义补齐到 17 行（0~16），两个越界的行各归各位。自检里加了一条**真的去比坐标**的用例：
选中一条「放置卡牌」的效果后，「数值」和「放到哪一摞」两行的 Y 坐标必须不同
（现在是 `数值Y=659.2 / 放到Y=987.4`；修之前两者同格）。

## 二、找得到：「多个触发时机同时成立」在哪勾

它在**「自定义状态」页 → 选中一个状态 → 下面时机列表里选中某一条时机 → 那条时机的编辑器里**，
勾选框写的是「**要和其他时机同时成立（都成立才触发）**」，把参与的那几条**都勾上**即可；
勾了 2 条以上才会多出「**重置范围**」（本回合 / 本场战斗）。

这一版在**时机列表正下方**加了一句指路的话（原来只有「同一个状态可以配好几个时机…」那一句）：
> 想让几条时机「都在同一个窗口里成立过才触发」？选中下面列表里的时机 → 在它编辑器里勾
> 「要和其他时机同时成立（都成立才触发）」，把参与的那几条**都勾上**即可。

并加了自检：那个勾选框必须**可见、可用**，勾了 2 条时「重置范围」那一行必须看得见。
