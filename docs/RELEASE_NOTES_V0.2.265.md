# V0.2.265 — 音频也能加入组 + 「仅能被下个同组音频顶替」

## 你要的三件事

> 音频也能加入组，并且音频效果下新增勾选项「仅能被下个同组音频顶替」，
> 确保这个勾选项不会重叠导致看不见，以及在组那边确实能看到音频能加入组

## ① 组页面新增第三列：「这个组里有哪些音频」

「组」页右边现在有三列：

```
┌ 组名 / 备注 ──────────────────────────────────────────────────────┐
├────────────────────┬──────────────────┬───────────────────────────┤
│ 这个组里有哪些牌    │ 这个组里有哪些状态 │ 这个组里有哪些音频（橙字） │
└────────────────────┴──────────────────┴───────────────────────────┘
```

* 候选 = 「美术资源」页上传的每个音频（一行显示 `名称 ｜ 文件名`）；
* 勾上就写进这个组的 `AudioIds`（存的是音频 Key，也就是「播放音频文件」效果里存的东西）；
* 已加入但「美术资源」页里已经没有的音频会照旧列出来（方便取消勾选）；
* 切组 / 组改名 / 勾选变化都会重新算（不会像上次那样停在空列表）。

## ② 「播放音频文件」底下新增勾选：「仅能被下个同组音频顶替」

位置：效果编辑器里，紧跟在「会被下一个自定义音频顶替」下面**单独一行**（只有「播放音频文件」这一档可见）。

两个勾一起用时：

| 勾法 | 行为 |
|---|---|
| 都不勾（默认） | 每段音频各自开播放器，可以叠着响 |
| 只勾「会被下一个自定义音频顶替」 | 任何下一段自定义音频都能把它停掉 |
| 两个都勾 | **只有和它同属一个组的音频**才能把它停掉（同组 = 两个音频至少同属一个组；同一段音频自己重播也算） |

> ⚠ 只勾「仅同组」而不勾「会被顶替」时它永远不会被停 —— 校验器会提示；
> 勾了「仅同组」但那个音频没进任何组 —— 校验器会警告（等于不会被顶替）。

## ③ 不会重叠、不会看不见

上次那个「重叠」是行号写到网格外面（WPF 把超出的行号折回最后一行）。这次：

* 这个网格**真的多加了第 19 行**（`RowDefinition`），勾选框落在**第 18 行整行**（跨两列）；
* 和「清除指定状态 → 或者清空一个组」那一行完全不挨着；
* 自检里那条「效果栏是两列 × N 行」的断言也一起放宽了（>= 17 行）。
