# V0.2.271 — 自定义参数新增「牌组里某种牌的数量」（范围含自定义关键词 / 组）

## 你要的

> 自定义参数页增加牌组里某种牌数，某种可以选择范围包括自定义关键词和组

## 新增来源：`牌组里某种牌的数量`

设置方式：自定义参数页 → 选中一个参数 → **取值来源** 选「牌组里某种牌的数量」，
下面会多出一栏 **「数牌组里的哪种牌」**，候选就是你在别处见过的那一整份**范围限定**：

| 候选 | 说明 |
|---|---|
| 不限 | 整副牌组多少张 |
| 攻击 / 技能 / 能力 / 诅咒 / 状态 | 按牌型数 |
| 自定义关键词：xxx | 你在「自定义关键词」页加的那些 |
| 组：xxx | 你在「组」页建的那些（含本体牌，如果你把本体牌加进了组） |

* 数的是**牌组**（`Deck`，跨战斗那一副），不是战斗里的抽牌堆；
* 这个来源属于「自己专属」，所以不会出现「从谁身上取」那一栏（和 V0.2.267 那条规则一致）；
* 出现在参数列表里时读作：`Z= ｜ 牌组里「攻击」的牌数`。

## 生成出来的是什么

```csharp
// 不限
(decimal)(__fgPlayer.Deck.Cards.Count)
// 内置牌型（攻击）
(decimal)(__fgPlayer.Deck.Cards.Where(__fgC => __fgC.Type == CardType.Attack).Count())
// 组 / 自定义关键词（游戏里没有对应枚举 → 生成期就把成员解析成类名清单）
(decimal)(__fgPlayer.Deck.Cards.Count(__fgC => __fgC is SevenSlash or SevenGuard))
```

关键词和组走的是和「生成卡牌的范围限定」**同一份**查表逻辑（`EffectCatalog.CardGroupCards` /
`KeywordGroupCards`），所以「组里有哪几张」永远只有一份口径，不会两边漂移。
