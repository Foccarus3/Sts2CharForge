# V0.2.82 更新说明

> 这一版两件事：① 你点名的「**丢弃卡牌：数值 0 = 丢弃这张牌自己**」；
> ② **额外资源量的自定义描述** + 修掉「资源不够时显示的还是辉星」。

## ① 「丢弃卡牌」数值 0 = 丢弃这张牌自己

你说的那个档位加了（**只有「丢弃卡牌」**加了，消耗卡牌仍然是「数值 = 张数，0 = 不生效」——
想消耗这张牌自己用卡牌页的「消耗」关键词）：

- 数值 **0** → 生成 `await CardCmd.Discard(choiceContext, this);`（不挑牌、没有张数）；
- 数值 **1~9** → 和以前完全一样（自己选 / 随机、手牌 / 抽牌堆，走 `CardSelectCmd` + `CardCmd.Discard`）；
- 那一档界面上会把「**选牌方式 / 从哪里丢弃 / 范围界定**」三行藏起来（它根本不挑牌，留着只会让人以为在生效）；
- 卡面写「丢弃这张牌自己。」；这一档**不声明 `Cards` 变量**（没有数字可显示），
  所以填了「升级增量」不生效（配置检查会提醒）；
- 从工程回读按标记行认回来，而且实现那一句不会被多回读成第二条「丢 1 张」（探针实测：3 条效果进来、3 条出去）。

顺便说明一下你之前担心的那件事：「数值 0 = 不生效」这条规矩**没有**误伤 0 有含义的那些档位 ——
召唤伙伴（0 = 用「召唤物」页配置的血量）、给予卡牌关键词（0 = 这张牌自己）、
回合结束时自动打出（0 = 这张牌自己）、按生命值算的伙伴攻击 / 牺牲伙伴（0 是常态）
都是在生成端**显式排除**的，不会被丢掉；这一版又把「丢弃卡牌 0 = 自己」加了进去。

## ② 额外资源量：自定义描述 + 「资源不够」那句提示

**(a) 自定义描述**：「额外资源量 / 状态」页新增「**自定义描述**」输入框。

- 留空 = 工具自动写（`<名字>：每场战斗开始时获得 N 点…；打出需要消耗它的牌时会扣除…`）；
- 填了 = **原样**用它（上传了图标的话，这段文字前面会自动补一张 24×24 的内联小图 —— 除非你自己写了 `[img]`）；
- 这段只出现在**你自己角色**的计数器上（补丁按「这个计数器归谁」判断），联机时别人看到的还是他自己的。

**(b) 「没用足够的额外资源量时显示的还是辉星」——根因和修法**：

那句提示是**思考气泡**里那行字，来自本体的**全局**本地化键
`combat_messages.NOT_ENOUGH_STARS`（`"我没有\n足够的[red]辉星[/red]。"`），
由 `UnplayableReasonExtensions.GetPlayerDialogueLine` 返回、在 `NMouseCardPlay` / `NControllerCardPlay`
里弹出。工具以前从来没碰过它，所以换了资源名也还是印「辉星」。

这一版改成（和「本体状态改名」「额外资源量悬停提示」同一套思路）：

1. 写**我们自己的键**：`<角色>_EXTRA_RESOURCE.notEnough` = `我没有\n足够的[red]<你的资源名>[/red]。`
   （新文件 `localization/zhs/combat_messages.json`，和本体同名文件**逐键合并**，本体的键一个字都不动）；
2. 生成一个补丁，**只在「这一局玩的是我方角色」时**把返回的 LocString 换成我们那个键。
   本体那个类是 `internal` 的（编译期连 `typeof` 都写不出来），所以目标方法用
   `AccessTools.TypeByName` 按名字找、补丁在模组入口里**手动打**并包在 `try/catch` 里 ——
   找不到时只丢这一句提示（日志里一条警告），绝不影响模组加载和其它补丁。

**顺带修的**：额外资源量换图标时，以前把卡面 `%UnplayableStarIcon` 也一起换掉了 ——
那个节点不是星星，是本体「这张牌打不出去」的**叉号**。现在只换 `%StarIcon`（星费那个图标）。
