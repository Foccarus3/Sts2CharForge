## 一、「取卡方式」四档（生成卡牌 / 变化卡牌 / 加牌进牌组（全局）/ 变化卡牌（全局））

以前这一栏在节点图里**被校验器报错拦住**（「节点图只能生成『目标卡』那一栏指定的那张卡」）。
现在四档全都真的能用：

| 档位 | 生成卡牌 | 变化卡牌 | 加牌进牌组（全局） | 变化卡牌（全局） |
|---|---|---|---|---|
| 指定卡（默认，老存档） | ✔（老路径，文本一个字没变） | ✔ | ✔ | ✔ |
| 按范围随机 | ✔ | ✔ | ✔ | ✔ |
| 按范围随机 + 多选 1（候选 M 张选 1） | ✔ | ✔ | ✔ | ✔ |
| 按范围随机 + 从范围里自己挑一张 | ✔ | ✔ | ✔ | ✔ |

做法：**复用「卡牌」页已经写了很久的那几份发射器**（`EmitGenerateCard` / `EmitTransformCard` /
`EmitGlobalCardEffect`），只是把它们里面写死的上下文（`base.Owner` / `choiceContext` / `this`）
开成了参数，节点图传 `__fgPlayer` / `__fgSelf` / `ctx.ChoiceVar` —— 一份实现两条链共用，不会再慢慢长歪。
「多选 1 / 自己挑」的候选界面照本体的规矩：候选 ≤ 3 张走 `FromChooseACardScreen`，
> 3 张走「简单网格」（本体「抉择悖论」同款）；候选为空时整条跳过，绝不用一张空界面等玩家。

恰好 N 张（默认）/ 最多 N 张 / 任意张 / 全部 —— 上一批（V0.2.169 之前）已经做完，这一版一起发。

## 三、「下回合生效」铺到**全部做得了的种类**

以前节点图只有「获得格挡 / 抽牌 / 施加状态」三种有延迟分支，别的种类勾了会被**静默降级成立即生效**
（只写一行注释）。现在：

* 除本体**没有延迟落点**的那 8 种（播放音效 / 播放上传音频 / 结束回合 / 自己变便宜 / 抽到就减费 /
  刮削 / 回合结束时自动打出 / 获得额外回合）之外，**每一种都走真的延迟分支**，
  和「卡牌」页同一套：打出时只挂一个延迟状态，下回合开始时它跑**同一套发射器**；
* 「获得格挡 / 抽牌」仍旧用本体现成的 `BlockNextTurnPower` / `DrawCardsNextTurnPower`；
  「获得能量 / 额外资源量」用本体现成的 `EnergyNextTurnPower` / `StarNextTurnPower`
  （能量填负数时用生成的「下回合少 N 点能量」负债 Power）；
* 那些延迟状态类是**用到才生成**的 —— 这一版把「锻造节点图里的效果」也算进了
  `CSharpCodeGen.CollectDelayedEffects`（漏了就是 CS0246，探针真编译抓出来的）。

## 四、要「打出这张牌」那一刻上下文的几种

* **重放卡牌**：给牌堆里的牌加本场战斗的重放次数（候选先筛掉打不出去的 / 已经有重放的；
  「全部 / 最多 N / 任意张」都认）。
* **回合结束时自动打出**：现在就把牌选好，交给生成的 `ForgeTurnEndPlayPower`，
  它在回合结束那一步逐张 `CardCmd.AutoPlay`。数值 0 = 「这张牌自己」（只有卡牌档有「自己」）。
* **将此牌放回手牌**：节点图里它是**内联**生成的（卡牌页那份是写在 `AfterCardPlayedLate` 钩子里的，
  节点图的钩子由【触发时机】决定）⇒ 必须挂在「**这张牌被消耗时 / 这张牌被丢弃时**」这类
  「牌已经不在手牌里」的时机上；挂在「打出一张牌时」上时这张牌还在手牌里，
  而且本体是打完牌之后才把它放进弃牌堆的，搬回去会被那一步覆盖 ——
  这种挂法校验器会给**警告**说清（不是静默不生效）。
* **斩杀条件**：图里用【条件】模块选「斩杀」时，序幕里补上 `__lastAttack` / `__fatalOk`
  两个变量、每条「造成伤害」都把攻击结果记进去（和卡牌页同一份写法）。
  只有**卡牌**档 + 拿得到 `cardPlay` 的时机才成立：遗物 / 药水档**报错**拦住，
  挂在「被消耗 / 被丢弃」这类拿不到 `cardPlay` 的卡牌时机上给**警告**。

## 五、这一批真编译抓出来并修掉的 4 个坑

1. 同一条链上放两个同类效果（例：一个「变化卡牌」+ 一个「变化卡牌（全局）」）会在同一个方法里
   重复声明固定的局部变量名（`__transformPool`）⇒ **CS0128**。修法：节点图里每一段复用的效果
   都包一层 `{ }` 块作用域（各效果自己的局部变量互不干扰，文本只多两行花括号）。
2. 「下回合生效」挂延迟状态时 Apply 的第 4 个实参要的是 **Creature**，节点图传了 Player ⇒ **CS1503**。
3. 节点图「获得能量 + 下回合生效」去引用一个**根本不会生成**的延迟类（`…ForgeDelayedPower`）
   ⇒ **CS0246**（那个类名只有卡牌页那套判据会生成）。
4. 节点图里的「回合结束时自动打出」漏在「用到才生成」名单外 ⇒ `TurnPlayEndPower` **CS0246**。
