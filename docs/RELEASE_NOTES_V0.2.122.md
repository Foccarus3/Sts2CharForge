# V0.2.122 更新说明

> 两件事：**遗物页现在能挂多条触发时机**（第 10 批 ①，用户要求），以及**修掉一个会把生成整个拦住的误报**
>（你的 Stelle 角色就撞在它上面）。

## 一、修掉：自检误报「引用了没有声明的动态变量」，把生成拦住了

**症状**：点生成弹「生成被拦住了，所以没法构建…… StelleCard3 → Damage；StelleCard34 → Block……」

**真相**：**生成出来的代码是好的**，是那条自检自己认错了变量名。

- 生成出来的声明长这样：
  `new ForgeFormulaDamageVar(static (card, target) => (… PowerAmount(…, "StellePower4") …), 1m)`
  —— 公式里引用了**自定义状态的类名**（你的参数 A / B 就是「某状态的层数」）；
- 自检取「变量名」的老写法是「**这一项里随便哪个带引号的字符串**」→ 把 `"StellePower4"` 当成了变量名 →
  于是认为 `Damage` / `Block` 没声明 → **误报**并拦住生成。所以只有「公式里引用了状态」的那几张卡中招；
- **修法**：只认「构造函数**第一个参数**就是字符串」的写法（`new DamageVar("Damage2", 3m)` 这种），
  公式 lambda 里的字符串不再参与。

**用你的存档实测**：修前 `生成成功 = False` + 那 3 张卡报错误；修后 `生成成功 = True`、三张卡自检全过。

## 二、遗物页现在能挂多条触发时机（第 10 批 ①）

- 遗物页右侧改成：**触发时机列表**（+ 添加 / 删除时机）→ 选中一条 → 在它自己的编辑器里配
  **这条时机独有的效果**、盯哪个状态、到达 N 层 / 每 N 次、统计范围、只对哪类牌生效；
- 勾 **「要和其他时机同时成立」**（和「自定义状态」页同一套语义）：勾了 2 条以上会出现「重置范围」（本回合 / 本场战斗）；
- 生成端**按钩子分组**：两条时机落在同一个本体钩子上时只写一个 override（各自包守卫，不会 CS0111）；
  回读会把每个钩子各自认成一条时机；
- **老存档逐字不变**：原来的单时机字段（`Trigger` / `Effects` / 盯哪个状态 / 数值 / 只对哪类牌）
  现在是「列表里第 1 条」的代理，只有一条时机时走的还是原来那条生成路径，描述与校验消息一字不变。
