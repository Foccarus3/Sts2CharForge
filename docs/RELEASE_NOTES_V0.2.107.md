# V0.2.107 更新说明

> 你问「遗物和状态的触发时机里，在哪填触发时机里的数值」——查了一遍，**那一栏确实在界面上，
> 但有个坑：在编辑器里把「触发时机」换掉之后，它不会当场出现**（得重新在左边列表里点一次遗物 /
> 状态才看得到）。这一版把它修好了，并把位置写进了说明。

## 一、修好了：换完触发时机，数值那一栏**当场出现**

「触发时机上的数值」那一栏（`每累计几次触发` / `花掉多少点触发` / `伤害至少多少才触发` …）
本来就是跟着触发时机**算出来**要不要显示的。问题是：换触发时机时只通知了界面刷新「盯哪个状态」那两栏，
**没通知**这一栏的显隐 / 标题 / 说明 —— 所以：

- 遗物页：新建的遗物默认「玩家回合开始时」（没有数值），换了「打出一张牌后」那一栏**不出来**；
- 状态页：换成「某个状态层数到达 N 层时」时，说明里写着「N 填在下面那栏」，但**下面没有那栏**；
- 只有重新在左边列表里点一次那只遗物 / 那个状态，编辑器重建了一遍，那一栏才出现。

现在 `RelicSpec.Trigger` / `PowerTriggerSpec.Kind` 的 setter 会一并通知
`ShowTriggerAmountField` / `ShowTriggerScopeField` / `TriggerAmountLabel` / `TriggerSpendHint`
（状态那边还有「到达 N 层」用的 `NeedsAmount`），换完时机**立刻**出现 / 换标题 / 收起来。
数值本身（`TriggerAmount`）改动也会刷新下面那句说明。

**为什么以前的自检没抓到**：那批断言只测了「属性算得对不对」（`new RelicSpec { Trigger = "CardPlayed" }.ShowTriggerAmountField`），
**没有真的去动界面上那个下拉**。这一版补了会**真的打开遗物页 / 状态页、真的改那个下拉**的用例
（用 `IsVisible` 判「这一行到底显示没有」—— `TextsIn` 连折叠掉的文字都会收，会被骗过），
先在修之前跑出 2 条 FAIL、修完转 PASS。

## 二、位置写进说明（回答「在哪」）

README 与「使用说明」里新增一节「触发时机上的数值（每 N 次 / 每 N 点 / 数值 ≥ N）**填在哪**」：

> 📍 就在**「触发时机」那个下拉的正下面**（遗物页在「遗物属性」里；状态页在「触发时机」那一块里、
> 每条时机自己的下方）。这栏**只在有数值可填的时机上出现**：选了战斗开始/结束、回合开始/结束、
> 获得遗物时这种没有数值的时机，它整栏都不显示。

| 触发时机 | 那一栏的标题 | 还带什么 |
|---|---|---|
| 打出一张牌后 / 消耗 / 丢弃 / 抽到 / 生成卡牌时 | **每累计几次触发** | 「统计范围」本回合 / 本场战斗 |
| 一个敌人死亡后 | **每累计几次触发** | 本场战斗内计数 |
| 花掉能量后 / 花掉额外资源量后 | **花掉多少点触发** | 「统计范围」 |
| 受到伤害后 / 造成伤害后 | **伤害至少多少才触发** | — |
| 自己失去生命时 / 获得格挡后 | **…至少多少才触发** | — |
| 某个状态层数到达 N 层时 | （不在这栏）**到达 N 层**，在它自己那一行 | 配合「盯哪个状态」 |

留空 / 填 0 = 老行为（每次都触发）；这栏只能填数字（公式只做在卡牌上）；状态可以配好几条时机，
每条各有自己的一份数值。
