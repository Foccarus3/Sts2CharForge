# V0.2.285 — 锻造新增【While】循环模块；以后只出更新包（不打整合包）

## ① 锻造页新增【While】（按你选的方案 A）

模块面板「流程」里多了一个紫色模块：

```
【while】条件成立就一直重复执行「循环」那条子链；条件每轮重新求值。
```

* 左边两个入口：**接入**、**条件**（接【条件】/【且】/【或】/【关系符】的结果）
* 右边两个出口：**循环**（每轮跑这条子链）、**结束**（循环之后继续走这里，可不接）

生成出来（探针实测原文）：

```csharp
// 【while】条件成立就一直跑「循环」那条子链（最多 50 轮，防卡死）
int __fgLoopGuard = 0;
while (条件) {
    if (++__fgLoopGuard > 50) { Log.Warn("[模组调试] 【while】跑了 50 轮还没结束，强制跳出（检查你的条件）"); break; }
    { ...「循环」那条子链... }
}
{ ...「结束」出口那条链... }
```

要点：
* **有 50 轮硬上限**：玩家的条件很容易永远成立（「我还活着」之类），没有这个上限会整局卡死；
* 条件**每轮重新求值**（不是进循环前算一次），所以「手上还有牌」这类条件能正常收敛；
* 不接「循环」出口 = 这一块什么都不做（图里会写一句注释）；「结束」不接 = 循环跑完就结束，合法。
