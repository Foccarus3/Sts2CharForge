# Sts2CharForge V0.2.51

> 这一版修**两个「不报错、但配了等于没配」的问题**，另外把「动画」页的署名改成醒目样式。功能与 V0.2.50 一样。

## 修了什么

### ① 自定义状态触发器里「施加状态 / 施加增益减益」填负数，语义和其它地方不一致

之前在这里填 **-3**，生成出来的是「**给目标挂一个 -3 层的新状态**」；
而卡牌 / 遗物 / 药水里填 -3 是「**扣掉目标身上已有的 3 层**」。同一个数字、两种意思 —— 现在统一了：
**填负数一律是"扣除目标身上已有的层数"**（目标身上没有这个状态时什么都不做）。
生成前如果填了负数，左下角的「问题」列表会给一条提示，告诉你它会怎么算。

### ② 遗物 / 药水上选了「只在卡牌上实现」的效果种类，会**静默什么都不生成**

效果种类下拉是所有地方共用的，所以遗物 / 药水上也能选到这些**只做在卡牌上**的种类：

`暴露` `清除某个状态` `清除所有减益` `翻倍状态` `禁止获得格挡` `禁止生命回复` `时间到` `透支能量（下回合少）`

以前选了它们，生成时**一行代码都不生成、也不报错**（你会以为配上了，进游戏发现没效果）。现在：
- **生成前**就会在「问题」列表里说清楚：如果这个遗物 / 药水的效果**全是**这类（生成出来是个空壳）→ **错误**，拦住生成；
  只是其中一条 → **警告**（其余效果照常，不打断你）；
- **生成的代码里**也会留一行醒目注释（`// ⚠⚠ 该效果种类在遗物上没有实现…本次一行代码都没生成`），翻工程时能直接看到。

## 顺带

- 「动画」页的署名改成 **金色加粗的「此动画板块由TのG制作」**，放在页面**左上角**（原来在右下角、灰色小字）。
- 存档格式不变；升级后**重新生成一次**工程即可。

## 上一版（V0.2.50）修的是什么

遗物 / 药水上的「获得状态」生成出**编译不过**的代码（`cardSource` 传了 `this`，从 V0.2.37 起存在）—— 那一版已修；
如果你还没升到 V0.2.50，这一版包含它。

## 使用方法

2. 详细功能说明见根目录 `README.md`
