## 你报的：「数值公式用不了，我设 A 为敌人的虚弱，却没效果」

**先说结论：那个公式没算错，是那张牌拿不到「敌人」。**

你那张牌（`SparkleCard40`）是这么配的：

- 参数 `A` = 增益减益 → **虚弱（WeakPower）** → 「从谁身上取」= **指定敌人**；
- 效果「造成伤害」→ 作用对象 = **全体敌人** → 数值公式 = `A+3` → 命中次数 4。

生成出来是这样（你可以对着工程里的 `SparkleCard40.cs` 看）：

```csharp
Creature? __fgTarget = cardPlay?.Target;                                  // ← 全体敌人的牌不选目标，这里是 null
decimal __pA = ForgeFormulaRuntime.PowerAmount(__fgTarget, "WeakPower");  // ← 所以 A 永远是 0
await DamageCmd.Attack((__pA + (3m)))                                     // ← 实际就是「造成 3 点伤害」
```

**根因**：这张牌的作用对象是「**对所有敌人**」，打出它的时候**根本不会让你选某个敌人**，
所以 `cardPlay.Target` 是 `null` —— 「指定敌人」那一档的参数永远是 0。
公式、生成、编译、进游戏全都不报错，你看到的就是「填了公式没反应」。

**这一版怎么处理**：生成前的检查会**报错拦住**，并把两种改法直接写进错误里：

> 卡牌「新卡」的「造成伤害」数值公式（A+3）里用了参数 A=，但它的「从谁身上取」是**指定敌人**，
> 而这张牌是「对所有敌人」—— 打出这张牌时**没有**「选中的那个敌人」，所以 A 永远是 0，公式等于白写。二选一：
> ① 把这条效果的「作用对象」改成「指定敌人（单体）」；
> ② 到「自定义参数 / 组」页把 A= 的「从谁身上取」改成「全部敌人」（取第一个活着的敌人）或「随机敌人」
> —— 注意公式是**整张牌只算一次**的，所以那样所有敌人吃到的是同一个数字。

你改完（比如把 `A` 的「从谁身上取」改成「全部敌人」）生成出来就是：

```csharp
Player __fgPlayer = base.Owner;
decimal __pA = ForgeFormulaRuntime.PowerAmount(ForgeFormulaRuntime.FirstEnemy(__fgPlayer), "WeakPower");
await DamageCmd.Attack((__pA + (3m))).FromCard(this, cardPlay).TargetingAllOpponents(base.CombatState)…
```

> **一个必须说清楚的限制**：公式是**整张牌算一次**的 —— 所以「每个敌人各自的虚弱层数」
> 这一档做不到（本体的伤害命令只吃一个数字）。全体敌人的牌上，只能用
> 「全部敌人（取第一个）/ 随机敌人」这样一个数字打到底。想要「每个敌人按自己身上的层数吃伤害」，
> 那是另一套机制（一个一个打：把作用对象改成「指定敌人」），现在做不了。

## 顺手接上：卡牌页「全体敌人 + 命中次数」的那个数字

你那张牌命中次数填的是 **4**，但生成出来**没有** `WithHitCount` ——
因为卡牌页这一档一直把「对群数 / 命中次数」整个忽略了（V0.2.69 那次只修了**锻造图**里的那一栏，
卡牌页当时写的是「本来就被忽略」，没动）。这次一起接上：

| 配置 | 以前生成的 | 现在生成的 |
|---|---|---|
| 全体敌人 + 命中次数 4 | `TargetingAllOpponents(…)`（**只打 1 下**） | `TargetingAllOpponents(…).WithHitCount(4)`（**每个敌人各挨 4 下**） |
| 全体敌人 + 命中次数 1 | 同上 | 同上（**不写** `WithHitCount`，和以前逐字一致） |
| 随机敌人 + 命中次数 4 | `ForEach` + `Targeting(foe)` + `WithHitCount(4)` | 一个字没变 |

> 也就是说：卡牌页的「全体敌人」现在和锻造图【效果】那一栏的语义**对齐**了
> （一次打全体 + 每个敌人挨 N 下）。这一档的行为变化只影响「全体敌人 + 命中次数 > 1」的牌。

## 已知限制（说清楚，不藏着）

- 公式是**整张牌算一次**的：「每个敌人各自的状态层数」做不到（见上）。
- 「数值公式」只做卡牌的那 5 种效果（伤害 / 格挡 / 失去生命 / 回复生命 / 施加增益减益）；
  遗物 / 药水 / 自定义状态触发时机 / 诅咒牌上填公式会被报错拦住。
- 公式那条的**升级增量不生效**，卡面印的也是公式本身。
- 「覆盖血条」只做自定义状态；同一只身上多个这种状态只显示第一个；观感没在游戏里肉眼确认过。
- 本体的「自定义参数 → 给予能量 / 给予额外资源量」这两栏目前**只是配置项**，生成端还没有用它。
- 【且】/【或】门的 A / B 两个入口，在图上落在【条件】模块的**出口 0** 上，积木编辑器不接管这条线，
  请在节点图里改。
