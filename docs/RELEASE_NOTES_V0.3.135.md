# V0.3.135 — 诅咒 / 先古 / 状态页也能勾选加入组

## 需求

用户原话：

> 将诅咒/先古/状态页的卡中侧的卡牌属性那边像卡牌页一样可以勾选加入组

## 一、三块「卡牌属性」标题右边多了「组：」勾选框

以前「组」勾选框只长在**卡牌**页的「卡牌属性」标题右边；诅咒 / 先古卡 / 状态卡这三栏
虽然能在「范围」下拉里被「组：XXX」选中，但**界面上没有地方把这三类牌勾进组**。

现在：

```text
诅咒属性   组：☑ 组A  ☑ 组B
先古卡属性 组：☑ 组A  ☑ 组B
状态卡属性 组：☑ 组A  ☑ 组B
```

- 诅咒在 `CurseDetail` 里单独一块；
- 先古卡 / 状态卡共用 `SpecialCardDetail`，所以两块详情里都有这一排（跟着选中的是哪种牌显示对应标题）；
- 行 = **当前选中的那张牌 × 每一个组**，和卡牌页共用同一个 `CardGroupRow` 类，
  勾选写进 `CardSpec.GroupIds` —— 数据格式和卡牌页完全一样，老存档不用迁移；
- 一个组都没有时，标题下面显示和卡牌页同一句提示：「（还没建组 —— 到「自定义参数 / 组」页下面点「新建组」）」。

刷新时机：`CurseGroupRows` / `SpecialCardGroupRows` 在**切换选中的牌**、**组增删 / 改名**、
**换存档**、以及卡牌页同步（`SyncDetail` → `RaiseGroupsChanged`）时一起重算（`RaiseCardGroupRows`）。

## 二、组页的「这个组里有哪些牌」改成 AllCards

只加勾选框还不够：组页右边那份列表原来只列 `Profile.Cards`，于是「在诅咒页勾进组 → 去组页看」
会**看不到这张诅咒**，看起来像没进组。

- `GroupCardRows` 的候选改成 `Profile.AllCards`（普通卡 + 诅咒 + 先古卡；状态卡本来就在 `Cards` 里）；
- 「全选 / 全不选」同样按 `AllCards` 算，和右边列出来的行数对得上。

## 三、生成端不用改

`EffectCatalog.CardGroupCards` 遍历的是 `Profile.AllCards`，本来就把诅咒 / 先古卡 / 状态卡算进组里；
「范围限定 / 范围界定 / 刮削条件 / 只对哪类牌生效」里的「组：XXX」早就认它们。
所以这一版是纯界面补齐，**生成出来的代码逐字节不变**（没有动任何生成分支）。

## 验证

`--uicheck` 新增 13 条断言（诅咒 / 先古卡 / 状态卡各 3~4 条 + 组页可见 + 收尾）：

| 断言 | 结果 |
|---|---|
| 诅咒页「诅咒属性」右边出现组的勾选框，而且真的画在屏幕上（`IsVisible`） | 通过 |
| 勾选框的 `IsChecked` 读的是这张诅咒的 `GroupIds` | 通过 |
| 在诅咒页勾上 → 写进 `CardSpec.GroupIds`，`CardGroupCards` 也筛得到这张诅咒 | 通过 |
| 组页「这个组里有哪些牌」里看得到这张诅咒 | 通过 |
| 先古卡页：勾选框跟着选中的先古卡走、勾上就进组、按组筛得到 | 通过 |
| 状态卡页：同上（和先古卡共用详情），再点一次取消勾选能移出 | 通过 |
| 自检收尾：临时组 / 临时状态卡都清理掉 | 通过 |
