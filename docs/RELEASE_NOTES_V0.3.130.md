# V0.3.130 — 生成器深色模式 + 自定义背景

## 深色模式

状态栏右侧新增：

```text
☑ 深色模式
```

切换后作用于整个生成器界面：

- 窗口页面底色 / 顶栏 / 状态栏；
- 按钮、输入框、下拉框、列表、标签页；
- 文本、边框、提示条；
- 深色模式下仍保留警告黄 / 错误红 / 成功绿的语义色（改成深色主题对应色）。

只改本工具的界面，不进入生成工程，也不影响模组内容。

## 自定义背景

状态栏右侧新增：

```text
背景…
清除背景
```

- `背景…`：选择 PNG / JPG / BMP；
- 工具会把图片复制到：

```text
%LOCALAPPDATA%\Sts2CharForge\ui-background.<扩展名>
```

- 界面内容与背景图之间有一层半透明遮罩，保证文字可读；
- 顶栏 / 状态栏使用半透明底色，背景图在边缘和控件间隙可见；
- `清除背景` 只恢复默认背景，不删除原图。

## 保存位置

主题和背景设置保存在：

```text
%LOCALAPPDATA%\Sts2CharForge\ui-theme.json
```

下次启动自动恢复。`--uicheck` / `--buildtest` 等命令行模式不会读写这份用户设置。
