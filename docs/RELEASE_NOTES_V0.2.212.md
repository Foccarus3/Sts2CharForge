# V0.2.212 —— 「放置卡牌」怎么选「放在哪里」：两处都能选（卡牌页 / 锻造页），外加把这两栏钉死

> 来源：用户提问「放置卡牌怎么选择放在哪里」。

## 1. 答案（本来就有，只是位置分散）

「放置卡牌」有**两个**要选的东西，都在**同一条效果的编辑器里**：

| 栏位 | 含义 | 候选 |
| --- | --- | --- |
| **放到哪一摞** | 放到**哪里** | 手牌 / 抽牌堆（牌堆底）/ 弃牌堆 / 消耗牌堆 / **牌顶（抽牌堆最上面）** |
| **从哪里选牌** | 要拿的牌**从哪一摞**来（只有「数值 ≥ 1」才用得到） | 手牌 / 抽牌堆 / 弃牌堆 / 消耗牌堆 / 牌顶 |
| 选牌方式 | 自己选（弹本体选牌界面）/ 随机 | — |
| 数值 | **0 = 把这张牌自己**放到「放到哪一摞」；≥ 1 = 从「从哪里选牌」挑 N 张放过去 | — |

在哪些地方能找到这一行：

- **卡牌页**（最常用）：右侧效果栏 → 「效果种类」选 **放置卡牌** → 编辑器里就出现「放到哪一摞」（在「从哪里选牌」下面一行）；
- **遗物 / 药水 / 自定义状态页**：同一个效果编辑器，同样有这一行；
- **锻造页（节点图）**：【效果】模块里选「放置卡牌」→ 同一个编辑器（`EffectEditorForge` 直接复用「卡牌」页那套模板），同一行也在。
  ⚠ 模块框比较小，里面是可滚动的 —— 看不到就**在模块里往下滚一点**。

生成出来长这样（数值 0 + 放到牌顶）：

```csharp
await CardPileCmd.Add(this, PileType.Draw, CardPilePosition.Top);
```

数值 ≥ 1 时先按「从哪里选牌」挑，再 `CardPileCmd.Add(挑中的那张, 目标那一摞, 底/顶)`；「牌顶」= 本体
`CardPilePosition.Top`（抽牌堆最上面），「抽牌堆」那一档是本体默认的**牌堆底**。

## 2. 这次顺手把它钉死的三件事

1. **判据抽成一份**：`EffectSpec.KindUsesPlaceTo(kind)` / `KindUsesSelectPile(kind)` ——
   原来只有实例属性（`UsesPlaceTo` / `UsesSelectPile`），现在「卡牌页 / 锻造页」两处
   显不显示这一行读的是**同一份**判据，以后不会出现「一边有、一边没有」。
2. **锻造页【效果】模块正式声明这两栏**：`ForgeGraphCatalog` 的【效果】模块补上
   「从哪里选牌 / 放到哪一摞」（候选直接复用 `EffectCatalog.SelectPiles` / `PlacePiles`，
   id 和措辞与卡牌页一致）。副作用是模块框高度按栏数算 → 【效果】模块变高了一点，
   里面的滚动条少滚一截（这正是「看不到那一行」的常见原因）。
3. **节点字段 ↔ EffectSpec 双向同步**（`ForgeEffectBridge`）：
   - 手写 / 老 JSON 里只有 `Fields`（`PlaceTo` / `SelectPile`）→ 读进 `EffectSpec`；
   - 在图上改完 → 写回节点字段（只对「用得到这两栏」的效果种类写，
     免得积木摘要里每个效果模块都多一句「放到哪一摞：手牌」的噪声）。
