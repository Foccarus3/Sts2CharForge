## 二、药水页照抄遗物页

**照抄了：**

- **左侧序号列**：序号在药水名最左侧、从上到下 1..N；**显示行数 = 5 × ⌈N/5⌉**（3 瓶 → 1~5，第 4、5 是空槽；6 瓶 → 1~10；11 瓶 → 1~15）。序号是**位置号、不跟着药水走**；
- **空槽**只是界面占位：选不中、不进全选、不影响删除与生成（`Potions` 里只有真药水），但**可以当拖放落点**；
- **拖动药水项换位置**（拖到空槽也算，落下后序号重新从 1 连续排）；
- **自动英文类名跟序号走**：生成前先「清掉以前工具自动生成的类名、按当前序号重新拼」（`<角色类名>Potion<序号>`）；**手填的一个字不动**，**没填的保持留空只记序号**（一写实就再也分不出是工具生成还是手打的）；**幂等**（反复生成结果一样）；
- **稀有度英文改中文**（常见 / 罕见 / 稀有，Id 仍是英文、老存档读得回来）；
- **右侧效果栏** + 右下角**单条效果的条件** + 自定义描述。

**没有抄（药水没有这些概念，不硬塞）：** 遗物的「触发时机列表 / 满足其中一个·全部满足的关系开关 / 重置范围」。

## 三、顺手修掉的老缺口（都不再静默）

1. **药水效果的条件现在真的会生成**：以前是「界面没入口 + 校验器一律报错 + 生成端不生成」三头堵死。现在照遗物那条链生成（条件不满足就不跑），校验器同步放开。
2. **药水的「概率生效」「命中次数」勾了不生效** → 改成校验器**明确报警告**（这一版**不补生成**：补了会让老存档的输出变，违反「老存档逐字不变」；要补请单独提）。
3. **额外资源量「载体遗物」的两个老坑（编译不过）**：只在「启用额外资源量 + 至少 1 条效果」时才炸，示例存档一直是关的所以没暴露 ——
   - `ExtraResourceSource` 的 `CanonicalVars` 用 `.Open(...)` 多开了一层 `{` 从来没关上 → 生成的 `cs/ExtraResource.cs` 语法错（一串 CS1002/CS1519）；
   - 勾「每场战斗只触发一次」用的 `_condUsedThisCombat` **没声明** → CS0103。
   两个都在基线副本上复现过，确认是既有问题、不是这一版引入的。
4. **从工程恢复（`--recover`）补 5 项**：`在游戏中隐藏` / `始终显示计数器` / `数量上限` / `加入药水池` / 额外资源量自定义描述。都靠**既有文件与既有常量**反推，**没有引入新的 `CET:` 标记**。

## 五、已知边界（留给你定）

1. 页头叫「**额外资源量**」（不带「页」字）—— 理由是这一栏其它页头也不带；要带「页」字说一声；
2. 药水稀有度只保留原来的三档（常见 / 罕见 / 稀有），中文名取的是**和遗物同一套词**（游戏本体文案在 pck 里，本机取不到原文校对）；
3. 药水**不支持**「概率生效」「命中次数」（校验器会明确提示，不是静默忽略）；
4. 遗物页右栏**还留着一份**额外资源量效果的编辑区（V0.2.124 起就在那儿）。现在额外资源量页右栏有了自己的编辑区，正常操作不会再碰到它；删它等于动遗物页行为，所以这一版没删。
