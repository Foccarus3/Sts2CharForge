# V0.2.164 更新说明

> 回答你问的：「状态和遗物不能使用公式吗」→ **现在能了**。
> （你那两条报错是校验器在拦：以前公式那一套只铺在**卡牌链**上。）

## 一、为什么以前不能、现在怎么能

公式求值需要「自己 / 玩家 / 目标」这几个量：
- **卡牌链**的做法是「打出这张牌之前先算一批局部变量」（`__pM` / `__X` / `__Y` / `__fgPlayer` / `__fgSelf`），
  遗物 / 药水 / 自定义状态的执行点（触发器钩子 / `OnUse`）**没有**这套前置 —— 所以以前直接拦住了。
- 但**锻造节点图**（遗物 / 药水那一档）一直能用公式 —— 那边走的是**全内联求值**
  （`ForgeFormula.ConditionResolver`：把参数就地展开成 `base.Owner…` 的表达式，不需要任何局部变量）。

这一版把这三条链接上同一个全内联求值：

| 链 | 「玩家」 | 「自己」 | 「指定敌人」类参数取谁 |
|---|---|---|---|
| 遗物 / 药水（`base.Owner` 是 Player） | `base.Owner` | `base.Owner.Creature` | **可打的第一个敌人** |
| 自定义状态（`base.Owner` 是 Creature） | `base.Owner.Player` | `base.Owner` | **可打的第一个敌人** |
| 卡牌（不变） | `__fgPlayer` | `__fgSelf` | 玩家选中的那个目标 |

支持的种类还是那 5 种：**造成伤害 / 获得格挡 / 失去生命 / 回复生命 / 施加增益减益**
（其余种类的数值必须在生成时就定下来，照旧报错拦住 —— 不静默）。

## 二、游戏里显示什么

- **遗物 / 药水**：照卡牌那套显示**算出来的数字**。本体遗物 / 药水描述里的 `{Heal:diff()}` 读的是
  动态变量的 `PreviewValue`，而它们**没有**卡牌那种「显示前回调」—— 所以工具自己挂在
  `ExtraHoverTips`（本体取悬停说明时一定会读它）上现算一遍，悬停看到的就是真实数字。
- **自定义状态**：状态说明是**生成期写死的纯文本**（本体那边不是动态变量那一套），现算不了 ——
  写了公式就把**公式本身**印在说明里（例：「玩家回合开始时：失去 `M/10` 点生命。」）。

## 三、界面上多出来的东西

- 遗物 / 药水 / 自定义状态的效果编辑器里，那 5 种效果现在也摆出**「可用量」小框**
  （以前只在卡牌页有）；「数值公式」底下的说明也改成了这三条链的口径（X / Y = **当前**能量 / 额外资源量、
  「指定敌人」= 可打的第一个敌人）。
- 「配置检查」里的两条**提示**：公式里用了 `X` / `Y`、或用了「指定敌人」来源的参数时会说清口径。

## 四、顺带修的那条（「状态里监听某状态被移除时无法触发」）

`PowerModel.RemoveInternal` 的通知补丁以前只通知**被移除那个状态所在的那一只生物** ——
所以「挂在你自己身上、盯**敌人**身上的状态被移除」的配置**永远收不到通知**（生成出来的守卫里
那个「任意敌人」分支就是死代码）。现在通知范围改成**这一场战斗里的所有生物**
（`CombatState.Creatures`），每条时机自己的守卫照旧筛。另外打开「生成调试日志」后，补丁会往游戏日志写一行
`[模组调试] 状态被移除：XxxPower（通知了 N 个盯这条时机的遗物 / 状态）` —— 下次再怀疑「没触发」，
一行就能分清是「没人配 / 补丁没生成」还是「通知到了但被守卫挡住」。

## 五、可以从工程恢复

三条链的公式都会写一行 `// CET:AmountFormula=<公式>`，「从工程恢复存档」原样认回来
（遗物 / 药水 / 状态的公式都验过生成 → 回读 → 一模一样）。

- `dotnet build Sts2CharForge.sln -c Debug` → **0 错误**；

  跑 `forge --profile … --out … --build` → **生成的模组工程 0 错误**（这一步抓出了两个真问题：
  属性不能直接写方法体（CS8124）、以及没写 `FormulaVars.cs` / `ForgeFormulaRuntime.cs` 会 CS0246）；
- `--uicheck`：Debug **3661 PASS / 0 FAIL**（新增 14 条：三条链的内联表达式 / 悬停现算 / 回读标记 /
  状态描述写公式 / 这两个「用到才生成」的文件 / 校验器正反例 / 生成→回读三条链）；
- **默认输出不变（红线①）**：`--samplegen` 与 V0.2.143 基线 **111 个文件逐字节一致**
