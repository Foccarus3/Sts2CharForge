# V0.2.275 — 撤回「概率自动开启」：不再全变 50%

## 你报的

> 为什么效果全默认勾选概率生效了
> 而且怎么全是 50，并且改了也有问题

## 原因（我 V0.2.272 引入的回归）

V0.2.272 我在读存档时加了一条「百分比在 1~99 就自动开启概率」的归一化，想解决你说的「填了 50% 却没生效」。
问题是：`EffectSpec.ChancePercent` 的**默认值当时是 50** —— 于是：

* **每一条**效果读档后都被自动勾上「概率生效」；
* 生成时每条效果都掷一次 **50%** 骰子（看起来「全是 50%、效果时灵时不灵」）；
* 你手动改回 100 / 取消勾选，**下次读档又被归一化改回来** —— 这就是「改了也有问题」。

## 修法

1. **撤回**自动开启（读档时不再碰 `ChanceEnabled`）。概率必须**显式勾选**才生效。
2. **默认值 50 → 100**（新建效果 = 必定生效，不会莫名其妙带个 50%）。
   「概率生效（百分比）」「概率各自独立」两个预设的初始值也从 118 / 50 统一成 100（填多少由你改）。
3. 读档时把「**没勾却留着 50 / 80 这种百分比**」的行归一到 **100** —— 那些值都是旧默认值，
   不勾本来就不掷骰，界面上留着 50% 只会误导。
4. 校验器新增提示：**写了 1~99% 的百分比（或概率公式）却没勾「概率生效」** → 明确说「这一条不会掷骰子，等于每次都生效」。

## 用你的存档验的

```
新建效果：                    ChanceEnabled=False  ChancePercent=100   ✓
你的 Shadow.json（121 卡）：   概率开=8  关=338   其中「填了 1~99% 但没勾」= 0
                                                    ↑ 以前是 281 条，就是你看到的「全是 50」
```

* 你那 8 条真正勾过概率的效果**保持原样**（勾着、百分比不变）；其余全部回到「必定生效、100%」。
