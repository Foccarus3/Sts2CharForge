# V0.2.80 更新说明

> 这一版就你点的两件事：
> ① **美术资源页**多了多人联机宝箱房的手势（选择 / 剪刀 / 石头 / 布 / 拿取）+ 自定义催促文本；
> ② **效果种类**多了一条「**将此牌放回手牌（值为 1 时生效）**」。

## ① 多人联机宝箱房：那只手 + 那句「开抢！！！」

以前这四张手势在「美术资源」页**没有上传入口**，生成时只是把本体的铁甲战士手复制成
`multiplayer_hand_<角色>_{point,rock,paper,scissors}.png`（能玩，但那只手是铁甲战士的）。

现在页面上多了五个槽位和一句文本：

| 槽位 | 传给谁 | 说明 |
|---|---|---|
| 手势（**选择**） | `CharacterModel.ArmPointingTexture` | 指哪个遗物那只手（本体叫 point） |
| 手势（**剪刀**） | `ArmScissorsTexture` | 石头剪刀布亮剪刀 |
| 手势（**石头**） | `ArmRockTexture` | 亮石头；也是「放弃 / 不抢」时亮出来的拳头 |
| 手势（**布**） | `ArmPaperTexture` | 亮布；也是伸手去够遗物那一下 |
| 手势（**拿取**） | **本体没有这张**，我们单独打补丁 | 抓住遗物、把它拎回自己那边那只手 |
| **催促文本** | 本体「开抢！！！」那一行字 | 留空 = 沿用本体 |

尺寸照本体原图：**422×1200 的竖图**（手从画面下沿伸进来），PNG-32 透明背景。

**四张手势必须成套**：本体是按固定路径读这一整套的，只传一部分的话，联机进宝箱房时那只手会
一半是你的一半是占位 —— 配置检查里会提醒「要么四张都传，要么都不传」。
（宝箱房只在联机出现，单机看不到这处美术，所以不提醒的话等联机时才发现就晚了。）

**「拿取」是本体的一个空白**：本体拿遗物是「布（伸手）→ 石头（拳头攥住）」两步糊出来的
（`NHandImage.GrabRelic`，只有三种 RPS 手势的贴图）。传了「拿取」之后，生成时会多写：

- `images/ui/hands/multiplayer_hand_<角色>_grab.png`；
- `cs/TreasureGesture.cs`：给私有的 `NHandImage.SetTextureToFightMove` 打 Postfix，
  只在 ① 这只手是我方的（`LocalContext.IsMe(Player)`）② 私有状态 `_state` 是 `GrabbingRelic`
  ③ 正要显示「石头」时，把贴图换成你的 `_grab.png`。
  状态是反射读的 —— 本体改了布局就静默退回本体表现，**绝不会把石头剪刀布亮牌时的拳头一起换掉**。
  不传这张就一个字节都不写（游戏里保持「布 → 石头」）。

**催促文本为什么不直接改本体的键**：那句话来自全局键 `gameplay_ui.TREASURE_FIGHT_TEXT`，
覆盖它 = 别的角色、主菜单、联机另一边的玩家跟着一起变。所以这一版改成给
`NTreasureRoomRelicCollection._Ready` 打 Postfix，**只在我方角色的这一局里**把 `%FightLabel`
那一行字换掉（本体的本地化键一个字都不动）。字太长会按屏幕自动缩字号（本体最小 8 号），
太长时配置检查会提醒一句。

两处都只对**我方角色**生效：联机时每个人看到的都是自己角色模组带的东西。
存档回读（`--recover` / 从工程恢复）也能把「拿取」那张图和催促文本认回来（靠生成时写的
`// CET:TreasureGrab=` / `CET:TreasureFightText=` 标记；四张本体手势和其它美术槽位一样只认配置里存着的那份）。

## ② 新效果种类：将此牌放回手牌（值为 1 时生效）

- **值 0** = 这条效果**不存在**：卡面不写、生成的代码里也不出现（别的效果照常）；
- **值 1** = 打出这张牌之后，把它从弃牌堆**搬回手牌**。

生成的是卡自己的 `AfterCardPlayedLate` 钩子 —— 本体「回响 MakeItSo」用的就是它：

```csharp
if (cardPlay.Card == this && base.Pile is not null && base.Pile.Type != PileType.Hand)
    await CardPileCmd.Add(this, PileType.Hand);
```

**为什么不写在打出那一刻（`OnPlay`）里**：本体 `PlayCardAction` 是**打完这张牌之后**才把它放进
弃牌堆的，在 OnPlay 里搬会被那一步覆盖 —— 这是这个效果唯一容易踩空的地方。
条件和概率照别的效果同一套（钩子里拿得到 `cardPlay`，所以「指定敌人」类条件读到的是这张牌打出去时选的目标）。

只做在卡牌上：遗物 / 药水没有「这张牌」，自定义状态的触发器里也没有「刚打出的那张牌」
（两处都会在配置检查里被拦住并说明）。它没有可升级的数值，所以「升级增量」填了不生效
（以前这种是静默忽略，现在会提醒你清成 0）。
