# V0.2.377 — 嵌套子表格改成**递归**：三层（敌人 → 招式 → 动作）现在界面上也能直接编辑

上一版（V0.2.376）只放开了生成端和校验，界面还是只可视化一层；这一版把界面补齐。

## 改了什么

* `SubRow` 的 `list` 分支：**子栏位里还有 list** 时，直接交给新的递归构建器 `BuildSubListEditor(...)`；
  否则仍走原来的单层子表格（老插件的行为一个像素都不变）。
* `BuildSubListEditor` 是**递归**的：每行渲染成
  * 标量子栏位 → 一行「标签：输入框」
  * 子栏位本身是 list → 缩进一层，**再画一个子表格**（可以继续往下套）
  * 每行右侧 `↑` `↓` `✕`，底部「+ 添加一行」
* 每一层各存自己的 JSON 文本（沿用 V0.2.375 的存储），所以 敌人 → 阶段 → 招式 → 动作 这种四层也能存。
