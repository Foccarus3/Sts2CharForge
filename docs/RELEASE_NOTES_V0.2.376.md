# V0.2.376 — 嵌套 list 放开到**任意层**（生成端 + 校验）

按你的选择（缺口文档第 18.1 节）做的：以前只允许**一层**嵌套，现在生成端和校验都支持任意层
（敌人 → 阶段 → 招式 → 动作 这种）。

## 改了什么

* **校验**（`PluginRegistry`）：删掉「子栏位不能再是 list（只支持一层嵌套）」这条限制；
  仍要求**每一层都声明 `fields`**（不然那层没有东西可编辑，会报页面问题）。
* **生成端**（`PluginGen`）：`ExpandRowListBlock` 改成**递归** —— 新增 `RenderSubRow(...)`：
  先展开这一行里的深层 list 块，再替换标量与 `{index}` / `{index0}`，层数不设上限。
* **存储没变**：每一层的嵌套值仍然是「那一格的 JSON 数组字符串」，`rows.json` 结构不变。

## 这一版**没**做的（如实说明）

* **界面上还只可视化一层**：V0.2.375 的子表格（增删行 / ↑↓ / ✕）仍然是给第一层用的；
  第二层及更深现在以 JSON 文本形式存在那一格里（能生成、能往返，但没有子表格）。
  我尝试把子表格改成递归时把 `MainWindow.xaml.cs` 改坏了（构建不过），已回滚到 V0.2.375 的界面代码
  —— 递归子表格作为下一步单独做，改动只在界面层，不动数据与生成。
* 因此：**三层结构目前「能声明、能生成」，但第二层要在 JSON 单元格里手改**。
