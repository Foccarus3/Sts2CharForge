# V0.2.86 更新说明

> 这一版就一件事：遗物的「稀有度」多了「**先古**」。

## 遗物稀有度「先古」

遗物页的「稀有度」下拉里多了一档，对应本体 `RelicRarity.Ancient` ——
本体的先古遗物（古老牙齿 `ArchaicTooth` / 星盘 `Astrolabe` / 黑星 `BlackStar`…）全是这一档。
生成出来就是 `public override RelicRarity Rarity => RelicRarity.Ancient;`，其余（触发时机 / 效果 / 图标）照旧。

**提示这一条**：本体的先古遗物**不是**从普通奖励 / 商店里抽出来的，是**先古之民给的**。
所以当你把稀有度设成「先古」、同时又还勾着「加入遗物池」时，配置检查会给一条提示：

> 本体这一档的遗物不会从普通奖励 / 商店里抽出来，是先古之民给的。想让它在奖励池里出现就把稀有度改成
> Common / Uncommon / Rare / Shop；确实要做先古遗物就取消那个勾，用「先古之民」页安排它（或自己的效果发放）。

（不做成硬拦截：想「先古稀有度 + 也进池」在某些自定义玩法里可能是有意的，所以只提示、不拦。）

## 上一版（V0.2.85）修的两件事，回顾

1. **「在锻造里怎么不能填范围了」**：上一版把「范围界定 / 选牌方式 / 从哪里选」按数值 0 藏起来了，
   而新效果数值默认就是 0 → 那几行直接消失。现在改为**只看种类**一直显示，
   「这一档填了不生效」交给配置检查提示。
2. **锻造卡改了能量、卡牌页还是显示 0**：卡牌页把费用那一栏藏掉后显示的是没人再改的旧 `Cost`。
   现在选中锻造卡会多一行只读提示：`费用：N 点能量（由锻造页左上角【能量】模块决定…）`。
