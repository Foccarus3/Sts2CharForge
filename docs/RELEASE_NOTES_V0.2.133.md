# V0.2.133 更新说明

> 这一版把「**下回合生效**」从「只有 12 种效果能用」补齐到「**65 种里 57 种能用**」，并且把判据收成一份（界面上能勾的，生成端一定真的支持）。

## 一、现在哪些效果支持「下回合生效」

**57 / 65 种**。做法是一条**通用延迟**：打出这张牌时只挂一个延迟状态（名字形如 `<角色>ForgeDelayed<效果种类><尾巴><作用对象>`），到你**下个回合开始时**，这个状态才跑**和立刻打出时完全相同的那套语句**，跑完自己消失 —— 所以「下回合再造成伤害 / 再抽牌 / 再生成卡 / 再给状态…」都是同一套语义，不需要每种效果各写一份。

**做不了的 8 种**（界面上**不再显示**那个勾选框，校验器会明确说清为什么，不会静默）：本回合这张牌自己费用变 0（`CheapenSelf`）、抽到这张牌时费用 -N（`CheapenSelfOnDraw`）、将此牌放回手牌（`ReturnSelfToHand`）、抽到就减费（`CheapenDraw`）、结束回合（`EndTurn`）、额外获得一回合（`ExtraTurn`）、刮削（`ScrapeDraw`）、回合结束时自动打出（`TurnEndPlay`）—— 这些要么本身就是「持续到之后」的机制、要么「延到下回合」讲不通。**如果你对其中某一个有具体想法**（例如「下回合开始时把我手上那张牌的费用变 0」），说一声，我单开一版按你的口径做。

## 二、⚠ 有 8 种效果**从此开始真的生效**

以前这 8 种在界面上能勾「下回合生效」，但生成端根本没有延迟分支 —— 勾了等于没勾（勾着的老存档**连生成都过不了**校验）。这一版补齐后，**勾过它们的老存档会重新生成成功、并真的延迟生效**（你已明确接受）：

**透支能量 / 翻倍状态层数 / 暴露 / 清除指定状态 / 清除全部减益 / 禁止获得格挡 / 禁止回复生命 / 伙伴攻击**

除这 8 种之外，**其它任何种类都不会改变老存档的生成结果**（我逐份对拍过：默认示例 113 个文件、老存档 106 个文件、以及你自己的两份真实存档，**内容全部逐字节一致**，只有 `.sln` 里那个随机 GUID 每次不同）。

## 三、界面与校验器

- 界面上「下回合生效」这个勾选框的**显隐判据**和生成端的支持判据**现在结构上就是同一个**（`SupportsNextTurn` 直接由 `HonorsNextTurn` 算出来），不可能再出现「界面能勾、生成端不管」的老毛病（`--uicheck` 里加了 65 种逐条断言钉死）；
- 不支持的那 8 种：勾选框不显示，老存档里如果勾过 → 校验器**报错**并说明理由。

## 五、已知边界（都没动手，留给你定）

1. **遗物 / 药水 / 自定义状态链上的「生成卡牌」类那 7 种**：挂延迟状态这条路是通的，但那 7 种在延迟状态里跑的是老的发射器，**这一版没在探针里把「遗物/药水链 × 生成类 + 下回合」这个组合真编译过**。要不要单开一版补这份探针（顺带给校验器加一条提示）？
2. **延迟执行的数值取「生成时算出来的那个数」**（数值 + 升级增量）：如果那条效果写的是「数值 = X」，延迟版本会退成基础数值 —— 要不要在界面上提示？
3. **目标的跨存档**：延迟状态靠 `base.Target` 把目标带到下一回合，**能不能扛过「存档→读档」我没法在这台机器上实测**（需要真游戏会话）。建议你进游戏试一次：打出带「下回合生效」的牌 → 存档 → 读档 → 过回合，看它是否还打原来的目标。
4. **7 处既有的回读缺口**没动（概率/数值之类回读后写法不同，属老边界；补标记会改老存档生成文本，所以留着）。
5. **同回合多次打出会叠层**：多次打出同一张「下回合生效」的牌 → 延迟状态层数叠加，下回合**一次性执行总量**（这是设计使然，文档里没细写，这里点明）。
