# V0.3.131 — 深色模式补齐白色控件 / 参数参考窗

## 修复

V0.3.130 的深色模式只覆盖了主框架的一部分，截图里仍有大量白色输入框、下拉框、标签页，部分文字还和底色同为白色，看不清。

V0.3.131 补了两层：

1. **系统颜色资源**
   - 深色时覆盖 WPF 的 `Window / Control / WindowText / ControlText / ControlDark / Highlight / Menu` 等系统色；
   - 默认的 `TextBox`、`ComboBox`、`TabControl`、`ListBox` 模板会跟着变深；
   - 切回浅色时移除覆盖，恢复 Windows 系统色。

2. **更完整的可视树刷新**
   - 启动后等首标签页内容模板实例化完再刷一次；
   - 切换标签页、切换深色时都刷新；
   - 独立窗口「参数参考」在 `Loaded` 后套用同一套深色规则；
   - 参数参考里的标题、分类、条目、底部说明、按钮、列表全部跟随主题。

## 参数参考窗

`ParamReferenceWindow` 不再固定浅色：

- 窗口背景、列表、条目文字、分隔线、说明文字都按当前主题；
- 主窗切换深色/浅色时，已经打开的参考窗也会同步。

## 使用

状态栏右下角：

```text
☑ 深色模式
背景…
清除背景
```
