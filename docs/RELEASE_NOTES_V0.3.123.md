# V0.3.123 — 初始打击 / 防御改为「按标签命中所有份数」

## 背景

初始打击 / 防御现在会生成：

```text
<角色>Strike
<角色>StrikeCopy2
<角色>StrikeCopy3
...
```

效果如果按**某个具体类名**去找，只会命中第一份，后面的 `Copy2`、`Copy3` 不生效。

## 修复

对「初始打击 / 防御」的目标判断统一改成：

```csharp
c.Rarity == CardRarity.Basic && c.Tags.Contains(CardTag.Strike)
```

覆盖：

- 「只对这张卡（指定）」：消耗 / 丢弃 / 升级 / 复制 / 重放 / 给关键词 / 从三摞拿牌 / 预见；
- 「变化卡牌」的源卡筛选；
- 「强化指定卡牌（像「精准」）」的目标卡判断。

配置里仍然写：

```text
Strike / Defend
```

生成时自动按标签匹配所有份数。

## 明确选中某一副本时

如果目标写的是：

```text
<角色>StrikeCopy2
```

仍然只命中那一份（精确匹配），不会扩大到所有份数。

## 生效方式

更新到 V0.3.123，重新生成工程并重装 DLL。
