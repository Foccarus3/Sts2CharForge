# V0.2.147 更新说明

> 回答并落实一个问题：「**当状态挂在敌人身上时，状态的『自己』是不是敌人自己**」——
> **是**。顺带把「挂到敌人身上会出错」的效果在配置检查里**报出来**（以前只对触发时机有警告）。

## 一、「自己」到底是谁

| 概念 | 实际是谁（生成的代码里） |
|---|---|
| 状态效果里的 **「自己」** | **挂着这个状态的那个单位**（`base.Owner`）；贴在敌人身上时 = **那个敌人** |
| 状态效果里的 **「单体敌人 / 全体敌人」** | 本体 `CombatState.HittableEnemies` = **玩家视角的敌方那一侧**（绝对的一侧，不随持有者变）→ 贴在敌人身上时打的是**它自己和它的同伴** |
| 「自己受到伤害后 / 自己获得格挡后 / 自己失去生命时」 | 盯**持有者** ✓ 贴敌人身上也能用 |
| 「玩家回合开始 / 结束、打出牌后、抽到牌后、花能量、获得金币、洗牌」 | 钩子给的是**玩家**，护栏 `player != base.Owner.Player` → 贴在敌人身上（`Player` 为 null）**永远不触发** |
| 「敌人回合开始 / 结束、敌人受伤后 / 造成伤害后 / 获得格挡后、敌人死亡后」 | 盯**敌方那一侧** ✓ 贴敌人身上能用 |

## 二、挂到敌人身上会「抛异常、战斗卡住」的效果（新增警告）

状态里凡是**要拿玩家对象**的效果，生成代码都会直接读 `base.Owner.Player`，而本体
`Creature.Player` **对怪物就是 null** → null 传进本体接口 = 运行时异常 → 战斗卡住
（和 V0.2.145 修的那个「没有选牌提示语」是同一类卡死）。

- 涉及的种类（**机械扫生成源码扫出来的**，共 18 种 + 「概率生效」那一档）：
  抽牌 / 获得能量 / 获得金币 / 获得额外资源量 / 生成卡牌 / 获得药水 /
  获得·变化·删除·升级卡牌（全局）/ 升级卡牌 / 消耗卡牌 / 丢弃卡牌 / 给予卡牌关键词 /
  从抽牌堆·弃牌堆·消耗牌堆拿牌到手牌 / 获得卡牌奖励；
- ⚠ **任何效果只要勾了「概率生效」**，掷骰子也要读 `base.Owner.Player` → 同样会抛异常；
- 现在「配置检查」会给一条**警告**，把上面这些逐条点名，并说清「贴在自己身上才有效」以及可替代的做法
  （造成伤害 / 失去生命 / 获得格挡 / 施加或清除状态 / 击晕 / 翻倍层数 / 暴露 / 毒性爆发 / 禁止格挡或回复生命…）。
  这条是**警告不是错误**：状态可以只为自己用，工具不拦你生成。

## 三、自检（防止这份清单以后漂掉）

新增 7 条 `V0.2.147` 断言：

- 清单里的种类（抽牌 / 生成卡牌 / 获得药水）生成出来的状态代码**确实**读 `base.Owner.Player`；
- 清单外的种类（造成伤害 / 施加状态 / 获得格挡 / 临时增益）**不读**（只跟持有者有关）；
- 勾了「概率生效」的任何种类都会读（掷骰）；
- **清单与生成端逐条一致**（清单里每一种都真的读；清单外一种都不读）——写这几条时它当场抓出漏掉的
  `GiveKeyword`（给予卡牌关键词），已补进清单；
- 警告确实会出现（「抽牌」状态那条），以及**不误报**（纯持有者相对的状态不报）。
