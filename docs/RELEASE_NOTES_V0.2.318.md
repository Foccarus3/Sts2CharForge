# V0.2.318 — 锻造状态「某个状态层数到达 N 层」不生效：图上的效果体被丢了

用户原话：

> 锻造状态某个状态层数到达N层触发时机不生效

用你这次给的存档（Carmenmod）复现了，**触发时机本身没问题，是「跑效果」那一步用错了代码**。

## 真因（两处叠在一起）

1. **图上的效果体没被用上**
   锻造状态的效果体由节点图渲染成一段正文（`PowerHookBodies`），`CustomPowerGen` 按「钩子分组名」
   去取（`PowerReached` → `PowerChanged`），而那份表的键写的是本体方法名
   （`AfterPowerAmountChanged`）—— 两把钥匙不一样，取不到 → 正文丢了。
2. **丢了之后退回老链发射器**
   「到达 N 层」这一档是**直接调 `EmitEffects`**（不走那个会换正文的闸门），于是效果按「状态效果列表」
   那套发射，而图里配的是「变化卡牌」（`TransformCard`）—— 这种在状态链上不支持 → 只剩一句注释
   「这个效果种类在状态触发器里用不了」= **什么都不发生**。

## 改法

* `PowerHookBodies` 现在**两个键都存**（本体方法名 + 钩子分组名），取得到正文了；
* `EmitEffects` 里加了一次兜底：只要是锻造状态（`_graphBody` 还在），就把图上正文写出来；
* 顺手修了一个重复执行：同一个钩子上一旦有多条触发时机，图正文以前会被 `Raw` **两遍**
  （效果被执行两次）；现在每个钩子方法里只落一次。
