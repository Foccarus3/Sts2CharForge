# V0.2.132 更新说明

> 这一版做的是《卡牌页优化.md》右侧④ 的**前半段**：**作用对象扩到 7 档**、**概率「不同效果之间是否独立」**、**效果编辑器按你写的顺序重排**，以及「命中次数 / 对群数」的收尾核对。

## 一、作用对象扩到 7 档

现在所有**作用对象**下拉都是这 7 档（卡牌 / 遗物 / 药水 / 自定义状态 / 锻造页共用同一份）：

**自己 ／ 指定队友 ／ 全部友方（可选「不包括召唤物」）／ 单体敌人 ／ 随机敌人 ／ 全部敌人 ／ 全体单位**

- 新增 **「全体单位」**（玩家 + 敌人 + 召唤物全打）与「全部友方」的**「不包括召唤物」**子选项；
- 生成端在卡牌 / 遗物 / 自定义状态三条链都补齐了分支（伤害 / 施加状态 / 临时增益 / 击晕 / 攻击…），卡面文案同步（「对所有单位…」/「对所有友方（不含召唤物）…」）；
- **用不到这档的效果种类会被校验器报错拦住**（不会静默生成空代码）；
- 锻造页那份节点图映射到本来就有的 `ForgeFormulaRuntime.AllUnits`。

## 二、概率：「不同效果之间是否独立」

以前（默认，**没变**）：同一张牌里勾了概率的效果**共用一次掷骰**、各占一段区间（比如 70% 打 5 点、30% 打 3 点）。
现在多一个开关：勾上「**各效果独立判定**」后，每条效果**自己掷一次**。默认不勾 = 完全保持老行为；只有勾上时才写新的回读标记。

## 三、效果编辑器按你给的顺序重排

卡牌链现在是：**升级增量 → 效果种类 → 数值（可写公式）→ 作用对象 → 命中次数（可写公式）→ 生效次数（可写公式）→ 概率（可写公式 + 独立开关）→ 下回合生效 →（其余栏位按效果种类只留用得到的）**。

⚠ **其余四条链（遗物 / 药水 / 自定义状态 / 锻造）的外观与绑定一个字没改**（新元素对它们恒为折叠、行高 0）。

## 四、「对群数」收尾

界面上已经没有那三个「= X」开关的残留，模型里也**没有**独立的「对群数」字段（只有「命中次数」一个数字）。对拍证据：老存档里「随机敌人 + 命中次数 2」的卡，改动前后生成出来的 `cs/Cards/…` 文件 **SHA256 完全相同**。

## 五、顺手抓到并修掉的真 bug

自定义状态链上 `base.Owner` **本身就是 `Creature`**（不像卡牌/遗物那样是 Player），「全体单位」最初照抄了 `base.Owner.Creature.CombatState` → 生成的状态类 **CS1061 编译不过**。这是**补的那份「自定义状态链」探针当场抓到的**（主探针盖不到这条链），已修并加 4 条断言钉死。
