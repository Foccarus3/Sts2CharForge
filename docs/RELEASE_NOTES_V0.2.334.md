# V0.2.334 — 动画页：滑条改回填数值；X/Y 偏移能看出相对血条中心的距离；血条宽度跟着缩放变

按你这次的三条要求改的。

## ① 滑条去掉，改回填数值

四项又变回输入框：缩放 / X 偏移 / Y 偏移 / 播放速度系数（右边不再有滑条）。
输入框改完**立刻**重画预览（不用点任何按钮）。

## ② X/Y 偏移现在能看出「相对血条中心偏了多少」

以前的毛病：预览画框的尺寸会跟着偏移**一起变大**（我给偏移留了 `|X|*2` 的余量），而外面是 Viewbox 按布局缩放
→ 一切都会重新缩放到框里，偏移的**相对距离看起来没变**。

现在：

* 画框尺寸**固定**（只随缩放变，横向固定留出足够空白），偏移只是让图在框内左右/上下挪 → 挪多少一眼可见；
* 血条（红条 + 蓝点）**固定在画框正中/底部**，不随偏移跑 —— 于是「图相对血条中心偏了 X 像素」是真能看出来的。

## ③ 缩放改了，预览底下那条血条的大小也跟着变

按本体 `NHealthBar` 的算法：**血条宽度 = 角色宽度 + 24px**（`bounds.Size.X + 24`）。

预览里就是 `红条宽 = 图宽 × 缩放 + 24`，缩放到 2 倍时血条也跟着变宽（下面那行小字会直接写
「红条 = 血条，宽 Npx = 角色 M + 24」）。
