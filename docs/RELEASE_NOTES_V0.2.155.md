# V0.2.155 更新说明

> 回答你上一版问的：「**那做自己上传音频文件**」。做好了 —— 这一版能上传自己的音频，并有一条
> 「**播放音频文件（我上传的）**」效果种类去放它。

## 一、为什么这件事必须绕开 FMOD（先说清楚，免得以后奇怪）

本体自己的声音**全部**走 FMOD：`SfxCmd.Play("event:/sfx/…")`。而**模组注册不了新的 FMOD 事件** ——
事件是编译进 `banks/desktop/*.bank` 的，bank 里存的还是事件 **GUID**（上一版我把那个 42MB 的 bank
全文扫过一遍，一个 `event:/` 字符串都没有），凭路径凭空注册一个事件是做不到的。

所以「放你自己的音频」走的是另一条路：**用 Godot 自己的播放器**（`AudioStreamPlayer`），
音频文件作为**普通资源**打进模组的 PCK：

```csharp
{
    var __sfx = new AudioStreamPlayer();
    __sfx.Stream = GD.Load<AudioStream>("res://audio/my_voice.ogg");
    __sfx.VolumeDb = Mathf.LinearToDb(1.0f);              // 「数值」= 音量%，这里是 100%
    ((SceneTree)Engine.GetMainLoop()).Root.AddChild(__sfx);   // 模型不是 Node，挂到场景根上最稳
    __sfx.Finished += __sfx.QueueFree;                    // 放完自己回收，不会越攒越多
    __sfx.Play();
}
```

整段包在 `{ }` 里 —— 同一条效果在一个方法里出现两次时局部变量名不会撞。

## 二、怎么用

1. **上传**：`美术资源` 页最下面多了「**音效 / 音频**」一块 → 点「**上传音频…**」选一个
   `.ogg / .mp3 / .wav`（`.oga` 也认）。列表里显示「名字 · 本机文件名 → 生成的 audio/xxx」；
   想删就选中点「删除」（**只从存档里去掉，不动你本机的文件**）。
   上传只是**记住你本机那个文件**，生成时才复制进工程（和「上传卡面 PNG」同一个口径）。
   名字会变成生成出来的文件名，重名会自动加序号（同名会互相覆盖）。
2. **用**：效果种类下拉里新增「**播放音频文件（我上传的）**」→「音频文件」那一栏选你上传的那条，
   「数值」那一栏 = **音量%**（留空 / 0 = 100%）。
   ——卡牌 / 遗物 / 药水 / 自定义状态的触发时机**都能放**（不需要玩家选目标，也不需要 choiceContext）。
3. **生成**：音频会被复制到工程的 `audio/<文件名>`；导出预设是 `export_filter="all_resources"`，
   所以它会一起打进 PCK，运行时 `GD.Load<AudioStream>("res://audio/<文件名>")` 就取得到。
4. **校验器**：没选音频 → 错误；选的那条被删了 → 错误；那条的文件在本机找不到了 → 错误；
   扩展名不是 `.ogg / .mp3 / .wav / .oga` → 错误（生成时会按 `.ogg` 命名并跳过不了，所以必须换）；
   同名两条会互相覆盖 → 警告；音量 > 200% → 警告。
5. **回读**：生成时写 `// CET:SfxFile=<文件名> CET:SfxVolume=<音量>`；
   「从工程恢复存档」会把效果**和音频清单**都认回来（清单是从工程 `audio/` 目录扫出来的，
   所以恢复出来的存档下次还能正常生成，不会丢文件）。

## 三、顺手修的一条老问题

`PlaySfx`（V0.2.154 加的「播放音效」）在**自定义状态**里**被校验器拦着用不了** ——
生成端其实早就实现了（`CustomPowerGen` 里有那一支），但「状态触发器里能用哪些效果种类」那份清单
没写上它 → 校验报「生成端还没给自定义状态这条链实现这个效果种类」。
这一版把 **播放音效 / 播放音频文件** 两条都补进那份清单了，现在状态里也能放声音。
