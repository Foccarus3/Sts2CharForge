# V0.2.72 更新说明

> 覆盖血条改成：**每个状态各占一条、颜色各自独立**（A 和 B 能同时看见），
> 并且每条可以选**从血条左边还是右边**开始盖。

V0.2.71 的内容（数值公式那两条修复 + 全体敌人命中次数）也都在这一版里。

## 覆盖血条：两条都能看见了

上一版为了让一个状态在血条上显色，借用了本体「中毒」那一截绿色（改它的颜色 + 位置）。
副作用就是你只能看到**一条** —— 身上同时有 A 和 B 时，谁后写谁赢，另一条被盖掉。

这一版改成：**每个状态各自一个节点**。

- 生成出来的补丁拿本体那一截当**模板** `Duplicate()` 出 N 份（每个状态一份、按状态类名命名、
  挂在同一个 Mask 里），每条**各染各的色、各占各的位置**；
- 本体那截绿色 / 灾厄不动了（上一版会把中毒那截染成你的颜色，这一版不会了）；
- 复制品退出场景唯一名注册（`UniqueNameInOwner = false`），不会去抢 `%PoisonForeground` 那个名字的查找；
- 每次刷新先把我们上次画的全部藏起来，再按当前身上的状态重摆 —— 状态掉了 / 层数归零就自动收尾。

## 新增：选「从哪端开始覆盖」

「自定义状态」页填了颜色之后，下面会多一个下拉：

| 选哪档 | 盖在哪 | 红条怎么让位 | 对应本体的画法 |
|---|---|---|---|
| **从右边开始**（默认） | 从「当前血量的右端」往左量一截 | 红条**右端**往左退 | 本体「中毒」那一截 |
| **从左边开始** | 从血条**最左端**往右量一截 | 红条**左端**往右退 | 本体「灾厄」占的那一端 |

宽度两种都是 **层数 / 最大生命 × 血条宽**（也就是「层数当会失去的血量」）。

- **同一边有好几条就依次往里堆**（互不重叠），**中间剩下那一段就是红条**；
- 两边加起来超过当前血量时，后面放不下的那几条**不画** —— 宁可少画，也不叠在一起糊成一片；
- 从左边开始的那条会让开本体灾厄那一截（它也从最左端盖）；
- 没配「从左边」的状态时，红条左端**一个像素都不动**，本体灾厄的观感不变。

生成出来是这样（每个状态一段，各自的颜色和左右）：

```csharp
HideOurs(mask);                                   // 上一次画的先全藏起来
float leftEnd = 0f, rightEnd = parentWidth + red.OffsetRight;
if (creature.GetPower<BurnPower>() is { } __hp0 && __hp0.Amount > 0m)
    Place(mask, …, "BurnPower", new Color("FF8800"), left: false, amount: (int)__hp0.Amount, ref leftEnd, ref rightEnd, ref anyLeft);
if (creature.GetPower<RotPower>() is { } __hp1 && __hp1.Amount > 0m)
    Place(mask, …, "RotPower",  new Color("3CB371"), left: true,  amount: (int)__hp1.Amount, ref leftEnd, ref rightEnd, ref anyLeft);
if (anyLeft) red.OffsetLeft = leftEnd;            // 红条 = 两边让完之后中间剩下的那一段
red.OffsetRight = rightEnd - parentWidth;
```

## 其它

- 「从工程恢复存档」会把「从哪端开始」一起认回来（标记变成
  `// CET:HpBarColor=FF8800 CET:HpBarSide=Left`）；**旧工程**里没有 Side 那一项，按默认「从右边」处理。
- 「从哪端开始」写了不认识的值会被**归一成「从右边」**（不会留个坏值在存档里）。
- 状态列表里会显示成「…　覆盖血条 FF8800（从左边开始）」，一眼看得出这条会怎么盖。
- 颜色仍必须是六位十六进制，写坏了生成前的检查**报错拦住**；
  不填颜色 = **一个文件都不多、一行补丁都不打**（老存档生成的模组一个字符都不变）。

## 已知限制（说清楚，不藏着）

- 「覆盖血条」只做**自定义状态**；本体的状态想换血条颜色请用「本体状态改写」页那一栏
  （那个是整局改色，和这里的「谁身上有谁变色」是两回事）。
- 覆盖条的观感只对着本体源码核过、也**真编译过**，但**没有在游戏里肉眼确认过** ——
  这一版多节点 / 左右两端都得你进游戏看一眼（尤其是「左右都有」时中间红条的样子）。
- 同一只身上状态特别多、层数特别大时，超出当前血量的那几条会被丢掉（不画），这是故意的。
- 「数值公式」只做卡牌的那 5 种效果，且是**整张牌算一次**的（「每个敌人各自的层数」做不到）。
- 本体的「自定义参数 → 给予能量 / 给予额外资源量」这两栏目前**只是配置项**，生成端还没有用它。
