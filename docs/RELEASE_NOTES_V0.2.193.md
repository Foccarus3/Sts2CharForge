# V0.2.193 更新说明

> 你问：「**我怎么在锻造页没看到自定义状态列表**」——分两种情况，先看下面第 0 条。

## 0. 先确认你装的是哪一版

【状态列表】这个模块是 **V0.2.192** 才加的。如果你看到的锻造页里**连【状态列表】都没有**，
说明跑的还是旧版程序（`Sts2CharForge.exe`）——用 `Sts2CharForge_更新包_V0.2.192.zip`（或这一版的 193）
覆盖一遍程序文件再打开。

装好之后它在两处：

* 锻造页 → 上方「**加模块**」下拉里（列表：触发时机 / if / 对象 / 状态 / **状态列表** / 数值 / 效果 / 且 / 或 / 条件 / 指向对象 / 关系符）；
* 锻造页 → 「积木」编辑器左边的**调色板**里。

## 1. 这一版修的：那一栏以前被默认档藏起来了（所以你「看不到状态可以挑」）

V0.2.192 里我把「**指定的那个状态**」那一栏做成了『只在「看哪些状态 = 只看指定状态」时才出现』——
于是默认档（全部状态）打开这个模块，**里面一个状态都看不到**，看着就像「这个模块没有状态可选」。
这是我的设计问题，这一版改掉了：

* 「**指定的那个状态**」现在**四种档位下都摆着**（可搜索下拉，**你自己的自定义状态排在最前面、带 ⭐**）；
* 它只在「看哪些状态 = 只看指定状态」时**参与生成**，其它档位填了也不影响（界面标签上写着这一句）；
* 和工具里另一条老规矩对齐了：**「在哪选状态」这种事不能藏** —— 用户会满界面找
  （当初【效果】模块的「增益 / 减益」就是照这条规矩一直摆着的）。

## 2. 三种用法回顾（【状态列表】模块）

| 想表达 | 怎么搭 |
|---|---|
| **身上有任意减益** | 【状态列表】(看哪些状态 = 只看减益 · 算哪一个 = 状态数) →【关系符】「大于」0 |
| **状态数 ≥ N** | 【状态列表】(全部状态 · 状态数) →【关系符】「大于等于」N |
| **身上有易伤**（不管几层） | 【状态列表】(只看指定状态 = 易伤 · 状态数) →【关系符】「大于」0 |

左边「归属」接【对象】= 看谁身上的（不接 = 打出牌时选中的那个目标）。

## 4. 提醒

* 那个「数值」出口是**数值**：直接接【if】的「条件」口会被连线规则拦住（那个口要「成立/不成立」），
  中间过一道【关系符】就行。
* 改完记得**重新生成 + 一键构建 + 替换 mod**。
