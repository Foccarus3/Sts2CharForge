# V0.2.297 — 公式数值实时显示

## 现在写成什么样

在「数值（公式）」那一栏下面那行小字里，**最前面**直接写出结果（卡牌 / 遗物 / 药水 / 自定义状态的效果编辑器共用这份模板，一处改动全覆盖）：

| 你写的公式 | 下面那行小字 |
|---|---|
| `6` | `= 6` |
| `(1+2)*3` | `= 9` |
| `M*3`（M 在「自定义参数」页设成**固定数值** 4） | `= 12` |
| `X+2` / `HandCount*2`（含运行时量） | `＝出牌时现算（含 X / 状态层数 / 手牌数这类运行时量）` |
| `M*`（写错） | `⚠ 公式有误：公式写到一半就没了（多半是少了一个数字或右括号）。` |

探针实测输出（原文）：

```
M*3            → ＝出牌时现算（含 X / 状态层数 / 手牌数这类运行时量）      ← 这个存档的 M 不是固定值
6              → = 6
X+2            → ＝出牌时现算（…）
HandCount*2    → ＝出牌时现算（…）
M*             → ⚠ 公式有误：公式写到一半就没了（多半是少了一个数字或右括号）。
(1+2)*3        → = 9
```

## 怎么算的

用的是工具里现成的求值器 `ForgeFormula.TryEvalConst`（`ForgeFormula.cs:475`）：

* **参数**只有「取值来源 = 固定数值」的才算常量，其它来源（最大生命 / 敌人层数 / 手牌数…）都当运行时量 → 如实说「出牌时现算」，不会给你一个假的数字；
* 内置只读量（Turn / HandCount / X / Y…）一律算运行时量；
* 纯数字 / 能折成常数的式子（`(1+2)*3`）当场折出来；
* 语法错直接把错因写在小字里，不用等校验器。
