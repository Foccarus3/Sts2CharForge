# V0.2.256 — 组页面「状态列表」看不见（改成并排两列）+ 存档里某项类型写错不再整份读不进

## 你报的两件事

## ① 组页面：现在是**并排两列**，两块都能看见

V0.2.255 里「这个组里有哪些状态」是**另起一块 Border**，跟卡牌那块叠在同一个单元格、靠底对齐 ——
窗口一矮就被裁在可视区外，所以你只看到「有哪些牌」。现在改成：

```
┌ 组名 / 备注 ────────────────────────────────┐
├───────────────────────┬────────────────────┤
│ 这个组里有哪些牌       │ 这个组里有哪些状态   │
│ ☑ 打击  ☐ 防御 …      │ ☑ 虚弱  ☐ 你的状态… │
└───────────────────────┴────────────────────┘
```

* 左列「有哪些牌」还带「全选 / 全不选」；右列是新的「有哪些状态」（标题是绿字，好认）；
* 两列各自带滚动条，窗口再矮也不会把哪一块挤出屏幕；
* 已用 1920×1080 实机截图确认两列都在（左列卡牌、右列绿字标题+状态列表）。

## ② 「配置解析失败」：不是你的存档坏了，是**某一项的值类型写错**

弹窗里的原文是：

> 配置解析失败：The JSON value could not be converted to System.String. Path: $.Version

意思是：`Version` 这一项应该是**字符串**，但文件里写成了数字 / true（例：`"Version": 1.5`）。
以前遇到这种情况整份存档都读不进来 —— 这次改了两件事：

* **宽容读**：存档里本该是字符串的项，写成数字 / true / false 也能读（`1.5` → `"1.5"`）；
  我们自己写出去的格式**不变**（还是带引号的字符串）。
* **说清楚**：以后真出错，弹窗会写清 **哪个文件** + 「这一项的值类型写错了：例如 `"Version": 1` 应该是 `"Version": "1"`」。
* 顺带：启动那个「选择配置存档」列表里**不再把 `*.forge_classmap.json` 当成存档列出来**
  （它是生成器自己的「锻造卡片 → 类名」对照表，点开必然报错 —— 刚才那个弹窗就是它引起的）。
