# V0.2.394 — 审核信息补齐：最近一次异常 / 最近一次生成输出（需求书 6.4）

需求书 6.4 列的「插件详情页要显示」那几项，这一版把最后两项接上。

## 新增

* `EditorExtensionStatus.LastError` / `LastGenerate`；
* **`Error` 的 setter 自动写进 `LastError`** —— 所有已有失败分支（版本不兼容 / 找不到程序集 / 入口没实现接口 /
  初始化抛异常 …）不用逐处改，就都自动记上了「最近一次异常」；
* `Host.Generate` 结束时写 `LastGenerate`（`已写出 N 个文件` / `用户取消了生成` / `…N 个问题`），
  写文件失败时同时记 `LastError`；
* 插件详情「编辑器扩展」页签新增两行：
  * **最近一次异常**：无 → 灰字「（无）」；有 → 红字显示；
  * **最近一次生成输出**：无 → 灰字「（无）」。
