# V0.2.242 — 那几条「本张牌这一次打出」的读数，现在一眼就能看到

## 用户报的

「那我怎么没看到 ThisCardBlock（本张牌这次打出获得的格挡）、ThisCardExhaust / ThisCardDiscard /
ThisCardTransform / ThisCardGenerate」

## 查证：东西一直在，只是**看不见**

`ThisCardBlock`（V0.2.194）和四条张数读数（V0.2.241）都真的做进去了 ——
`FormulaBuiltins` 里有、生成端认、校验器认、卡面也能印。但界面上只有**两个地方**能看到它们的名字：

1. **参数参考窗**（启动时弹的那个）→ 「内置实时读数」这一类有 **80+ 行**，那 6 条排在**最后**；
   窗口一开只露出开头十来行，要一路滚到底才看得见 —— 等于没有。
2. **锻造页**的公式框才有「填入参数…」按钮；**卡牌页**的公式框旁边什么都没有，
   名字只写在 tooltip 那一大段文字里（而且 tooltip 里只列到 `ThisCardDamage` 为止）。

所以「生成了但看不到」是**界面发现性**的问题，不是功能缺失。

## 这一版做了什么

1. **参数参考窗把卡牌专用读数拆成第一类**（`ParamReferenceWindow.BuildCategories`）：
   标题「这张牌这一次打出（只能写在卡牌上）」，一条 6 项：
   `ThisCardDamage` / `ThisCardBlock` / `ThisCardExhaust` / `ThisCardDiscard` / `ThisCardTransform` / `ThisCardGenerate`。
   窗口一打开默认就选中这一类（以前默认是那张大表的第一行）。
   同时这几条**从「内置实时读数」里剔除** —— 每条在参考窗里只出现一次（分类不重不漏，自检钉着）。
2. **卡牌页的公式框旁边加了「…」按钮**（`OnInsertFormulaParam` + `MainWindow.InsertFormulaParamInto`）：
   挂了四个公式框 —— 「数值（公式）」「命中次数（公式）」「生效次数（公式）」两档。
   点开就是整张清单，**卡牌专用那 6 条排最上面**，其次 X / Y、当前存档的自定义参数、其余内置读数。
   点一下按光标位置插进去（`InsertFormulaText`）。
   因为那个效果编辑器是 `App.xaml` 里的模板，事件处理器只能挂在 `App` 上（挂 MainWindow 会 CS1061），
   所以 `App.xaml.cs` 里那个 `OnInsertFormulaParam` 只做转发。
3. 「数值（公式）」的 tooltip 也改了：不再手工列举到 `ThisCardDamage` 为止，而是
   **把 6 条卡牌专用读数点名列出**，并注明「完整清单见参数参考窗，或点右边『…』直接插」。

## 验收

- 自检：开发版 **4287 PASS / 0 FAIL**（新增 5 条：第一类就是那 6 条 / 只出现一次 / 「…」菜单里它们排最前 /
  菜单里 X·Y·其余读数一条不少（88 项）/ 卡牌页真的画出 4 个「…」按钮）。
- 截图确认（本机实跑）：参考窗一打开就是「这张牌这一次打出」那一类，6 条**全部在首屏可见**，不用滚。
- 本版**只动界面（App 项目）**，`Sts2CharForge.Core` 的源码一行没改 —— 老存档的生成结果与 V0.2.241 完全一致。

## 怎么用

卡牌页 → 选一条效果 → 在「数值（公式）」框里点右边的「…」→ 最上面那一组就是这 6 条；
或者打开「参数参考」窗，第一个分类同样是它们（每个名字后面都带中文说明）。
