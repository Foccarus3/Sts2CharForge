# V0.2.150 更新说明

> 回答你报的：「**卡牌页右边的效果栏做的太差了，能不能优化一下**，像造成伤害这个效果，只需要
> 数值（公式）/ 升级增量 / 作用对象 / 命中次数（公式）/ 生效次数（公式）/ 概率（公式）/ 下回合生效 /
> 随机目标允许攻击同个敌人，其他的都可以隐藏掉。其他每一条效果你都需要问我每一个需要保留什么」。

这一版做的就是这件事：**每种效果只摆它真的用得上的栏位**。

## 一、先把「用得上」量出来，而不是猜

65 种效果 × 每条链（卡牌 / 遗物 / 药水）× 47 个栏位，一栏一栏**机械测量**：

1. 给每种效果各造一条效果，把某一栏改成特征值（例：数值填 111、选牌方式改成「自己选」）；
2. 重新生成这条效果的代码；
3. 和「不填」的基线**逐字符比对**（`// CET:` 那种给回读用的标记行整行删掉，它不算「读了」）；
4. **不一样 ⇒ 生成端真的读了这一栏**。

结果落在 `Sts2CharForge.Core.Effects.EffectFieldPolicy`（唯一一份允许清单），
测量器是 `EffectFieldUsage`，命令行也能自己跑：

```
forge --fieldmatrix "D:\out.tsv"      # 输出 chain / kind / field / read
```

## 三、按你拍板的那些组，逐类收起来

你给的分组答复是「按推荐」，实现时**以测量结果为准**（推荐的措辞是概略的，实测更细），
所以有这几处和当时的措辞不一样，都是「少摆一些白摆的框」：

- **命中次数**：只有「造成伤害」和几种「伙伴攻击」真的读它（外加「作用对象 = 随机敌人」那一档）——
  所以施加状态、失去生命这些种类不再摆（它们填了不生效，这次连框都不摆了）；
- **下回合生效**：卡牌链上**正好**是那 8 种「语义上做不了」的不读它（和 V0.2.149 一样），
  所以这一行的判据没变（V0.2.150 只是用测量复核了一遍，没有再写第二份清单）；
- **作用对象**：只留 19 种真的会读它的（造成伤害 / 格挡 / 回复 / 失去生命 / 最大生命 / 施加状态 /
  击晕 / 翻倍 / 暴露 / 清除指定状态 / 清除全部减益 / 禁止格挡 / 禁止回血 / 临时增益 / 大限已至 /
  伙伴攻击那 4 种）；其余（生成卡牌、抽牌、获得能量、获得金币…）全部收起；
- **升级增量**：23 种生成端根本不读它（击晕 / 翻倍 / 暴露 / 清除 / 结束回合 / 额外回合 / 获得药水 /
  回合结束自动打出 / 填满手牌 / 给予关键词 / 四种全局牌组 / 卡牌奖励 / 伙伴承伤开关…）→ 收起；
- **生效次数**：只有「将此牌放回手牌」和「抽到这张牌时它本场费用 -N」这两种不读它（它们的生成代码
  挂在卡自己的钩子上，没有「整条效果重复几遍」的落点）→ 这两种收起。

## 四、顺手修好「有用却摆不出来」的几处（测量顺带发现的）

以前有几栏**生成端明明在读、界面上却藏起来了**（等于做不出来）。这次按测量结果摆出来：

- **取几张（恰好 N / 最多 N / 任意张）**：以前只有 6 种能填，实测「变化卡牌 / 复制卡牌 / 重放卡牌 /
  回合结束自动打出 / 放置卡牌 / 给予关键词 / 三种全局牌组 / 删除卡牌（全局）」也真的会读它 → 现在都能填；
- **多选1**：以前只有「生成卡牌」能填，实测「变化卡牌 / 获得卡牌（全局）/ 变化卡牌（全局）」
  在「按范围随机」时也读它 → 现在也跟着出现；
- **选牌方式（自己选 / 随机）**：以前一直摆着，现在按测量结果摆，并且补上了「三种全局牌组」那几种。

另外「复制卡牌」不再摆「取卡方式 / 范围限定」（它挑哪张牌由「选牌方式 / 从哪里选牌 / 范围界定」决定，
不读取卡方式）——它仍然保留「附加处理」（复制出来的卡升级 / 免费 / 加关键词）。

**锻造节点图一个字都没改**：那边的栏位显隐本来就是它自己那套（`ForgeCanvasView`），
这次只在卡牌 / 遗物 / 药水 / 自定义状态这四条共用编辑器上生效。
