# V0.2.335 — 预览只留描点（去掉血条方块）

按你要求：预览底下不再画那条红色血条，只留**瞄点**：

* 一条贯穿的蓝**竖虚线**（= 血条中心的横向位置）；
* 中心一条短**横线 + 蓝点**（= 血条中心那一点）。

X / Y 偏移的参照仍然是这个瞄点：偏移一改，图就在固定画框里相对瞄点挪动；缩放仍以瞄点为中心。

## 顺带回答：缩放的「1」是不是原尺寸？

**是「帧图 1:1」，不是「和静态立绘一样大」。** 两条口径：

| 填的值 | 含义 |
|---|---|
| `0` | **自动**：按「静态立绘高 ÷ 待机内容高」算一个缩放，让动画和静态立绘一样高（推荐） |
| `1` | 帧图按**原始像素尺寸**放（不额外放大/缩小），再乘静态立绘节点自己的缩放 |
| `2` | 在 1 的基础上放大一倍 |

所以想让动画和静态立绘**等高**，用 `0`（自动），或者手填 `静态立绘高 ÷ 待机内容高` 的那个数。
预览下面那行小字里也会写「缩放 1 = 原尺寸，0 = 自动」。
