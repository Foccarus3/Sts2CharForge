# V0.2.262 — 「召唤所有召唤物不生效」：自定义状态链没展开「全部召唤物」

## 你报的

> 召唤所有召唤物不生效

## 真因

「全部召唤物」在工具里是一个特殊标识 `"*"`，生成时要按**每只启用的召唤物逐只展开**成 N 段代码。
这个展开写在了**卡牌链**和**遗物链**上，**自定义状态那条链漏了** —— 它把 `"*"` 直接丢给「单只」那套，
而单只那套只认真正的宠物类名，`"*"` 认不出来，于是只生成了一句注释：

```csharp
// ⚠ 这条「召唤伙伴」没有可用的召唤物（找不到召唤物「*」）：到「召唤物」页添加一只并勾上「启用」
```

代码编得过、游戏里一只都不召 —— 就是你说的「不生效」。

## 改法（`CustomPowerGen` 的「召唤伙伴」）

和卡牌 / 遗物同一份口径，按 `PetGen.ResolveMany` **逐只展开**：

```csharp
// 【全部召唤物】这一条对 2 只各来一遍：小石头、小铁块
await UiCheckPetCmd.Summon(choiceContext, base.Owner.Player, 9m);   // CET:PetHp=configured // CET:PetAll=p1181019282
await UiCheckPet2Cmd.Summon(choiceContext, base.Owner.Player, 15m); // CET:PetHp=configured // CET:PetAll=p1181019282
```

* 每份都带同一个 `// CET:PetAll=<组号>` 标记 —— 「从工程恢复存档」时会把同组的多份**合并回一条效果**，
  不会变成 N 条散效果；
* 组号按这条效果的内容算，同一份配置每次生成都一样；
* 「召唤物」页一只都没启用时，生成的是**明说的注释**（不再假装召过）。

**药水**仍然不放行（「召唤伙伴」只支持卡牌 / 遗物触发 / 自定义状态）—— 这条校验器早就按**错误**拦住。
