# Sts2CharForge V0.2.47

> 这一版实现需求 ③：**所有会挑牌 / 对牌动手的效果都能限定范围**（和「生成 / 变化卡牌」同一份选项表）。
> 例：只消耗攻击牌、只随机丢技能牌、只升级能力牌、只给「命运」那一组牌加关键词。

## 新：「范围界定（哪些牌能选）」

效果种类选下面任意一条时，编辑器里会多出一行「**范围界定（哪些牌能选）**」：

| 效果种类 | 「范围界定」管什么 |
| --- | --- |
| 消耗卡牌 / 丢弃卡牌 / 升级卡牌 / 复制卡牌 / 重放卡牌 / 回合结束时自动打出 / 给予卡牌关键词 | 只从那一摞里挑**符合范围**的牌来动手（自己选 + 随机两条路都过同一份过滤） |
| 从抽牌堆 / 弃牌堆 / 消耗牌堆拿牌到手牌 | 选牌界面里只列符合范围的牌 |
| 预见 | 先看抽牌堆顶 N 张，再把其中**符合范围**的列进可以丢掉的那一批 |

- 候选和「生成 / 变化卡牌」的**「范围限定」完全同一份**：不限 / 攻击 / 技能 / 能力 / 诅咒 / 状态，
  再加上**每个自定义关键词一组**（把关键词当「卡的组」用）。
- 这一行**一直在**（不像「范围限定」藏在「按范围随机」那一档后面），因为「自己选」那一档同样要筛候选 ——
  以前有用户报过「找不到在哪限定范围」，这次不做成一档才出现。
- 范围里一张牌都没有时这条效果**什么都不做**（不会弹一个空的选牌界面让你干等）。
- 卡面描述会写清范围，例：「自己选消耗 1 张手牌**（只限攻击牌）**。」；
  列表里也会写「｜ 范围界定：攻击」。
- **选「不限」= 和以前完全一样**：生成的代码、卡面描述一个字都不多（自检里把生成文本钉死了）。
- 「给予卡牌关键词」「回合结束时自动打出」数值填 0（= 这张牌自己）时不显示这一行 —— 那一档不挑牌。
- 「自定义关键词」那一组一张牌都没有时，生成前的检查会**报错**拦住；
  「范围界定」用在**自定义状态**的触发器里也会报错拦住（那条链上拿不到角色配置）。

**「变化卡牌」没有这一行**：它的「范围限定」早就有含义了（那是「变出来的新卡从哪个范围抽」），
同一个字段再拿去限定「挑哪几张牌去变」会变成一句话两个意思，还会让老存档静默改行为，所以不重复给。

## 顺带修的两个回读老毛病

都是这一批效果上的，探针实测踩出来的（`--recover` 从工程恢复存档时）：

- 「消耗卡牌 + 自己选」生成的是一行 `foreach (…) await CardCmd.Exhaust(…)`，
  以前回读会**掉这条效果**、并多出一行「没认出来」；
- 「升级卡牌（战斗内）+ 随机」紧跟的那句 `CardCmd.Upgrade(pick);` 会被当成
  「升级卡牌（全局）」，回读后**多出一条**效果。

## 其它

- 「从消耗牌堆拿牌到手牌」这一轮把**遗物触发 / 药水**两个上下文也补上了（以前只有卡牌能用）。
- 自检（`--uicheck`）新增 30 条断言（这些种类都能选范围 / 生成的候选池真被过滤 / 范围为空时与旧版逐字一致 /
  描述写了范围 / 三个上下文都接上 / 空组报错 / 生成 → 回读 12 条效果原样回来 / 界面那一行的显隐）；
  探针：生成 → `dotnet build` 0 错误 → 回读**没有**「没认出来」。

## 说明

- 存档格式没有变化，直接覆盖更新即可；你的存档在 `自定义角色存档\` 里，覆盖程序文件不会动它。
- 发布包里**不含任何存档**、也不含任何《杀戮尖塔 2》的游戏素材。
- 程序内嵌的效果库数据需要你自己用「效果库」页从本机解包工程生成（仓库不附带游戏文本）。

3. 详细功能说明见根目录 `README.md`
