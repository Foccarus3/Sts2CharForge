# V0.2.100 更新说明

> 你问的「参数监听那些量（回合数 / 丢弃数 / 消耗数 / 生成数 / 复制的牌数 / 获得的能量 / 获得的额外资源量 /
> 身上状态数）找不到在哪」—— 它们**一直能用**，但界面里只写在说明文字里、没列出来，所以确实难找。
> 这一版在效果编辑器里加了一块**一直显示**的「可用量」清单。

## 一、现在去哪找（界面位置）

**「卡牌」页 → 选中一张牌 → 右边效果栏选中一条效果 → 效果编辑器最下面那块蓝色小框「可用量」**：

- 里面按「名字 + 中文说明」列出了全部 **17** 条内置只读量，一直显示（不用先填错才知道）；
- 框里同时写明还能写 `X`（当前能量）、`Y`（当前额外资源量）和参数名（`M` / `N`…，要到「自定义参数 / 组」页定义）；
- 这块清单就是**生成端用的那张表本身**（`FormulaBuiltins.All`）—— 界面列出来的名字和生成时认的名字是同一份，
  不会出现「界面写着能写、生成时报不认」。

能写进公式的三个地方（都在卡牌的效果编辑器里）：

| 公式框 | 在哪 |
|---|---|
| **数值公式** | 效果编辑器上半部分「数值公式」那一栏 |
| **次数公式** | 「次数公式」那一块（生效次数 / 命中次数 / 复制份数 / 重放次数 / 概率） |
| **条件数值公式** | 「条件选项」里的「数值 N」/「数值 M」旁边那个框 |

## 二、清单里的 17 条（对照你列的那几项）

| 你要的 | 内置名字 |
|---|---|
| 回合数 | `Turn`（自己这一侧的第几回合）、`Round`（战斗轮数） |
| 本回合 / 本场战斗丢弃的牌数 | `DiscardedThisTurn` / `DiscardedThisCombat` |
| 本回合 / 本场战斗消耗的牌数 | `ExhaustedThisTurn` / `ExhaustedThisCombat` |
| 本回合 / 本场战斗生成的牌数 | `GeneratedThisTurn` / `GeneratedThisCombat` |
| 本回合 / 本场战斗**复制的牌数** | 同上的 `GeneratedThisTurn` / `GeneratedThisCombat`（**含复制**）—— 见下 |
| 本回合 / 本场战斗获得的能量 | `EnergySpentThisTurn` / `EnergySpentThisCombat`（**花掉的**能量，见下） |
| 本回合 / 本场战斗获得的额外资源量 | `StarsGainedThisTurn` / `StarsGainedThisCombat`（只数正数 = 获得） |
| 身上状态数量 | `PowersOnMe`（不含本体内部状态） |
| （额外送的）四摞张数 | `HandCount` / `DrawCount` / `DiscardCount` / `ExhaustCount` |

## 三、那两处「和你想的可能不一样」的地方（说清楚，不糊过去）

- **「复制的牌数」没有单独的名字**：本体把复制出来的牌也记成「生成」
  （复制走的是同一个 `CardPileCmd.AddGeneratedCardToCombat` → `History.CardGenerated`，历史里没有单独的「复制」条目）——
  所以 `GeneratedThisTurn` 里**包含**复制出来的。要「只数复制」得额外补丁记一份，需要的话说一声。
- **「获得的能量」目前是「花掉的能量」**（`EnergySpentThisTurn/ThisCombat`）：本体在战斗历史里只记了
  `EnergySpentEntry`（花掉的），**没有**「获得能量」的条目；要「获得」得靠工具自己记（加个记录器）。
  如果你要的是「本回合获得过几点能量」，告诉我，我照 `EnergySpent` 那套加一个自记的计数器。

## 四、配套（这一版一起做的）

- **界面**：新的窗口级模板 `FormulaBuiltinList`（一处定义、三处公式区共用外观），
  数据源 `MainWindow.FormulaBuiltinRows => FormulaBuiltins.All`；
- **文案**：`数值公式` / `次数公式` / `条件数值公式` 三处说明都指向了这块清单；
  `数值公式` 那行还补了「⚠ 只做在卡牌上」（在遗物 / 药水 / 状态上填了会被拦住，免得白试）；
- **自检**：7 条新断言（清单数据源就是生成端那张表、标题在界面上真的显示、
  17 个名字至少抽查 9 个、中文说明在、X/Y/参数名那行在、说明文字指向清单、
  **遗物编辑器里没有这块清单**）。
