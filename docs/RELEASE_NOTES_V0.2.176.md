```csharp
Creature? __petWolf0435dc = __fgPlayer.PlayerCombatState?.Pets.FirstOrDefault(c => c.Monster is PetWolf); {
    if (__petWolf0435dc is not null) {
        await DamageCmd.Attack((decimal)__petWolf0435dc.MaxHp)
```

* 「按生命值算的三种攻击」在图上**内联**算伤害（图上没有卡牌的 `CalculatedDamage` 计算变量）；

## 二、顺手修掉的两个**结构性**坑（比补种类更要紧）

### 2.1「用到才生成」的判据以前**一条节点图效果都不收**

`CSharpCodeGen.AllEffects`（所有辅助类 / 补丁的「用到才生成」判据）只看「效果列表」，
**节点图上的效果一条都不看** —— 于是图上用到那些辅助类就是 **CS0246、整个工程编译不过**。
V0.2.168 给 `BoostCard` 单独打过一次补丁，那是逐个补的做法，加一个新种类就漏一次。
现在改成**一处收全**（`ForgeEffectBridge.GraphsOf` 把四类布全收进来），后面加种类不用再逐个补。

### 2.2 同类漏判还有两处（真编译抓出来的）

* `PetGen.UsesAttackExtension` 以前只看卡牌 / 状态列表 → 图上的伙伴攻击会让
  `PetAttackExtensions.cs` 不生成（`.FromPetAttacker(...)` 找不到 → CS1061）。改成走统一的 `UsesKind`。
* 「增加额外资源量上限值」那个 Power 类只在「页面上开了额外资源量 + 填了上限」时才生成 →
  只在图上用这一条时 **CS0246**。现在按「有没有用到这条效果」单独判。

## 三、剩下 3 种为什么没做（不是漏，是说清了）

| 种类 | 原因 |
|---|---|
| 本回合这张牌自己费用变 0 | 本体语义是**这张牌自己的行为**（生成 `base.SetToFreeThisTurn()`），节点图的【效果】模块没有「牌自己」可以挂 |
| 抽到这张牌时它本场战斗费用 -N | 同上：生成的是**卡自己的 `AfterCardDrawn` 钩子** |
| 转化为先古遗物 | 它要选「换成哪只遗物」，而节点图的【效果】模块按卡牌页那套字段存（没有遗物下拉）→ 选不到正确的值、生成出来会引用一张卡当遗物类（CS0311）。**它仍然在「遗物 / 药水」的效果列表里可用**（那一页有专用编辑器） |

> 「生成卡牌 + 按范围随机 / 多选1 / 从范围里自己挑」**早就支持**（V0.2.170）—— 那一项不是缺口，
> 是我第一版探针没填目标卡造成的误报。

**这 3 种在节点图上选中时，生成代码会写一行说明**（卡牌专属的会说「这一档是卡牌自己的行为」，
其余说「还没接上」），并且**校验器在生成前就报错拦住**（不会静默不生效）—— 报错里还会列出「节点图现在支持哪些」。
