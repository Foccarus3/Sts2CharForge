# V0.2.146 更新说明

> 修你报的：**「数值公式」框里填纯数字会被拦住**（你原话「数值公式就不能填纯数值吗」）。
> 这一版起，非那 5 种效果（生成卡牌 / 抽牌 / 消耗…）的「数值公式」框里填一个**纯数字**（或 `2+3` 这种纯常数式子）
> 会被**自动折成左边的固定数值** —— 不用你手填两处，也不会再弹出那句「不支持『数值公式』」。

## 一、真因与修法

**以前的行为**：「生成卡牌 / 抽牌 / 消耗 / 生成几张」这类效果的数值必须在**生成的时候**就定下来
（要提前分配动态变量、算好选牌上限），所以工具直接把「数值公式」那一栏**报错拦住**：

```
卡牌「新卡」的「生成卡牌」不支持「数值公式」（现在填的是 1）：……
卡牌上这一栏只有两种情况能用：① 那 5 种……支持完整公式；② 其余种类只支持光秃秃一个 X……
请清空「数值公式」，改用左边的固定数值。
```

这句提示本身是对的，但对填了 `1` 的人来说只会觉得「填个 1 为什么不行」—— `1` 本来就能在生成期折出来。

**现在**：开工之前自动折好 —— 数值 = 那个常数、公式框清空（等价于填在左边的固定数值框里）。

- 打开存档时折一次（老存档里已经填着 `1` 的，打开就已经是「固定数值 1」，不用手改）；
- 点「生成 / 一键构建」前的配置检查里再折一次（界面里刚改完、还没存盘的也算）；
- **折的是纯常数**：`1`、`2+3`、`=1`、`0.5` 都算；
- **不折**：`M*3`、`HandCount`、`X` 这些**运行时**量（照旧报错拦住，说清原因）；
- **那 5 种效果（伤害 / 格挡 / 失去生命 / 回复生命 / 施加状态）上的公式一个字符都不动**
  （它们的公式栏是正牌编辑器，`6` 是常态，折了会和「固定数值 → 公式」的自动迁移来回打架）；
- 「数值 = X」那种老写法也不动（X 是另一套语义）。

生成结果：**填在「数值公式」里的 `1` 与填在「固定数值」里的 `1`，生成出来的卡牌源码逐字节相同**
（自检里有这条对拍断言）。

## 三、说明

- 上一版（V0.2.145）修的是「自定义状态用生成卡牌会让战斗卡死」；这一版只动「数值公式填纯数字」这一件小事，
  两版都在这一份程序里。
- 界面上的措辞也一起改了：「数值公式」那一栏的说明 / 悬停提示现在写明「纯数字 = 左边的固定数值（会自动折好）」。
