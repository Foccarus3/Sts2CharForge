# V0.2.239 — 自定义状态可以「允许负层数」了（层数能到负值）

## 用户问的

「在自定义状态增加状态层数能否到负值」

## 以前的实际情况

**不能。** 生成端按「这个状态的本体允不允许负层数」分两档（`CSharpCodeGen.ApplyPowerLine`）：

- **允许**（本体就那 5 个：力量 / 敏捷 / 专注 / 尖啸 / 萎缩）→ 照本体「尖啸 PiercingWail」那套
  `PowerCmd.Apply<状态>(目标, -3)`：目标身上**本来 0 层也能扣成 -3**；
- **不允许**（其余全部，**包括你自己造的状态**）→ 先 `GetPower<状态>()` 再 `ModifyAmount(-3)`：
  只从**目标身上已有的层数**里扣，扣到 0 就把这个状态去掉 —— 层数永远到不了负值。

判据是 `EffectCatalog.AllowsNegativeLayers`，里面原本只有本体那 5 个写死的类名，自定义状态一个都不在里面。

## 这一版做了什么

「自定义状态」页的状态属性里多了一个勾选框：

**允许负层数（像力量那样，0 层也能扣成负的）**

勾上之后，这个状态和本体 力量 / 敏捷 / 专注 完全同一个口径：

1. 生成的状态类多一行 `public override bool AllowNegative => true;`
   （`PowerModel.SetAmount` 不再把层数夹在 0 以上，`ShouldRemoveDueToAmount` 变成「正好 0 才移除」）；
2. 这个类名会被登记进「允许负层数」名单，于是**所有**「施加增益 / 减益」填负数的地方
   （卡牌 / 遗物 / 药水 / 状态 / 锻造【效果】）对它都改成「直接施加负值」——
   目标身上 0 层也能变成 -N；
3. 「临时增益」填负数的分档也跟着一致（同样走「直接施加 -N 层」，到点再还原）。

不勾（默认）时行为和以前一模一样（一个字符都不多写）。

## 连带表现（都是本体那套，不是我们另写的）

- 负层数在游戏里按**减益**显示（红框 + 红字层数）—— 力量负值也是这样；
- 层数正好回到 0 时，本体把这个状态移除（不是「留一个 0 层的挂件」）；
- 「每回合衰减」仍然是「减到 0 就移除」，**不会**继续往负数扣（想让它保持负数就别配衰减）。

## 校验器的提示也跟着改

以前那句提示一律说「本体允许 / 本体不允许负层数」—— 自己造的状态没有「本体」。
现在按三类分开说：本体允许的（力量…）、你勾了「允许负层数」的自定义状态、以及没勾的自定义状态
（后者会明确提示「想让层数能到负值，请到『自定义状态』页勾上『允许负层数』」）。
