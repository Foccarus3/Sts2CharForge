# V0.2.194 —— 锻造页新增「状态列表」：用那块布给自定义状态编效果

> 用户原话：「我要的不是模块，是**锻造页左边『要锻造哪一类』里多一个『状态列表』**（像卡牌列表 / 药水列表 /
> 遗物列表那样，用那块布给自定义状态编效果）。」
> （V0.2.192 先做的那个【状态列表】**取值模块**留着不动 —— 它解决的是「按状态数 / 层数算一个数值」，
> 这一版解决的是「**状态本身**也用锻造页那块布来编」。）

## 1. 锻造页多了第四类：状态列表

「锻造」页左边「要锻造哪一类」现在有四档：卡牌列表 / 药水列表 / 遗物列表 / **状态列表**。
选中「状态列表」后：

* 左边列出你这个存档里的**自定义状态**（就是「自定义状态」页那些，同一份数据）；
* 右边那块布（节点图 / 积木）显示 / 编辑这只状态的触发时机与效果链；
* 「添加」新建一只状态（自动起名，并给一块带【触发时机】的空布）；
* 布上的【触发时机】用的是**「自定义状态」页那一整套时机**（同一份菜单：玩家回合开始 / 打出一张牌时 /
  自己受到伤害后 / 某个状态层数到达 N 层时 … 一共三十多条），一个都不少。

## 2. 老状态怎么上布：一个按钮，不偷偷改

以前在「自定义状态」页配过东西的状态（触发时机 + 效果列表），选中时**不会**被自动搬到布上 ——
自动搬的话，布上一有模块就会立刻「图说了算」，老配置会**静默失效**（这是本工具最忌讳的）。
所以：

* 没配过东西的状态 → 直接给一块空布（上面只有【触发时机】）；
* 配过东西的状态 → 出现一个按钮「⤓ 把现在的触发时机 / 效果搬到这块布上」，点了才搬，
  搬完在界面下方说清「从这一刻起这块布说了算」；
* 搬完「自定义状态」页那几栏**不再参与生成**（配置检查里会有一句警告说明），要改请到锻造页改；
* 想退回老路子：把那块布清空（一个模块都不留）。

搬迁是**逐字段**搬的，包括：

* 「只对哪类牌生效」（打牌类时机上那一栏，攻击 / 技能 / 能力 / 诅咒 / 状态 / 关键词 / 组）——
  布上的【触发时机】多了一栏「只对哪类牌生效」，不留空就照旧筛；
* 「数值 / 生效次数 / 命中次数 = 本状态层数」这三个开关 —— 布上生成的是 `base.Amount`（就是这个状态自己的层数）；
* 效果本身的所有栏位（同一份效果编辑器，连「最多 N 张 / 恰好 N 张」这种只有编辑器才知道的档位也不丢）。

## 3. 生成端

* **图非空 = 图说了算**：状态类的钩子（签名 / 归属守卫 / choiceContext / 数值闸门 / 回合结束衰减移除）
  和「自定义状态」页那条链**是同一份代码**，只有「跑效果」那一步换成图上渲染好的正文 ——
  所以两边的行为不会各走各的；
* **图空 / 没有图 = 老路**：生成文本**一个字节都不变**（已用一份 31 只状态的存档逐文件对拍：412 个文件里
  只有 `.sln` 里的随机 GUID 不同）；
* 图版生成出来的工程**真编译通过**（`dotnet build` 0 error）；
* 「从工程恢复」认得出状态的布（生成时在类级写一行 `// CET:ForgeGraph=1:<Base64>`）。

## 4. 状态那块布上做不了 / 会打错人的地方（一律报错说清，不静默）

* 【触发时机】=「获得时」→ 那是遗物专属的（状态是被添加的，没有「拿到的那一刻」）；
* 【获得卡牌奖励】→ 那几句要用 `base.Owner.Character.CardPool`，状态上没有这个属性；
* 一块【触发时机】都没有 → 这块布不会生成任何钩子；
* 布上摆了【能量】模块 → 状态没有「费用」这一说，那一块不参与生成（给一句警告）；
* 「打谁」的默认档：**获得格挡 / 回复·失去生命 / 最大生命 / 抽牌 / 能量 / 金币 / 额外资源量**这类
  一律写在自己身上（和「自定义状态」页那条链一致）；只有**造成伤害 / 施加·扣除·翻倍状态 / 击晕 /
  禁止格挡 / 暴露**这些才看效果自己的「作用对象」那一栏（默认 = 第一个可打的敌人）。
  想自己指定就拖一块【对象】模块接到那条链上。

## 5. 自检（`Sts2CharForge.exe --uicheck`）

本次新增 **32 条**断言（界面 12 条 + 生成端 20 条），整轮 **3899 PASS / 0 FAIL**：

* 界面上：`CardFilter` 那一栏只在「状态列表」档 + 打牌类时机显示（卡牌档 / 非打牌时机都不显示）；
  状态档的「加模块」下拉里没有【能量】、卡牌档照旧有；
  **红线**：有老配置又没图的状态，选中它**不会**自动建布；「⤓ 搬到这块布上」按钮点了之后图非空、
  按钮收起、搬的是同一份效果对象；「添加」出来的状态自带一块空布并立刻选中；
* 生成端：Power 档时机菜单与「自定义状态」页**逐条对齐**（32 条）、钩子分组同一份、且没混进另外三档；
  图空 = 老路（没有图的序幕、也没有图标记）；图版两条链各生成一个钩子（序幕按状态取
  `base.Owner.Player` / `base.Owner`）、【效果】进钩子、【状态列表】默认数自己身上的、写 `CET:ForgeGraph` 标记、
  「只对哪类牌生效」保住；「数值 = 本状态层数」生成 `base.Amount` 且**只对状态放行**；
  搬迁助手（能不能自动建布 / 搬了什么 / 搬完生成语义与老路一致）；
  校验器四条（没有触发时机 → 错误、「获得时」→ 错误、【卡牌奖励】→ 错误、【能量】模块 → 警告）+
  「图说了算 + 页面上还配着老内容 → 警告」。

# 追加（同一版）：内置读数 `ThisCardDamage` —— 「荒疫打击」怎么做

> 你问的：「生成器怎么做荒疫打击」→「没有这张卡造成的伤害的参数吗」→「那做 B 这种，把做出来的参数
> 放在参数弹窗里」。本体 `BlightStrike.cs`（荒疫打击）的层数是
> `attackCommand.Results.SelectMany(r => r).Sum(r => r.TotalDamage)` —— **这一下打出的伤害**
> （含被格挡的部分），生成器以前一条这样的读数都没有（只有「本回合 / 本场累计」那几条）。

## 6.1 新的内置读数

参数参考窗 / 「填入参数…」弹窗里多一条：

* **`ThisCardDamage`** —— 「本张牌这一次打出造成的伤害（含被格挡的；只算普通攻击，和本体「荒疫打击」同口径）」。

它读的是**生成出来的卡片类上的一个属性** `ForgeThisCardDamage`：打出时清零、每条「造成伤害」之后累加。
所以：**每次打出各算一次**（回手再打 / 重放 / 复制出来的第二张互不影响），**不查战斗历史**
（跟 `DamageDealtThisTurn` / `DamageDealtThisCombat` 那两条不是一回事 —— 那两条只算没被格挡的、
还会把别的牌 / 中毒 / 遗物打的伤害算进来）。

## 6.2 荒疫打击怎么配（一分钟）

「卡牌」页 → 新建一张牌 → 效果栏两条：

| 效果种类 | 数值（公式） | 升级增量 | 作用对象 |
|---|---|---|---|
| 造成伤害 | `8` | `+2` | 指定敌人 |
| 施加增益/减益 → 选 **灾厄**（`DoomPower`） | **`ThisCardDamage`** | `0` | 指定敌人 |

卡面自动印成「对指定敌人造成 {Damage:diff()} 点伤害。**对指定敌人施加等量于所造成伤害的灾厄。**」
（后半句不印数字 —— 本体也是这么写的）。锻造页那块布上同样能用：把 `ThisCardDamage` 写进【数值】模块的公式。

## 6.3 会静默失效 / 编不过的写法，一律拦住（不静默）

| 写法 | 结果 |
|---|---|
| 遗物 / 药水 / 自定义状态（含它们的锻造图） | **错误**：它读的是这张牌自己的字段 |
| 卡牌上但挂在「卡牌时机」钩子上（被消耗 / 被丢弃 / 被抽到 / 放回手牌 / 抽到减费） | **错误**：读到的是上一次打出留下的数 |
| 勾了「下回合生效」 | **错误**：延迟状态在下回合开始时才求值 |
| 写在**整张牌条件**里 | **错误**：那个条件在打出之前求值（`IsPlayable` / 描金边），恒 0 |
| 和别的量混写（`ThisCardDamage + 1`） | **错误**：只能光秃秃单独写（`(ThisCardDamage)` 可以）—— 卡面预览那个 lambda 只拿得到 `CardModel` |
| 这条效果**前面没有**「造成伤害」 | **警告**：恒 0 |
| 想当「自定义参数 / 组」的取值来源 | 下拉里**不提供**（参数是打出那一刻先算一次的，选了会恒 0）—— 直接写进「数值（公式）」 |
