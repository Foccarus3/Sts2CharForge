# V0.2.77 更新说明

> 你问的：「为什么效果种类里『对自己造成伤害』不会被护盾格挡？」
> 答案：**那是我们写错了** —— 生成端把它和「失去生命」写成了同一段代码（都带 `Unblockable`），
> 所以护盾一点都吃不到。这一版修好了。

## 为什么会穿盾（本体判据）

本体的伤害管线里，格挡扣多少只看 props 里有没有 `Unblockable`：

```csharp
// src/Core/Entities/Creatures/Creature.cs:433
decimal num = (props.HasFlag(ValueProp.Unblockable) ? 0m : Math.Min(Block, amount));
```

而本体自己把「卡牌对玩家造成的伤害」分成三个常量（`src/Core/ValueProps/DamageProps.cs`）：

| 常量 | 值 | 本体用在哪 |
|---|---|---|
| `card` | `Move` | 卡牌打出的**普通伤害**（可格挡、吃力量/易伤） |
| `cardUnpowered` | `Unpowered \| Move` | **诅咒/状态牌对玩家造成的伤害**（可格挡、不放大） |
| `cardHpLoss` | `Unblockable \| Unpowered \| Move` | 「失去 X 点生命」那种代价（祭品 / 放血）—— **无视格挡** |
| `nonCardUnpowered` | `Unpowered` | 非卡牌来源但**仍可格挡**的伤害（例如荆棘） |
| `nonCardHpLoss` | `Unblockable \| Unpowered` | 非卡牌来源且**无视格挡**（例如中毒） |

我们以前对「造成伤害 + 自己」生成的是 `cardHpLoss` —— 和「失去生命」**一模一样**。
更明顯的是卡面描述：那条路一直写的是「**受到 N 点伤害**」（不是「失去 N 点生命」），
文字和代码对不上。

## 修了什么

| 位置 | 以前 | 现在 |
|---|---|---|
| 卡牌效果栏：造成伤害 + 自己 | `Unblockable \| Unpowered \| Move` | `Unpowered \| Move`（`cardUnpowered`，**格挡能挡**、不被力量/易伤放大） |
| 遗物效果栏：造成伤害 + 自己 | 同上 | `Unpowered`（`nonCardUnpowered`，**格挡能挡**） |
| 自定义状态触发器：造成伤害 + 自己 | `Unpowered`（本来就是对的） | 不变 |
| 任意来源：失去生命 + 自己 | `Unblockable \| Unpowered \| Move` | **不变**（本体就是这么定义的，无视格挡） |
| 节点图：【效果】造成伤害 +【对象】自己 | 走本体攻击链（可格挡） | **不变**（图里这条路一直是对的） |

所以现在：

- 想「打自己一下、**护盾能吸收**」→ 用**造成伤害** + 作用对象「自己」；
- 想「**无视护盾**扣血」（祭品 / 放血那种代价）→ 用**失去生命**。

顺带补掉一个静默坑：**药水的目标如果是「自己」，里面那条「造成伤害」根本不会执行**
（药水没有「自己挨打」这条路，以前只在生成的代码里留一行注释，生成/编译/进游戏全都不报错、就是没反应）。
现在配置检查会**警告**并说清怎么改：

> 药水「××」的目标是「自己」，但里面有一条「造成伤害」—— 这条**不会执行**（药水不会对自己造成伤害）。
> 想喝下去打敌人，请把药水的「目标」改成「单体敌人 / 全体敌人」；真要「付出生命换效果」请用效果种类「失去生命」。

## 要不要改你的存档

**不用**。只有「造成伤害 + 自己」这一条的行为变了（从穿盾变成可格挡）。
如果你本来就是想要「穿盾的自伤」，把那条效果换成**失去生命**即可（数值照抄）。
