# V0.2.348 — 修掉动画预览里的「三个重影、大小不一」

## 原因

预览里其实叠了**三层**东西，其中一层是 V0.2.347 改造时忘了关掉的旧单图：

1. 半透明**静态立绘**（参照物）—— V0.2.347 新增；
2. 按裁剪框缩放的**帧动画**（实际位置 / 大小）—— V0.2.347 新增；
3. ⚠ **旧的 `AnimPreviewImage`**：动画定时器每播一帧就 `AnimPreviewImage.Source = 下一帧`，
   而这张图是**整幅动图**（没裁剪、被拉伸到整个画布），于是每播一帧就多冒出一个大小不同的角色。

三层尺寸都不一样（立绘按 340 缩、帧图按「裁剪框 × 自动缩放 × 立绘缩放」、整幅动图被拉成画布大小），
所以看起来就是「3 个大小不一的角色」。

## 改法

* 动画 tick 改成**只换 overlay 里那张帧图**的 Source（新字段 `_animPreviewFrameImage`），
  再也不用 `AnimPreviewImage`；
* `AnimPreviewImage` 的 `Source` 恒为 `null`、`Visibility = Collapsed`（彻底不画）；
* 预览下方那行小字补上说明：`半透明 = 静态立绘（参照），彩色 = 帧动画（实际位置 / 大小）`。

## 自检

**+2 条**：
* 预览不再用旧单图（`Source` 为 null 且 `Collapsed`）；
* 预览画布上最多只有 **1 张**不透明图片（彩色帧图），不会再叠出多个角色。
