# V0.2.135 更新说明

> 这一版做的是《卡牌页优化.md》第 2 条 ⑤ 里你要的那个做法：**在「升级后的自定义描述」底下放一个按钮，让你挑「哪些字段要变绿」**。
> 生成端一个字没改（这个功能只改那个输入框里的文字），所以**默认档生成结果逐字节不变**。

## 一、界面：新增「高亮字段…」按钮

- 位置：卡牌页 →「**升级后的自定义描述**」输入框**底下**（在「填入参数…」那一行的下一行），旁边一行小字实时告诉你「这段里已经高亮了哪些字段」；
- 点开一个小窗口，标题是「**升级后要高亮的字段 —— 〈卡名〉**」，里面是**这张牌每一条效果各自声明的字段**（带中文效果名），每行一个勾选框，例如 `{Damage:diff()} — 造成伤害`，右边写清它现在的状态：
  - 「这段文字里**已经是** `{Damage:diff()}`（升级后按差异变绿）」；
  - 「这段文字里**现在是** `{Damage}`（普通颜色）；勾上 = 换成高亮写法」；
  - 「这段文字里**还没用到** `{Block}` —— 勾它**不会**替你加字，要加请用『填入参数…』」→ **这一行是灰的**（我刻意不主动往你的文案里塞字）；
- 底部：`确定` / `全部不勾（保持原样）` / `取消`；再打开窗口时**会按正文自动勾好**（已经是 `{X:diff()}` 的预先勾上），所以「不勾」永远不会把你已经写好的高亮去掉。

**它只做一件事**：把你这段文字里已有的 `{X}` 与 `{X:diff()}` 互相换（勾上 = 加 `:diff()`，取消 = 去掉），**其它字符一个都不动**；重复点确定结果一样（幂等）。

## 二、⚠ 你现在那几段文字暂时用不上这个开关

你的「升级后自定义描述」（例如芬奇的「闪光」、闪光的卡 42）是**纯中文 + 直接写的数字**，里面**一个 `{}` 占位符都没有** —— 而高亮只能作用在字段上，所以按钮点开会有一条黄底提示：

> 这段里没有可高亮的字段：一个 `{}` 占位符都没有（你现在写的是直接的数字 / 中文）。请先点上面的「**填入参数…**」把数字换成占位符（例：造成 `{Damage:diff()}` 点伤害），再回来勾。

同一句指路也直接显示在按钮右边那行小字里（不用点开就知道），确定之后状态栏也会说一遍。

## 三、校验器

- 你写了 `{X:diff()}`、但这张牌当前**没有**声明那个字段 → **报错拦住生成**并点名是哪张牌（防止手滑写错、进游戏变空白）；
- 只写了普通的 `{X}` 而没有对应声明 → 只给**警告**（可能是你手写的本体自己的键，放宽一档，免得把正常存档拦死）。

## 五、已知边界 / 没做

1. **勾选状态没有单独存进存档**（第 2 档没做）：它是从正文里的 `{X:diff()}` 反推出来的 —— 好处是不会出现「存档字段与正文不一致」的二义性；坏处是如果你把那段文字整段删掉再粘回来，勾选状态就跟着正文走；
2. `inverseDiff`（反向高亮）与 `:diff()` 带参数的写法**没有实测**，界面上也没提供；
3. 「一键把升级后那段里的数字换成占位符」这种批量改写**没做**（要做得先定一套「哪些数字该换成哪个字段」的规则，需要你拍板）。
