# V0.2.386 — 校验命中「落到具体位置」+ 页面级规则实现合并

两个内部改进（缺口文档第 9 节收尾）。

## ① 命中的行/栏位现在被记下来

* `PluginPageSpec.ProblemRows`（`list栏位key#行下标`）与 `ProblemFields`（页面级栏位 key）——
  都是 `[JsonIgnore]` 的**活集合**，只在内存里用，不写进 `values.json` / `rows.json`；
* **主从布局**里，命中校验的那一行在左侧列表显示成 **`⚠ 1. attack`**，没命中的不带标记；
* 页面顶部那条「这页有配置问题，生成时会跳过」照旧保留（措辞里带行号 / 栏位名）。

## ② 页面级规则合并到 `ApplyOneCheck`

以前「页面级校验」是一份内联的旧代码、「行内校验」是另一份 —— 两份措辞和边界各有细微差别。
现在页面级也走 `ApplyOneCheck`，**只有一处实现**（`required` / `number` / `int` / min / max / 自定义 message 全走它）。
