# V0.2.261 — 「那我如何决定是哪张牌被替换呢」：被古老牙齿换掉的初始卡现在能自己选

## 你问的

> 那我如何决定是哪张牌被替换呢

之前那张「替换古老牙齿所替换的初始卡牌」只决定**换成哪张先古卡**，被换掉的**初始卡**是我按规则自动挑的：
「卡牌页里勾了『初始牌』的**第一张**（按『初始卡组』那一栏从上往下）」。现在你可以自己指定了。

## 新加的东西

先古卡页「先古卡属性」下，那两个勾下面多了一个下拉：

> **被古老牙齿换掉的初始卡（留空 = 自动取初始卡组第一张）** ［下拉］

* 第一项 = **（自动：初始卡组里第一张）** —— 和以前完全一样；
* 其余每一项写成 `中文名  (英文类名)  ｜ 初始牌 / 不在初始卡组`，**整个存档的牌都能选**
  （不止初始牌：本体那张 `TranscendenceUpgrades` 表也是「任意一张牌 → 换成先古卡」）；
* 选中的是**类名**（和「目标卡」下拉同一个口径），所以改中文名不会掉选；
* 生成时：`CreateCard<你选的那张>(player)` 换掉它，再给你这张先古卡。

## 不静默

* 你指定的那张牌后来**改了类名 / 被删了** → 生成时**自动退回**「初始卡组第一张」，并且校验器给一条：
  「指定的『被古老牙齿换掉的初始卡』是 `XXX`，但当前存档里找不到 …… 请到先古卡页那个下拉里重新选一次」；
* 一条先古卡都没勾「替换古老牙齿…」时，这个下拉**填了不起作用**（tooltip 里写了）。
