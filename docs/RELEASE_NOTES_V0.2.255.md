# V0.2.255 — 状态能进组，「清除指定状态」可以选组（一次清一组）

## 你要的

> 能不能让状态进组，然后在清空指定状态的效果里可以选组

## 怎么用

### ① 先把状态放进组

「**组**」页 → 选中一个组（没有就「新建组」）→ 右边现在有**两块**勾选列表：

* 上面「这个组里有哪些牌」（原来就有）；
* 下面新增「**这个组里有哪些状态**」—— 勾上就加入。候选 =
  **你自己的自定义状态**（排在最前）/ 已经加进组但当前配置里没有的（会标出来，方便取消勾选）/ **本体状态**（按中文名）。

> 状态的归属记在**组**这边（`CardGroupSpec.PowerIds`），而不是状态身上 ——
> 因为本体状态（虚弱 / 易伤…）没法往它身上加字段，只有组这边能同时放下「自己的状态」和「本体状态」。

### ② 在「清除指定状态」里选这个组

任何效果里选「清除指定状态」后，状态那一行的右边多出一栏：

> **或者清空一个组** ［下拉：你的组］

* 选了组 = 把组里**每个状态各清一次**（生成出来是每只目标一句
  `PowerModel? __clr_XxxPower = 目标.GetPower<XxxPower>(); if (__clr_XxxPower is not null) await PowerCmd.Remove(__clr_XxxPower);`）；
* **留空 = 和以前完全一样**（只清上面选的那一个状态，生成文本一个字都不变）；
* 两边都填时**组优先**，校验器会提示「上面那个单独的状态栏会被忽略」。

### ③ 不静默

* 选了组但组里**一个状态都没有** → **警告**「这条效果什么都不会清」；
* 用了组 → **提示**列出「会把组里这 N 个状态全部清掉：虚弱、你的某个状态…」；
* 状态没选、组也没选 → **警告**「这条效果什么都不做」。
