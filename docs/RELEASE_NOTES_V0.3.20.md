# V0.3.20 — 变量：卡牌描述不写变化、乘 / 除、0 的语义、伤害一直 0 的诊断

这一版按你的四条反馈改：

## 一、卡牌描述不再生成「变量变化」

「变量」效果是内部记账，卡面 / 自定义描述里不需要写「变量「a」加 1」。
现在 `LocalizationGen.Describe`（卡牌描述）与 `DescribeEffect(isCard: true)` 都跳过 `VarWrite`；
**效果列表里的摘要仍然保留**（方便你在编辑器里确认这条效果存在）。
遗物 / 药水 / 自定义状态的描述**照旧保留**（那三处没有卡面，不写就看不到效果）。

## 二、「怎么改」新增乘 / 除

六档：`+ 加 / - 减 / * 乘 / / 除 / = 设为 / 清零`。

生成：

```csharp
SevenVars.cnt *= (int)(2m);
SevenVars.cnt = ((int)(1+1)) == 0 ? SevenVars.cnt : SevenVars.cnt / ((int)(1+1));
```

除法的**除数可能是 0**（公式算出来），所以生成的是「除数为 0 时保持原值」的条件式，不会崩。

## 三、数值填 0 的语义（`+/-` 不是「整条不生效」）

「变量」效果和普通效果不同：**0 不会把整条效果丢掉**，按操作解释：

| 操作 | 值 0 的结果 |
|---|---|
| `+ 加` / `- 减` | **什么都不改**（这是你截图里伤害一直 0 的直接原因） |
| `= 设为` | 把变量设成 0 |
| `清零` | 把变量设成 0 |
| `* 乘` | 把变量乘成 0 |
| `/ 除` | 保持原值（除数为 0 不执行） |

* 公式框底下的说明已按这个口径重写；
* 校验器新增提示：`+0 / -0` →「不会改变变量，要 +1 请把值填 1」；
* `/0` →「保持变量不变（不会崩）」。

## 四、你那张卡伤害一直 0：大概率就是值填了 0

截图里第二条效果是 **「变量「a」加 0」**，不是加 1：

* 值 = 0 → `a` 永远不变；
* 第一条伤害的公式是 `a` → 每张牌都读 0 → 伤害一直 0。

改法（任选）：

1. 把第二条的「数值（公式）」填 **`1`**；或
2. 想第一张就打出 1 点：把「变量」效果排到「造成伤害」**前面**，并把值填 1；或
3. 把变量 `a` 的初值设成 1（变量页「初值 / 取值公式」填 `1`）。

另：变量名区分大小写，`a` 和 `A` 不是一个名字；如果公式里写的是 `A` 而只建了 `a`，
现在会明确提示「算不出来：「A」不是常数」。
