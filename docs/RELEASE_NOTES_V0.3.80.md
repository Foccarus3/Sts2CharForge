# V0.3.80 — 遗物底部小字可自定义

## 问题

遗物卡面最底部一直显示：

```text
由 Sts2CharForge 生成的自定义遗物。
```

这行是生成器写死的 `flavor` 本地化键，之前没有配置项。

## 新增

「遗物」页新增：

```text
底部小字 / 风味文本（留空 = 生成器默认那句）
```

- 留空：仍然输出原来的：
  ```text
  由 Sts2CharForge 生成的自定义遗物。
  ```
- 填了：用你写的文本；
- 支持 `{能量图标}`（和自定义描述同一套占位符处理）；
- 支持换行。

生成结果写进：

```text
localization/zhs/relics.json
```

的：

```json
"<遗物>.flavor": "你写的文本"
```

## 从工程恢复

生成代码里会多一行：

```csharp
// CET:RelicFlavor=你写的文本
```

从工程恢复时会把自定义底部小字读回来，不会因为重新生成变回默认。
