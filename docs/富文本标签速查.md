# 富文本标签速查（自定义描述里能改的颜色 / 特效）

> 一份**独立速查表**，只讲「自定义描述里能打什么」。不改任何代码、不影响其它文件。
>
> 适用位置（所有走本地化表的文本都通用）：卡牌的「自定义描述 / 升级后的自定义描述」、
> 遗物 / 药水 / 自定义状态 / 自定义关键词的说明、角色描述、死亡文本、多人催促文本、
> 额外资源量的名字等。
>
> 这些标签是**本体自带**的（`src/Core/RichTextTags/RichText*.cs`，颜色值在 `src/Core/Helpers/StsColors.cs`），
> 生成器那边认的白名单在 `src/Sts2CharForge.Core/Generation/RichTextFix.cs`。

---

## 1. 颜色（8 个，本体自带）

写法一律是 `[标签]文字[/标签]`，**成对**。

| 标签 | 颜色 | 色值 | 备注 |
|---|---|---|---|
| `[gold]…[/gold]` | 金 | `#EFC851` | 本体最常用：关键词 / 强调（「[gold]消耗[/gold]」） |
| `[blue]…[/blue]` | 浅蓝 | `#87CEEB` | 本体用于「冰 / 冷静」一类提示 |
| `[red]…[/red]` | 红 | `#FF5555` | 危险 / 警告（「[red]辉星[/red]不够」） |
| `[green]…[/green]` | 亮绿 | `#7FFF00` | 增益 / 正数提示 |
| `[purple]…[/purple]` | 紫 | `#EE82EE` | 稀有 / 神秘 |
| `[orange]…[/orange]` | 橙 | `#FFA518` | 提醒 |
| `[pink]…[/pink]` | 粉 | `#FF78A0` | 点缀 |
| `[aqua]…[/aqua]` | 青 | `#2AEBBE` | 本体用于先古台词里的词 |

例：

```
造成 [orange]8[/orange] 点伤害，并[gold]消耗[/gold]这张牌。
每当你在你的回合失去生命时，获得[green]1[/green]点力量。
```

---

## 2. 特效（7 个，本体自带，同样成对）

| 标签 | 效果 | 示例 |
|---|---|---|
| `[sine]…[/sine]` | 文字上下波浪起伏 | `[sine]诡计[/sine]` |
| `[jitter]…[/jitter]` | 抖动（像在发抖） | `[jitter]它会动的[/jitter]` |
| `[scramble]…[/scramble]` | 乱码字符逐渐还原成正文 | `[scramble]未知的语言[/scramble]` |
| `[thinky_dots]…[/thinky_dots]` | 省略号跳动（本体先古对话用） | `[thinky_dots]我明白了……[/thinky_dots]` |
| `[fly_in]…[/fly_in]` | 入场飞入 | `[fly_in]登场[/fly_in]` |
| `[fade_in]…[/fade_in]` | 淡入 | `[fade_in]渐渐显现[/fade_in]` |
| `[ancient_banner]…[/ancient_banner]` | 先古卡那种横幅观感 | `[ancient_banner]先古[/ancient_banner]` |

⚠ 特效是**动画**，会一直播（`[sine]` / `[jitter]` 适合短词，整段都套会晃得看不清）。

## 3. 任意颜色（Godot 原生标签）

```
[color=#4FC3F7]文字[/color]
```

- 值可以是 `#RGB` / `#RRGGBB` / `#RRGGBBAA`；
- 工具**认得并原样保留**；不过**本体自己没这么用过**，实机若显示不对就退回上面 8 个颜色；
- 白名单外的标签（例如 `[bgcolor=…]`）工具会给一条警告说「不是游戏认识的标签」。

配合本体的色值可以直接写：

| 想要 | 等价写法 |
|---|---|
| 金 | `[color=#EFC851]…[/color]` |
| 红 | `[color=#FF5555]…[/color]` |
| 蓝 | `[color=#87CEEB]…[/color]` |
| 绿 | `[color=#7FFF00]…[/color]` |
| 紫 | `[color=#EE82EE]…[/color]` |
| 橙 | `[color=#FFA518]…[/color]` |
| 粉 | `[color=#FF78A0]…[/color]` |
| 青 | `[color=#2AEBBE]…[/color]` |

| 标签 | 作用 |

| `[u]…[/u]` | 下划线 |

## 5. 两个特殊写法

| 想要的 | 怎么写 |
|---|---|
| 显示**方括号本身** | `[lb]` = `[`，`[rb]` = `]`（不要直接打 `[` `]`） |
| 换行 | 写 `\n`（也认 `[br]`） |

例：`伤害 [lb]2[rb] 倍` → 卡面显示「伤害 [2] 倍」。

---

## 6. 规则与坑（很重要）

1. **必须成对**：`[gold]文字` 少写 `[/gold]` → 生成时会自动在结尾补上，并给一条警告；
2. **不能交叉嵌套**：`[gold][blue]x[/gold][/blue]` → 生成时会被理顺（内容不变），并给警告；
3. **拼错会被自动纠正**：只差一个字母的标签（`[god]` / `[goldd]`）会被改成最接近的那个
   （`[gold]`），并在校验 / 生成日志里报「已改成 …」；
4. **不认识的标签不会生效**：`[foo]` 这种游戏里会把方括号**原样印出来**（看到方括号就是没生效）；
5. **数字别手写死**：用占位符（如 `{Damage:diff()}`），升级后会自动变成新数字；
   见「自定义描述」下面那行「填入参数…」/ 高亮字段；
6. **别写竖线 `|`**：这张牌的升级前 / 升级后描述不一样时，生成端会用 `{IfUpgraded:show:A|B}`
   这种写法，描述里自己写 `|` 会把那句截断（生成端会换成全角 `｜` 并提醒）。

---

## 7. 一段可以直接抄的示例

```
造成 [orange]{Damage:diff()}[/orange] 点伤害。
[gold]斩杀[/gold]时：如果你没有[gold]格挡[/gold]，改为造成 [blue]双倍[/blue] 伤害。
```

想要"会动"的词，把某一个词单独套：

```
[sine][purple]回响[/purple][/sine]
```

> 提醒：同一段里特效不要叠太多层，卡面字号是自动算的，整段抖动 / 波浪会很难看清。
