# 本回合失去过生命值（条件插件）

条件 Id：`HpLostThisTurn`

## 行为

- 本回合**自己**的生命值真的少过 → 成立；
- 敌人掉血不算；
- 包含「受到伤害」和「失去生命」（中毒 / 血祭那种穿盾掉血）——判据是
  `DamageReceivedEntry.Result.UnblockedDamage > 0`，只统计真正掉到血上的部分；
- 全被格挡 / 0 伤害的那一下不算。

## 用在哪些地方

- 卡牌页 → 效果 → 条件选项；
- 遗物页 → 条件选项；
- 自定义状态 → 触发时机下面的条件；
- 锻造页 → 【条件】模块的下拉。

## 注意

它读的是本体的战斗历史 `DamageReceivedEntry`，所以：

- 本场战斗还没开始 / 不在战斗里时永远不成立；
- 这张牌自己即将造成的掉血不会提前算进条件（看的是「打出之前」已经发生过的事）。

不需要时把整个 `plugins\本回合失去过生命值` 文件夹删掉即可，编辑器会恢复成没有这条条件。
